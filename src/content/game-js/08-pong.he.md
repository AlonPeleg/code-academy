פונג, מ-1972, הוא סבא של משחקי הווידאו: שני מחבטים, כדור וניקוד. הוא נראה פשוט מדי בשביל להיות מעניין, אבל הוא מכיל כמעט כל מה שלמדתם עד כה: תנועה עם `dt`, הגבלת טווח (clamping), התנגשות וניקוד. והוא מוסיף שלושה רעיונות חדשים: **מהירות כוונית** (velocity), **קפיצות** ו**בינה מלאכותית** קטנה מאוד.

## מהירות כוונית

עד עכשיו הזזנו דברים עם `speed` אחד. כדור נע בשני כיוונים בו-זמנית, ולכן יש לו מהירות לכל ציר, שנקראת ה-**velocity** שלו:

```js
let ball = { x: 160, y: 120, vx: 200, vy: 140 };
// each frame:
ball.x += ball.vx * dt;
ball.y += ball.vy * dt;
```

`vx` (פיקסלים לשנייה ימינה) ו-`vy` (פיקסלים לשנייה למטה) קובעים יחד את הזווית. עם `vx = 200` ו-`vy = 140` הכדור עף ימינה ולמטה. מספר **שלילי** פירושו הכיוון ההפוך.

## קפיצה היא היפוך סימן

כשהכדור פוגע בקיר אופקי (למעלה או למטה), הוא ממשיך הצידה אבל מסתובב אנכית. במספרים: `vy` הופך ל-`-vy`.

```js
if (ball.y < 4) {          // the ball has a radius of 4
  ball.y = 4;              // put it back on the edge
  ball.vy = -ball.vy;      // and turn around
}
```

השורה `ball.y = 4` חשובה: היא מחזירה את הכדור פנימה, כך שהוא לא נשאר בקיר עוד פריים וקופץ פעמיים. הקיר התחתון: אותו דבר עם `game.HEIGHT - 4`.

פגיעה במחבט היא אותו רעיון לציר השני: `vx = -vx`. מכיוון שהמחבטים הם מלבנים, אנחנו משתמשים בפונקציה `touching` מהשיעור על התנגשות, ומתייחסים לכדור כאל ריבוע של 8 על 8 שמתחיל ב-`(ball.x - 4, ball.y - 4)`.

```js
if (ball.vx < 0 && touching(ball.x - 4, ball.y - 4, 8, 8, 10, leftY, PW, PH)) {
  ball.vx = -ball.vx;
}
```

`ball.vx < 0` אומר "הכדור נע שמאלה". בלי הבדיקה הזאת, הכדור עדיין יכול לחפוף למחבט פריים אחד אחר כך, להתהפך **שוב** ולהיתקע בתוך המחבט, רועד קדימה ואחורה. בדיקת הכיוון קודם מבטיחה שהוא מתהפך פעם אחת.

## בינה מלאכותית קטנה

המחבט הימני משחק לבד. לא צריך שום דבר מתוחכם: המחשב פשוט מסתכל איפה הכדור וזז לכיוונו.

```js
if (rightY + PH / 2 < ball.y - 5) {
  rightY += 120 * dt;          // the paddle's middle is above the ball: go down
} else if (rightY + PH / 2 > ball.y + 5) {
  rightY -= 120 * dt;          // the paddle's middle is below the ball: go up
}
```

`rightY + PH / 2` הוא אמצע המחבט. השוליים של 5 פיקסלים מונעים מהמחבט לרעוד כשהוא כבר מיושר. והמחשב נע במהירות מוגבלת (120), ולכן אפשר לנצח אותו עם זריקה חדה. מעצבי משחקים קוראים לזה **כיוונון** (tuning): משנים את המספר והיריב נהיה קל או קשה יותר. ל-AI שאף פעם לא מפסיד לא כיף לשחק נגדו.

## ניקוד

אם הכדור יוצא מהצד השמאלי של המסך, המחשב קולע. אם הוא יוצא מהימני, אתם קולעים. בשני המקרים הכדור מתחיל מחדש מהאמצע, לכיוון השחקן שהפסיד את הנקודה, בעזרת הפונקציה העוזרת `resetBall(direction)` (‏`-1` פירושו שמאלה, ‏`1` פירושו ימינה).

## משחקים ובודקים

נסו את זה בלייב: W ו-S מזיזים את המחבט שלכם (המחבטים מוגבלים לתוך המסך). כדי לבדוק את הקוד, הבדיקה מחזיקה את S כך שהמחבט השמאלי יושב בתחתית, נותנת למשחק לרוץ כמה שניות ואז מצפה שהמחשב החזיר את הכדור לפחות פעמיים, קלע כשהכדור עבר אתכם, ושהכדור עדיין בתוך המסך.

> **שימו לב:** אם הכדור נעלם דרך הקצה העליון, שכחתם את קפיצת הקיר או שהשוואתם לערך הלא נכון. הדפיסו את `ball.y` עם `console.log`.
>
> **שימו לב:** כדור שרועד בתוך המחבט לא בדק את הכיוון (`ball.vx > 0` או `< 0`) לפני ההיפוך.
>
> **שימו לב:** `rightY` הוא **החלק העליון** של המחבט. כדי לכוון את האמצע אל הכדור צריך `rightY + PH / 2`.
>
> **שימו לב:** `ball.vx = -ball.vx` הוא היפוך. כתיבת `ball.vx = -200` במקום זה תמיד שולחת את הכדור שמאלה, גם אם הוא כבר הולך שמאלה.

## להמשיך הלאה

הפכו את הכדור למהיר מעט יותר בכל פגיעה במחבט, תנו לשחקן מחבט שני במקלדת (חיצי למעלה ולמטה), או תנו לזווית הקפיצה להיות תלויה במקום שבו הכדור פוגע במחבט.

> **תורכם:** השלימו את ארבעת השלבים הממוספרים: הזיזו את מחבט המחשב לעבר הכדור, קפצו מהקצה העליון והתחתון, קפצו משני המחבטים (תוך ספירת `hits`), וטפלו בניקוד עם `resetBall`.
