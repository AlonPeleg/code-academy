הגיע הזמן שהדברים ייראו טוב. המנוע יכול לצייר ארבעה סוגים של דברים: מלבנים, עיגולים, קווים וטקסט. רק איתם, בתוספת צבעים וקצת דמיון, אפשר לצייר כמעט כל משחק: חללית היא כמה מלבנים, מטבע הוא עיגול, לייזר הוא קו, והניקוד הוא טקסט.

## ארגז כלי הציור

```js
game.rect(x, y, width, height, color);     // x, y = top-left corner
game.circle(x, y, radius, color);          // x, y = CENTER
game.line(x1, y1, x2, y2, color, width);   // from point 1 to point 2
game.text(x, y, message, color, size);     // x, y = top-left of the text
```

דוגמאות:

```js
game.rect(10, 10, 100, 20, game.RED);              // a red bar
game.circle(160, 120, 30, game.CYAN);              // a ball in the middle
game.line(0, 0, 320, 240, game.WHITE, 3);          // a thick diagonal
game.text(10, 10, 'Score: ' + 5, game.WHITE, 16);  // text with a number inside
```

אפשר להשמיט את הארגומנט האחרון של `line` (עובי) ושל `text` (גודל). אפשר לבנות טקסט מחלקים באמצעות `+`: הביטוי `'Score: ' + score` הופך את המספר לטקסט ומדביק את החלקים יחד.

## סדר הציור

המסך מצויר לפי **סדר הקוד**, כמו צבע על קיר. צורה שמצוירת מאוחר יותר מכסה צורה שצוירה קודם. לכן השמיים באים לפני השמש, והשמש לפני הדשא שעשוי להסתיר את החצי התחתון שלה. אם משהו בלתי נראה, בדקו אם צורה אחרת מצוירת מעליו.

## צבעים הם מערכים

צבע במנוע הזה הוא **מערך** (array) של שלושה מספרים, `[red, green, blue]`, כל אחד מ-0 (כלום) עד 255 (מלא). חלקם מובנים: `game.RED`, `game.ORANGE`, `game.YELLOW`, `game.GREEN`, `game.CYAN`, `game.BLUE`, `game.PURPLE`, `game.PINK`, `game.WHITE`, `game.GRAY`, `game.DARK` ו-`game.BLACK`. אפשר גם לערבב צבעים משלכם:

```js
const BROWN = [120, 72, 36];
const SKY = [100, 180, 255];    // a pale blue
```

הערבוב עובד כמו אור: `[255, 255, 0]` (אדום + ירוק) הוא צהוב, `[0, 0, 0]` הוא שחור ו-`[255, 255, 255]` הוא לבן. צבעים שבהם אותו מספר חוזר שלוש פעמים הם גוונים של אפור.

מערך הוא רשימה שנכתבת בין סוגריים מרובעים ומופרדת בפסיקים, וקוראים פריט בודד לפי מיקומו, החל מאפס: `BROWN[0]` הוא `120`.

## פונקציית ציור משלכם

כשרוצים עץ פעמיים, אפשר להעתיק ולהדביק את קוד הציור. רעיון טוב יותר הוא לשים אותו ב**פונקציה עם פרמטרים** (parameters):

```js
function drawTree(x, y) {
  game.rect(x, y, 10, 30, BROWN);
  game.circle(x + 5, y - 5, 20, game.GREEN);
}

drawTree(60, 150);     // a tree here
drawTree(250, 160);    // and another one there
```

`x` ו-`y` הם מקומות שמורים שמתמלאים בכל פעם שקוראים לפונקציה. שימו לב שהעלים ממוקמים *ביחס* לגזע (`x + 5`, `y - 5`), כך שכל העץ זז כיחידה אחת. פונקציות ציור הן הסוד למשחקים מסודרים: `drawPlayer`, `drawEnemy`, `drawHud`...

## תנועה בסצנה

כל דבר שיש לו משתנה למיקום שלו יכול לנוע: `game.circle(sunX, 40, 18, game.YELLOW)` מצייר את השמש ב-`sunX`, ו-`sunX += 40 * dt` ב-`update` גורם לה לגלוש ימינה.

> **שימו לב:** `TypeError: A color must be three numbers like [255, 0, 0]` פירושו שהעברתם משהו אחר, כמו המילה `'red'` או מערך עם שני מספרים בלבד.
>
> **שימו לב:** `TypeError: width must be a number, but got undefined` פירושו שאחד הערכים שלכם לא הוגדר מעולם. בדקו את האיות של המשתנה.
>
> **שימו לב:** ציור הרקע אחרי הצורות האחרות מכסה אותן. קודם הרקע, ובסוף החזית.
>
> **שימו לב:** עיגול ממוקם לפי **המרכז** שלו, ומלבן לפי **הפינה** שלו. אם עיגול וריבוע לא מתיישרים, זו הסיבה.

> **תורכם:** בחרו צבע `SKY` משלכם, כתבו את `drawTree(x, y)` (גזע חום עם `game.rect` ועלים ירוקים עם `game.circle`), הזיזו את השמש עם `sunX += 40 * dt`, וסיימו את `draw` בקו אופק לבן עם `game.line` ובכותרת עם `game.text`.
