סנייק הוא הצעד הבא המושלם: משחק שאינו חלק בכלל. הנחש קופץ מריבוע לריבוע ברשת, כמה פעמים בשנייה, בזמן שהשאר של התוכנית (מקלדת, ציור) עדיין רץ 60 פעמים בשנייה. בשביל זה צריך טכניקה חדשה אחת, **צובר טיימר** (timer accumulator), והסתכלות טובה על איך **מערך יכול לייצג גוף**.

## רשת מעל הפיקסלים

במקום מיקומי פיקסלים, הנחש חי על **רשת** (grid) של תאים. כל תא הוא `CELL = 16` פיקסלים, ולכן במסך של 320 על 240 יש 20 עמודות ו-15 שורות. מיקום הוא מספר תא כמו `{ x: 5, y: 7 }`. כדי לצייר אותו, ממירים לפיקסלים בהכפלה:

```js
game.rect(cell.x * CELL, cell.y * CELL, CELL, CELL, game.GREEN);
```

עבודה בתאים הופכת התנגשויות לטריוויאליות: שני דברים נמצאים באותו מקום בדיוק כששני המספרים שווים (`a.x === b.x && a.y === b.y`). אין צורך בחשבון חפיפה.

## צובר הטיימר

איך עושים משהו כל 0.185 שניות כש-`update` רצה כל 0.0167 שניות? אוספים זמן במשתנה:

```js
timer += dt;                 // add the time of this frame
if (timer >= STEP) {         // enough time has gathered for one move
  timer -= STEP;             // spend it
  step();                    // and move the snake once
}
```

ברוב הפריימים לא קורה כלום. בערך כל פריים 11 הטיימר חוצה את `STEP`, והנחש זז. אנחנו מפחיתים `STEP` ולא מאפסים, כך שנשארת שארית קטנה והמהירות לטווח ארוך נשארת מדויקת גם אם פריים היה ארוך מעט מדי. הטריק הזה משמש לכל דבר שקורה במרווחים קבועים: הופעת אויבים, אנימציות, אפילו סימולציות פיזיקה.

## הנחש הוא מערך

הנחש הוא מערך (array) של תאים, **הראש ראשון**:

```js
let snake = [{ x: 5, y: 7 }, { x: 4, y: 7 }, { x: 3, y: 7 }];
```

איך מזיזים גוף כזה? לא מזיזים כל חלק. במקום זה:

1. יוצרים **ראש חדש** תא אחד קדימה: `{ x: snake[0].x + dir.x, y: snake[0].y + dir.y }`.
2. מוסיפים אותו לתחילה: `snake.unshift(head)`. (`unshift` שם פריט ב**תחילת** מערך, ו-`push` שם אחד בסופו.)
3. מסירים את החלק האחרון: `snake.pop()` (‏`pop` מסירה ומחזירה את הפריט **האחרון**).

הגוף מתקדם בתא אחד והאורך נשאר זהה. כדי **לגדול**, מדלגים פעם אחת על שלב 3: הנחש עכשיו ארוך באחד. זה כל מה שיש בגדילה!

## כיוון

`dir` מחזיק את התנועה לכל צעד: `{ x: 1, y: 0 }` הוא ימינה, ‏`{ x: 0, y: -1 }` הוא למעלה. קראו את המקשים עם `keyPressed`, כי הקשה מהירה בין שני צעדים לא יכולה ללכת לאיבוד. ולעולם אל תאפשרו פנייה ישר אחורה: אם הנחש נע אופקית (`dir.y === 0`), למעלה ולמטה מותרים; אם הוא נע אנכית (`dir.x === 0`), רק שמאלה וימינה.

## התרסקות

המשחק נגמר כשהראש החדש מחוץ לרשת, או בתא ששייך לנחש. `snake.some(p => p.x === head.x && p.y === head.y)` היא `true` אם חלק כלשהו תואם לראש. (`some` היא מתודה של מערך ששואלת "האם לפחות פריט אחד עובר את הבדיקה הזאת?".) בדקו את זה **לפני** שאתם מוסיפים את הראש, והשתמשו ב-`return` כדי לצאת מהפונקציה מוקדם.

> **שימו לב:** אם הנחש דוהר מיד, הזזתם אותו ב-`update` בכל פריים במקום להשתמש בטיימר.
>
> **שימו לב:** `snake.pop()` בלי תנאי גורמת לנחש לא לגדול אף פעם, ושכחת `pop` גורמת לו לגדול לנצח. בכל צעד קורה בדיוק אחד מבין "אכל" או "pop".
>
> **שימו לב:** ערבוב פיקסלים ותאים. המיקומים ב-`snake` הם תאים; מכפילים ב-`CELL` רק בציור.
>
> **שימו לב:** שימוש ב-`keyDown` לפנייה יכול לפספס הקשה מהירה שנופלת בין שני צעדים, או לפנות פעמיים. `keyPressed` נכונה.

## להמשיך הלאה

גרמו לנחש להאיץ מעט בכל פעם שהוא אוכל (`STEP -= 0.005`, אבל קודם הפכו אותו ל-`let`), ציירו את הראש בצבע אחר, או מקמו אוכל בתאים ריקים אקראיים.

> **תורכם:** ממשו את חמשת השלבים: פנייה עם `keyPressed` (בלי היפוך לאחור), צובר הטיימר ב-`update`, וב-`step()` הראש החדש, בדיקת ההתרסקות (קירות והנחש עצמו), ‏`unshift` לראש ו-`pop` לזנב אלא אם האוכל נאכל.
