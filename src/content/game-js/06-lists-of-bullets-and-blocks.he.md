כדור אחד קל: כמה משתנים. אבל משחק יריות יורה עשרות כדורים, ואי אפשר ליצור ביד משתנה `bullet37` בזמן שהמשחק רץ. התשובה היא **מערך** (array): רשימה שיכולה להכיל כל מספר של דברים, ולגדול ולהתכווץ בזמן שהמשחק רץ. מערכים הם מבנה הנתונים שמאחורי כדורים, אויבים, חלקיקים, מטבעות וכמעט כל דבר אחר שבא בכמויות.

## אובייקטים ומערכים

קודם כל, משהו שמתאר כדור. ב-JavaScript אפשר לקבץ ערכים ל**אובייקט** (object), שנכתב עם סוגריים מסולסלים:

```js
let player = { x: 150, y: 200 };
player.x += 5;          // read and change a property with a dot
```

גם כדור הוא אובייקט: `{ x: 158, y: 200, alive: true }`. המילה שלפני הנקודתיים היא **שם התכונה** (property).

מערך מחזיק הרבה מהם בין סוגריים מרובעים:

```js
let bullets = [];                         // empty list
bullets.push({ x: 10, y: 20, alive: true });   // add one at the end
bullets.length;                           // how many are in the list: 1
bullets[0].y;                             // the first one's y (counting starts at 0): 20
```

## מעבר על מערך בלולאה

כדי לעשות משהו לכל פריט, משתמשים ב-`for ... of`:

```js
for (const b of bullets) {
  b.y -= 300 * dt;      // move every bullet up
}
```

בכל סיבוב, `b` הוא הכדור הבא. מכיוון ש-`b` הוא בדיוק אותו אובייקט שנמצא במערך, שינוי של `b.y` משנה את הכדור ברשימה. (ה-`const` אומר רק ש-`b` עצמו לא מקבל כדור אחר; התכונות עדיין יכולות להשתנות.)

## הסרת דברים עם filter

דברים צריכים להיעלם: כדור שיצא מהמסך, בלוק שנפגע. אחרת המערך גדל בלי סוף והמשחק מאט. הטריק הוא `filter`, שבונה מערך **חדש** עם הפריטים שעוברים בדיקה בלבד:

```js
bullets = bullets.filter(b => b.alive && b.y > -10);
```

החלק `b => b.alive && b.y > -10` הוא **פונקציית חץ** (arrow function): פונקציה זעירה בלי שם שמקבלת את `b` ומחזירה `true` (לשמור) או `false` (לזרוק). מציבים את התוצאה בחזרה במשתנה; בגלל זה `bullets` מוגדר עם `let` ולא עם `const`.

אל תסירו פריטים ממערך בזמן מעבר עליו עם `for...of`: זה מדלג על פריטים. במקום זה סמנו אותם (`alive = false`) במהלך הלולאה וסננו אחר כך, וזו התבנית בשיעור הזה.

## ירי עם קירור

אם יורים כש-`space` לחוץ, אז 60 פריימים בשנייה פירושם 60 כדורים בשנייה. **טיימר קירור** (cooldown) פותר את זה. זה מספר שניות שסופר לאחור; יורים רק כשהוא הגיע לאפס, ואז מגדירים אותו שוב:

```js
cooldown -= dt;
if (game.keyDown('space') && cooldown <= 0) {
  bullets.push({ x: player.x + 8, y: player.y, alive: true });
  cooldown = 0.26;     // wait about a quarter of a second
}
```

טיימרים כאלה נמצאים בכל מקום במשחקים: זמני טעינה, אל-פגיעות אחרי מכה, טיימרים של הופעת אויבים. `player.x + 8` שם את הכדור באמצע ספינה ברוחב 20 פיקסלים.

## כדורים פוגשים בלוקים

לכל כדור, בדקו כל בלוק עם הפונקציה `touching` מהשיעור הקודם, לולאה בתוך לולאה. כשהם נפגשים, סמנו את שניהם כלא חיים ותנו נקודה. ניקוי עם `filter` אחרי הלולאה מסיר אותם.

> **שימו לב:** `TypeError: Cannot read properties of undefined (reading 'y')` נובעת לעיתים קרובות מקריאת `bullets[5]` כשבמערך יש פחות פריטים. עברו בלולאה עם `for...of` במקום מספרים קבועים.
>
> **שימו לב:** `TypeError: Assignment to constant variable` מופיעה אם מגדירים `const bullets = []` ואחר כך כותבים `bullets = bullets.filter(...)`. השתמשו ב-`let`.
>
> **שימו לב:** `bullets.filter(...)` לבדה בשורה לא עושה כלום, כי filter מחזירה מערך חדש. חייבים להציב אותו.
>
> **שימו לב:** אם שוכחים להסיר כדורים שמחוץ למסך שום דבר לא יקרוס, אבל המערך גדל וכל פריים נעשה איטי יותר ויותר.

> **תורכם:** השלימו את ארבעת השלבים הממוספרים ב-`update`: ירו עם קירור באמצעות `bullets.push`, הזיזו את הכדורים, סמנו כדורים ובלוקים שנוגעים זה בזה כלא חיים (והוסיפו ל-`score`), ונקו את שני המערכים עם `filter`.
