משחקים מתעוררים לחיים כשדברים **נוגעים** זה בזה: הגיבור תופס מטבע, כדור פוגע באויב, כדור קופץ מקיר. הבדיקה "האם שני הדברים האלה חופפים?" נקראת **זיהוי התנגשות** (collision detection). תכתבו אותה פעם אחת כפונקציה (function) ותשתמשו בה כדי לאסוף מטבעות ולשמור ניקוד.

## חפיפה, ציר אחד בכל פעם

דמיינו שני קטעים על ציר מספרים. קטע A משתרע מ-`ax` עד `ax + aw`, וקטע B מ-`bx` עד `bx + bw`. הם חופפים כש-A מתחיל **לפני ש-B נגמר** וגם A נגמר **אחרי ש-B מתחיל**:

```js
ax < bx + bw && ax + aw > bx
```

`&&` פירושו "וגם": שני הצדדים חייבים להיות נכונים. שני מלבנים חופפים כשזה נכון בציר x **וגם** בציר y. חיבור ארבעת התנאים נותן את בדיקת ההתנגשות המלאה, שעוטפים בפונקציה כדי שאפשר יהיה להשתמש בה בכל מקום:

```js
function touching(ax, ay, aw, ah, bx, by, bw, bh) {
  return ax < bx + bw && ax + aw > bx && ay < by + bh && ay + ah > by;
}
```

פונקציה יכולה להחזיר (`return`) תוצאה. כאן התוצאה היא `true` או `false`, ולכן אפשר לכתוב `if (touching(...)) { ... }` ישירות. בדקו ידנית עם `touching(0, 0, 10, 10, 5, 5, 10, 10)`: הריבועים חולקים את השטח מ-5 עד 10, ולכן התשובה היא `true`. עבור `touching(0, 0, 10, 10, 20, 20, 5, 5)` הריבוע השני רחוק: `false`. אנחנו משתמשים ב-`<` וב-`>` ולא ב-`<=`, כך שריבועים שרק חולקים צלע אינם נוגעים.

## מטבע אחד שקופץ

במקום ליצור מטבע חדש בכל פעם, שומרים **מטבע אחד** ומעבירים אותו למקום הבא כשהוא נאסף. המקומות נמצאים ב**מערך של מערכים** (array of arrays):

```js
const coinSpots = [[150, 100], [150, 30], [40, 30]];
let coinIndex = 0;
const coin = coinSpots[coinIndex];   // [150, 100]
coin[0];                              // 150 (the x)
coin[1];                              // 100 (the y)
```

`coinSpots[0]` הוא המערך הפנימי הראשון. מיקום `0` במערך הזה הוא `x`, ומיקום `1` הוא `y`. מיקומים במערך מתחילים באפס.

כשהשחקן נוגע במטבע:

```js
score += 1;
coinIndex = (coinIndex + 1) % coinSpots.length;
```

`coinSpots.length` הוא `3`. **אופרטור השארית** `%` נותן את מה שנשאר אחרי חילוק: `(0 + 1) % 3` הוא `1`, ‏`(1 + 1) % 3` הוא `2`, ו-`(2 + 1) % 3` הוא `0`. האינדקס מתקדם לאורך הרשימה ומתחיל מחדש מההתחלה, ואף פעם לא נופלים מסוף המערך.

## למה רשימה קבועה?

רשימה של מקומות קבועים הופכת את המשחק לצפוי, כך שהבודק שלנו יכול להוביל את השחקן לאורך מסלול מוכר ולדעת בדיוק כמה מטבעות הוא חייב לאסוף. כשהמשחק שלכם עובד, החליפו אותה במיקומים אקראיים: `Math.random()` נותנת מספר מ-0 עד ממש מתחת ל-1, ולכן `Math.random() * 300` הוא x אקראי.

## קריאת מצב המשחק בבדיקה

הבודק קורא את המשתנה `score` שלכם אחרי ההליכה המתוסרטת, וגם קורא ל-`touching` עם כמה מלבנים משלו כדי לוודא שהפונקציה נכונה ולא רק במקרה מתאימה להליכה הזאת.

> **שימו לב:** אם הניקוד מזנק בעשרות בתוך שנייה, המטבע לא התרחק אחרי שנגעו בו, ולכן הוא נספר בכל פריים.
>
> **שימו לב:** `TypeError: Cannot read properties of undefined (reading '0')` אומר ש-`coinIndex` עבר את סוף המערך. השתמשו ב-`% coinSpots.length`.
>
> **שימו לב:** `ax + aw` הוא **הקצה הימני**, לא רוחב. אם ההתנגשויות מרגישות לא נכונות, ציירו את שני המלבנים על נייר עם הקצוות שלהם.
>
> **שימו לב:** `&` או `|` יחידים הם אופרטור אחר. השתמשו ב-`&&` וב-`||` בתנאים.

## להמשיך הלאה

ציירו את המטבע כעיגול, הוסיפו טיימר, או גרמו לשחקן לגדול בכל פעם שנאסף מטבע.

> **תורכם:** השלימו את `touching` כך שתחזיר `true` רק כששני המלבנים חופפים. אחר כך, כשהשחקן נוגע במטבע, הוסיפו 1 ל-`score` והעבירו את `coinIndex` למקום הבא, עם מעבר מעגלי בעזרת `%`.
