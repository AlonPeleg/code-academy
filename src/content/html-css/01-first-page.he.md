כל דף אינטרנט שביקרתם בו אי פעם בנוי מ-**HTML**. בשיעור הזה תלמדו איך כותבים HTML ותבנו דף קטן משלכם.

## תגיות אומרות לדפדפן מה הדברים

HTML בנויה מ*תגיות* (tags). תגית היא מילה עטופה בסוגריים משולשים, כמו `<p>`. רוב התגיות באות בזוגות: **תגית פתיחה** ו**תגית סגירה** שיש לפני שמה סימן `/`. הטקסט שביניהן הוא ה**תוכן**.

```html
<h1>Hello!</h1>
<p>This is a paragraph.</p>
```

יחד, תגית הפתיחה, התוכן ותגית הסגירה נקראים **אלמנט** (element). כאן יש לנו שני אלמנטים: כותרת ופסקה.

- `<h1>` היא הכותרת הראשית של הדף. יש גם `<h2>` עד `<h6>`, כל אחת קצת קטנה וחשובה פחות.
- `<p>` היא פסקת טקסט. הדפדפן מוסיף עבורכם מעט רווח מעליה ומתחתיה.

## השלד של דף

לכל דף HTML יש אותה צורה בסיסית:

```html
<!doctype html>
<html>
  <head>
    <title>My page</title>
  </head>
  <body>
    <h1>Welcome</h1>
  </body>
</html>
```

- `<!doctype html>` אומרת לדפדפן "זה דף HTML מודרני".
- `<html>` עוטפת הכול.
- `<head>` מכילה מידע *על* הדף (כמו הכותרת שלו בלשונית הדפדפן). אף אחד לא רואה אותה בתוך הדף עצמו.
- `<body>` מכילה כל מה שהמבקר **יכול** לראות. כאן תעשו את רוב העבודה.

## קינון והזחה

אלמנטים יכולים להיות בתוך אלמנטים אחרים. זה נקרא **קינון** (nesting). בשלד שלמעלה, `<h1>` מקונן בתוך `<body>`, שמקונן בתוך `<html>`. אנחנו מזיחים אלמנטים מקוננים בשני רווחים כדי שהדף יהיה קל לקריאה. לדפדפן לא אכפת מהרווחים, אבל לכם כן.

## הערות

אפשר להשאיר לעצמכם פתקים שהדפדפן מתעלם מהם:

```html
<!-- This is a comment. Nobody sees it on the page. -->
```

## מה תראו

התצוגה המקדימה מימין מתעדכנת בזמן ההקלדה. אם תכתבו `<h1>Hello!</h1>` תראו טקסט גדול ומודגש. אם תכתבו `<p>` עם טקסט, תראו טקסט בגודל רגיל מתחתיו.

> **שימו לב:**
> - שוכחים את תגית הסגירה, כמו ב-`<h1>Hello` בלי `</h1>`. הדפדפן מנחש למה התכוונתם, ושאר הדף עלול פתאום להיראות גדול ומודגש. ב-HTML אין הודעת שגיאה, ולכן בדקו את התגיות בזוגות.
> - מקלידים את הקו הנטוי בכיוון הלא נכון, כמו `<\h1>`. קו הסגירה נוטה קדימה: `</h1>`.
> - כותבים את התוכן מחוץ ל-`<body>`. הדפדפן אולי עדיין יציג אותו, אבל זה מבולגן ועלול להישבר בהמשך כשתוסיפו סגנונות.
> - משתמשים ב-`<h1>` רק כדי להגדיל טקסט. כותרות נועדו למשמעות (כותרות ראשיות). בהמשך תגדילו טקסט עם CSS.

## להמשך

נסו להוסיף כותרות `<h2>` ו-`<h3>` מתחת ל-`<h1>` וראו איך הגדלים יורדים בהדרגה. הוסיפו `<p>` שני. שימו לב שכל פסקה מתחילה בשורה חדשה גם אם כתבתם אותן זו לצד זו בקוד.

> **תורכם:** בתוך `<body>` הוסיפו כותרת `<h1>` ופסקת `<p>` עם כל טקסט שתרצו, ואז לחצו על **Check answer**.
