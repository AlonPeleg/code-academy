שני דברים שתשתמשו בהם כמעט בכל דף הם **רשימות** ו**קישורים**. רשימות מארגנות מידע, וקישורים הם מה שהופך את הרשת (web) לרשת.

## רשימות

**רשימה לא ממוספרת** מציגה תבליטים. היא משתמשת בתגית `<ul>`, וכל פריט בתוכה עטוף ב-`<li>` (פריט ברשימה).

```html
<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Cherries</li>
</ul>
```

זה מציג:

- Apples
- Bananas
- Cherries

אם הסדר חשוב (כמו שלבים במתכון) משתמשים ב**רשימה ממוספרת**, `<ol>`. הפריטים עדיין `<li>`, אבל הדפדפן ממספר אותם 1, 2, 3 במקומכם:

```html
<ol>
  <li>Boil water</li>
  <li>Add pasta</li>
  <li>Wait ten minutes</li>
</ol>
```

שימו לב ש-`<li>` מופיע תמיד רק בתוך `<ul>` או `<ol>`. הרשימה היא המכל והפריטים חיים בתוכה.

## קישורים

קישור הוא תגית `<a>`. האות "a" מייצגת *anchor* (עוגן). לקישור יש שני חלקים חשובים:

```html
<a href="https://example.com">Visit Example</a>
```

- `href="https://example.com"` היא **תכונה** (attribute). תכונות נכתבות בתוך תגית הפתיחה ונראות כמו `name="value"`. התכונה `href` מכילה את הכתובת שאליה הקישור מוביל.
- `Visit Example` הוא **טקסט הקישור**: המילים שהמבקר רואה ולוחץ עליהן.

קישורים יכולים להוביל גם לדפים אחרים באתר שלכם בעזרת כתובת יחסית, כמו `<a href="about.html">About me</a>`.

כברירת מחדל קישור נפתח באותה לשונית. כדי לפתוח אותו בלשונית חדשה מוסיפים `target="_blank"`:

```html
<a href="https://example.com" target="_blank">Open in a new tab</a>
```

## מחברים הכול יחד

אפשר לשים קישורים בתוך פריטי רשימה כדי לבנות תפריט:

```html
<ul>
  <li><a href="index.html">Home</a></li>
  <li><a href="about.html">About</a></li>
</ul>
```

> **שימו לב:**
> - שוכחים את המרכאות סביב ערך התכונה, כמו ב-`<a href=https://example.com>`. תמיד עטפו ערכים במרכאות.
> - כותבים כתובת של אתר חיצוני בלי `https://`, כמו `href="example.com"`. הדפדפן חושב שזה קובץ בשם `example.com` באתר שלכם, והקישור נשבר.
> - שמים פריטי `<li>` ישירות בגוף הדף בלי `<ul>` או `<ol>`. זו לא רשימה תקינה, ולא יופיעו תבליטים.
> - כותבים `Click here` כטקסט קישור. עדיף לתאר לאן הקישור מוביל, כמו `Read the MDN guide`.

## להמשך

שנו את ה-`<ul>` ל-`<ol>` וראו איך התבליטים הופכים למספרים. הוסיפו קישור שני בתוך `<li>`.

> **תורכם:** הוסיפו רשימה עם שלושה פריטי `<li>`, וקישור אל `https://developer.mozilla.org`.
