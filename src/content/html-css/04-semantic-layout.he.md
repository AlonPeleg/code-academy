עד עכשיו כל מה שכתבנו היה כותרת, פסקה או רשימה. לדפים אמיתיים יש *חלקים*: באנר עליון, תפריט, התוכן הראשי ורצועה תחתונה. בשיעור הזה תלמדו את תגיות ה-HTML שנותנות שם לחלקים האלה.

## הבעיה עם div

התגית `<div>` היא קופסה כללית. היא לא אומרת כלום. דף שבנוי רק מ-div-ים הוא כמו בית שבו כל חדר מסומן רק "חדר". זה עובד, אבל אף אחד (כולל מנוע חיפוש או אדם שמשתמש בקורא מסך) לא יכול לדעת למה משמש כל חלק.

תגיות **סמנטיות** הן תגיות עם משמעות. כברירת מחדל הן נראות בדיוק כמו `<div>`, אבל הן אומרות מה התוכן *הוא*.

## התגיות הסמנטיות השימושיות ביותר

| תגית | למה היא משמשת |
| --- | --- |
| `<header>` | ההקדמה בראש הדף: שם האתר, לוגו, ואולי התפריט |
| `<nav>` | קבוצת קישורי ניווט |
| `<main>` | התוכן המרכזי והייחודי של הדף (השתמשו רק באחת) |
| `<section>` | חלק נושאי בתוכן, בדרך כלל עם כותרת משלו |
| `<article>` | יחידה עצמאית, כמו פוסט בבלוג |
| `<aside>` | תוכן צדדי, כמו תיבת טיפ |
| `<footer>` | החלק התחתון: זכויות יוצרים, פרטי קשר, קישורים קטנים |

הנה מבנה טיפוסי:

```html
<body>
  <header>
    <h1>My Blog</h1>
    <nav>
      <a href="/">Home</a>
      <a href="/about">About</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>My first post</h2>
      <p>Hello, world!</p>
    </article>
  </main>

  <footer>
    <p>Copyright 2025</p>
  </footer>
</body>
```

שימו לב ש-`<nav>` נמצאת בתוך `<header>`. אפשר לקנן תגיות סמנטיות, בדיוק כמו כל תגית אחרת.

## למה זה חשוב

- **נגישות:** קוראי מסך מאפשרים למשתמשים לקפוץ ישר אל `<main>` או אל `<nav>`.
- **מנועי חיפוש:** הם מבינים את הדף שלכם טוב יותר.
- **קריאות:** כשאתם קוראים `<footer>` אתם יודעים על מה אתם מסתכלים, ואילו עשר תגיות `<div>` מקוננות לא אומרות לכם כלום.
- **עיצוב:** בהמשך תוכלו לכתוב CSS כמו `header { ... }` בלי להמציא שמות של classes.

## מתי div עדיין מתאים

השתמשו ב-`<div>` כשאתם צריכים רק קופסה כדי לקבץ דברים לצורכי פריסה או עיצוב, ואין תגית סמנטית שמתאימה. לשתיהן יש מקום.

> **שימו לב:**
> - תגיות שלא תואמות: פותחים ב-`<header>` וסוגרים ב-`</div>`. הדפדפן מנחש בשקט והפריסה עלולה להישבר. תמיד שנו את תגית הפתיחה ואת תגית הסגירה יחד.
> - שימוש בכמה אלמנטי `<main>`. בדף צריך להיות רק אחד.
> - שימוש ב-`<h1>` יותר מפעם אחת. בדרך כלל בדף יש `<h1>` אחד, ואחריו `<h2>` לחלקים.
> - בחירת תגית לפי המראה שלה. `<header>` אינו "הטקסט הגדול": בחרו לפי משמעות והשתמשו ב-CSS למראה.

## להמשך

הוסיפו פסקה שנייה בתוך `<main>` ועטפו את שתי הפסקאות ב-`<section>`. נסו להוסיף `<aside>` עם טיפ קטן אחרי ה-`<section>`.

> **תורכם:** שנו את תגיות ה-`<div>` הפשוטות ל-`<header>`, `<nav>`, `<main>` ו-`<footer>`, ושמרו על התוכן שבתוך כל אחת.
