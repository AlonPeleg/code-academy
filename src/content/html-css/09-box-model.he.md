הנה הסוד שמאחורי כל פריסה באינטרנט: **כל אלמנט הוא קופסה מלבנית**. ברגע שמבינים את הקופסה, בעיות מרווחים נעשות קלות לתיקון.

## ארבע השכבות

מבפנים החוצה, בכל קופסה יש:

1. **תוכן** (content) - הטקסט או התמונה עצמם.
2. **ריפוד** (padding) - מרחב נשימה בין התוכן למסגרת.
3. **מסגרת** (border) - קו סביב הריפוד.
4. **שוליים** (margin) - מרווח מחוץ למסגרת, שדוחף קופסאות אחרות הלאה.

```css
.card {
  padding: 20px;
  border: 2px solid black;
  margin: 16px;
}
```

תמונה עוזרת: דמיינו תמונה ממוסגרת שתלויה על קיר. התצלום הוא התוכן, הכרטיס הלבן סביבו הוא הריפוד, המסגרת היא ה-border, והרווח בין המסגרת למסגרת הבאה הוא ה-margin.

## Padding

ה-padding נמצא *בתוך* הקופסה, ולכן צבע הרקע של הקופסה ממלא אותו. השתמשו בו כדי שהטקסט לא ייגע בקצה.

- `padding: 20px;` קובע את כל ארבעת הצדדים.
- `padding: 10px 20px;` הוא 10px למעלה ולמטה, 20px לימין ולשמאל.
- `padding: 5px 10px 15px 20px;` הולך בכיוון השעון: למעלה, ימין, למטה, שמאל.
- `padding-left: 8px;` קובע צד אחד בלבד. אותו דבר עובד עם `margin-top`, `margin-bottom` וכן הלאה.

## Border

הקיצור `border` מקבל שלושה חלקים בכל סדר: **עובי, סגנון, צבע**.

```css
border: 2px solid black;
border: 1px dashed gray;
border-radius: 8px; /* rounded corners */
```

בלי סגנון כמו `solid`, לא נצייר מסגרת, גם אם קבעתם עובי וצבע.

## Margin

ה-margin נמצא *מחוץ* למסגרת והוא תמיד שקוף. הוא מרחיק קופסאות זו מזו. טריק נחמד: קופסה עם `width` קבוע ו-`margin: 0 auto;` ממורכזת אופקית.

שוליים אנכיים של בלוקים שכנים **מתמזגים**: אם לקופסה אחת יש `margin-bottom: 20px` ולקופסה שמתחתיה `margin-top: 30px`, הרווח הוא 30px ולא 50px.

## מה רוחב הקופסה?

כברירת מחדל, `width` קובע רק את רוחב התוכן, וה-padding וה-border מתווספים מעליו. קופסה עם `width: 200px` ו-`padding: 20px` מגיעה לרוחב של 240px. מפתחים רבים מוסיפים את השורה הזאת כדי שהגדלים יפתיעו פחות:

```css
* {
  box-sizing: border-box;
}
```

עם `border-box`, הרוחב כולל את ה-padding ואת ה-border.

> **שימו לב:**
> - `border: 2px black;` לא מציג מסגרת כי הסגנון (`solid`) חסר.
> - משתמשים ב-`margin` כשרוצים `padding` (ולהפך). אם רוצים שהרקע יגדל, השתמשו ב-padding. אם רוצים לדחוף קופסאות זו מזו, השתמשו ב-margin.
> - רווחים במקום הלא נכון: `padding: 20 px;` אינו תקין. כתבו `20px`.
> - שוכחים שאלמנטים בשורה (inline) כמו `<span>` מתעלמים משוליים אנכיים. השתמשו ב-`<div>` או ב-`display: inline-block`.

## להמשך

השתמשו בכלי המפתחים של הדפדפן (קליק ימני, Inspect) בכל אתר כדי לראות את תרשים מודל הקופסה של כל אלמנט. נסו `border-radius: 50%` על קופסה מרובעת.

> **תורכם:** תנו ל-`.card` את `padding: 20px`, מסגרת `2px solid` ו-`margin: 16px`.
