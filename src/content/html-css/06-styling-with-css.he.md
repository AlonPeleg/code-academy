HTML נותנת לדף את המבנה שלו; **CSS** (Cascading Style Sheets, גיליונות סגנון מדורגים) נותנת לו את המראה. בשיעור הזה תלמדו איך בנוי כלל CSS ותשנו את הצבע והגודל של טקסט.

## האנטומיה של כלל

```css
h1 {
  color: tomato;
}
```

- **סלקטור** (selector, `h1`): על אילו אלמנטים הכלל חל. כאן, על כל `<h1>` בדף.
- **בלוק הצהרות** (ה-`{ ... }`): מכיל הצהרה אחת או יותר.
- **מאפיין** (property, `color`): מה רוצים לשנות.
- **ערך** (value, `tomato`): למה רוצים לשנות.
- **נקודתיים** מפרידות בין המאפיין לערך, ו**נקודה-פסיק** מסיימת כל הצהרה.

בכלל אחד יכולות להיות הרבה הצהרות:

```css
p {
  color: darkslategray;
  font-size: 18px;
  font-family: Georgia, serif;
}
```

## חיבור CSS ל-HTML

הדרך הקלה ביותר היא קובץ נפרד, שמקשרים אליו ב-`<head>` של ה-HTML:

```html
<link rel="stylesheet" href="style.css" />
```

`rel="stylesheet"` אומר "זה גיליון סגנון", ו-`href` אומר איפה הקובץ. בעורך הזה עוברים בין `index.html` ל-`style.css` בעזרת הלשוניות שמעל הקוד.

אפשר גם לכתוב CSS ישירות בתוך תגית `<style>` ב-head, אבל קבצים נפרדים שומרים על סדר ומאפשרים לדפים רבים לחלוק אותו סט סגנונות.

## כתיבת צבעים

CSS מבינה צבעים בכמה דרכים:

- **שמות:** `red`, `tomato`, `skyblue`, `darkgreen`, ועוד כ-140.
- **קודי hex:** `#ff6347` (אדום, ירוק וכחול בבסיס 16). צורה קצרה: `#f00`.
- **rgb():** `rgb(255, 99, 71)`, כל מספר בין 0 ל-255.

`color` משנה את צבע הטקסט. `background-color` משנה את הרקע.

## כתיבת גדלים

`font-size: 20px;` פירושו 20 פיקסלים. פיקסלים (`px`) הם גודל קבוע. תפגשו גם את `em` ו-`rem`, שהם יחסיים לגדלי גופן אחרים; `1rem` הוא בדרך כלל 16px.

## הערות

```css
/* This is a CSS comment. The browser ignores it. */
```

שימו לב שהערות CSS משתמשות ב-`/* ... */` ולא ב-`<!-- -->` של HTML.

> **שימו לב:**
> - נקודה-פסיק חסרה. אם כותבים `color: red` ובשורה חדשה `font-size: 20px;` הדפדפן לא יודע איפה הראשונה נגמרת ומתעלם משתיהן. אין הודעת שגיאה, פשוט העיצוב לא מופיע.
> - סוגר מסולסל סוגר `}` חסר. כל מה שאחריו עלול להפסיק לעבוד.
> - כתיבת `colour` באיות הבריטי. CSS מכירה רק את `color`.
> - שוכחים את היחידה, כמו ב-`font-size: 20;`. תמיד כתבו `20px`.
> - שגיאת כתיב בשם הקובץ בתוך `href`. אם גיליון הסגנון לא נמצא, שום דבר לא מעוצב.

## להמשך

נסו `background-color: lightyellow;` על `p`, `text-align: center;` על `h1`, וראו איך הדף מגיב בכל פעם שאתם מקלידים.

> **תורכם:** ב-`style.css` תנו ל-`h1` צבע שאינו שחור, וקבעו את גודל הגופן של `p` ל-`20px`.
