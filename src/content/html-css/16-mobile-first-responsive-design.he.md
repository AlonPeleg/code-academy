יותר ממחצית הביקורים באינטרנט מתרחשים בטלפונים, והעמוד שלכם ייפתח גם בטאבלטים, במחשבים ניידים ובמסכי ענק. **עיצוב רספונסיבי** (responsive design) פירושו עמוד אחד שמתאים את עצמו לכולם. בשיעור הזה תלמדו את הדרך של נייד קודם לעשות את זה, והיא פשוטה יותר ממה שנשמע.

## חושבים קטן קודם

**Mobile-first** פירושו שכותבים את הפריסה למסך הצר ביותר בתור ה-CSS הרגיל שלכם, ואז מוסיפים תוספות ככל שהמסך מתרחב. פריסת טלפון היא לרוב הפשוטה ביותר (הכול בעמודה אחת), ולכן ה-CSS הבסיסי שלכם נשאר קצר, וטלפונים לא צריכים להוריד כללים שלעולם לא ישתמשו בהם.

קודם כל, ל-HTML צריכה שורה אחת ב-`<head>`:

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

בלעדיה, טלפונים מעמידים פנים שהם מסך שולחני רחב (בערך 980px) ומקטינים הכול. איתה, העמוד משתמש ברוחב האמיתי של המכשיר, ולכן ה-media queries שלכם אומרים מה שאתם חושבים שהם אומרים.

## Media queries עם min-width

**נקודת שבירה** (breakpoint) היא רוחב מסך שבו הפריסה משתנה. קובעים אותה עם `min-width`, שפירושו "ברוחב הזה או רחב יותר":

```css
.nav {
  display: flex;
  flex-direction: column;   /* phone: stacked links */
}

@media (min-width: 600px) {
  .nav {
    flex-direction: row;    /* 600px and up: one row */
  }
}
```

מכיוון שהכלל הרחב מופיע מאוחר יותר וחל רק על מסכים גדולים יותר, הוא דורס את הבסיס. בחרו נקודות שבירה במקום שבו *התוכן שלכם* מתחיל להיראות רע (נסו 600px ו-900px), לא לפי דגמי טלפון מסוימים. תמיד שימו media queries אחרי הכללים שהם משנים.

## גדלים גמישים במקום קבועים

הרבה בעיות נעלמות אם הגדלים מתכופפים במקום להישבר:

```css
.page {
  max-width: 960px;   /* a ceiling, not a fixed width */
  margin: 0 auto;     /* centre it when the screen is wider */
}

h1 {
  font-size: clamp(1.5rem, 4vw, 2.5rem);
}
```

- `width: 960px` קבוע מכריח גלילה לצדדים בטלפון. `max-width` נותן לתיבה להתכווץ.
- אחוזים (`width: 50%`) הם יחסיים להורה. `vw` הוא 1% מרוחב המסך.
- `clamp(min, preferred, max)` בוחרת את הערך המועדף אבל אף פעם לא יורדת מתחת למינימום או עולה מעל למקסימום. כאן הכותרת גדלה עם המסך בין 1.5rem ל-2.5rem.

## תמונות שמתכווצות

תמונה שומרת על הגודל שלה, שיכול להיות רחב יותר מטלפון. זוג השורות הזה הוא סטנדרטי כמעט בכל גיליון סגנונות:

```css
img {
  max-width: 100%;  /* never wider than the parent */
  height: auto;     /* keep the proportions */
}
```

## רשת שמתאימה את עצמה

אפשר לכתוב שלושה media queries עבור עמודת כרטיסים אחת, שתיים ושלוש. Grid יכול לעשות את זה בלי אף אחד:

```css
.grid {
  display: grid;
  gap: 16px;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
}
```

קראו את זה כך: "צרו כמה שיותר עמודות שנכנסות, כל אחת ברוחב של לפחות 220px, וחלקו את המקום שנשאר שווה בשווה (`1fr`)". בטלפון מקבלים עמודה אחת, בטאבלט שתיים, במחשב נייד שלוש. השתמשו ב-**media queries** כש*מבנה* הפריסה משתנה (ניווט הופך לשורה, סרגל צד מופיע) וב-**auto-fit** כשיש סתם ערימה של כרטיסים שווים.

## בדיקה

גררו את קצה חלונית התצוגה המקדימה לרוחב צר יותר ורחב יותר וראו את העמוד מגיב. בדפדפן אמיתי, פתחו את DevTools והשתמשו בסרגל המכשירים. בודק השיעור לא יכול לשנות את גודל התצוגה המקדימה, ולכן הוא קורא בקוד שלכם את תג ה-viewport, את `clamp()`, את `auto-fit` ואת ה-media query של `min-width`.

> **שימו לב:**
> - שוכחים את תג ה-viewport meta. אז נדמה ש-media queries "לא עובדים" בטלפון אמיתי, כי הוא מדווח על רוחב של בערך 980px.
> - ערבוב סגנונות: media query של `max-width` מעל אחד של `min-width` מקשה לראות איזה כלל מנצח. בחרו כיוון אחד (min-width) והישארו איתו.
> - כותבים `@media (min-width: 600)` בלי `px`, או שוכחים את הסוגר הסוגר. ה-query מתעלם בשקט.
> - נותנים לתמונה `max-width: 100%` וגם `height` קבוע. אז היא נמעכת. השתמשו ב-`height: auto`.
> - משתמשים ב-`minmax(300px, 1fr)` במיכל צר מ-300px, מה שגורם לגלילה לצדדים. שמרו על מינימום קטן או עטפו אותו כ-`min(300px, 100%)`.

## להמשך

הוסיפו נקודת שבירה שנייה ב-`900px` שמשנה את ה-padding של `.page` מ-`16px` ל-`32px`. החליפו את `220px` ב-`min(220px, 100%)` כדי לראות את הגרסה הבטוחה יותר של הרשת.

> **תורכם:** ב-`index.html` הוסיפו את תג ה-viewport meta. ב-`style.css` תנו ל-`h1` גודל גופן עם `clamp()`, הוסיפו כלל `img` עם `max-width: 100%` ו-`height: auto`, הפכו את `.grid` לרשת עם רווח של `16px` ועמודות `repeat(auto-fit, minmax(220px, 1fr))`, והוסיפו query של `@media (min-width: 600px)` שקובע ל-`.nav` את `flex-direction: row`.
