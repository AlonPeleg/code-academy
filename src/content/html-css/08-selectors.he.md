עד עכשיו עיצבתם כל `<h1>` או כל `<p>`. לדפים אמיתיים צריך יותר שליטה: "רק הפסקה הזאת", "כל האזהרות", "קישורים אבל רק בתפריט". **סלקטורים** (selectors) הם הדרך לכוון את העיצוב.

## סלקטורים של סוג תגית

הסלקטור הפשוט ביותר הוא שם של תגית. `p { ... }` מעצב כל פסקה.

## Classes

**class** הוא תווית שמוסיפים לאלמנטים ב-HTML:

```html
<p class="note">Water the roses.</p>
<p class="note urgent">Buy soil today!</p>
```

ב-CSS בוחרים class עם **נקודה**:

```css
.note {
  background-color: #fff3bf;
}
```

- הרבה אלמנטים יכולים לחלוק class אחד, וה-class יכול להופיע בכל תגית.
- לאלמנט יכולים להיות **כמה** classes, מופרדים ברווחים. לפסקה השנייה למעלה יש שניים: `note` ו-`urgent`. היא מקבלת את הסגנונות משניהם.

## Ids

**id** הוא שם ייחודי לאלמנט אחד:

```html
<h1 id="title">Garden notes</h1>
```

ב-CSS בוחרים אותו עם **סולמית**:

```css
#title {
  color: darkgreen;
}
```

אפשר להשתמש ב-id רק פעם אחת בכל דף. לעיצוב בדרך כלל עדיף class, וה-ids טובים לקישורים כמו `href="#title"` ול-JavaScript.

## סלקטורים של צאצאים

רווח בין שני סלקטורים פירושו "השני, איפשהו בתוך הראשון":

```css
.tools li {
  font-weight: bold;
}
```

זה מעצב אלמנטי `<li>` בתוך `.tools` אבל לא פריטי רשימה במקום אחר. סלקטור עם `>` כמו `ul > li` פירושו רק *ילדים ישירים*.

## כמה סלקטורים, כלל אחד

מפרידים בפסיקים כדי לחלוק כלל:

```css
h1, h2, h3 {
  font-family: Georgia, serif;
}
```

## איזה כלל מנצח?

כששני כללים סותרים, הספציפי יותר מנצח: **id** מנצח **class**, ו-class מנצח **תגית**. אם הם ספציפיים באותה מידה, זה שנכתב *אחרון* מנצח. זה ה"מדורג" (cascading) ב-CSS.

```css
p { color: black; }
.urgent { color: red; }  /* this wins on <p class="urgent"> */
```

> **שימו לב:**
> - כותבים `note { ... }` במקום `.note { ... }`. בלי הנקודה הדפדפן מחפש תגית `<note>`.
> - כותבים `.#title` או `#.title`. class משתמש ב-`.`, id משתמש ב-`#`, ובוחרים אחד מהם.
> - חסר הרווח ב-`.toolsli`. זה נקרא כשם class אחד שלא קיים.
> - שמים רווח אחרי הנקודה, כמו `. note`. זה שובר את הסלקטור.
> - מעצבים כל `p` כשרצו רק חלק מהם. הוסיפו class במקום.

## להמשך

הוסיפו `p.note { font-style: italic; }` (פסקה שיש לה גם את ה-class) ו-`.note.urgent { ... }` (שני ה-classes בבת אחת). שימו לב אילו אלמנטים משתנים.

> **תורכם:** כתבו ארבעה כללים ב-`style.css`: `#title` בירוק כהה, `.note` עם רקע צהוב בהיר `#fff3bf`, `.urgent` עם טקסט אדום, ואלמנטי `li` מודגשים בתוך `.tools`.
