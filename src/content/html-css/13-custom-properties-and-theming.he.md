פתחו כל גיליון סגנונות גדול ותמצאו את אותו סגול כתוב חמישים פעם. תשנו את דעתכם לגבי הסגול ותצטרכו לצוד את כל החמישים. **CSS custom properties** (שקוראים להם לעתים קרובות משתני CSS) פותרים את זה: כותבים ערך פעם אחת, נותנים לו שם ומשתמשים בו בכל מקום. כבונוס הם הופכים ערכות נושא, כמו מצב כהה (dark mode), לכמעט חינמיות.

## הצהרה ושימוש במשתנה

custom property הוא כל מאפיין ששמו מתחיל ב**שני מקפים**. מצהירים עליו בתוך כלל, וקוראים אותו עם הפונקציה `var()`:

```css
:root {
  --brand: #6d5efc;
  --radius: 8px;
}

.btn {
  background: var(--brand);
  border-radius: var(--radius);
}
```

חלק אחרי חלק:

- `:root` הוא סלקטור שמתאים לאלמנט העליון של העמוד (התג `html`). שימת משתנים כאן הופכת אותם לזמינים לכל המסמך.
- `--brand: #6d5efc;` שומר ערך. השם תלוי בכם, אבל הוא רגיש לאותיות גדולות וקטנות: `--Brand` ו-`--brand` הם משתנים שונים.
- `var(--brand)` מוחלף בערך השמור במקום שבו משתמשים בו.

בניגוד למשתנים ב-Sass או בכלים אחרים, אלה חיים בדפדפן, ולכן הם יכולים להשתנות בזמן שהעמוד רץ.

## משתנים עוברים בירושה

custom properties **עוברים בירושה** ו**פועלים בקסקדה** בדיוק כמו `color`. אם אלמנט קובע `--bg`, הוא וכל הילדים שלו רואים את הערך הזה. זה הטריק שמאחורי ערכות נושא:

```css
:root { --bg: #ffffff; --text: #1f2937; }
.dark { --bg: #111827; --text: #f9fafb; }

.card { background: var(--bg); color: var(--text); }
```

הכלל `.card` אף פעם לא משתנה. כשכרטיס נמצא בתוך אלמנט `.dark` (או שהוא עצמו כזה), המשתנים מקבלים ערכים אחרים, ולכן אותו כלל מפיק מראה אחר. אתרים אמיתיים מחליפים מאפיין `data-theme="dark"` על האלמנט `html`, או משתמשים בהגדרת המערכת:

```css
@media (prefers-color-scheme: dark) {
  :root { --bg: #111827; --text: #f9fafb; }
}
```

## ערכי גיבוי (Fallback)

`var()` מקבלת ארגומנט שני, שמשמש כשהמשתנה חסר:

```css
.tag { padding: var(--tag-padding, 4px 8px); }
```

זה נותן לרכיב לעבוד מהקופסה ועדיין להיות ניתן להתאמה על ידי מי שמשתמש בו: קבעו `--tag-padding` על הורה והוא ישתנה.

## שינוי משתנים עם JavaScript

מכיוון שהמשתנים חיים, סקריפט יכול לעדכן אותם והעמוד כולו מגיב:

```js
document.documentElement.style.setProperty("--brand", "tomato");
```

## משתנים ו-calc()

משתנים מחזיקים כל ערך, כולל מספרים עם יחידות, ומשתלבים יפה עם `calc()`:

```css
:root { --space: 8px; }
.box { padding: calc(var(--space) * 2); }
```

> **שימו לב:**
> - כותבים `var(brand)` או `var(-brand)`. השם חייב לכלול את שני המקפים: `var(--brand)`.
> - משתמשים בשם משתנה במקום של מאפיין בלי `var()`, כמו `background: --brand;`. זה לא תקין ומתעלמים מזה.
> - מצפים ש-`--space: 8` יעבוד ב-`padding: var(--space)px`. אי אפשר להדביק יחידות אחר כך. שמרו את היחידה (`8px`) או השתמשו ב-`calc(var(--space) * 1px)`.
> - מצהירים על משתנה על `.card` ומשתמשים בו מחוץ ל-`.card`. משתנים זורמים רק כלפי מטה לצאצאים, ולכן הצהירו על המשותפים על `:root`.
> - שגיאת כתיב בשם לא נותנת שגיאה. המאפיין פשוט הופך לבלתי תקין והדפדפן חוזר לברירת המחדל שלו, ולכן בדקו את האלמנט ב-DevTools אם חסר צבע.

## להמשך

הוסיפו כרטיס שלישי עם המחלקה `.ocean` שקובעת `--brand: #0ea5e9`, וראו את הכפתור משנה צבע בלי לגעת ב-`.btn`.

> **תורכם:** ב-`style.css`, הצהירו על `--bg`, על `--text` ועל `--brand` על `:root`, השתמשו בהם עם `var()` ב-`.card` וב-`.btn`, ואז הוסיפו כלל `.dark` שמצהיר מחדש על `--bg` בתור `#111827` ועל `--text` בתור `#f9fafb`.
