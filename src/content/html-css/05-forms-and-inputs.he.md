טפסים הם הדרך שבה אתרים מקשיבים: הרשמות, תיבות חיפוש, תגובות, קופות תשלום. בשיעור הזה תבנו טופס הרשמה קטן עם התגיות הנכונות, כך שיעבוד לכולם, כולל אנשים שמשתמשים בקוראי מסך.

## התגית form

הכול נמצא בתוך אלמנט `<form>`. כשהמבקר לוחץ על כפתור השליחה, הדפדפן אוסף את הערכים של כל השדות שבתוכו. (שליחה שלהם לשרת היא נושא להמשך; כרגע אנחנו בונים את צד הלקוח.)

```html
<form>
  ...fields go here...
</form>
```

## label ועוד input

רוב השדות הם **label** (תווית) ו-**input** (שדה קלט):

```html
<label for="username">Username</label>
<input type="text" id="username" name="username" />
```

- `<label>` הוא השם הנראה של השדה. התכונה `for` שלו מכילה את ה-`id` של שדה הקלט שאליו הוא שייך. בזכות הקישור הזה, לחיצה על התווית מעבירה את הסמן לשדה, וקוראי מסך מכריזים על שם השדה.
- `<input>` הוא אלמנט ריק (בלי תגית סגירה), כמו `<img>`. התכונה `type` שלו קובעת איזה סוג שדה הוא.
- `id` הוא שם ייחודי לאלמנט אחד בדף. רק לאלמנט אחד מותר לקבל id מסוים.
- `name` הוא השם שבו הטופס משתמש כששולח את הערך. תמיד תנו לשדות הקלט שלכם `name`.

## סוגים שונים של שדות קלט

| `type` | מה מקבלים |
| --- | --- |
| `text` | תיבת טקסט של שורה אחת |
| `email` | כמו טקסט, אבל הדפדפן בודק שיש `@` ומציג בטלפונים מקלדת מותאמת לאימייל |
| `password` | נקודות במקום אותיות |
| `number` | מספרים בלבד, עם חצים למעלה ולמטה |
| `checkbox` | תיבת סימון |
| `date` | בורר תאריכים |

תוספות שימושיות: `placeholder="..."` מציג טקסט רמז אפור בתוך התיבה, ו-`required` מונע שליחת הטופס כל עוד השדה ריק.

## טקסט מרובה שורות וכפתורים

להודעה ארוכה משתמשים ב-`<textarea>`. בניגוד ל-`<input>`, יש לה תגית סגירה:

```html
<textarea name="message" rows="4"></textarea>
```

כפתור ששולח את הטופס:

```html
<button type="submit">Join</button>
```

## רשימות נפתחות (בונוס)

```html
<select name="level">
  <option>Beginner</option>
  <option>Expert</option>
</select>
```

> **שימו לב:**
> - `for` שלא תואם אף `id`. אז התווית לא עושה כלום. בדקו היטב את האיות: `for="email"` צריך `id="email"`.
> - שימוש באותו `id` פעמיים בדף. ערכי id חייבים להיות ייחודיים.
> - שימוש ב-`placeholder` במקום תווית. טקסט ה-placeholder נעלם כשמקלידים, וקוראי מסך עשויים להתעלם ממנו. השתמשו בתווית אמיתית.
> - הצבת תוכן בתוך `<input>` כמו `<input>Name</input>`. שדות קלט הם אלמנטים ריקים; השם הנראה שייך ל-`<label>`.
> - כפתור מחוץ ל-`<form>`. הוא לא ישלח את הטופס.

## להמשך

הוסיפו את התכונה `required` לשדה האימייל שלכם ואת התכונה `placeholder="you@example.com"`. נסו את הסוג `number` בשדה חדש וראו איך הוא מסרב לאותיות.

> **תורכם:** בתוך הטופס הוסיפו שדה טקסט `username` ושדה `email` (כל אחד עם תווית מתאימה), `textarea`, וכפתור שליחה שאומר `Join`.
