עמוד טוב מגיב. הוא נותן משוב כשמצביעים על כפתור, והוא מסדר את עצמו מחדש כשפותחים אותו בטלפון. השיעור הזה מראה לכם את שני הדברים עם כמה שורות CSS.

## מחלקות מדומות (Pseudo-classes): עיצוב של מצב

**מחלקה מדומה** (pseudo-class) היא מילת מפתח שמוסיפים לסלקטור עם נקודתיים. היא מכוונת לאלמנט רק ב*מצב* מסוים. הפופולרית ביותר היא `:hover`, שפעילה כל עוד מצביע העכבר נמצא מעל האלמנט:

```css
.btn:hover {
  background: #4c3fd1;
}
```

אחרות שתפגשו: `:focus` (שדה שלחצתם בתוכו), `:active` (בזמן לחיצה) ו-`:first-child`.

שימו לב שאין רווח ב-`.btn:hover`. זה אומר "`.btn` שמרחפים מעליו".

## מעברים (Transitions): שינויים חלקים

כברירת מחדל שינוי ב-hover קורה מיד. **מעבר** (transition) הופך אותו לאנימציה. שמים אותו על המצב *הרגיל* של האלמנט:

```css
.btn {
  background: #6d5efc;
  transition: background-color 0.3s;
}
```

לקיצור יש עד שלושה חלקים:

- המאפיין שמנפישים (`background-color`, או `all` לכל דבר),
- משך הזמן (`0.3s`, שהם 300 אלפיות שנייה),
- אופציונלית, פונקציית תזמון כמו `ease-in-out`.

אפקטי hover טובים נוספים: `transform: translateY(-2px);` כדי להרים כפתור, `transform: scale(1.05);` כדי להגדיל אותו מעט, ו-`box-shadow` לעומק.

## עיצוב רספונסיבי

העמוד שלכם נצפה בטלפונים, בטאבלטים, במחשבים ניידים ובמסכים גדולים. **עיצוב רספונסיבי** (responsive design) פירושו שהוא מתאים את עצמו. שני כלים עושים את רוב העבודה:

1. תג ה-viewport ב-`<head>`. בלעדיו, טלפונים מעמידים פנים שהם רחבים ומכווצים הכול:

   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1" />
   ```

2. **Media queries**, שמפעילים CSS רק כשתנאי מתקיים:

   ```css
   @media (max-width: 600px) {
     .menu {
       flex-direction: column;
     }
   }
   ```

   זה נקרא: "במסכים ברוחב 600px או צרים יותר, הפכו את התפריט לעמודה".

שימו לב שה-media query עוטף כללים רגילים בסוגריים מסולסלים נוספים. הכלל שבפנים מנצח רק כשהמסך קטן, כי הוא מופיע מאוחר יותר ומחליף את ה-`flex-direction` הקודם (שהוא `row` כברירת מחדל).

גישה נפוצה היא **mobile first**: כותבים את פריסת הטלפון בתור הבסיס ומשתמשים ב-`@media (min-width: 600px) { ... }` כדי להוסיף את הפריסה הרחבה.

## בודקים

גררו את חלונית התצוגה המקדימה לרוחב צר יותר (או השתמשו בסרגל המכשירים של הדפדפן) וראו את התפריט מסתדר בערימה. בדיקת השיעור לא יכולה לשנות את גודל החלון, ולכן היא בודקת בקוד שלכם את כלל ה-hover ואת ה-media query.

> **שימו לב:**
> - שמים `transition` רק על `:hover`. אז האנימציה עובדת בכניסה אבל קופצת חזרה כשהעכבר עוזב. שימו אותו על המצב הרגיל.
> - רווח לפני הנקודתיים, כמו `.btn :hover`. זה אומר "אלמנט שמרחפים מעליו בתוך .btn".
> - שוכחים את הסוגר המסולסל הסוגר של בלוק ה-`@media`. צריך אחד לכלל ואחד ל-media query.
> - כותבים את כלל ה-`@media` *לפני* הכלל הרגיל. הכלל המאוחר מנצח כששניהם חלים, ולכן שימו media queries בסוף גיליון הסגנונות.
> - `max-width: 600` בלי `px`.
> - שימוש ב-hover בתור הדרך היחידה להגיע למשהו. למסכי מגע אין hover.

## להמשך

הוסיפו `transform: translateY(-2px);` ל-`.btn:hover` ואת `transform` לרשימת המעברים: `transition: background-color 0.3s, transform 0.3s;`. נסו media query שני ב-`max-width: 400px` שמקטין את ה-padding.

> **תורכם:** הוסיפו ל-`.btn` מעבר של background-color למשך `0.3s`, כלל `.btn:hover` עם הרקע `#4c3fd1`, ו-media query של `max-width: 600px` שקובע `flex-direction: column` על `.menu`.
