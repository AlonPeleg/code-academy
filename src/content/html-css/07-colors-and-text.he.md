רוב האינטרנט הוא טקסט, ולכן כמה מאפייני CSS לוקחים אתכם רחוק מאוד. בשיעור הזה תפגשו את אלה שתשתמשו בהם כל הזמן: גופנים, צבעים, יישור, הדגשה ומרווחים.

## גופנים

`font-family` בוחר את סוג האות (typeface). מכיוון שאי אפשר להיות בטוחים שלכל מבקר יש את הגופן שבחרתם, נותנים **רשימה**, מהגופן המועדף ועד לגיבוי:

```css
body {
  font-family: Georgia, serif;
}
```

השם האחרון הוא **משפחה כללית** (generic family) שקיימת תמיד: `serif` (אותיות עם רגליים קטנות), `sans-serif` (אותיות נקיות), או `monospace` (קוד). אם בשם של גופן יש רווחים, שמים אותו במרכאות, כמו `"Times New Roman"`.

מאפיינים שקובעים על `body` **עוברים בירושה**: כותרות ופסקאות שבתוכו משתמשות באותו גופן אלא אם דורסים אותו. לכן קובעים את הגופן פעם אחת על `body`.

## צבע

`color` הוא צבע הטקסט. כבר ראיתם שמות כמו `tomato`. קודי hex נותנים מיליוני גוונים מדויקים:

```css
h1 {
  color: #1e90ff; /* a bright blue */
}
```

קוד hex הוא `#` ואחריו שלושה זוגות: אדום, ירוק, כחול. `#1e90ff` הוא אדום 30, ירוק 144, כחול 255. הכלים של הדפדפן מדווחים על אותו צבע בדיוק כ-`rgb(30, 144, 255)`.

## יישור ואותיות רישיות

- `text-align` מקבל `left`, `center`, `right` ו-`justify`.
- `text-transform` משנה אותיות גדולות בלי להקליד מחדש: `uppercase`, `lowercase` או `capitalize`.

## הדגשה

- `font-weight: bold;` (או מספר כמו `700`) הופך את הטקסט לכבד יותר.
- `font-style: italic;` מטה אותו.
- `text-decoration` מוסיף `underline` או מסיר אותו (`none`), וכך מסירים את הקו התחתון מקישורים.

## מרווחים בטקסט

- `line-height` הוא המרחק משורה אחת לשורה הבאה. ערך נוח הוא פי 1.5 עד 1.8 מגודל הגופן. אפשר לכתוב מספר פשוט כמו `1.6` או אורך כמו `28px`.
- `letter-spacing: 2px;` מוסיף רווח בין אותיות, נחמד לכותרות קטנות באותיות גדולות.

```css
p {
  line-height: 28px;
  letter-spacing: 0.5px;
}
```

## שימוש ב-class

בקוד ההתחלה, לפסקה אחת יש `class="lead"`. **מחלקה** (class) מאפשרת לעצב אלמנטים מסוימים ולא אחרים. ב-CSS בוחרים class עם נקודה: `.lead { ... }`. תלמדו על זה עוד בשיעור על סלקטורים.

> **שימו לב:**
> - `font-color` ו-`text-color` לא קיימים. המאפיין הוא `color`.
> - `font-weight: bolder;` אינו מה שאתם רוצים; השתמשו ב-`bold` או במספר.
> - שוכחים את הנקודה לפני שם ה-class. `lead { ... }` מחפש תגית `<lead>`. כתבו `.lead { ... }`.
> - מבלבלים בין `text-align` למיקום הקופסה. `text-align: center` ממרכז את הטקסט *בתוך* הקופסה שלו.
> - בוחרים צבע בהיר מאוד לטקסט על רקע לבן. ודאו שאפשר לקרוא אותו.

## להמשך

נסו `text-decoration: underline;` על ה-`h1`, `letter-spacing: 3px;` על הכותרת, ורשימת גיבוי אחרת כמו `"Trebuchet MS", sans-serif`.

> **תורכם:** מלאו את ארבעת הכללים הריקים ב-`style.css` לפי ההערות הממוספרות.
