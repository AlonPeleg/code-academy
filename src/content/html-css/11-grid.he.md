Flexbox מסדר פריטים בכיוון אחד. **CSS Grid** מסדר אותם ב**שורות ועמודות בו-זמנית**, כמו טבלה או גיליון אלקטרוני. הוא מושלם לגלריות תמונות, לוחות בקרה (dashboards) ופריסות של עמודים שלמים.

## מפעילים אותו

כמו flexbox, גם grid מתחיל מההורה. שימו `display: grid` על המיכל והילדים הישירים שלו הופכים ל*פריטי grid*:

```css
.gallery {
  display: grid;
}
```

לבד זה רק מערים את הפריטים. צריך גם להגיד לו כמה עמודות רוצים.

## הגדרת עמודות

```css
.gallery {
  display: grid;
  grid-template-columns: 200px 200px 200px; /* three fixed columns */
}
```

ל-Grid יש יחידה מיוחדת, `fr`, שמייצגת *חלק מהמקום הפנוי*. שלוש עמודות של `1fr` כל אחת תופסות שליש כל אחת:

```css
grid-template-columns: 1fr 1fr 1fr;
```

יש קיצור לחזרה: `repeat(3, 1fr)` פירושו "שלוש עמודות, כל אחת `1fr`". אפשר גם לערבב יחידות, כמו `200px 1fr` עבור סרגל צד קבוע ואזור ראשי גמיש.

שורות נוצרות אוטומטית כשמוסיפים פריטים: עם שלוש עמודות, שישה פריטים יוצרים שתי שורות.

## רווחים

`gap` שם רווח בין שורות ועמודות (לא סביב הקצה):

```css
gap: 16px;           /* both */
row-gap: 8px;        /* just between rows */
column-gap: 24px;    /* just between columns */
```

## פריסה על פני כמה תאים

פריט יכול לכסות יותר מתא אחד. שמים את זה על **הפריט**, לא על המיכל:

```css
.wide {
  grid-column: span 2; /* take up two columns */
}
```

אפשר גם לבחור קווים מדויקים: `grid-column: 1 / 3;` הולך מקו 1 עד קו 3, וכך מכסה שתי עמודות.

## Flexbox או Grid?

- **Flexbox:** כיוון אחד, התוכן קובע את הגודל. מתאים לתפריטים, לקבוצות כפתורים ולמירכוז.
- **Grid:** שני כיוונים, אתם מחליטים קודם על הפריסה. מתאים לגלריות ולפריסות של עמודים.

הרבה עמודים משתמשים בשניהם: grid לעמוד, flexbox בתוך הכרטיסים.

## טריק רספונסיבי

```css
grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
```

זה יוצר כמה שיותר עמודות של לפחות 150px שנכנסות. כשהחלון מצטמצם, עמודות יורדות לשורות חדשות אוטומטית.

> **שימו לב:**
> - שמים `grid-column` על המיכל במקום על הפריט. הוא חייב להיות על הילד.
> - כותבים `grid-template-column` (בלי ה-s). המאפיין הוא `grid-template-columns`.
> - מוסיפים `px` אחרי `fr`, כמו `1fr px`, או `1 fr` עם רווח. כתבו `1fr`.
> - מצפים ש-`gap` יעבוד בלי `display: grid` (או flex) על ההורה.
> - פריסה על יותר עמודות ממה שקיים. אז הדפדפן מוסיף עמודות משתמעות נוספות והפריסה נראית שבורה.

## להמשך

שנו את העמודות ל-`repeat(2, 1fr)` וראו איך שישה פריטים יוצרים שלוש שורות. נסו `grid-template-columns: 1fr 2fr 1fr;` כך שהעמודה האמצעית רחבה פי שניים.

> **תורכם:** הפכו את `.gallery` לרשת (grid) עם שלוש עמודות שוות (`repeat(3, 1fr)`) ורווח של `16px`, וגרמו ל-`.wide` לכסות שתי עמודות.
