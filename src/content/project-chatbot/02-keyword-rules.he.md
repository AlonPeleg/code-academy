בוט הד הוא מנומס אבל חסר תועלת. בשלב הזה הבוט מתחיל **להגיב**: הוא מחפש מילות מפתח במה שאמרתם ובוחר תשובה מתאימה. הרעיון הזה (התאמה מבוססת כללים) הפעיל את הצ'אטבוטים הראשונים בשנות ה-60, ועדיין משמש בהרבה בוטים של שירות לקוחות היום.

## איפה אנחנו עומדים

הבוט מברך אתכם, מקשיב דרך פונקציית העזר `listen()` וחוזר על כל שורה עד שתגידו `bye`.

## מה נוסיף, ולמה

טבלה של **כללים**: כשההודעה מכילה את המילה `weather`, עונים על מזג האוויר; כשהיא מכילה `music`, מדברים על מוזיקה. **מילון** (dictionary) של Python הוא הטבלה המושלמת לזה, כי הוא ממפה *מפתח* (מילת המפתח) ל*ערך* (התשובה). אנחנו צריכים גם תשובת **ברירת מחדל** (fallback) למקרה שאף כלל לא מתאים, כי בוט ששותק מרגיש מקולקל.

## מדריך צעד אחר צעד

**1. מילון הכללים.** סוגריים מסולסלים, וזוגות `key: value` מופרדים בפסיקים:

```python
RULES = {
    "hello": "Hello! Nice to meet you.",
    "weather": "I hear it is sunny somewhere.",
}
FALLBACK = "Hmm, I do not know about that yet."
```

שמות באותיות גדולות הם מוסכמה ב-Python עבור קבועים (constants), ערכים שלא משתנים בזמן שהתוכנית רצה.

**2. מפצלים את ההודעה למילים נקיות.** במשפט `"What is the weather like?"` יש את המילה `weather?` עם סימן שאלה דבוק אליה, והיא לא שווה ל-`"weather"`. לכן הופכים לאותיות קטנות, מפצלים לפי רווחים ומסירים סימני פיסוק מכל מילה:

```python
def clean_words(text):
    return [word.strip(".,!?;:") for word in text.lower().split()]
```

החלק שבסוגריים המרובעים הוא **list comprehension**: "לכל מילה בטקסט המפוצל, תן לי את המילה אחרי הניקוי". הקריאה `.strip(".,!?;:")` מסירה כל אחד מהתווים האלה משני קצוות המילה.

**3. מחפשים כלל מתאים.** עוברים על המילון בלולאה עם `.items()`, שמחזירה זוג `(key, value)` אחד בכל סיבוב:

```python
def find_reply(text):
    words = clean_words(text)
    for keyword, reply in RULES.items():
        if keyword in words:
            return reply
    return FALLBACK
```

הביטוי `keyword in words` שואל "האם מילת המפתח הזו היא אחת מהמילים?". הכלל הראשון שמתאים מנצח, כי `return` מסיימת את הפונקציה מיד. רק כשהלולאה נגמרת בלי התאמה מגיעים לשורה האחרונה ומחזירים את ברירת המחדל. ה-`return` האחרון חייב להיות **מחוץ** ללולאה (באותה הזחה כמו `for`), אחרת הבוט ייכנע אחרי שבדק רק את הכלל הראשון.

**4. משתמשים בזה בלולאה.** מחליפים את ההד ב-`print("Bot: " + find_reply(text))`.

נסו את השיחה המתוסרטת: `Hello there!` מתאימה ל-`hello`, `What is the weather like?` מתאימה ל-`weather` (בזכות `clean_words`), ו-`blah blah` נופלת לברירת המחדל.

> **שימו לב:**
> - בדיקה של `if keyword in text` (המחרוזת כולה) במקום רשימת המילים מתאימה גם לחלקי מילים: `"this"` יפעיל את הכלל `"hi"`. התאמה של מילים שלמות מדויקת יותר.
> - סדר המילון חשוב: אם הודעה מכילה שתי מילות מפתח, הכלל הראשון במילון מנצח. שימו כללים ספציפיים יותר קודם.
> - `KeyError: 'weather'` מופיעה כשכותבים `RULES["weather"]` עבור מפתח שחסר. מעבר בלולאה עם `.items()` מונע את זה.
> - שכחתם פסיק בין רשומות במילון: `SyntaxError: invalid syntax. Perhaps you forgot a comma?`.

> **תורכם:** המילון `RULES` ו-`FALLBACK` כבר כתובים בראש קוד ההתחלה (קראו אותם, ואחר כך תוכלו להוסיף מילת מפתח משלכם אם תרצו). כתבו את `clean_words(text)` ואת `find_reply(text)` בדיוק כמתואר, והשתמשו ב-`find_reply` בלולאה כך שהבוט ידפיס `Bot: <reply>`. גם שורת הברכה השתנתה, והיא כבר מעודכנת.
