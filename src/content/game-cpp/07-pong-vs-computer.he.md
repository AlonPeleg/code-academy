פונג הוא המשחק האמיתי הראשון הקלאסי: כדור, שני מחבטים וניקוד. בשיעור הזה תתנו למחבט הימני **מוח**, מתודה שרודפת אחרי הכדור, ותראו איך מחלקה שומרת על הנתונים שלה בעזרת `private` ועדיין מציעה סט נקי של פעולות.

## השחקנים: Ball ו-Paddle

הכדור הוא struct פשוט עם ערכי ברירת מחדל. יש לו מיקום (`x`, `y`) ו**מהירות** (`vx`, `vy`): כמה פיקסלים הוא זז בכל פריים. פריים אחד הוא 1/30 שנייה, ולכן `vx = 4` פירושו 120 פיקסלים בשנייה.

```cpp
struct Ball {
    int x = 156, y = 116, vx = 4, vy = 3, size = 6;
    void step() {
        x += vx;
        y += vy;
        if (y < 0 || y + size > SCREEN_H) vy = -vy;    // bounce: flip the sign
    }
};
```

המחבט הוא **מחלקה**. המיקום שלו `private`: קוד חיצוני לא יכול לדחוף את `y_` ישירות, הוא חייב לבקש תנועה דרך מתודה:

```cpp
class Paddle {
public:
    void move(int dy) { y_ = std::clamp(y_ + dy, 0, SCREEN_H - H); }
private:
    int y_ = 100;
};
```

`std::clamp(v, lo, hi)` (מ-`<algorithm>`, C++17) מחזירה את `v` מוגבל לטווח מ-`lo` עד `hi`. מכיוון ש**כל** תנועה עוברת דרך `move`, המחבט לעולם לא יוצא מהמסך, לא משנה מי קורא לה: מקשי השחקן או המחשב. זה היתרון הגדול של שמירת כללים בתוך מחלקה.

## שחקן מחשב שאפשר לנצח

מחשב שתמיד יושב בדיוק בגובה הכדור לעולם לא מפספס, וזה לא כיף. הטריק הוא **לעקוב אחרי הכדור, אבל לאט**. בכל פריים המחבט משווה את האמצע שלו לאמצע הכדור וזז לעברו לכל היותר `AI_SPEED` פיקסלים:

```cpp
void follow(const Ball& b) {
    int target = b.y + b.size / 2;     // the ball's middle
    int middle = y_ + H / 2;           // this paddle's middle
    if (middle < target - 4)      move(AI_SPEED);    // ball is lower: go down
    else if (middle > target + 4) move(-AI_SPEED);   // ball is higher: go up
}
```

- `const Ball& b` היא **הפניה** (reference): לא נוצר עותק, וה-`const` מבטיח שהמתודה רק מסתכלת על הכדור.
- ה-`4` הוא **אזור מת** (dead zone). אם המחבט כבר קרוב מספיק, הוא נשאר במקומו ולא רועד.
- `follow` משתמשת שוב ב-`move`, ולכן כלל ה-clamp מופעל בחינם.

מכיוון ש-`AI_SPEED` (2) קטן מהמהירות האנכית של הכדור (3), אפשר לברוח מהמחשב כשהכדור קופץ בזווית חדה. זה הופך את המשחק לבן-ניצחון. שימו לב שזו כל ה"בינה המלאכותית": השוואה אחת. בינה מלאכותית במשחקים היא בדרך כלל פשוטה כמו זו. היא רק צריכה להרגיש אמינה.

## ניקוד עם למדה

כל נקודה עושה את אותם שני דברים: מוסיפה 1 לניקוד ומגישה את הכדור מחדש. אנחנו כותבים את זה פעם אחת כ**למדה** (lambda), פונקציה קטנה שמוגדרת בדיוק איפה שצריך אותה:

```cpp
auto point = [&](int& score, int dir) {
    score++;
    ball.serve(dir);
};
```

- `[&]` פירושו "הלמדה רשאית להשתמש במשתנים שמסביבה (כמו `ball`) בהפניה".
- `int& score` הוא פרמטר הפניה, ולכן `point(cpu_score, -1)` באמת מגדילה את `cpu_score`.
- `dir` הוא -1 להגשה שמאלה ו-+1 להגשה ימינה: הכדור הולך לעבר השחקן שהפסיד את הנקודה.

הכדור בחוץ בצד שמאל כש-`ball.x + ball.size < 0` ובחוץ בצד ימין כש-`ball.x > SCREEN_W`.

## איך ההשמעה החוזרת הזאת עובדת

המחבט השמאלי נשלט על ידי **שחקן מתוסרט**: הטקסט ב-`stdin` מפרט מתי מקשי החץ למעלה ולמטה נלחצים ומשתחררים. התוכנית רצה על שרת והדפדפן משמיע את ההקלטה. פתחו את הלשונית **קלט השחקן** (Player input), שנו כמה מספרי פריימים, ו"תשחקו" משחק אחר עם תוצאה אחרת. הבדיקה עוברת רק עבור התסריט המדויק שמגיע עם השיעור, ולכן החזירו אותו לפני שתלחצו על בדיקת תשובה.

> **שימו לב:**
> - כתיבת `point(cpu_score, -1)` עם למדה שמקבלת `int score` (בלי `&`) משנה עותק, והניקוד אף פעם לא עולה.
> - `std::clamp` צריכה `#include <algorithm>`; בלעדיו: `error: 'clamp' is not a member of 'std'`.
> - קריאה ל-`y_` מתוך `main` נותנת `error: 'int Paddle::y_' is private within this context`. השגיאה הזאת היא המחלקה שמגנה על עצמה, ולכן הוסיפו מתודה במקום.
> - אם מהירות המחשב שווה למהירות הכדור, הוא אף פעם לא מפספס, והניקוד נשאר 0 : N.

## להמשיך הלאה

נסו `AI_SPEED = 3` וראו את המחשב לוקח כל נקודה. אחר כך האיצו את הכדור אחרי כל נקודה, או שנו את `vy` לפי המקום שבו הוא פוגע במחבט.

> **תורכם:** מלאו את `Paddle::follow` בעזרת target, middle והאזור המת של 4 פיקסלים עם `AI_SPEED`, והוסיפו את הניקוד עם הלמדה: כדור שיצא משמאל נותן `point(cpu_score, -1)`, כדור שיצא מימין נותן `point(player_score, 1)`. עם המקשים שניתנו התוכנית אמורה להדפיס `player 4, computer 3`.
