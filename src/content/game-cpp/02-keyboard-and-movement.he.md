משחקים הם כיפיים רק כשאפשר לשחק בהם. בשיעור הזה תקראו את המקלדת, תהפכו אותה לכיוון ותזיזו ריבוע במהירות קבועה. תלמדו גם את ההבדל בין *החזקת* מקש לבין *הקשה* עליו.

## שתי שאלות על מקש

```cpp
if (key_down(KEY_RIGHT)) {
    x += 3;                // true on EVERY frame the key is held
}

if (key_pressed(KEY_SPACE)) {
    shots++;               // true on ONE frame: the moment the key goes down
}
```

- `key_down(key)` היא **אמת כל עוד המקש לחוץ**. השתמשו בה להליכה, להיגוי, לכל דבר רציף.
- `key_pressed(key)` היא **אמת רק בפריים הראשון של לחיצה**. השתמשו בה לפעולות חד-פעמיות: ירי, קפיצה, הפיכת מתג. החזקת המקש לא חוזרת עליה.

## מהירות לפריים, ולמה אין dt

כשהשחקן מחזיק ימינה במשך 30 פריימים ב-3 פיקסלים לפריים, הריבוע עובר `3 x 30 = 90` פיקסלים. מהירות ב**פיקסלים לפריים** היא סוג המהירות הפשוט ביותר. הרבה מנועים נותנים לכם `dt` (הזמן מאז הפריים הקודם) כדי שהתנועה תישאר זהה כשקצב הפריימים משתנה. המנוע הזה תמיד רץ ב-30 פריימים בשנייה בדיוק, ולכן אפשר לוותר על `dt`. זה גם שומר על ההקלטה ניתנת לשחזור לגמרי.

## כיוון כפול מהירות

הרגל נחמד הוא לפצל את התנועה לשני רעיונות: **לאיזה כיוון** ו**באיזו מהירות**. הכיוון בכל ציר הוא `-1` (שלילי), `0` (עומד) או `+1` (חיובי):

```cpp
int dx = 0, dy = 0;
if (key_down(KEY_LEFT))  dx -= 1;
if (key_down(KEY_RIGHT)) dx += 1;

x += dx * speed;    // dx is -1, 0 or +1, so we move left, not at all, or right
```

מכיוון שכל מקש מוסיף או מחסיר 1, החזקת שמאלה וימינה יחד נותנת `dx = 0` והמקשים מתבטלים יפה. עכשיו אפשר לשנות את המהירות בלי לגעת בקוד הכיוון, וזה בדיוק מה שדרוש להאצה (boost).

## האופרטור השלישוני

```cpp
int speed = boosted ? BOOST : NORMAL;
```

`condition ? a : b` הוא if/else בשורה אחת שמייצר ערך: `a` אם התנאי (condition) מתקיים, ואחרת `b`. כאן `speed` הוא `BOOST` כל עוד `boosted` הוא true.

## החלפת מצב של bool

`!` פירושו "לא", ולכן `boosted = !boosted;` מחליף בין `true` ל-`false`. שימו אותו מאחורי `key_pressed` וההאצה נדלקת בהקשה הראשונה ונכבית בבאה:

```cpp
if (key_pressed(KEY_SPACE)) boosted = !boosted;
```

עם `key_down` הוא היה מתהפך 30 פעמים בשנייה כל עוד המקש לחוץ, ולא הייתם יודעים באיזה מצב תסיימו.

כדי להדפיס `bool` כמילה `true` או `false` במקום `1` או `0`, שלחו את `boolalpha` אל `cout`:

```cpp
cout << boolalpha << boosted;    // true
```

> **שימו לב:**
> - שימוש ב-`key_down` להחלפת מצב: הדגל מתהפך בכל פריים. השתמשו ב-`key_pressed`.
> - כתיבת `boosted == !boosted;` (שני סימני שווה) משווה במקום להשים, ולכן שום דבר לא משתנה. gcc מזהיר: `statement has no effect`.
> - `if (key_down(KEY_UP)) dy += 1;` מזיז למטה, כי `y` גדל כלפי מטה. למעלה חייב לחסר.
> - צבעים כמו `RGB_ORANGE` הם מאקרו שמתרחבים לשלושה מספרים, ולכן `boosted ? RGB_ORANGE : RGB_YELLOW` נשבר (gcc מזהיר `right operand of comma operator has no effect`). בחרו צבע עם `if`/`else` רגיל במקום, כמו שקוד ההתחלה עושה.

## להמשך

ערכו את תסריט הקלט: שנו את `85 up up` ל-`100 up up` וראו איך המיקום הסופי משתנה. או הוסיפו את `a` ו-`d` כמקשים נוספים לשמאלה וימינה.

> **תורכם:** הוסיפו את שורות הכיוון UP/DOWN עבור `dy`, וגרמו ל-SPACE להפוך את `boosted` פעם אחת בכל לחיצה עם `key_pressed`. עם הקלט הנתון התוכנית צריכה להדפיס `final: 285, 140, boosted: true`.
