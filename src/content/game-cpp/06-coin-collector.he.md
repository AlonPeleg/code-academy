הגיע הזמן לחבר הכול. אתם יודעים להזיז שחקן, לשמור עליו בתוך המסך, להשתמש במחלקות ולשמור וקטור של אובייקטים. בשיעור הזה תוסיפו **זיהוי התנגשויות** ו**ניקוד** כדי ליצור משחק קטן ושלם של איסוף מטבעות, בעזרת רכיבי C++ אידיומטיים: מתודה, מחלקה ווקטור.

## מתי שני מלבנים נוגעים?

רוב המשחקים הפשוטים מתייחסים לדברים כאל מלבנים, שנקראים **תיבות תוחמות** (bounding boxes). שתי תיבות חופפות כשהן חופפות ב*שני* הצירים בו-זמנית. בציר x אלה שתי בדיקות:

1. הקצה השמאלי של התיבה הזאת נמצא **משמאל לקצה הימני של השנייה**: `x < o.x + o.w`
2. הקצה הימני של התיבה הזאת נמצא **מימין לקצה השמאלי של השנייה**: `x + w > o.x`

אותן שתי בדיקות עם `y` ו-`h` מטפלות בציר האנכי. חברו את כל הארבע עם `&&` ("וגם"). שימו את הרעיון בתוך הטיפוס שאליו הוא שייך, כמתודה:

```cpp
struct Rect {
    int x, y, w, h;

    bool overlaps(const Rect& o) const {
        return x < o.x + o.w && x + w > o.x &&
               y < o.y + o.h && y + h > o.y;
    }
};
```

- `struct` היא מחלקה שהחברים בה ציבוריים כברירת מחדל, וזה נוח לנתונים פשוטים כמו מלבן. עדיין אפשר לתת לה מתודות.
- `const Rect& o` מקבלת את המלבן השני **בהפניה** (בלי העתקה) ומבטיחה לא לשנות אותו.
- ה-`const` בסוף מבטיח שהמתודה לא משנה את המלבן שעליו נקראה.
- בתוך המתודה, `x` חשוף פירושו "ה-x שלי" ו-`o.x` פירושו של המלבן השני. השוואה נותנת `true` או `false`, ולכן הביטוי כולו כבר התשובה ל-`return`.

השימוש קורא כמו אנגלית: `player.overlaps(coin.box)`.

> טיפ: ציירו שני ריבועים על נייר והחליקו אחד מעל השני. שימו לב איזה מארבעת התנאים הופך לשקר ראשון. זו הדרך הטובה ביותר להבין למה צריך את כולם.

## מטבעות שאפשר לאסוף פעם אחת

```cpp
class Coin {
public:
    Coin(int x, int y) : box{x, y, 12, 12} {}
    void draw() const {
        if (!collected) engine_circle(box.x + 6, box.y + 6, 6, RGB_YELLOW);
    }
    Rect box;
    bool collected = false;
};
```

מטבע מחזיק את ה-`Rect` שלו ויודע לצייר את עצמו (עיגול מצויר מה*מרכז* שלו, ולכן מוסיפים חצי מהגודל). רשימת המטבעות היא וקטור שנבנה מרשימת קריאות לבנאי: `std::vector<Coin> coins = {Coin(90, 25), Coin(170, 25)};`.

שלב ההתנגשות מבקר בכל מטבע:

```cpp
for (auto& coin : coins) {
    if (!coin.collected && player.overlaps(coin.box)) {
        coin.collected = true;
        score++;
    }
}
```

`auto&` נותן לכם את המטבע האמיתי כדי שהדגל יישמר. `!coin.collected` פירושו "עדיין לא נאסף". מכיוון שפריים נמשך רק 1/30 שנייה, השחקן חופף למטבע כמה פריימים ברצף. הדגל מבטיח שמטבע שווה נקודות בדיוק פעם אחת.

## ספירת מה שנשאר

בסוף קוד ההתחלה משתמש ב-`std::count_if` עם למדה כדי לספור את המטבעות שלא נאספו. זה כמו `remove_if` מהשיעור הקודם, אבל הוא רק סופר את ההתאמות:

```cpp
auto left = std::count_if(coins.begin(), coins.end(),
                          [](const Coin& c) { return !c.collected; });
```

## הפריים המוגמר

1. **קלט** משנה את `player.x` ו-`player.y`.
2. **עדכון** בודק כל מטבע ומעדכן את הניקוד.
3. **ציור** מנקה, מצייר את המטבעות, את השחקן ואת טקסט הניקוד (`std::to_string(score)` הופך את המספר לטקסט).
4. **הצגה** (present).

> **שימו לב:**
> - `||` במקום `&&` גורם לכמעט הכול להיחשב כנגיעה.
> - `for (auto coin : coins)` (בלי `&`) מסמן עותק, ולכן המטבע האמיתי נשאר ניתן לאיסוף והניקוד ממשיך לעלות.
> - `coin.collected == true` מילולי יותר מ-`coin.collected` וקל לטעות ולהקליד `=`. העדיפו `!coin.collected`.
> - אם שוכחים את ה-`const` ב-`overlaps`, מקבלים `passing 'const Rect' as 'this' argument discards qualifiers` כשקוראים לה על אובייקט const.

## להמשיך הלאה

המטבע השישי נמצא בפינה השמאלית התחתונה, מחוץ להישג ידו של התסריט שניתן. ערכו את קלט השחקן (Player input) כך שהשחקן יאסוף את כל השישה והתוכנית תדפיס `score: 6` ו-`left: 0`. אחר כך הוסיפו טקסט "YOU WIN" כש-`left` מגיע ל-0.

> **תורכם:** השלימו את `Rect::overlaps` עם ארבע ההשוואות, ובלולאת המטבעות סמנו מטבע שלא נאסף ונוגעים בו כנאסף והוסיפו אחד ל-`score`. עם תסריט המקשים שניתן התוכנית אמורה להדפיס `score: 5` ו-`left: 1`.
