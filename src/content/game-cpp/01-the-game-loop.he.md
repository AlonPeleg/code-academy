ברוכים הבאים לתכנות משחקים ב-C++‎! בשיעור הזה תלמדו מהי **לולאת משחק** (game loop), הרעיון האחד שעומד מאחורי כל משחק, ותקבלו את הרשימה המלאה של כל מה שמנוע המיני יודע לעשות.

## הרעיון הגדול: חוברת הזזה

סרט הוא ערימה של תמונות נייחות שמוצגות במהירות, ומשחק עובד באותו אופן. התוכנית מריצה לולאה, וכל סיבוב בלולאה הוא **פריים** (frame). בכל פריים המשחק מבצע שלוש משימות:

1. **עדכון**: משנים את המשתנים (variables) שמתארים את העולם (מזיזים את השחקן, מוסיפים לניקוד).
2. **ציור**: מציירים את העולם לפי המשתנים האלה.
3. **הצגה**: אומרים למנוע שהתמונה הזאת הסתיימה.

המנוע רץ ב-**30 פריימים בשנייה**, ולכן פריים אחד נמשך 1/30 שנייה.

```cpp
while (engine_running()) {
    // update: change variables
    // draw: engine_clear(...), engine_circle(...), ...
    engine_present();
}
```

`engine_running()` היא אמת (true) עד שכל הפריימים הוקלטו (180 פריימים, שהם 6 שניות, אלא אם מבקשים מספר אחר). בכל פעם שקוראים לה, המנוע גם מתקדם לפריים הבא.

## קואורדינטות

המסך הוא **ברוחב 320 פיקסלים ובגובה 240**. הנקודה `(0, 0)` היא הפינה **השמאלית העליונה**, `x` גדל ימינה ו-`y` גדל **כלפי מטה**. מלבן מצויר מהפינה השמאלית העליונה שלו, ועיגול מהמרכז שלו.

## מדריך למנוע

קובץ הכותרת (header) של המנוע עובד גם ב-C וגם ב-C++‎, ולכן אלה פונקציות רגילות (בלי מחלקות). צבעים נכתבים כמילה אחת, כמו `RGB_RED`.

| פונקציה | מה היא עושה |
|---|---|
| `engine_running()` | תנאי הלולאה. אמת כל עוד נשארו פריימים; מקדמת לפריים הבא. |
| `engine_present()` | מסיימת את הפריים. קראו לה פעם אחת בתחתית הלולאה. |
| `engine_clear(color)` | ממלאת את כל המסך בצבע אחד. |
| `engine_rect(x, y, w, h, color)` | מלבן מלא, ‏`(x, y)` היא הפינה השמאלית העליונה שלו. |
| `engine_circle(x, y, radius, color)` | עיגול מלא, ‏`(x, y)` הוא המרכז שלו. |
| `engine_line(x1, y1, x2, y2, color)` | קו בין שתי נקודות. |
| `engine_text(x, y, size, color, text)` | מציירת טקסט. ‏`text` חייב להיות `const char*`. |
| `key_down(KEY_...)` | אמת בכל פריים שהמקש לחוץ. |
| `key_pressed(KEY_...)` | אמת רק בפריים היחיד שבו המקש יורד. |
| `engine_frames(n)` | מקליטה `n` פריימים (ברירת מחדל 180, מקסימום 600). קראו לה לפני הלולאה. |
| `engine_frame()` | מספר הפריים הנוכחי, מתחיל מ-0. |
| `SCREEN_W`, `SCREEN_H` | גודל המסך: 320 ו-240. |

**צבעים:** `RGB_BLACK RGB_WHITE RGB_GRAY RGB_DARK RGB_RED RGB_ORANGE RGB_YELLOW RGB_GREEN RGB_CYAN RGB_BLUE RGB_PURPLE RGB_PINK`, או שלושה מספרים מ-0 עד 255: `engine_rect(10, 10, 20, 20, 255, 0, 0)`.

**מקשים:** `KEY_LEFT KEY_RIGHT KEY_UP KEY_DOWN KEY_SPACE KEY_A KEY_D KEY_W KEY_S KEY_Z KEY_X KEY_ENTER`.

## טקסט מתוך std::string

`engine_text` מצפה למחרוזת C פשוטה. ל-`std::string` יש דרך למסור אחת כזאת עם `.c_str()`, ו-`std::to_string` הופכת מספר למחרוזת:

```cpp
string label = "frame " + to_string(engine_frame());
engine_text(8, 8, 14, RGB_WHITE, label.c_str());   // shows: frame 0, frame 1, ...
```

## קבועים עם שם

במקום לפזר את המספר `2` בכל הקוד, תנו לו שם. ב-C++‎ הדרך המודרנית היא `constexpr`:

```cpp
constexpr int SPEED_X = 2;    // a constant the compiler knows at compile time
```

עכשיו `x += SPEED_X;` מסביר את עצמו, ושינוי המהירות פירושו עריכת שורה אחת.

## זו הקלטה שמנגנים מחדש

אי אפשר לשחק בתוכנית שלכם בזמן אמת בדפדפן. היא רצה על שרת עם **שחקן מתוסרט**: הלשונית *Player input* מכילה שורות כמו `10 right down` (לחצו ימינה בפריים 10). התוכנית מציירת את כל הפריימים, והדפדפן מנגן אותם כמו וידאו. ערכו את השורות האלה ולחצו על Run כדי "לשחק" אחרת. כל מה שמודפס עם `cout` הוא פלט רגיל, ואנחנו משתמשים בו כדי להדפיס תוצאה סופית כך ש-**Check answer** יוכל לוודא את ההיגיון שלכם.

> **שימו לב:**
> - אם שוכחים את `#include "engine.h"` מקבלים `'engine_running' was not declared in this scope`.
> - העברת `std::string` ישירות ל-`engine_text` נותנת `cannot convert 'std::string' to 'const char*'`. הוסיפו `.c_str()`.
> - אם שוכחים את `engine_present()` הפריים אף פעם לא מסתיים, ולכן שום דבר לא מוצג.
> - ציור לפני `engine_clear()` משאיר את התמונה הישנה מאחור כמריחה.

## להמשך

גרמו לעיגול לנוע באלכסון בכיוון ההפוך: התחילו ב-`y = 200` וחסרו ממנו. הוסיפו מלבן עם `engine_rect` שנשאר במקומו באמצע.

> **תורכם:** קראו ל-`engine_frames(90)` לפני הלולאה, ובתוך הלולאה הוסיפו את `SPEED_X` ל-`x` ואת `SPEED_Y` ל-`y`. התוכנית צריכה להדפיס `final: 200, 110` ו-`last frame: 89`.
