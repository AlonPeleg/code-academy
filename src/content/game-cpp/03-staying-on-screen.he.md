כרגע ריבוע יכול לשוטט מעבר לקצה ולא לחזור. בשיעור הזה תשמרו את השחקן בתוך החלון בשורה אחת, בעזרת עזרים מהספרייה הסטנדרטית של C++‎.

## כמה גדול מגרש המשחקים?

המסך הוא `SCREEN_W` x `SCREEN_H` (‏320 x 240). זכרו ש-`x` ו-`y` של מלבן הם **הפינה השמאלית העליונה** שלו. לשחקן ברוחב `SIZE` פיקסלים הקצה הימני נמצא ב-`x + SIZE`, ולכן המיקומים המותרים הם:

```
0  <=  x  <=  SCREEN_W - SIZE
0  <=  y  <=  SCREEN_H - SIZE
```

עם קבועים של C++‎ אפשר לתת שם לגבולות האלה פעם אחת:

```cpp
constexpr int SIZE = 24;
constexpr int MAX_X = SCREEN_W - SIZE;     // 296
```

`constexpr` פירושו "מחושב בזמן ההידור", והוא יכול להשתמש בקבועים אחרים כמו `SCREEN_W` כדי לחשב בשבילכם את המספר.

## std::clamp

**לעשות clamp** למספר פירושו לדחוס אותו לתוך טווח: קטן מדי הופך לערך הנמוך ביותר המותר, גדול מדי הופך לערך הגבוה ביותר המותר, וכל השאר נשאר. ב-C++17 זה מובנה:

```cpp
#include <algorithm>

std::clamp(15, 0, 10);    // 10  (too big)
std::clamp(-3, 0, 10);    // 0   (too small)
std::clamp(7, 0, 10);     // 7   (fine already)
```

הארגומנטים הם תמיד **value, low, high**. בלולאת המשחק קודם זזים, אחר כך עושים clamp, ואז מציירים:

```cpp
x += SPEED;                          // may go past the edge for a moment
x = std::clamp(x, 0, MAX_X);         // ...but is fixed before we draw
```

`std::clamp` מחזירה את המספר החדש. היא לא משנה את `x` בעצמה, ולכן חייבים להשים את התוצאה בחזרה עם `x = ...`.

## std::min ו-std::max

`std::min(a, b)` מחזירה את הקטן משני מספרים ו-`std::max(a, b)` את הגדול. יחד הן עושות את אותה עבודה כמו clamp, "בדרך הארוכה":

```cpp
y = std::min(y, MAX_Y);     // never larger than MAX_Y  (an upper cap)
y = std::max(y, 0);         // never smaller than 0     (a lower cap)
```

(‏`std::clamp` דורשת C++17. אם שרת ההרצה אומר `'clamp' is not a member of 'std'`, השתמשו ב-`std::min` וב-`std::max` לשני הצירים.)

השמות מרגישים הפוכים בהתחלה: `min` היא זו ששומרת על `y` מלהיות **גדול**, כי היא בוחרת את הקטן מבין `y` והתקרה. אמרו בקול: "y, אבל לכל היותר MAX_Y".

אפשר גם לקנן אותן בשורה אחת: `y = std::max(0, std::min(y, MAX_Y));`. שני הארגומנטים של `min`/`max` חייבים להיות מאותו טיפוס, ולכן `std::min(y, 2.5)` לא מתקמפל, אבל שני `int` זה בסדר.

## std:: או using namespace?

כל מה שבספרייה הסטנדרטית חי במרחב השמות (namespace) `std`. אפשר לכתוב את התחילית `std::`, או לשים `using namespace std;` בראש הקובץ ולוותר עליה. כתיבת התחילית היא הרגל טוב בתוכניות גדולות יותר כי היא מראה מאיפה שם מגיע. בשיעור הזה אנחנו משתמשים בתחילית.

> **שימו לב:**
> - `std::clamp(x, 0, MAX_X);` בשורה לבדה לא עושה כלום: התוצאה נזרקת. כתבו `x = std::clamp(...)`.
> - הכנסת הארגומנטים בסדר שגוי, כמו `std::clamp(x, MAX_X, 0)`, היא התנהגות לא מוגדרת: ה-low אסור שיהיה גדול מה-high.
> - שכחת `#include <algorithm>` נותנת `'clamp' is not a member of 'std'`.
> - אם מקבלים `error: no matching function for call to 'min(int&, double)'`, ערבבתם `int` עם `double`. השתמשו בשני מספרים מאותו טיפוס.

## להמשך

הקטינו את מגרש המשחקים: שנו את `MAX_X` ל-`SCREEN_W / 2` וראו את השחקן נעצר באמצע. או גרמו לשחקן להיות מוקפץ מהקיר במקום להיעצר: כש-`x` פוגע בקצה, הפכו את הסימן של משתנה `dx`.

> **תורכם:** שמרו על `x` בטווח עם `std::clamp`, ושמרו על `y` בטווח בעזרת `std::min` ו-`std::max`. תסריט הקלט רץ אל כל ארבעת הקירות והתוכנית צריכה להדפיס `final: 296, 216`.
