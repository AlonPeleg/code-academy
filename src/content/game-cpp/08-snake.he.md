סנייק מלמד את אחד הרעיונות השימושיים ביותר במשחקים: **רשת** (grid) ו**רשימה שגדלה**. ב-C++ הכלי הטבעי לרשימה שגדלה הוא `std::vector`, והכלי הטבעי לכללי הנחש הוא **מחלקה** (class). תכתבו את שניהם.

## קואורדינטות של רשת

המסך הוא 320 על 240 פיקסלים. אנחנו חותכים אותו לריבועים של 20 פיקסלים: 16 עמודות ו-12 שורות. הנחש חי בקואורדינטות של **תאים**, כמו `(4, 6)`, ורק בזמן הציור הופכים תאים לפיקסלים:

```cpp
struct Cell {
    int x, y;
    bool operator==(const Cell& o) const { return x == o.x && y == o.y; }
};
```

שורת ה-`operator==` מלמדת את C++ איך להשוות שני תאים. אחר כך `head == food` פשוט עובד וקורא כמו אנגלית.

## הנחש הוא וקטור של תאים

```cpp
std::vector<Cell> body_{{4, 6}, {3, 6}, {2, 6}};   // body_[0] is the head
```

וקטור גדל בעצמו, ולכן אין `MAX_LEN` ואין מונה נפרד: `body_.size()` הוא האורך. הראש הוא `body_[0]` והזנב הוא `body_.back()`.

## תנועה כל N פריימים

הלולאה רצה 30 פעמים בשנייה, אבל נחש שזז 30 תאים בשנייה אי אפשר לנווט. לכן העולם **עושה צעד** רק כל 5 פריימים:

```cpp
if (engine_frame() % STEP_FRAMES == 0) { /* one step */ }
```

`%` הוא שארית החילוק, ולכן `engine_frame() % 5` הוא 0 בפריימים 0, 5, 10, 15... המקשים עדיין נקראים בכל פריים.

## זחילה בשתי שורות

הנה הדרך הנאה ב-C++ להזיז נחש: **מוסיפים ראש חדש בחזית, מסירים את הזנב הישן מהסוף.**

```cpp
body_.insert(body_.begin(), head);   // new head at index 0, everything shifts along
body_.pop_back();                    // forget the tail
```

`insert(position, value)` מכניסה ערך לפני `position`; `body_.begin()` הוא החזית. `pop_back()` מוחקת את האיבר האחרון. האורך לא השתנה וכל הנחש זז תא אחד.

## אכילה פירושה לדלג על pop_back אחד

גדילה היא פשוט "לא לשכוח את הזנב הפעם":

```cpp
void move_to(Cell head, bool ate) {
    body_.insert(body_.begin(), head);
    if (!ate) body_.pop_back();
}
```

כש-`ate` הוא true הוקטור שומר את הזנב שלו, ולכן הוא ארוך באחד. ואיך יודעים שהנחש אכל? מקומות האוכל קבועים בוקטור, ו-`next_food` אומר איזה מהם נמצא על הלוח:

```cpp
bool ate = next_food < foods.size() && head == foods[next_food];
if (ate) next_food++;
```

החלק `next_food < foods.size()` חייב לבוא **ראשון**: `&&` נעצר ברגע שהוא רואה `false`, ולכן אף פעם לא קוראים את `foods[next_food]` אחרי סוף הוקטור.

## מחלקה ששומרת על הכללים שלה

`Snake::turn` מסרבת להסתובב לאחור אל הצוואר. הכיוונים `dx_` ו-`dy_` הם `private`, ולכן הדרך היחידה לנווט היא המתודה, ואי אפשר לעקוף את הכלל:

```cpp
void turn(int dx, int dy) {
    if (dx + dx_ != 0 || dy + dy_ != 0) { dx_ = dx; dy_ = dy; }
}
```

תנועה ימינה היא `(1, 0)`. המקש שמאלה מבקש `(-1, 0)`: הסכום הוא `(0, 0)`, ולכן הוא נדחה. למעלה מבקש `(0, -1)`: הסכום הוא `(1, -1)`, ומתקבל.

> **שימו לב:**
> - שימוש ב-`foods[next_food]` כש-`next_food == foods.size()` קורא אחרי הסוף. זו התנהגות לא מוגדרת (undefined behavior) והמהדר לא יזהיר אתכם. תמיד בדקו קודם את הגודל.
> - `body_.insert(body_.end(), head)` מוסיפה את הראש ב**סוף**, ולכן הנחש היה גדל בקצה הלא נכון.
> - קריאה ל-`pop_back()` על וקטור ריק היא התנהגות לא מוגדרת, ולכן וודאו שלנחש תמיד יש קטע.
> - אם שוכחים את `operator==` מקבלים `error: no match for 'operator==' (operand types are 'Cell' and 'const Cell')`.

## להמשיך הלאה

בדיקת הקיר כבר מסיימת את המשחק. הוסיפו בדיקת נשיכה עם `std::find(body.begin(), body.end(), head)`, שעובדת בזכות ה-`operator==` שלכם.

> **תורכם:** (1) ב-`Snake::move_to`, הכניסו את `head` בחזית והסירו את הזנב אלא אם `ate`; (2) ב-`main`, חשבו את `ate` כ-"next_food נמצא בתוך foods וה-head שווה ל-foods[next_food]" וקדמו את `next_food` כשהוא true. עם המקשים שניתנו התוכנית אמורה להדפיס `length: 7`.
