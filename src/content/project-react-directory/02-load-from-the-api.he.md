פנקס כתובות עם שלושה אנשים שהוקלדו בתוך הקוד הוא הדגמה. בשלב הזה האנשים מגיעים משרת, וכך עובדת כמעט כל אפליקציה אמיתית. תלמדו את התבנית בת שלושת החלקים שתשתמשו בה לאורך כל הקריירה: **state, effect, רינדור**.

## איפה אנחנו עומדים

האפליקציה מציגה מערך קבוע `PEOPLE` עם שלושה אנשים. עדיין אין בקשת רשת.

## מה נוסיף, ולמה זה חשוב

נטען את הרשימה מהכתובת `https://api.academy.test/users`. זהו שרת אימון שמובנה בדף, ולכן הוא עובד גם בלי חיבור לאינטרנט ותמיד עונה באותו אופן. הוא מחזיר **חמישה** אנשים בפורמט JSON, ולכן תדעו שהבקשה הצליחה כשהמונה יראה `5 people` במקום `3`.

בקשות רשת לוקחות זמן. לרגע אין למסך מה להציג, ואפליקציה טובה אומרת את זה ("Loading...") במקום להציג דף ריק. לכן אנחנו שומרים state נוסף, `loading`.

## הדרכה שלב אחר שלב

**1. שני חלקי state.** הפונקציה `useState` זוכרת ערך בין רינדורים ומרנדרת מחדש את הקומפוננטה כשמשנים אותו:

```jsx
const [people, setPeople] = useState([]);   // starts empty
const [loading, setLoading] = useState(true); // we are waiting at the start
```

**2. ה-effect.** הפונקציה `useEffect(fn, deps)` מריצה את `fn` **אחרי** ש-React הציבה את הקומפוננטה על המסך. הארגומנט השני אומר מתי להריץ אותה שוב: `[]` פירושו "רק בפעם הראשונה".

```jsx
useEffect(() => {
  fetch(API + '/users')
    .then((res) => res.json())
    .then((data) => {
      setPeople(data);
      setLoading(false);
    });
}, []);
```

קראו את זה מהתחלה. `fetch(url)` מתחילה בקשה ומחזירה **הבטחה (promise)**, ערך שיגיע מאוחר יותר. `.then(...)` אומר מה לעשות כשהוא מגיע. ה-`then` הראשון הופך את התשובה לנתוני JavaScript בעזרת `res.json()` (שגם היא מחזירה promise), והשני מקבל את הנתונים. קריאה ל-`setPeople` גורמת ל-React לרנדר שוב עם הרשימה החדשה.

**3. הניקוי.** effect יכול להחזיר פונקציה ש-React קוראת לה כשה-effect מוחלף או כשהקומפוננטה נעלמת. אנחנו משתמשים בה כדי להדליק דגל, `cancelled`, ולהתעלם מתשובה שמגיעה באיחור. זה מונע את הבאג הקלאסי "עדכון state בקומפוננטה שהוסרה":

```jsx
let cancelled = false;
...
return () => { cancelled = true; };
```

**4. רינדור לכל שלב.** השתמשו באופרטור התנאי בתוך JSX:

```jsx
{loading ? <p className="loading">Loading people...</p> : <ul>...</ul>}
```

כשבענף אחד יש יותר מאלמנט אחד, עטפו אותו ב-fragment `<> ... </>`, עטיפה בלתי נראית.

**5. מסירים את המערך הישן.** החליפו את `PEOPLE` ב-`people` בכל מקום ומחקו את הקבוע, אחרת עדיין תציגו נתונים מזויפים.

## מה אמורים לראות

לרגע קצר `Loading people...`, ואז `5 people` וחמישה כרטיסים, כולל Katherine Johnson ו-Linus Torvalds, שלא היו במערך הישן שלנו.

> **שימו לב:**
> - שכחתם את `[]`: ה-effect רץ אחרי כל רינדור, כל הרצה קובעת state, שמרנדר שוב, שמריץ את ה-effect... לולאה אינסופית של בקשות.
> - `people.map is not a function`: `people` התחיל כ-`undefined` או כאובייקט. התחילו עם `[]`.
> - הפיכת פונקציית ה-effect ל-`async` ישירות (`useEffect(async () => ...)`). React מצפה שהיא לא תחזיר דבר או שתחזיר פונקציית ניקוי, לא promise. השתמשו ב-`.then`, או הגדירו פונקציה אסינכרונית בפנים.
> - שכחתם את `res.json()`: תכניסו אובייקט Response אל תוך ה-state.
> - `fetch` מכירה רק כתובות מלאות: `'/users'` לבדה לא תגיע לשרת האימון.
