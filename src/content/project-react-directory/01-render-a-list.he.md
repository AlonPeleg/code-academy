ברוכים הבאים לפרויקט השני של האקדמיה. במהלך שמונה שלבים תבנו **People Directory**: אפליקציית React שטוענת אנשים מ-API ברשת, מטפלת בטעינה ובשגיאות, מחפשת, מציגה פרטים, עורכת נתונים ומדפדפת בין תוצאות. זו אותה צורה של אלפי לוחות בקרה וכלי ניהול אמיתיים.

כל שלב מתחיל מהקוד המוגמר של השלב הקודם וברשימה של הערות `TODO`. הקובץ `styles.css` שלם מהרגע הראשון, כך שאפשר להתמקד ב-React.

## איפה אנחנו עומדים

אנחנו בתחילת הדרך. התצוגה המקדימה מראה דף ריק עם כותרת. בסוף השלב הזה היא תציג רשימה של שלושה אנשים.

## מה נוסיף, ולמה זה חשוב

לכל מסך שמבוסס על נתונים יש אותו ליבה: **רשימה של דברים, שורה אחת לכל דבר**. לפני שמתחברים לשרת אנחנו משתמשים במערך פשוט בתוך הקוד. כך אפשר לתרגל את המיומנות האמיתית: לתאר את המסך כפונקציה של הנתונים. אם במערך יש חמישה פריטים, המסך מציג חמש שורות. React קוראת לזה ממשק *הצהרתי* (declarative): אתם אומרים *איך* המסך נראה עבור הנתונים, ו-React מבינה בעצמה איך לעדכן אותו.

## הדרכה שלב אחר שלב

**1. הנתונים.** אדם הוא אובייקט, ופנקס כתובות הוא מערך של אובייקטים כאלה. שימו אותו מעל הקומפוננטה:

```jsx
const PEOPLE = [
  { id: 1, name: 'Ada Lovelace', email: 'ada@example.com', role: 'admin', city: 'London' },
  // ... two more
];
```

לכל אובייקט יש `id`. לנתונים אמיתיים ממסד נתונים תמיד יש כזה, ובעוד רגע נצטרך אותו.

**2. הצגת מספר ב-JSX.** סוגריים מסולסלים מחזירים מ-JSX אל JavaScript:

```jsx
<p className="count">{PEOPLE.length} people</p>
```

זכרו ש-JSX משתמש ב-`className` במקום ב-`class`, כי `class` היא מילה שמורה ב-JavaScript.

**3. הופכים את המערך לשורות בעזרת `map`.** הפונקציה `array.map(fn)` קוראת לפונקציה שלכם עבור כל פריט ומחזירה מערך חדש עם התוצאות. React יודעת לרנדר מערך של אלמנטים:

```jsx
<ul className="people">
  {PEOPLE.map((person) => (
    <li key={person.id} className="person">
      ...
    </li>
  ))}
</ul>
```

בואו נעבור על זה. `PEOPLE.map(...)` הוא JavaScript, ולכן הוא יושב בסוגריים מסולסלים. עבור כל `person` אנחנו מחזירים `li`. פונקציית החץ משתמשת בסוגריים עגולים `( ... )` סביב ה-JSX כדי להחזיר אותו בלי צורך במילה `return`.

**4. ה-`key`.** React מבקשת מכל פריט ברשימה `key`: זהות ייחודית ויציבה, כמו ה-id. כשהרשימה תשתנה בהמשך (חיפוש מסיר שתי שורות, אדם חדש מופיע) React משתמשת במפתחות כדי להחליט אילו שורות להשאיר, להזיז או למחוק. לעולם אל תשתמשו באינדקס של המערך בתור key כשהסדר ברשימה יכול להשתנות.

**5. ממלאים את השורה.** בתוך ה-`li` השתמשו במבנה מהערת ה-`TODO`. `{person.name}`, `{person.email}`, `{person.role}` ו-`{person.city}` ממלאים את הערכים. שמות המחלקות תואמים ל-CSS המוגמר.

## מה אמורים לראות

מונה, `3 people`, ושלושה כרטיסים, ובכל אחד השם, האימייל, תג תפקיד קטן והעיר.

> **שימו לב:**
> - `Warning: Each child in a list should have a unique "key" prop.` מופיעה בקונסולה אם שכחתם את ה-key.
> - אם תכתבו `PEOPLE.map(...)` בלי סוגריים מסולסלים, הדף יציג את הטקסט `PEOPLE.map(...)` במקום את הרשימה.
> - `class="person"` צריך להיות `className="person"`.
> - שימוש ב-`{ }` סביב אובייקט, כמו `{person}`, גורם לשגיאה `Objects are not valid as a React child`. הציגו את השדות, לא את האובייקט כולו.
> - סוגריים עגולים לעומת מסולסלים: `(person) => ( <li>..</li> )` מחזיר את ה-li, אבל `(person) => { <li>..</li> }` לא מחזיר דבר.

> **תורכם:** בצעו את שלוש הערות ה-`TODO` בקובץ `App.jsx`: הוסיפו את המערך `PEOPLE` עם שלושה אנשים, פסקת מונה, ו-`ul.people` עם `li.person` אחד לכל אדם, עם key ועם המבנה מההערה. הדף חייב להציג "3 people" ואת השמות Ada Lovelace, Grace Hopper ו-Alan Turing.
