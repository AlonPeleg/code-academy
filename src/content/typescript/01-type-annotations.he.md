JavaScript מאפשרת למשתנה להחזיק כל דבר בכל זמן, וזה גמיש אבל גם דרך מצוינת להסתיר באגים. **TypeScript** היא JavaScript בתוספת **טיפוסים** (types): תוויות שאומרות איזה סוג ערך מוחזק. TypeScript קוראת את התוויות האלה ומזהירה אתכם מפני טעויות עוד לפני שהתוכנית רצה.

## תחביר הנקודתיים

**הצהרת טיפוס** (type annotation) היא נקודתיים ואחריהן שם של טיפוס. מניחים אותה מיד אחרי הדבר שמתארים:

```ts
let age: number = 20;
let name: string = "Ava";
let ready: boolean = true;
```

- `age: number` פירושו "age מחזיק מספר".
- `name: string` פירושו "name מחזיק טקסט".
- `ready: boolean` פירושו "ready הוא `true` או `false`".

עכשיו TypeScript תסרב לקבל שטויות כמו `age = "twenty"`. בעורך תראו קו אדום מתחת ואת ההודעה `Type 'string' is not assignable to type 'number'`.

## טיפוסים בפונקציות

בפונקציות יש שני מקומות לטיפוסים: ה**פרמטרים** (parameters, הקלט) ו**טיפוס ההחזרה** (return type, הפלט).

```ts
function greet(name: string): string {
  return "Hi " + name;
}

console.log(greet("Ava")); // prints: Hi Ava
```

קוראים את זה חלק אחרי חלק:

1. `name: string` אומר שהקלט חייב להיות טקסט.
2. ה-`: string` אחרי הסוגר הסוגר אומר שהפונקציה מחזירה טקסט.
3. אם תקראו ל-`greet(42)`, TypeScript תתלונן: `Argument of type 'number' is not assignable to parameter of type 'string'`.

אם פונקציה לא מחזירה כלום, טיפוס ההחזרה שלה הוא `void`.

## מה קורה בזמן ריצה?

שום דבר מיוחד. כשהקוד רץ, כל הטיפוסים **נמחקים** ומה שנשאר הוא JavaScript רגילה. טיפוסים הם רק רשת ביטחון עבורכם בזמן הכתיבה. זו גם הסיבה שבדף התרגול הזה אי אפשר להציג שגיאת טיפוסים בפלט: הוא בודק שההצהרות נכתבו, ושהתוכנית עדיין מדפיסה את הדבר הנכון.

> **שימו לב:**
> - כתיבת הטיפוס לפני השם, כמו `number a`. ב-TypeScript השם בא קודם: `a: number`.
> - שכחה שפרמטרים צריכים הצהרות אחד אחד. `function add(a, b: number)` מגדירה טיפוס רק ל-`b`, והעורך יגיד `Parameter 'a' implicitly has an 'any' type`.
> - שימוש באות גדולה, כמו `Number` או `String`. אלה טיפוסים אחרים, שנדיר שרוצים. השתמשו באותיות קטנות `number` ו-`string`.

## להמשיך הלאה

שנו את הקריאה ל-`add(3, "4")` בעותק שלכם והסתכלו על הקו האדום. אחר כך בטלו את השינוי כדי שהשיעור ימשיך לעבור.

> **תורכם:** תנו ל-`add` פרמטרים עם טיפוסים (`a` ו-`b` הם מספרים) וטיפוס החזרה `number`.
