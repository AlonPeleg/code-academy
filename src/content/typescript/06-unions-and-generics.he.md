לפעמים ערך יכול להיות אחד ממספר טיפוסים, ולפעמים פונקציה צריכה לעבוד עבור כל טיפוס ועדיין להיות בטוחה. **איחודים** (unions) ו**גנריקה** (generics) פותרים את שתי הבעיות האלה.

## טיפוסי איחוד

**איחוד** משתמש בסימן `|` ומשמעותו "אחד מהטיפוסים האלה":

```ts
let userId: string | number;

userId = 42;      // fine
userId = "abc";   // also fine
userId = true;    // error: Type 'boolean' is not assignable to type 'string | number'
```

אפשר לקרוא את `|` כ"או". איחודים שימושיים למזהים שיכולים להיות מספרים או טקסט, לערכים שאולי חסרים (`string | null`), ולקלט של פונקציות שמקבלות יותר מצורה אחת.

## כינויי טיפוס

לכתוב `string | number` בכל מקום זה מעייף. **כינוי טיפוס** (type alias) נותן שם לכל טיפוס בעזרת המילה `type`:

```ts
type Id = string | number;

function show(id: Id): string {
  return `ID: ${id}`;
}
```

כינוי לא יוצר שום דבר חדש בזמן ריצה. זה רק שם חיבה ש-TypeScript מבינה.

## שימוש בערך מסוג איחוד

TypeScript מרשה לעשות רק דברים שבטוחים לגבי **כל** אחד מחברי האיחוד:

```ts
function shout(id: Id) {
  return id.toUpperCase(); // error: Property 'toUpperCase' does not exist on type 'number'
}
```

קודם בודקים איזה טיפוס יש לכם (זה נקרא צמצום, narrowing, והשיעורים הבאים מסבירים אותו בהרחבה).

## גנריקה

דמיינו פונקציה שמחזירה את הפריט הראשון של מערך. עבור מספרים היא צריכה להחזיר מספר, ועבור מחרוזות מחרוזת. פונקציה **גנרית** משתמשת בטיפוס מציין מקום, שנהוג לקרוא לו `T`:

```ts
function first<T>(items: T[]): T {
  return items[0];
}

const a = first([1, 2, 3]);     // T is number, so a is a number
const b = first(["a", "b"]);    // T is string, so b is a string
```

צעד אחר צעד:

1. `<T>` מיד אחרי שם הפונקציה מצהיר "אני צריך מציין מקום לטיפוס בשם T".
2. `items: T[]` אומר "מערך שהפריטים בו הם מטיפוס T".
3. `: T` אומר "ואני מחזיר T אחד".

כשקוראים לפונקציה, TypeScript ממלאת את `T` לפי הארגומנטים. טיפוס הקלט וטיפוס הפלט נשארים קשורים זה לזה, מה ש-`any` לעולם לא יכול לעשות. רחפו עם העכבר מעל `a` ו-`b` בעורך כדי לראות מה TypeScript הסיקה.

קיימים גם טיפוסים גנריים: `Array<number>` היא הדרך הגנרית לכתוב `number[]`, ואפשר לבנות טיפוסים כאלה בעצמכם, למשל `interface Box<T> { value: T }`.

> **שימו לב:**
> - שימוש ב-`|` במקום שהתכוונתם ל-`&`: `string & number` ("חיתוך", intersection) בלתי אפשרי לקיום.
> - `Property '...' does not exist on type 'string | number'`: השתמשתם במשהו שיש רק לחבר אחד באיחוד. צמצמו קודם את הטיפוס.
> - שכחה של `<T>` אחרי השם גורמת ל-`Cannot find name 'T'`.

> **תורכם:** צרו את כינוי הטיפוס `Id` ואת הפונקציה הגנרית `first`.
