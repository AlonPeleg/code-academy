Rust היא שפה לכתיבת תוכניות **מהירות** ו**בטוחות**. משתמשים בה בדפדפנים, במנועי משחקים, בכלי שורת פקודה ובחלקים של מערכות הפעלה. יש לה מוניטין של שפה קפדנית, אבל הקפדנות הזו היא מתנה: הקומפיילר (הכלי שהופך את הטקסט שלכם לתוכנית שאפשר להריץ) תופס משפחות שלמות של באגים עוד לפני שהתוכנית שלכם רצה בכלל. בשיעור הזה תכתבו את התוכנית הראשונה שלכם ותלמדו להדפיס.

## התוכנית הקטנה ביותר

```rust
fn main() {
    println!("Hello, world!");
}
```

חלק אחר חלק:

- `fn` הוא קיצור של *function* (פונקציה). פונקציה היא בלוק קוד עם שם.
- `main` הוא השם המיוחד של הפונקציה שבה כל תוכנית Rust **מתחילה**. בלעדיו, הקומפיילר מתלונן.
- `()` היא רשימת הקלטים (הריקה). `main` לא מקבלת אף אחד.
- סוגריים מסולסלים `{ ... }` עוטפים את גוף הפונקציה.
- `println!("Hello, world!");` מדפיסה טקסט ואחריו שורה חדשה.

קוד Rust בדרך כלל נבנה עם כלי שנקרא **cargo**, אבל בקורס הזה אנחנו משתמשים בקובץ יחיד `main.rs` והקומפיילר `rustc` מריץ אותו בשבילכם. לא צריך שום דבר נוסף.

## println! וסימן הקריאה

`println!` מסתיימת ב-`!` כי היא **מאקרו** (macro), קטע קוד שהקומפיילר מרחיב לקוד נוסף. כרגע רק זכרו: ל-`println!` ול-`print!` יש סימן קריאה, לפונקציות רגילות אין. `print!` זהה אבל לא מוסיפה שורה חדשה בסוף.

טקסט בין מרכאות כפולות הוא **מחרוזת** (string). מרכאות בודדות מיועדות לתווים בודדים (`'a'`), ולכן `println!('hi')` היא שגיאה.

## מציינים מקום

כדי להדפיס ערכים, שמים `{}` בתוך הטקסט ומעבירים את הערכים אחרי המחרוזת, מופרדים בפסיקים:

```rust
let name = "Ferris";
let age = 7;
println!("{} is {} years old.", name, age);   // prints: Ferris is 7 years old.
println!("1 + 1 = {}", 1 + 1);               // prints: 1 + 1 = 2
```

כל `{}` לוקח את הערך הבא לפי הסדר. אפשר אפילו לשים ברשימה חישוב כמו `1 + 1`. ב-Rust חדשה יותר אפשר גם לכתוב את שם המשתנה בתוך הסוגריים, `println!("{name} is {age}")`, וזה נוח לשמות פשוטים.

אם רוצים להדפיס סוגר מסולסל עצמו, מכפילים אותו: `println!("{{ and }}")` מדפיסה `{ and }`.

## משתנים עם let

`let name = "Ferris";` יוצרת משתנה בשם `name` שמחזיק את הטקסט. Rust מבינה את הטיפוס בעצמה (כאן string slice, שנכתב `&str`). על משתנים תלמדו הרבה יותר בשיעור הבא.

## הערות

שורה שמתחילה ב-`//` היא הערה: הקומפיילר מתעלם ממנה. השתמשו בהערות כדי להסביר *למה* הקוד עושה משהו.

```rust
// this is a note for humans
println!("this runs");
```

> **שימו לב:** אם שוכחים את ה-`!` מקבלים `error[E0423]: expected function, found macro` (או "cannot find function `println`").
>
> **שימו לב:** נקודה-פסיק חסרה מניבה `error: expected `;``. Rust קוראת את השורה הבאה כחלק מאותה פקודה.
>
> **שימו לב:** מספר ה-`{}` חייב להיות שווה למספר הערכים: `println!("{} {}", 1);` נכשלת עם `error: 2 positional arguments in format string, but there is 1 argument`.
>
> **שימו לב:** מחרוזות ב-Rust משתמשות במרכאות כפולות. `'Hello'` במרכאות בודדות היא שגיאה כי מרכאות בודדות מיועדות לתו אחד בלבד.

## ממשיכים הלאה

נסו `print!` פעמיים ברצף וראו שהטקסט מסתיים בשורה אחת. נסו להדפיס את השם והגיל שלכם, או להדפיס חישוב קטן כמו `7 * 6`.

> **תורכם:** ב-`fn main`, הדפיסו `Hello, Rust!`, ואז צרו `let name = "Ferris";` והדפיסו `Ferris is a crab.` בעזרת מציין מקום `{}`, ולבסוף הדפיסו `2 + 3 = 5` בעזרת שלושה מציני מקום (הערכים `2`, `3` ו-`2 + 3`).
