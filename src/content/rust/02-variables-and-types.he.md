בשפות רבות משתנה (variable) הוא קופסה שאפשר לשנות את תוכנה בכל רגע. ב-Rust משתנים הם **בלתי ניתנים לשינוי כברירת מחדל**: אחרי שנתתם להם ערך, הוא נשאר כך אלא אם ביקשתם אחרת. זה נשמע מגביל, אבל זה הופך תוכניות להרבה יותר קלות להבנה: כשרואים `let x = 5;` יודעים ש-x שווה 5 כל עוד הוא קיים.

## let ו-mut

```rust
let x = 5;
// x = 6;          // error[E0384]: cannot assign twice to immutable variable `x`

let mut y = 5;
y = 6;             // fine, y is mutable
y += 1;            // y is now 7
```

`mut` הוא קיצור של *mutable* (ניתן לשינוי). הקיצורים `+=`, `-=`, `*=` ו-`/=` משנים משתנה במקום: `y += 1` פירושו `y = y + 1`. ב-Rust אין `++`.

## טיפוסים

לכל ערך יש טיפוס (type), והמהדר (compiler) בדרך כלל מנחש אותו. אפשר גם לכתוב אותו אחרי נקודתיים:

```rust
let age: u8 = 30;
let temperature: f64 = 21.5;
let is_open: bool = true;
let initial: char = 'R';
let greeting: &str = "hello";
```

הטיפוסים הנפוצים ביותר:

| טיפוס | משמעות | דוגמה |
| --- | --- | --- |
| `i32` | מספר שלם, יכול להיות שלילי (ברירת המחדל) | `-42` |
| `u32`, `u8`, `u64` | מספר שלם, אף פעם לא שלילי (`u` = unsigned) | `7` |
| `f64` | מספר עשרוני (ברירת המחדל למספרים עשרוניים) | `3.14` |
| `bool` | `true` או `false` | `true` |
| `char` | תו אחד, בגרשיים בודדים | `'x'` |
| `&str` | טקסט, בגרשיים כפולים | `"hi"` |

המספר שאחרי האות הוא מספר הביטים. טיפוס `u8` מכיל ערכים מ-0 עד 255, ו-`i32` מכיל בערך פלוס מינוס שני מיליארד. Rust תסרב לקמפל אם תכתבו `let x: u8 = 300;`.

## המרה בין טיפוסים

Rust לעולם לא ממירה מספרים מאחורי הגב שלכם. כדי לערבב מספר שלם עם מספר עשרוני, ממירים בעזרת `as`:

```rust
let total: i32 = 7;
let count: i32 = 2;
println!("{}", total / count);                 // prints: 3   (integer division)
println!("{}", total as f64 / count as f64);   // prints: 3.5
```

## Shadowing

אפשר להצהיר על משתנה חדש עם אותו שם בעזרת `let` שוב. המשתנה החדש **מצל** (shadows, כלומר מסתיר) את הישן:

```rust
let spaces = "   ";
let spaces = spaces.len();   // now spaces is the number 3
```

זה שונה מ-`mut`: נוצר משתנה חדש, ולכן יכול להיות לו אפילו טיפוס אחר. משתמשים ב-shadowing כשמעבדים ערך, וב-`mut` כשהערך משתנה עם הזמן (מונה, ניקוד).

## קבועים

```rust
const MAX_LIVES: u32 = 3;
```

`const` לעולם לא משתנה, חייב טיפוס שכתוב במפורש, ולפי המוסכמה נכתב ב-`SHOUTING_CASE`. קבועים יכולים להיות מחוץ לפונקציות.

> **שימו לב:** `error[E0384]: cannot assign twice to immutable variable` אומר ששכחתם `mut`.
>
> **שימו לב:** `error[E0308]: mismatched types` מופיעה כשמערבבים טיפוסים, למשל `let x: f64 = 5;` (כתבו `5.0`) או `3.5 + 2` (כתבו `2.0`).
>
> **שימו לב:** `let mut` הופך רק את המשתנה לניתן לשינוי, לא את הטיפוס שלו: אי אפשר לשים טקסט במשתנה של מספר.
>
> **שימו לב:** אזהרה כמו `unused variable` אינה שגיאה. הוסיפו קו תחתון בתחילת השם (`_x`) כדי להשתיק אותה.

> **תורכם:** הפכו את `counter` לניתן לשינוי והוסיפו לו 5, בצעו shadowing ל-`spaces` עם האורך שלו (`spaces.len()`), וחשבו את `average` בתור `total as f64 / count as f64`.
