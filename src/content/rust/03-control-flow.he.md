תוכניות נעשות שימושיות כשהן יכולות להחליט ולחזור על פעולות. Rust נותנת לכם את `if` להחלטות ושלושה סוגי לולאות (loops): `for`, `while` ו-`loop`. הצורה שלהם פשוטה, עם תוספת אחת: ב-Rust `if` הוא **ביטוי** (expression), כלומר הוא יכול להפיק ערך.

## if, else if, else

```rust
let temperature = 25;
if temperature > 30 {
    println!("hot");
} else if temperature > 15 {
    println!("nice");   // prints: nice
} else {
    println!("cold");
}
```

אין סוגריים עגולים סביב התנאי, אבל הסוגריים המסולסלים הם **חובה**, גם בשורה אחת. התנאי חייב להיות `bool` אמיתי: `if 1 { }` היא שגיאה, בניגוד ל-C. אפשר לשלב תנאים עם `&&` (וגם), `||` (או) ו-`!` (לא).

### if בתור ביטוי

מכיוון ש-`if` מחזיר ערך, אפשר להציב את התוצאה שלו:

```rust
let label = if temperature > 20 { "warm" } else { "cool" };
```

שני הענפים חייבים להיות מאותו **טיפוס**, ואין נקודה-פסיק אחרי הערך בתוך כל ענף. הנקודה-פסיק אחרי הסוגר המסולסל הסוגר שייכת ל-`let`.

## לולאות for וטווחים

```rust
for i in 1..=3 {
    println!("{}", i);   // prints 1, 2, 3
}
```

`1..=3` הוא **טווח כולל** (1, 2 ו-3). `1..3` הוא טווח לא כולל ונותן 1 ו-2. לולאת `for` מוציאה מהטווח ערך אחד בכל פעם, ו-`i` קיים רק בתוך הלולאה. אפשר גם לעבור בלולאה על רשימה, ותראו זאת בשיעור מאוחר יותר.

## לולאות while

לולאת `while` חוזרת כל עוד תנאי מתקיים:

```rust
let mut n = 3;
while n > 0 {
    println!("{}", n);
    n -= 1;
}
println!("liftoff");
```

זכרו את `mut`: המונה משתנה, ולכן הוא חייב להיות ניתן לשינוי. אם שוכחים את `n -= 1` מקבלים לולאה אינסופית.

## loop, break ו-continue

`loop` חוזרת לנצח עד שיוצאים ממנה עם `break`. הפקודה `continue` מדלגת לסיבוב הבא.

```rust
let mut count = 0;
loop {
    count += 1;
    if count == 2 { continue; }
    if count > 4 { break; }
    println!("{}", count);   // prints 1, 3, 4
}
```

## אופרטור השארית

`a % b` הוא השארית של חילוק. `10 % 3` הוא `1`. מספר מתחלק ב-`b` כאשר `a % b == 0`. זה לב הלב של FizzBuzz, תרגיל קלאסי: מדפיסים את המספרים מ-1 עד 15, אבל אומרים "Fizz" לכפולות של 3, "Buzz" לכפולות של 5 ו-"FizzBuzz" לשתיהן.

> **שימו לב:** `error[E0308]: mismatched types ... expected `bool`, found integer` אומר שהתנאי שלכם אינו ערך של אמת/שקר. כתבו `x != 0` במקום `x`.
>
> **שימו לב:** ב-FizzBuzz בדקו את המקרה של "שניהם" **קודם**. מספר כמו 15 מתחלק ב-3, ולכן בדיקה מוקדמת של `i % 3 == 0` הייתה תופסת אותו.
>
> **שימו לב:** ענפי `if` מטיפוסים שונים (`if a { 1 } else { "no" }`) גורמים ל-`error[E0308]: `if` and `else` have incompatible types`.
>
> **שימו לב:** לולאת `while` שהמשתנה שלה אף פעם לא משתנה רצה לנצח, והריצה נעצרת בגלל מגבלת זמן.

> **תורכם:** השלימו את FizzBuzz עבור 1 עד 15 עם `if` / `else if` / `else`, חברו את 1 עד 10 בלולאת `while` לתוך `total`, ובחרו את `label` עם ביטוי `if` ("big" כש-`total` גדול מ-50).
