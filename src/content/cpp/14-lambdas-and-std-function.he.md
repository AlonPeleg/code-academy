לעיתים קרובות צריך קטע התנהגות זעיר: "מיינו את אלה לפי אורך", "השאירו רק את הזוגיים". לכתוב פונקציה נפרדת עם שם לכל אחד מהם זה מסורבל. **למבדה** (lambda) היא פונקציה קטנה ללא שם שכותבים בדיוק איפה שצריך אותה. בשילוב עם `std::function` אפשר גם לשמור פונקציות במשתנים, בוקטורים ובמפות, וזה פותח את הדלת ל-callbacks ולטבלאות פקודות.

## האנטומיה של למבדה

```cpp
auto square = [](int x) { return x * x; };
cout << square(7);     // prints: 49
```

קראו משמאל לימין:

- `[]` היא **רשימת הלכידה** (capture list) (עוד בהמשך). ריקה פירושה "לא משתמשת בכלום מבחוץ".
- `(int x)` היא רשימת הפרמטרים, בדיוק כמו בפונקציה רגילה.
- `{ return x * x; }` הוא הגוף. טיפוס ההחזרה מוסק מה-`return`.
- `auto square = ...` שומרת את הלמבדה במשתנה. לטיפוס האמיתי שלה אין שם שאפשר לכתוב, ולכן משתמשים ב-`auto`.

אפשר גם להשתמש בלמבדה מיד, בלי משתנה. העברה שלה לאלגוריתם היא השימוש הנפוץ ביותר:

```cpp
vector<int> v = {5, 3, 9, 1};
sort(v.begin(), v.end(), [](int a, int b) { return a > b; });   // biggest first
// v is now 9 5 3 1
```

הארגומנט השלישי אומר ל-`sort` איך להשוות שני פריטים: החזירו `true` כש-`a` צריך לבוא לפני `b`.

## לכידות (captures)

למבדה לא רואה משתנים מקומיים של הפונקציה שמסביבה אלא אם לוכדים אותם.

```cpp
int factor = 3;
auto times = [factor](int x) { return x * factor; };   // copy of factor
cout << times(5);        // prints: 15
```

| לכידה | משמעות |
|---|---|
| `[]` | כלום |
| `[x]` | **עותק** של x, שנוצר כשהלמבדה נוצרת |
| `[&x]` | **הפניה** ל-x המקורי |
| `[=]` | עותקים של כל מה שהלמבדה משתמשת בו |
| `[&]` | הפניות לכל מה שהלמבדה משתמשת בו |

עותק קפוא: שינוי של `factor` אחר כך לא משנה את `times`. עותק גם נשאר לקריאה בלבד בתוך הלמבדה אלא אם כותבים `mutable`. עם הפניה, הלמבדה יכולה לשנות את המקור:

```cpp
int calls = 0;
auto counted = [&calls](int x) { calls++; return x + 1; };
counted(1);
counted(2);
cout << calls;           // prints: 2
```

היזהרו עם `[&]`: אם הלמבדה חיה יותר מהמשתנה (למשל כשמחזירים אותה מפונקציה), ההפניה נשארת תלויה (dangling) והשימוש בה הוא התנהגות לא מוגדרת.

## std::function

לכל למבדה יש טיפוס ייחודי משלה וללא שם, ולכן אי אפשר לשים שתי למבדות שונות באותו וקטור או באותה מפה. `std::function<ReturnType(ParameterTypes)>` מ-`<functional>` הוא מכל אוניברסלי לכל דבר שאפשר לקרוא לו:

```cpp
map<string, function<int(int, int)>> ops;
ops["add"] = [](int a, int b) { return a + b; };
ops["mul"] = [](int a, int b) { return a * b; };

cout << ops["add"](5, 7);    // prints: 12
```

`function<int(int, int)>` פירושו "משהו שאפשר לקרוא לו עם שני מספרים שלמים והוא מחזיר מספר שלם". הוא מקבל גם פונקציות רגילות ואובייקטי פונקציה. כך בונים תפריטים, מטפלי אירועים וטבלאות פקודות: מחפשים את הפעולה לפי שם, ואז קוראים לה.

ל-`std::function` יש עלות קטנה בזמן ריצה בהשוואה ללמבדה גולמית או ל-`auto`. לפרמטרים שמקבלים callback אפשר גם להשתמש בתבנית, אבל `function` הכי פשוטה לקריאה.

> **שימו לב:**
> - שכחתם ללכוד: `error: 'factor' is not captured`. הוסיפו אותו לסוגריים המרובעים.
> - שינוי של עותק שנלכד: `error: assignment of read-only variable 'x'`. לכדו בהפניה `[&x]` או סמנו את הלמבדה `mutable`.
> - הפניה תלויה: החזרת למבדה שלכדה משתנה מקומי בהפניה נותנת זבל או קורסת מאוחר יותר. לכדו לפי ערך במקום.
> - חתימה שגויה עבור `function`: השמת למבדה שמקבלת int אחד ל-`function<int(int, int)>` נותנת `error: no match for call` או שגיאת המרה.
> - שכחתם את הנקודה-פסיק אחרי הסוגר המסולסל הסוגר של למבדה ששמורה במשתנה: `error: expected ';'`.

## להמשיך הלאה

השתמשו ב-`count_if(v.begin(), v.end(), [](int n) { return n % 2 == 0; })` כדי לספור מספרים זוגיים, או צרו `vector<function<void()>>` של פעולות והריצו אותן בלולאה.

> **תורכם:** כתבו את חמש הלמבדות שההערות מתארות: `square`, `times` (לכידה לפי ערך), השוואת `sort` יורדת, מפה של פעולות עם `function<int(int, int)>`, ו-`counted` (לכידה בהפניה).
