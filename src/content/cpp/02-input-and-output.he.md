עד עכשיו התוכניות שלכם רק דיברו. מעכשיו הן גם יקשיבו. בשיעור הזה תשתמשו ב-`cin` כדי לקרוא מספרים ומילים, וב-`getline` כדי לקרוא שורת טקסט שלמה, על כל הרווחים שבה.

## קריאה עם cin

`cin` (console input, קלט מהקונסולה) הוא ההיפך של `cout`. הוא משתמש בחצים לכיוון ההפוך, `>>`, כי הנתונים זורמים מהקלט *אל* המשתנה שלכם:

```cpp
int age;
cin >> age;                 // reads a number
string word;
cin >> word;                // reads one word
cout << word << " " << age << endl;
```

אפשר לשרשר קריאות, בדיוק כמו ששרשרתם `<<`:

```cpp
int x, y;
cin >> x >> y;              // input "3 4" gives x = 3, y = 4
```

`cin >>` מדלג על רווחים ועל שורות חדשות לפני הערך, וקורא עד התו הלבן הבא. הוא גם ממיר את הטקסט לסוג של המשתנה (`int`, `double`, `string`, `char`).

באתר הזה הטקסט שמקלידים בלשונית **Input** של העורך נמסר לתוכנית שלכם כאילו אדם הקליד אותו. שנו אותו והריצו שוב כדי לנסות ערכים אחרים.

## קריאת שורה שלמה עם getline

שם כמו `Ava Lovelace Smith` מכיל רווחים, ולכן `cin >>` היה מקבל רק את `Ava`. השתמשו ב-`getline`:

```cpp
string line;
getline(cin, line);         // reads everything up to the end of the line
```

## המלכודת של שורה חדשה שנשארה

אחרי `cin >> age`, מקש Enter שבא אחרי המספר עדיין מחכה בקלט. אם תקראו ל-`getline` מיד, הוא יראה את שארית השורה הריקה הזו ויחזיר מחרוזת ריקה. כך מתקנים את זה: זורקים קודם את תו השורה החדשה:

```cpp
cin >> age;
cin.ignore();               // skip the leftover newline
getline(cin, line);         // now reads the next real line
```

(`cin.ignore()` מדלג על תו אחד; הגרסה `cin.ignore(1000, '\n')` מדלגת עד סוף השורה גם כשיש רווחים בסופה.)

## האם הקריאה הצליחה?

אם הקלט חסר או מסוג שגוי, הקריאה נכשלת והמשתנה שומר על הערך הישן שלו (מאז C++11 הוא הופך ל-`0` במספרים). קריאה בתוך תנאי אומרת לכם אם היא הצליחה, וזה נותן לולאה (loop) אלגנטית:

```cpp
int n, total = 0;
while (cin >> n) {          // true as long as a number was read
    total += n;
}
```

> **שימו לב:**
> - ערבוב של `cin >>` ו-`getline` בלי `cin.ignore()` גורם ל-`getline` להחזיר שורה ריקה. שום דבר לא קורס, ולכן קל לפספס את הבאג.
> - שימוש ב-`<<` עם `cin` (או ב-`>>` עם `cout`) גורם ל-`error: no match for 'operator<<'`. החצים מצביעים לאן שהנתונים הולכים.
> - קריאה לתוך משתנה שלא הוגדר גורמת ל-`error: 'age' was not declared in this scope`.
> - תמיד אתחלו משתנים (`int age = 0;`) כדי שגם אחרי קריאה שנכשלה יישאר ערך ידוע.

## להמשיך הלאה

קראו `double` והדפיסו את מחציתו. אחר כך נסו להקליד טקסט במקום מספר בלשונית Input, והדפיסו אם `cin >> n` הצליח.

> **תורכם:** קראו את `first` ואת `age` עם `cin >>` והדפיסו את הברכה, השתמשו ב-`cin.ignore()` וב-`getline` כדי לקרוא את השם המלא, ואז קראו שלושה מספרים בפקודה אחת והדפיסו את הסכום שלהם.
