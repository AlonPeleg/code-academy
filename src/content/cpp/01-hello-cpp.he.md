בשיעור הזה תכתבו, תקמפלו ותריצו את תוכנית ה-C++ הראשונה שלכם. השפה C++ בנויה על שפת C ומוסיפה לה מחלקות (classes), מחרוזות, מבני נתונים וכלים רבים נוספים. היא מפעילה דפדפנים, מנועי משחקים, מסדי נתונים ומערכות מסחר מהירות במיוחד, ולכן זו מיומנות שמשתלמת.

## מקומפלת, לא מפורשת

C++ היא שפה **מקומפלת**: תוכנה שנקראת מהדר (compiler) מתרגמת את כל הקובץ שלכם לקוד מכונה לפני שמשהו רץ. כשלוחצים על **Run**, הקוד נשלח לשרת הרצה שמקמפל אותו עם `g++` ושולח חזרה את הפלט. אם המהדר מוצא טעות, תראו במקום זה את הודעת השגיאה שלו.

## התוכנית השימושית הקטנה ביותר

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello!" << endl;
    return 0;
}
```

בואו נעבור על כל חלק:

- `#include <iostream>` מביא את כלי הקלט והפלט (`cout` לפלט, `cin` לקלט).
- `using namespace std;` אומר שאפשר לכתוב את שמות הספרייה הסטנדרטית בקיצור. בלעדיו הייתם צריכים לכתוב `std::cout` ו-`std::endl` בכל פעם.
- `int main()` היא הפונקציה (function) שבה מתחילה כל תוכנית C++. `int` אומר שהיא מחזירה מספר שלם כשהיא מסתיימת.
- `{ ... }` מכילים את גוף הפונקציה.
- `cout << "Hello!"` שולח טקסט אל פלט הקונסולה (**c**onsole **out**put). החצים `<<` מצביעים לכיוון שבו הנתונים זורמים.
- `endl` מסיים את השורה (כמו לחיצה על Enter). אפשר גם לכתוב `"\n"` בתוך הטקסט כדי לעבור שורה.
- `;` מסיים כל פקודה.
- `return 0;` מסיים את `main`; הערך `0` פירושו "הצלחה".
- `//` פותח **הערה** (comment), שהמהדר מתעלם ממנה.

## שרשור והדפסת כמה שורות

אפשר לשרשר כמה `<<` בפקודה אחת ולערבב טקסט ומספרים:

```cpp
cout << "Two plus two is " << 2 + 2 << endl;   // prints: Two plus two is 4
cout << "First" << endl;
cout << "Second" << endl;
```

> **שימו לב:**
> - כתיבה של `cout >> "Hi"` (חצים הפוכים) גורמת ל-`error: no match for 'operator>>'`. בפלט משתמשים ב-`<<`.
> - שכחת נקודה-פסיק גורמת ל-`error: expected ';' before 'return'`.
> - שכחת `#include <iostream>` גורמת ל-`error: 'cout' was not declared in this scope`.
> - גרש בודד מיועד לתו אחד (`'A'`), ומרכאות כפולות לטקסט (`"Hello"`).
> - בלי `endl` (או `\n`) הפלט הבא ממשיך באותה שורה.

## להמשיך הלאה

הדפיסו את השם שלכם בשורה שנייה, ואז נסו `cout << "A" << "B" << endl;` וראו שלא מתווסף דבר בין החלקים.

> **תורכם:** בתוך `main`, השתמשו ב-`cout` כדי להדפיס `Hello, C++!` בשורה משלו.
