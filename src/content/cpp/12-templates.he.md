דמיינו שאתם צריכים פונקציה שמחזירה את הגדול משני מספרים. אתם כותבים אותה עבור `int`. אחר כך צריך אותה עבור `double`, ואחר כך עבור `string`. שלוש הגרסאות זהות חוץ מהטיפוס. העתקה והדבקה היא רעיון רע, ולכן C++ נותנת לכם **תבניות** (templates): כותבים את הקוד פעם אחת עם placeholder במקום הטיפוס, והקומפיילר מפיק גרסה אמיתית לכל טיפוס שמשתמשים בו.

## תבנית פונקציה

```cpp
template <typename T>
T maxOf(T a, T b) {
    return a > b ? a : b;
}

cout << maxOf(3, 7);        // T becomes int, prints: 7
cout << maxOf(2.5, 1.5);    // T becomes double, prints: 2.5
```

אחד אחד:

- `template <typename T>` אומרת "מה שבא אחרי משתמש בטיפוס placeholder בשם `T`". (`class T` פירושו בדיוק אותו דבר; `T` הוא רק שם, גם `Type` או `Item` יעבדו.)
- `T maxOf(T a, T b)` היא פונקציה רגילה שהפרמטרים וטיפוס ההחזרה שלה משתמשים ב-`T`.
- `a > b ? a : b` הוא אופרטור התנאי: "אם a גדול יותר קחו את a, אחרת את b".
- כשקוראים ל-`maxOf(3, 7)` הקומפיילר **מסיק** `T = int` מהארגומנטים ומייצר את `int maxOf(int a, int b)`. אפשר גם לציין זאת בעצמכם: `maxOf<double>(3, 7)`.

היצירה הזאת קורית ב**זמן קומפילציה**, ולכן תבניות לא עולות כלום בזמן ריצה, והקוד שנוצר מהיר כאילו כתבתם אותו ביד.

## במה טיפוס חייב לתמוך

גוף התבנית נבדק רק כשמשתמשים בו עם טיפוס מסוים. `maxOf` צריכה ש-`>` יעבוד על `T`. למספרים ול-`std::string` יש אותו, ולכן הם עובדים. טיפוס בלי `operator>` גורם לקומפיילר להתלונן בתוך התבנית, וההודעות האלה יכולות להיות ארוכות. קראו את שורת השגיאה הראשונה: בדרך כלל היא מציינת את האופרטור החסר.

## תבנית מחלקה

גם מחלקות יכולות להיות תבניות. הספרייה הסטנדרטית מלאה בהן: `vector<int>`, `map<string, int>`, `optional<T>`.

```cpp
template <typename T>
class Box {
    T value_;

public:
    Box(T v) : value_(v) {}
    T get() const { return value_; }
};

Box<int> a(5);
Box<string> b("hi");
cout << a.get() << " " << b.get();   // prints: 5 hi
```

במחלקות חייבים לכתוב את הטיפוס בסוגריים משולשים: `Box<int>`. (מאז C++17 הקומפיילר יכול לפעמים להסיק אותו מארגומנטי הבנאי, ולכן `Box c(5);` עובד, אבל לכתוב אותו במפורש ברור יותר למתחילים.)

## שני פרמטרי טיפוס או יותר

```cpp
template <typename K, typename V>
struct Entry {
    K key;
    V value;
};

Entry<string, int> e{"age", 30};
```

## איפה לשים תבניות

הקומפיילר צריך לראות את גוף התבנית המלא בכל מקום שבו משתמשים בה. לכן תבניות בדרך כלל יושבות כולן בקבצי header ולא מפוצלות להצהרה ולהגדרה נפרדת בקובץ cpp. בשיעור הזה, שהוא קובץ יחיד, הגדירו את התבנית מעל `main`.

> **שימו לב:**
> - טיפוסי ארגומנטים מעורבים: `maxOf(3, 2.5)` נותנת `error: no matching function for call to 'maxOf(int, double)'` כי `T` לא יכול להיות שניהם. כתבו `maxOf<double>(3, 2.5)` או המירו ארגומנט אחד.
> - העברת ליטרלים של מחרוזות: `maxOf("apple", "pear")` משווה **מצביעים**, לא טקסט, ועלולה גם להיכשל כי למערכים יש גדלים שונים. עטפו אותם ב-`string(...)`.
> - שכחתם את הטיפוס במחלקה: `Pair p(4, 9);` אולי יעבוד ב-C++17, אבל `Pair p;` נותנת `error: missing template arguments before 'p'`.
> - שכחתם `template <typename T>` על כל פונקציה נפרדת שמשתמשת ב-`T`: `error: 'T' was not declared in this scope`.
> - הודעות שגיאה ארוכות מגיעות מכך שהקומפיילר יוצר מופע (instantiates) של התבנית. חפשו את השורה שמזכירה את הקוד שלכם.

## להמשיך הלאה

הוסיפו תבנית פונקציה `printAll` שמקבלת `vector<T>` ומדפיסה כל איבר, או הוסיפו תבנית מחלקה שנייה `Stack<T>` שבנויה על `vector<T>` עם `push`, `pop` ו-`empty`.

> **תורכם:** כתבו את תבנית הפונקציה `maxOf` ואת תבנית המחלקה `Pair<T>` (בנאי, `larger`, `swapValues`, `first`, `second`) כך שהפונקציה `main` תדפיס את שש השורות הצפויות.
