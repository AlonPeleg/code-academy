כוחן של תוכניות נובע משני דברים: **קבלת החלטות** ו**חזרה על פעולות**. בשיעור הזה תשתמשו ב-`if`/`else` להחלטות וב-`for` וב-`while` ללולאות (loops). אם ראיתם שפה אחרת, זה ירגיש מוכר, אבל לתחביר של C++ יש פרטים משלו.

## תנאים עם if

```cpp
int temp = 25;

if (temp > 30) {
    cout << "Hot" << endl;
} else if (temp > 20) {
    cout << "Warm" << endl;
} else {
    cout << "Cool" << endl;
}
// prints: Warm
```

C++ בודקת את התנאים מלמעלה למטה ומריצה את הבלוק **הראשון** שהתנאי שלו נכון, ואז מדלגת על כל השאר. ה-`else` האחרון הוא אופציונלי ותופס את כל מה שנשאר.

| אופרטור | משמעות |
| --- | --- |
| `==` `!=` | שווה, לא שווה |
| `<` `<=` `>` `>=` | השוואות |
| `&&` | וגם (שניהם נכונים) |
| `\|\|` | או (לפחות אחד נכון) |
| `!` | לא |

תנאים הם מסוג `bool` (`true` או `false`). גם מספרים עובדים: `0` נחשב לשקר, וכל השאר לאמת.

## לולאת for

```cpp
for (int i = 0; i < 3; i++) {
    cout << i << endl;
}
// prints: 0 then 1 then 2
```

שלושת החלקים הם: **התחלה** (`int i = 0`, רצה פעם אחת), **תנאי** (`i < 3`, נבדק לפני כל סבב) ו**צעד** (`i++`, רץ אחרי כל סבב; פירושו הוספת 1).

## לולאת while

השתמשו ב-`while` כשאינכם יודעים מראש כמה סבבים נדרשים:

```cpp
int count = 3;
while (count > 0) {
    cout << count << endl;
    count--;
}
// prints: 3 then 2 then 1
```

התנאי נבדק לפני כל סבב. אם שום דבר בגוף הלולאה לא הופך אותו ללא נכון, הלולאה רצה לנצח (*לולאה אינסופית*).

## אופרטור השארית

`%` נותן את השארית של חילוק מספרים שלמים: `7 % 3` הוא `1`. מספר הוא זוגי כש-`n % 2 == 0`, וכפולה של 5 כש-`n % 5 == 0`. זכרו גם שחילוק של שני `int` זורק את הספרות אחרי הנקודה: `7 / 2` הוא `3`.

> **שימו לב:**
> - כתיבה של `if (x = 5)` מבצעת השמה במקום השוואה והתנאי תמיד נכון. השתמשו ב-`==`. המהדר מזהיר: `suggest parentheses around assignment used as truth value`.
> - נקודה-פסיק מיד אחרי `if (...)`, `for (...)` או `while (...)` מסיימת את הפקודה, והבלוק שמתחתיה כבר לא שייך אליה.
> - הפרש של אחד (off-by-one): `i < 15` נעצר ב-14, ו-`i <= 15` כולל את 15.
> - אם שוכחים לשנות את המשתנה בלולאת `while`, מתקבלת לולאה אינסופית. שרת ההרצה עוצר אותה אחרי כמה שניות עם שגיאת מגבלת זמן.
> - הסדר בשרשרת `else if` חשוב: שימו את הבדיקה הספציפית ביותר ראשונה.

## להמשיך הלאה
