Snake הוא המשחק שעוסק בסתר ברשימות. הנחש הוא רשימה של תאים ברשת, תנועה פירושה הוספת תא אחד בחזית והסרת אחד מאחור, וגדילה פירושה דילוג על ההסרה. השיעור הזה מלמד שלושה רעיונות חשובים בתכנות משחקים: **רשת** (grid) במקום פיקסלים חופשיים, **צובר טיימר** (timer accumulator) לצעדים קבועים, ו**רשימה המשמשת כמו תור** (queue).

## חושבים בתאים

המסך הוא 320 על 240 פיקסלים, אבל Snake לא נע פיקסל אחר פיקסל. מחלקים אותו ל-16 עמודות ו-12 שורות של תאים בני 20 פיקסלים ושומרים מיקומים כצמדי `(column, row)` מסוג **tuple**, למשל `(5, 5)`. tuple הוא זוג שאי אפשר לשנות, וזה בדיוק מה שרוצים למיקום. רק `draw` הופכת תאים לפיקסלים: `x = column * CELL`.

הנחש הוא רשימה של התאים האלה כשהראש ראשון:

```python
snake = [(5, 5), (4, 5), (3, 5)]    # head at column 5, tail at column 3
```

## צובר הטיימר

אילו הנחש היה נע בכל פריים הוא היה חוצה את המסך ברבע שנייה. אנחנו רוצים תא אחד כל `STEP = 0.15` שניות, אבל `update` רצה 60 פעמים בשנייה. הפתרון הרגיל הוא **צובר**: אוספים את הזמן שעבר, ומוציאים אותו במנות קבועות.

```python
timer = timer + dt
while timer >= STEP:
    timer = timer - STEP
    step()
```

כל פריים מוסיף קצת זמן. ברגע שנצבר לפחות `STEP`, מוציאים אותו בקריאה ל-`step()`. משתמשים ב-`while` ולא ב-`if` כדי שאחרי פריים איטי (נניח 0.4 שניות) המשחק ישלים פער בכמה צעדים. מפחיתים `STEP` ולא מאפסים את הטיימר ל-0, כדי שלא יאבדו חלקי שנייה. התבנית הזאת מופיעה בכל מקום: מנועי פיזיקה, יוצרי אויבים, אנימציות.

## צעד אחד של הנחש

בתוך `step()` מחשבים קודם את הראש החדש לפי הכיוון `(dx, dy)`: `head = (snake[0][0] + dx, snake[0][1] + dy)`. אחר כך:

1. **התרסקות?** אם הראש מחוץ לרשת, או `head in snake` (האופרטור `in` שואל "האם התא הזה כבר אחד מתאי הגוף?"), המצב הופך ל-`"dead"`.
2. `snake.insert(0, head)` שמה את הראש החדש בחזית.
3. **אוכל?** אם הראש נמצא על האוכל, מוסיפים נקודה ושומרים את הזנב. אחרת `snake.pop()` מסירה את התא האחרון. האורך נשאר זהה, והנחש רק החליק קדימה בתא אחד.

זה כל הטריק: נחש שאוכל ארוך בתא אחד כי דילגנו על ה-`pop`.

## היגוי

מקשי החצים רק משנים את `dx` ואת `dy` (למשל `dx, dy = -1, 0` פירושו "שמאלה"). פונקציית הצעד משתמשת בהם. שימו לב לשומר `and dx != 1`: נחש שנע ימינה אסור שיפנה ישר שמאלה, אחרת הראש שלו יתנגש בצוואר של עצמו. זה כלל קלאסי של הז'אנר.

> **שימו לב:** `IndexError: pop from empty list` או נחש שנעלם: ביצעתם pop בצעד שבו הנחש בדיוק אכל, או שהרשימה ההתחלתית ריקה. בצעו pop רק בענף ה-`else`.
>
> **שימו לב:** `UnboundLocalError: cannot access local variable 'score' where it is not associated with a value`: הוסיפו את `score` (ואת `state`) לשורת ה-`global` של הפונקציה שמשימה להם.
>
> **שימו לב:** לחיצה מהירה על שני מקשים עדיין יכולה להרוג אתכם. לחצו למטה ואז שמאלה בתוך צעד אחד של 0.15 שניות והנחש מתהפך, כי השומר רואה רק את הכיוון מהמקש האחרון. משחקים אמיתיים שומרים תור קטן של פניות. אתגר נחמד להמשך!
>
> **שימו לב:** לולאת `while` בלי `timer = timer - STEP` לא נגמרת לעולם ותקפיא את הדף. תמיד ודאו שהתנאי יכול להפוך לשקרי.
