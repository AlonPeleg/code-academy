עד עכשיו ציירנו קופסאות. בשיעור הזה תוסיפו עיגולים, קווים וטקסט, תלמדו איך צבעים באמת עובדים, ותצבעו סצנה קטנה. בדרך תכירו טיפוס חדש ב-Python: ה-**tuple** (רשימה קבועה של ערכים).

## צבעים הם tuples

כל צבע הוא שלושה מספרים: כמה אור **אדום**, **ירוק** ו-**כחול**, כל אחד מ-0 (כלום) עד 255 (מלא). Python מקבצת כמה ערכים בסוגריים עגולים ל-**tuple**:

```python
RED_LIKE = (255, 0, 0)       # all red, no green, no blue
SKY      = (120, 190, 255)   # a light blue
BLACK    = (0, 0, 0)
WHITE    = (255, 255, 255)
```

tuple דומה לרשימה (list), אבל **אי אפשר לשנות אותו** אחרי שיצרו אותו, וזה מושלם לצבע. השמות המובנים כמו `game.RED` או `game.CYAN` הם פשוט tuples ששמר עבורכם מישהו. אפשר להשתמש בשם או לכתוב את המספרים ישירות בקריאה:

```python
game.rect(10, 10, 50, 50, (255, 128, 0))   # an orange made on the spot
```

מתן שם באותיות גדולות לצבעים משלכם בראש הקובץ (`SKY = (...)`) שומר על קוד הציור קריא, ומאפשר לשנות את המראה של כל המשחק במקום אחד.

טיפ: ערבוב שווה נותן אפור (`(100, 100, 100)`), ערבוב אדום וירוק נותן צהוב (`(255, 255, 0)`), ומספרים גדולים יותר בהירים יותר. נסו ערכים בשיעור וראו מה קורה.

## ארגז כלי הציור

| קריאה | משמעות |
| --- | --- |
| `game.clear(color)` | ממלאת את כל המסך (עשו זאת ראשון). |
| `game.rect(x, y, w, h, color)` | מלבן. `(x, y)` היא הפינה **השמאלית העליונה**. |
| `game.circle(x, y, radius, color)` | עיגול. `(x, y)` הוא ה**מרכז**. |
| `game.line(x1, y1, x2, y2, color, width)` | קו בין שתי נקודות; `width` הוא העובי בפיקסלים (ברירת מחדל 1). |
| `game.text(x, y, message, color, size)` | טקסט. `(x, y)` הוא הפינה השמאלית העליונה; `size` בפיקסלים. |

הצבע עובד ב**שכבות**: מה שמציירים אחרון נוחת למעלה. לכן מציירים קודם את השמיים, אחר כך את הקרקע, ואת הדברים שבחזית בסוף.

```python
def draw():
    game.clear((120, 190, 255))             # sky
    game.circle(80, 50, 20, game.YELLOW)    # sun, on top of the sky
    game.line(0, 100, 320, 100, game.WHITE, 3)
    game.text(10, 10, "Score: " + str(5), game.WHITE, 16)
```

## מתכננים את התמונה עם קואורדינטות

זכרו ש-`(0, 0)` היא הפינה השמאלית העליונה ו-y גדל כלפי מטה. גזע שעולה מהקרקע `y = 180` **למעלה** עד `y = 130` יש לו y שני קטן יותר. כשסצנה נראית לא נכון, שרטטו אותה על נייר עם הרשת של 320 על 240.

## לערבב ציור ומצב

ציור הוא רק תמונה של המשתנים שלכם. בסצנה הזאת המיקום של השמש `sun_x` משתנה ב-`update`, ו-`draw` קוראת אותו, ולכן השמש נסחפת על פני השמיים. החלוקה הזאת (update משנה מספרים, draw מציגה אותם) זהה בכל משחק.

> **שימו לב:** `TypeError: a color must be three numbers like (255, 0, 0), but got None` פירושו שמשתנה צבע לא מולא מעולם (כמו `SKY = None` בקוד ההתחלתי), או שהעברתם רק שני מספרים.
>
> **שימו לב:** צבעים מחוץ לטווח 0 עד 255 עלולים להיראות מוזר. הישארו בטווח הזה.
>
> **שימו לב:** ב-`game.circle(100, 50, game.RED)` שכחתם את הרדיוס, ולכן המנוע קורא את הצבע כרדיוס. בדקו את הסדר: x, y, radius, color.
>
> **שימו לב:** צורה מוסתרת מאחורי צורה אחרת? היא צוירה מוקדם מדי. הזיזו את השורה שלה נמוך יותר ב-`draw`.

> **תורכם:** הפכו את `SKY` לצבע tuple משלכם, ואז ציירו את השמש עם עיגול, את גזע העץ עם קו עבה, את ראש העץ עם עיגול נוסף, וכותרת עם `game.text`. לחצו על Run כדי לראות, ואז בדקו.
