משחקים אמיתיים אינם לולאה אחת ארוכה של פעולה. יש מסך פתיחה, יש המשחק עצמו, יש מסך סיום ואולי גם הפסקה. כל אחד מאלה הוא **מצב** (state, או "מוד"), והמעבר ביניהם נקרא **מכונת מצבים** (state machine). בשיעור הזה תוסיפו חיים, ניקוד, מסך סיום והתחלה מחדש למשחק קטן של התחמקות.

## מצב הוא פשוט משתנה

מכונת המצבים הפשוטה ביותר היא משתנה טקסט:

```python
state = "playing"
```

המשחק תמיד נמצא בדיוק במצב אחד. ב-`update` עושים דברים שונים לכל מצב:

```python
def update(dt):
    if state == "playing":
        ...move things, check for hits...
    else:
        ...wait for enter...
```

וגם `draw` יכולה להציג תמונות שונות לכל מצב (הודעת "GAME OVER", למשל). המעבר בין מצבים הוא רק השמה של ערך חדש: `state = "game over"`. שימו לב לסימן השוויון הכפול: `==` **שואל** שאלה, ו-`=` **קובע** ערך.

## חיים וניקוד

שניהם מספרים רגילים:

- `lives = lives - 1` כשהשחקן נפגע,
- `score = score + 1` כשהוא מתחמק מבלוק.

כלל הסיום הוא השוואה: כשמתקיים `lives <= 0`, משנים את המצב. השתמשו ב-`<=` ולא ב-`== 0`, כדי שזה ימשיך לעבוד גם אם באג ייקח פעמיים חיים בפריים אחד.

```python
if lives <= 0:
    state = "game over"
```

## עצירת הפעולה

מכיוון שכל מה שזז נמצא בתוך `if state == "playing":`, העולם קופא ברגע שהמצב משתנה: הבלוק מפסיק ליפול ואי אפשר להפסיד עוד חיים. הציור (draw) ממשיך לרוץ, ולכן השחקן עדיין רואה את התמונה האחרונה ואת טקסט הסיום.

## התחלה מחדש עם פונקציית reset

כשהשחקן לוחץ על **enter**, צריך להחזיר כל מספר לערך ההתחלתי שלו. שימו את השורות האלה בפונקציה אחת וקראו לה בכל פעם שצריך משחק חדש:

```python
def reset():
    global lives, score, state
    lives = 3
    score = 0
    state = "playing"
```

השתמשו ב-`game.key_pressed("enter")` (ולא ב-`key_down`), כדי שלחיצה אחת תתחיל מחדש בדיוק פעם אחת. פונקציית `reset()` נוחה כי ערכי ההתחלה של המשחק כתובים במקום אחד.

## מבט על הדוגמה

הקוד ההתחלתי מפיל בלוק אדום מלמעלה, תמיד ב-`x = 150`. השחקן (ברוחב 40) מחליק שמאלה וימינה כדי להתחמק ממנו. הפונקציה `hit()` מחזירה `True` כשהבלוק חופף לשחקן. פגיעה עולה בחיים ומחזירה את הבלוק למעלה, והתחמקות נקייה מקנה נקודה.

> **שימו לב:** `UnboundLocalError` כשמשימים ל-`state` או ל-`lives` ב-`update` אומרת שהם חסרים בשורת ה-`global`.
>
> **שימו לב:** סימן `=` בודד ב-`if state = "playing":` הוא `SyntaxError`. השתמשו ב-`==` להשוואה.
>
> **שימו לב:** ה-`else:` חייב להיות מיושר (באותה הזחה) עם `if state == "playing":`. אם תזיחו אותו יותר, הוא הופך ל-else של `if` אחר, וההתחלה מחדש לא קורית, בלי שום הודעת שגיאה.
>
> **שימו לב:** כתיבת `"Game Over"` במקום אחד ו-`"game over"` במקום אחר: המחרוזות שונות, ולכן בדיקת המצב נכשלת בשקט. העתיקו בדיוק את אותו טקסט.

> **תורכם:** אחרי קוד הפגיעה, העבירו את המצב ל-`"game over"` כש-`lives <= 0`. אחר כך הוסיפו `else:` שממתין ל-`game.key_pressed("enter")` וקורא ל-`reset()`. הריצו (Run), עמדו במקום, הפסידו שלושה חיים ואז לחצו על enter.
