משחק שאי אפשר לשלוט בו הוא סתם שומר מסך. בשיעור הזה תקראו את המקלדת ותגרמו לשחקן לנוע בכל ארבעת הכיוונים, במהירות שלא תלויה בכמה מהיר המחשב.

## לשאול "האם המקש הזה מוחזק?"

המנוע נותן לכם שתי שאלות שאפשר לשאול על מקש:

| פונקציה | True כאשר... | משתמשים בה עבור |
| --- | --- | --- |
| `game.key_down("left")` | המקש **מוחזק**, בכל פריים | הליכה, היגוי |
| `game.key_pressed("space")` | המקש **נלחץ בפריים הזה בדיוק** | קפיצה, ירי |

שמות המקשים שאפשר להשתמש בהם הם `left right up down space a d w s z x enter`. השמות הם טקסט, ולכן הם צריכים מרכאות. את `key_pressed` תשתמשו בשיעור מאוחר יותר; היום הכול `key_down`.

מכיוון ש-`update` רצה בערך 60 פעמים בשנייה, שואלים את השאלה מחדש בכל פריים:

```python
def update(dt):
    global x
    if game.key_down("right"):
        x = x + speed * dt
```

כל עוד מחזיקים את החץ ימינה, `key_down("right")` היא `True` בכל פריים ו-`x` גדל מעט בכל פעם. מרפים, ושום דבר לא קורה.

## למה dt חשוב (שוב)

דמיינו ש-`speed = 120` פיקסלים בשנייה. ב-60 פריימים לשנייה `dt` הוא בערך `1/60`, ולכן כל פריים מזיז `120 * (1/60) = 2` פיקסלים. ב-120 פריימים לשנייה `dt` הוא `1/120`, כל צעד הוא פיקסל אחד, אבל יש פי שניים צעדים. אחרי שנייה אחת השחקן נע 120 פיקסלים בשני המקרים. אילו שכחתם את `dt` והוספתם `2` בכל פריים, השחקן במחשב המהיר היה נע מהר פי שניים, והמשחק היה מרגיש אחרת לכל שחקן.

## ארבעה כיוונים, ארבעה if

כל כיוון הוא `if` משלו. זכרו את כיווני הצירים:

- ימינה: `x` גדל, שמאלה: `x` קטן.
- למטה: `y` גדל, למעלה: `y` קטן (y נספר מ**למעלה**).

מכיוון שאלה משפטי `if` נפרדים, החזקת שני מקשים עובדת בחינם: החזיקו ימינה ולמטה והשחקן יזוז באלכסון.

```python
if game.key_down("a"):
    x = x - speed * dt    # the letter keys work too: a d w s
```

## להפוך את המהירות למשתנה

שמירת המהירות במשתנה (`speed = 120`) מאפשרת לכוונן את תחושת המשחק על ידי שינוי מספר אחד. נסו `60` לשחקן מנומנם ו-`300` לרקטה. אפשר אפילו לגרום לשחקן להיות מהיר יותר כל עוד מקש כמו `x` מוחזק, וזה ניסוי נחמד להמשך.

> **שימו לב:** `game.key_down(left)` בלי מרכאות מעלה `NameError: name 'left' is not defined`. שמות מקשים הם טקסט.
>
> **שימו לב:** הכתיבה `game.key_down("Left")` עובדת (המנוע הופך שמות לאותיות קטנות), אבל `"arrow_left"` או `"leftarrow"` אינם מקשים ופשוט לא ילחצו לעולם. השתמשו בדיוק ב-`left right up down`.
>
> **שימו לב:** אם שכחתם להוסיף את `y` לשורת ה-`global`, מקבלים `UnboundLocalError` כשמנסים לשנות את `y`.
>
> **שימו לב:** השחקן נע בכיוון הלא נכון אנכית? זכרו ש-y גדל כלפי מטה, ולכן "למעלה" חייב **לחסר**.
