פונג הוא סבא של כל משחקי הווידאו, והוא משחק "אמיתי" ראשון מושלם: שני מחבטים, כדור אחד, ניקוד. בשיעור הזה תבנו אותו כולו, וכל חלק הוא משהו שאתם כבר מכירים: משתנים למיקומים, משפטי `if` לכללים, והטריק של `dt` לתנועה חלקה. הרעיון החדש הוא **מהירות כווקטור** (velocity): לכדור אין רק מיקום, יש לו גם מהירות וכיוון, וקפיצה פשוט הופכת את הכיוון הזה.

## מצב המשחק

כל מה שיכול להשתנות נמצא במשתנה גלובלי:

| משתנה | משמעות |
|---|---|
| `py`, `ay` | הקצה העליון של המחבט שלכם ושל מחבט המחשב |
| `bx`, `by` | מרכז הכדור |
| `vx`, `vy` | מהירות הכדור בפיקסלים לשנייה (`vx` שלילי פירושו "נע שמאלה") |
| `pscore`, `ascore` | הנקודות שלכם ושל המחשב |
| `hits` | כמה פעמים מחבט פגע בכדור (שימושי לבדיקות) |

בכל פריים `update(dt)` משנה את המספרים האלה ו-`draw()` מציירת אותם. הכדור נע באותו מתכון כמו השחקן בשיעורים הראשונים: `bx = bx + vx * dt`. מכיוון שמכפילים ב-`dt` (השניות מאז הפריים הקודם), הכדור עובר 150 פיקסלים בשנייה בלי קשר למהירות המחשב.

## שלב 1: המחבט שלכם

מקשי החצים משנים את `py`. הרעיון החדש היחיד הוא **הגבלת טווח** (clamping): `max` בוחרת את הגדול משני מספרים ו-`min` את הקטן, ולכן `max(0, py - 200 * dt)` לעולם לא יעלה מעל הקצה העליון, ו-`min(game.HEIGHT - PADDLE_H, ...)` לעולם לא ישקע מתחת לקצה התחתון.

```python
if game.key_down("up"):
    py = max(0, py - 200 * dt)
```

## שלב 2: יריב מחשב

הבינה המלאכותית היא כמה שורות של "רדוף אחרי הכדור". משווים את הקצה העליון של המחבט למקום שהוא היה רוצה להיות בו (`target`, גובה הכדור פחות חצי מהמחבט) ודוחפים אותו לשם. אזור מת של 4 פיקסלים מונע מהמחבט לרעוד כשהוא כבר מיושר:

```python
target = by - PADDLE_H / 2
if ay < target - 4:
    ay = ay + 70 * dt
```

שימו לב למהירות: 70 פיקסלים לשנייה, איטית מהמהירות האנכית של הכדור שהיא 95. זו החלטת עיצוב. יריב שמתאים לכדור באופן מושלם לעולם לא מפסיד, ואף אחד לא נהנה מזה. שנו מאוחר יותר את ה-70 ל-200 והרגישו את ההבדל.

## שלב 3: קפיצה

קפיצה היא היפוך סימן. מחבט הוא קיר אנכי, ולכן הוא הופך את `vx`. אנחנו גם מכפילים ב-1.05 כך שכל פגיעה מהירה את הכדור ב-5%, וזה הופך את ההחלפות למתוחות. הפונקציה `on_paddle` (כבר כתובה) עונה על "האם הכדור נוגע במחבט הזה?", כך שהקוד נקרא כמו משפט:

```python
if vx < 0 and on_paddle(10, py):
    vx = -vx * 1.05
```

החלק `vx < 0` הוא **שומר כיוון** (direction guard). מיד אחרי קפיצה הכדור עשוי עוד להיות חופף למחבט לפריים או שניים; בלי השומר הוא היה מתהפך שוב ונתקע ברעידה בתוך המחבט.

## שלב 4: נקודות והגשה

כשהכדור עוזב את המסך מישהו הבקיע. מוסיפים נקודה וקוראים ל-`serve(direction)`, שמחזירה את הכדור לאמצע ושולחת אותו לצד אחד. הקירות העליון והתחתון כתובים בשבילכם, והם משתמשים ב-`abs()` כדי שהכדור לעולם לא ייתקע בקיר: `vy = abs(vy)` פירושו "לך למטה", לא משנה מה היה הסימן.

> **שימו לב:** `UnboundLocalError: cannot access local variable 'hits' where it is not associated with a value` אומרת שמשתנה שאתם משנים ב-`update` חסר בשורת ה-`global` בראש הפונקציה.
>
> **שימו לב:** כדור שרוטט בתוך מחבט מקפץ בכל פריים. הוסיפו את שומר הכיוון (`vx < 0` או `vx > 0`).
>
> **שימו לב:** `TypeError: unsupported operand type(s)` בשורה כמו `py - 200 * dt` אומרת בדרך כלל שטעות כתיב הפכה מספר למחרוזת או לשם של פונקציה. הדפיסו את הערכים עם `print(py)` כדי לראות אותם ב-Console.
>
> **שימו לב:** אם נראה שהמחבט קופץ מחוץ למסך, בדקו באיזו מבין `max` ו-`min` השתמשתם. הקצה העליון משתמש ב-`max(0, ...)`, והתחתון ב-`min(..., ...)`.
