כרגע השחקן שלכם יכול ללכת ישר אל מחוץ למסך ולא לחזור לעולם. משחקים צריכים **גבולות**: קירות, רצפות, קצה העולם. בשיעור הזה תלמדו **להגביל** (clamp) מספר, כלומר להכריח אותו להישאר בתוך טווח.

## קצוות המסך

המסך הוא ברוחב `game.WIDTH` (320) פיקסלים ובגובה `game.HEIGHT` (240). המיקום `x = 0` הוא הקצה השמאלי ו-`y = 0` הקצה העליון. שימוש בשמות במקום במספרים 320 ו-240 הוא הרגל טוב: הקוד מסביר את עצמו, והוא ממשיך לעבוד גם אם גודל המסך משתנה.

יש בעיה אחת. המיקום `(x, y)` של מלבן הוא **הפינה השמאלית העליונה** שלו. ריבוע ברוחב 30 פיקסלים ב-`x = 300` מתחיל בתוך המסך אבל בולט 10 פיקסלים מהקצה הימני! המקום הרחוק ביותר ימינה שהפינה יכולה להגיע אליו הוא:

```python
game.WIDTH - size     # 320 - 30 = 290
```

כך גם בתחתית: `game.HEIGHT - size`.

## min ו-max

ב-Python יש שתי פונקציות מובנות קטנטנות שעושות את כל העבודה:

```python
print(min(3, 8))     # prints: 3   (the smaller one)
print(max(3, 8))     # prints: 8   (the bigger one)
```

- `max(0, x)` היא "x, אבל לא פחות מ-0". אם `x` הוא `-12`, מקבלים `0`.
- `min(x, 290)` היא "x, אבל לא יותר מ-290". אם `x` הוא `400`, מקבלים `290`.

חברו אותן ותוכלו לדחוס מספר לתוך טווח, מבפנים החוצה:

```python
x = max(0, min(x, game.WIDTH - size))
```

קראו את זה כך: קודם `min(x, 290)` מגבילה מלמעלה, ואז `max(0, ...)` מגבילה את התוצאה מלמטה. כך `x` תמיד נמצא בין `0` ל-`290`. שימו את השורה **אחרי** קוד התנועה כדי שתתקן כל חריגה מיד, לפני שהפריים מצויר.

## אותו דבר עם if

אפשר לעשות את אותה עבודה עם `if`, ויש מי שמוצאים אותו קל יותר לקריאה:

```python
if x < 0:
    x = 0
if x > game.WIDTH - size:
    x = game.WIDTH - size
```

שתי הדרכים טובות. `min`/`max` קצרה יותר, ותראו אותה במשחקים אמיתיים רבים.

## למה לא פשוט לעצור את התנועה?

אפשר לכתוב `if x < 290: x = x + ...` ולסרב לזוז בקצה, אבל אז צעד גדול עלול להעביר אתכם את הקצה בפריים אחד, ואתם עלולים להיתקע בחוץ. הגבלה אחרי התנועה פשוטה יותר ותמיד נכונה.

> **שימו לב:** בלבול בסדר, כמו `max(game.WIDTH - size, min(x, 0))`, יוצר טווח חסר היגיון והשחקן נדבק לקצה אחד. זכרו: `max` שומרת על הקצה התחתון, `min` שומרת על הקצה העליון.
>
> **שימו לב:** שכחה של `- size` מאפשרת לריבוע להחליק עד חציו מחוץ לקצה הימני והתחתון. אין קריסה; זה פשוט נראה לא נכון, ולכן בדקו בעיניים בכך שתדחפו כל קיר.
>
> **שימו לב:** `NameError: name 'WIDTH' is not defined` פירושו שכתבתם `WIDTH` לבדה. היא חיה בתוך המנוע, ולכן כתבו `game.WIDTH`.

## נסו בעצמכם

אחרי שזה עובד, גרמו לשחקן להקפיץ מהקירות במקום רק לעצור, או גרמו לו "להיעטף", כך שיציאה מהקצה הימני מחזירה אותו מהשמאלי.

> **תורכם:** בסוף `update`, הגבילו את `x` בין `0` ל-`game.WIDTH - size`, ואת `y` בין `0` ל-`game.HEIGHT - size`. הבדיקה מחזיקה את מקשי החצים מספיק זמן כדי לפגוע בכל קיר.
