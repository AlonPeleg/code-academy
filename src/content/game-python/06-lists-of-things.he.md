כדור אחד זה קל: משתנה `x` ומשתנה `y`. אבל במשחק ירי יש **הרבה** כדורים בבת אחת, ואף פעם לא יודעים כמה. הכלי ל"קבוצה של דברים" הוא **רשימה** (list). בשיעור הזה תשמרו כדורים ברשימה, תזיזו אותם בלולאה ותסירו אותם כשהם יוצאים מהמסך.

## רשימות ולולאות, בקצרה

רשימה מחזיקה הרבה ערכים לפי סדר, וכותבים אותה עם סוגריים מרובעים:

```python
bullets = []                 # an empty list
bullets.append([100, 200])   # add one bullet: x = 100, y = 200
bullets.append([150, 200])
print(len(bullets))          # prints: 2
print(bullets[0])            # prints: [100, 200]
print(bullets[0][1])         # prints: 200   (the y of the first bullet)
```

כל כדור הוא בעצמו רשימה קטנה `[x, y]`. `b[0]` הוא ה-x שלו ו-`b[1]` הוא ה-y שלו (רשימות סופרים מ-0). אפשר לשנות פריט בפנים: `b[1] = b[1] - 5`.

לולאת `for` עוברת על כל פריט:

```python
for b in bullets:
    b[1] = b[1] - 240 * dt     # every bullet moves up
```

כאן `b` הוא כל כדור בתורו. מכיוון ש-`b` הוא אותו אובייקט רשימה שנמצא בתוך `bullets`, שינוי שלו משנה את הכדור באמת. ב-`draw` משתמשים באותה לולאה כדי לצייר את כולם.

## יצירה עם key_pressed

זכרו ש-`key_down` אמת ב**כל** פריים כל עוד המקש לחוץ, וזה היה יוצר 60 כדורים בשנייה. כדי לירות יריה אחת בכל לחיצה משתמשים ב-**`key_pressed`**, שאמת רק בפריים שבו המקש יורד:

```python
if game.key_pressed("space"):
    bullets.append([player_x + 10, 200])
```

## הסרת הכדורים שמתו

כדורים שעפים מעבר לקצה העליון חייבים להימחק, אחרת הרשימה גדלה לנצח והמשחק מאט. כדור ב-`y = -10` נמצא כולו מעל המסך (הגובה שלו 10).

הדרך המפתה היא `bullets.remove(b)` בתוך הלולאה, אבל הסרה מרשימה **בזמן שעוברים עליה בלולאה** גורמת ללולאה לדלג על פריטים. הדרך הבטוחה היא לבנות **רשימה חדשה** עם השורדים, ואז להחליף את הרשימה הישנה:

```python
alive = []
for b in bullets:
    if b[1] > -10:        # still on screen
        alive.append(b)
bullets = alive           # (needs bullets on the global line)
```

בכל פריים הכדורים הישנים עוברים הלאה, והמתים נשארים בחוץ. זה פשוט, וזה תמיד עובד.

## הסדר חשוב קצת

קודם יצירה, אחר כך תנועה, ואז הסרה: כדור חדש זז קצת באותו פריים שבו נולד, וכדור שזה עתה יצא מהמסך מנוקה מיד. אם מסירים לפני התנועה, פשוט מסירים פריים אחד מאוחר יותר, וגם זה בסדר.

> **שימו לב:** `UnboundLocalError` ב-`bullets = alive` אומרת ש-`bullets` חסר בשורת ה-`global` בראש `update`. (קריאה ל-`bullets.append(...)` עובדת בלי `global`, אבל השמה של רשימה חדשה לא.)
>
> **שימו לב:** `IndexError: list index out of range` קורית כשמבקשים `bullets[0]` בזמן שהרשימה ריקה. בדקו קודם את `len(bullets)`.
>
> **שימו לב:** `TypeError: 'int' object is not subscriptable` אומרת שהשתמשתם ב-`b[1]` על מספר רגיל. האם `b` באמת רשימה `[x, y]`?
>
> **שימו לב:** מקלע של כדורים כשהרווח לחוץ אומר שהשתמשתם ב-`key_down` במקום ב-`key_pressed`.

## להמשך

הפכו את הכדורים למהירים יותר, גרמו לשחקן לירות שני כדורים בבת אחת, או הגבילו את השחקן ל-5 כדורים בכל רגע עם `if len(bullets) < 5:`.

בקוד ההתחלתי יש גם מונה `shots` שסופר כל כדור שנורה אי פעם. רשימה מראה רק מה חי *עכשיו*, ולכן מונה שימושי לניקוד או לתצוגת תחמושת, והוא מאפשר לבדיקה לראות שכדור באמת נורה ואחר כך נוקה.

> **תורכם:** כתבו את שלוש המשימות ב-`update`. כשלוחצים על רווח, הוסיפו כדור `[player_x + 10, 200]` והוסיפו 1 ל-`shots`. הזיזו כל כדור למעלה ב-`240 * dt`, ושמרו רק את הכדורים עם `y > -10`. בדקו בהרצה חיה: לחצו על רווח וראו את מונה הכדורים עולה ויורד.
