משחקים בסגנון Space Invaders נראים מסובכים (שורות של אויבים, כדורים בכל מקום), אבל הם בנויים משלוש תבניות פשוטות שאתם כבר מכירים: **רשימה** של דברים, **לולאה** שמעדכנת כל אחד מהם, ו**כללים** להסרתם. הרעיונות החדשים כאן הם הזזת קבוצה יחד כ**מערך** אחד (formation), ו**זמן קירור** (cooldown), טיימר קטן שמגביל כמה מהר אפשר לירות.

## מערך הוא רשימה עם כיוון משותף

כל חייזר הוא רשימה קטנה `[x, y]` וכולם נמצאים ברשימה אחת `aliens`, שנוצרת עם **הבנת רשימה** (list comprehension, לולאה שנכתבת בתוך הסוגריים):

```python
aliens = [[40 + c * 36, 30 + r * 24] for r in range(ROWS) for c in range(COLS)]
```

קראו אותה מהסוף: לכל שורה `r` ולכל עמודה `c`, צרו חייזר במרחק 36 פיקסלים אופקית ו-24 פיקסלים אנכית. זה 12 חייזרים עבור 2 שורות ו-6 עמודות.

כל המערך חולק כיוון אחד, `fdir` (1 לימין, -1 לשמאל). התנועה היא לולאה: `a[0] = a[0] + fdir * 40 * dt` לכל חייזר, כך שהם מחליקים יחד במהירות 40 פיקסלים לשנייה.

הטריק הוא בקצה. כשהחייזר הרחוק ביותר מגיע לקיר, הופכים את `fdir` ומורידים את כל החייזרים ב-12 פיקסלים. כדי למצוא את החייזר הרחוק ביותר, אוספים את ערכי ה-x עם הבנת רשימה (`xs = [a[0] for a in aliens]`) ומשתמשים ב-`max(xs)` או ב-`min(xs)`. שימו לב ל**בדיקת הכיוון**: מתהפכים בקצה הימני רק כשנעים ימינה (`fdir == 1 and max(xs) > 296`). אם מתעלמים מהכיוון, מיד אחרי ההיפוך החייזרים עדיין מעבר לקצה לפריים אחד, והקוד היה מתהפך שוב, ושוב: המערך היה רועד בקיר לנצח. בכל פעם שאתם הופכים משהו לפי תנאי, שאלו את עצמכם "האם התנאי עדיין יהיה נכון בפריים הבא?".

## ירי עם זמן קירור

אילו יריתם כדור בכל פריים כשמקש הרווח לחוץ, הייתם יורים 60 כדורים בשנייה. זמן קירור פותר את זה. הוא מספר שניות שסופר לאחור; מותר לירות רק כשהוא הגיע לאפס, וכל ירייה מחזירה אותו למעלה:

```python
cooldown = cooldown - dt
if game.key_down("space") and cooldown <= 0:
    bullets.append([px + 10, 205])
    cooldown = 0.35
```

בהשוואה ל-`key_pressed` (כדור אחד בכל לחיצה), זה נותן את התחושה של "להחזיק כדי להמשיך לירות" ועדיין שולט בקצב. אותה תבנית מגבילה כל יכולת במשחק: דאש, מגן, יצירת אויבים.

## כדורים נגד חייזרים

כל כדור צריך להיבדק מול כל חייזר, וזה אומר לולאה בתוך לולאה. כשכדור נמצא בתוך המלבן של חייזר, השוואה משורשרת נקראת באופן טבעי: `a[0] < b[0] < a[0] + 20`. בפגיעה החייזר מוסר, הניקוד עולה, והכדור חייב להיעלם גם הוא, וזה נעשה בכך שפשוט לא מעתיקים אותו לרשימה `alive`.

השורה החשובה היא `break`. אחרי `aliens.remove(a)` הרשימה השתנתה בזמן שהלולאה `for a in aliens` עדיין עוברת עליה, ו-Python הייתה מדלגת על חייזר. כדור יכול להרוג רק חייזר אחד בכל מקרה, ולכן יוצאים מהלולאה מיד.

## ניצחון והפסד

כשהרשימה ריקה השחקן מנצח: `len(aliens) == 0`. אם הקצה התחתון של חייזר מגיע לשורה של השחקן, הוא נחת והשחקן מפסיד. שני מצבי הסיום מקפיאים את המשחק עם `if state != "playing": return`, כמו בשיעורים הקודמים.

> **שימו לב:** `ValueError: list.remove(x): x not in list` מופיעה כשאותו חייזר מוסר פעמיים, למשל כששני כדורים פוגעים בו באותו פריים. ה-`break` והדגל `hit` מונעים את רוב המקרים האלה.
>
> **שימו לב:** `TypeError: 'int' object is not subscriptable`: `a[0]` דורשת ש-`a` תהיה רשימה `[x, y]`. בדקו שמשתנה הלולאה הוא החייזר ולא מספר.
>
> **שימו לב:** `UnboundLocalError ... 'bullets'`: השורה `bullets = alive` משימה רשימה חדשה, ולכן `bullets` חייב להיות בשורת ה-`global`.
>
> **שימו לב:** אם נראה שכדורים עוברים דרך החייזרים, הבדיקה משתמשת בנקודה השמאלית העליונה של הכדור, שנעה 4 פיקסלים בפריים. חייזרים בגובה 14 פיקסלים בסדר גמור, אויב בגובה 2 פיקסלים לא היה בסדר.
