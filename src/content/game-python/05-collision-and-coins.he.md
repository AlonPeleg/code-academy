משחקים מתעוררים לחיים כשדברים **נוגעים** זה בזה: השחקן תופס מטבע, כדור פוגע באויב, דמות נוחתת על הרצפה. הבדיקה "האם שני המלבנים האלה נוגעים?" נקראת **זיהוי התנגשות** (collision detection). בשיעור הזה תכתבו אותה פעם אחת כפונקציה (function), ותשתמשו בה כדי לאסוף מטבעות ולספור ניקוד.

## חפיפה, ציר אחד בכל פעם

דמיינו שני קטעים על ציר מספרים. קטע A הולך מ-`ax` עד `ax + aw`. קטע B הולך מ-`bx` עד `bx + bw`. הם חופפים כש-A מתחיל לפני ש-B נגמר **וגם** A נגמר אחרי ש-B מתחיל:

```python
ax < bx + bw  and  ax + aw > bx
```

שני מלבנים חופפים רק אם זה נכון בציר x **וגם** בציר y. חיבור ארבעת התנאים עם `and` נותן את הבדיקה המלאה:

```python
def touching(ax, ay, aw, ah, bx, by, bw, bh):
    return ax < bx + bw and ax + aw > bx and ay < by + bh and ay + ah > by
```

פונקציה ש-`return`-ת השוואה מחזירה `True` או `False`, ולכן אפשר לכתוב `if touching(...):` ישירות. שימו לב שאנחנו משתמשים ב-`<` וב-`>` ולא ב-`<=`: מלבנים שרק חולקים צלע לא נחשבים כנוגעים.

בדקו בראש עם `touching(0, 0, 10, 10, 5, 5, 10, 10)`: הריבועים חולקים שטח פינתי מ-5 עד 10, ולכן התוצאה `True`. עם `touching(0, 0, 10, 10, 20, 20, 5, 5)` הריבוע השני רחוק, ולכן התוצאה `False`.

## מטבע שקופץ

במקום ליצור מטבע חדש בכל פעם, שומרים **מטבע אחד** ומעבירים אותו למקום הבא כשהוא נאסף. המקומות נמצאים ברשימה (list) של צמדים (tuples):

```python
coin_spots = [(150, 100), (150, 30), (40, 30)]
coin_number = 0
cx, cy = coin_spots[coin_number]     # unpack a tuple into two variables
```

`coin_spots[0]` הוא הצמד הראשון, `(150, 100)`. הכתיבה `cx, cy = ...` מפצלת אותו לשני משתנים (זה נקרא *פירוק*, unpacking).

כשהשחקן נוגע במטבע:

```python
score = score + 1
coin_number = (coin_number + 1) % len(coin_spots)
```

`len(coin_spots)` הוא `3`. האופרטור `%` נותן את **השארית** של חילוק. הסדרה `0, 1, 2, 3, 4...` הופכת ל-`1, 2, 0, 1, 2...` כשעושים `(n + 1) % 3`, ולכן המטבע עובר ברשימה ומתחיל מחדש אחרי המקום האחרון, ואף פעם לא חורגים מסוף הרשימה.

> **למה רשימה קבועה ולא `random`?** רשימה קבועה הופכת את המשחק לצפוי. הבדיקה שלנו יכולה להוביל את השחקן לאורך מסלול מוכר ולדעת בדיוק כמה מטבעות נאספים. כשהמשחק שלכם עובד, החלפת הרשימה במיקומים אקראיים (`import random` ו-`random.randint(0, 300)`) היא שדרוג נחמד.

> **שימו לב:** `IndexError: list index out of range` אומרת ש-`coin_number` עבר את הסוף. ה-`% len(coin_spots)` מתקן את זה.
>
> **שימו לב:** אם שוכחים לשים את `score` ו-`coin_number` בשורת ה-`global`, מקבלים `UnboundLocalError`.
>
> **שימו לב:** בלבול בין הרוחב של מלבן למיקום ה-x שלו (`ax + aw` פירושו **הקצה הימני**). ציירו שני ריבועים על נייר אם אתם הולכים לאיבוד.
>
> **שימו לב:** אם הניקוד מזנק בעשרות בשנייה, המטבע לא התרחק אחרי שנגעו בו, ולכן הוא נספר בכל פריים.

## להמשיך הלאה

ציירו את המטבע כעיגול, הוסיפו טיימר, או גרמו לשחקן לגדול בכל פעם שנאסף מטבע.

> **תורכם:** השלימו את `touching` כך שתחזיר `True` רק כששני המלבנים חופפים, ואז, כשהשחקן נוגע במטבע, הוסיפו 1 ל-`score` והעבירו את `coin_number` למקום הבא (עם מעבר מעגלי בעזרת `%`).
