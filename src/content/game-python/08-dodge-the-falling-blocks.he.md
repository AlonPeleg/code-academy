זה הגמר: תסיימו משחק קטן ושלם בשם **Dodge!**. בלוקים אדומים נופלים מהשמיים, אתם מחליקים שמאלה וימינה כדי להתחמק מהם, כל התחמקות מקנה נקודה, כל פגיעה עולה בחיים, ובאפס חיים המשחק נגמר עד שלוחצים על enter. כל חלק כאן הוא משהו שכבר למדתם, ולכן השיעור הזה עוסק ב**חיבור** ביניהם.

## התוכנית

לפני שכותבים קוד, שרטטו את המשחק כרשימת משימות שקורות בכל פריים:

1. **קלט**: קוראים את חצי שמאלה וימינה ומזיזים את השחקן (עם הגבלה בעזרת `max`/`min` כדי להישאר על המסך). זה כבר נעשה בשבילכם.
2. **יצירה**: כל חצי שנייה בלוק חדש מופיע למעלה.
3. **תנועה והתנגשות**: כל בלוק נופל. אם הוא נוגע בשחקן מפסידים חיים, ואם הוא נופל מתחת למסך מקבלים נקודה.
4. **בדיקת המצב**: אין יותר חיים פירושו סיום משחק.
5. **ציור**: מציירים הכול לפי המספרים הנוכחיים.

המבנה הגדול ב-`update` הוא מכונת המצבים מהשיעור הקודם: כשהמצב הוא `"game over"` הפונקציה רק ממתינה ל-`enter` ואז עושה `return` מוקדם, כך שדבר אחר לא רץ. `return` בתוך פונקציה מסיים אותה מיד, וזו דרך נאה לדלג על כל השאר.

## TODO 1: טיימר ליצירה

`dt` הוא הזמן של פריים אחד, ולכן חיבור שלו שוב ושוב נותן את הזמן שעובר. התבנית ל"לעשות משהו כל חצי שנייה" היא:

```python
timer = timer + dt
if timer >= 0.5:
    timer = 0          # start counting again
    # ...do the thing...
```

הדבר הזה הוא `blocks.append([x, -20])`, כאשר `x` מגיע מהרשימה `SPAWN_X`. האופרטור `%` מחזיר את האינדקס ל-0 אחרי המיקום האחרון:

```python
x = SPAWN_X[spawned % len(SPAWN_X)]
```

## TODO 2: הלולאה שעושה הכול

זו תבנית "בונים רשימה חדשה" מהשיעור על הכדורים, עם שלוש תוצאות אפשריות לכל בלוק:

```python
alive = []
for b in blocks:
    b[1] = b[1] + 150 * dt        # fall
    if touching(...):             # hit: it vanishes and costs a life
        lives = lives - 1
    elif b[1] > game.HEIGHT:      # dodged: it vanishes and scores
        score = score + 1
    else:                         # still falling: keep it
        alive.append(b)
blocks = alive
```

השתמשו בפונקציה `touching` להתנגשות, כאשר השחקן הוא מלבן A (`px, PLAYER_Y, 24, 24`) והבלוק הוא מלבן B (`b[0], b[1], 20, 20`).

## TODO 3: סיום משחק וניקוד שיא

כשהחיים נגמרים, מחליפים את המצב, וזוכרים את הניקוד הטוב ביותר של ההפעלה בעזרת `max`:

```python
if lives <= 0:
    state = "game over"
    best = max(best, score)
```

`restart()` מחזירה כל מספר לערך ההתחלתי שלו (חוץ מ-`best`, שנשאר בכוונה!).

> **שימו לב:** `UnboundLocalError` על `timer`, `spawned`, `best` וחבריהם: כל משתנה שמשימים לו ב-`update` חייב להופיע בשורת ה-`global` (זה כבר נעשה בקוד ההתחלתי).
>
> **שימו לב:** אם שוכחים `alive.append(b)` בענף ה-else, בלוקים נעלמים ברגע שהם נוצרים. אם שוכחים `blocks = alive` בסוף, שום דבר לא מוסר לעולם ומפסידים חיים בכל פריים.
>
> **שימו לב:** `IndexError: list index out of range` כשמשתמשים ב-`SPAWN_X[spawned]` בלי `% len(SPAWN_X)`.
>
> **שימו לב:** הבדיקה עומדת במקום וצופה שלוש פגיעות. אם המשחק אף פעם לא נגמר, בדקו שהקריאה ל-touching באמת משתמשת במיקום של השחקן.
