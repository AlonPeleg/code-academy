כל משחק, מ-Pong ועד ההרפתקאות התלת-ממדיות הגדולות ביותר, בנוי סביב רעיון אחד: **לולאת המשחק** (game loop). לולאה שרצה בערך 60 פעמים בכל שנייה ועושה בכל פעם שתי משימות:

1. **update**: לשנות את המספרים שמתארים את המשחק (איפה הדברים נמצאים, הניקוד, ...).
2. **draw**: לצייר את התמונה הנוכחית על המסך.

בשיעור הזה תכירו את שתיהן, ותגרמו לקופסה להחליק על פני המסך ולקפוץ מהקירות.

## חמש השורות שכל משחק צריך

```python
import game

def update(dt):
    pass            # change numbers here

def draw():
    game.clear(game.DARK)   # paint here

game.run(update, draw)
```

- `import game` טוענת את מנוע המשחקים הקטן שלנו. כל מה שהוא מציע נכתב `game.something`.
- `def update(dt):` היא פונקציה (function) שהמנוע קורא לה פעם אחת בכל פריים. הפרמטר (parameter) `dt` ("delta time", הפרש זמן) הוא מספר **השניות** שעברו מאז הפריים הקודם, מספר קטן כמו `0.0167`.
- `def draw():` נקראת מיד אחרי `update`. היא רק מציירת; היא לא אמורה לשנות את המשחק.
- `game.run(update, draw)` מתחילה את הלולאה. שימו אותה בתחתית, אחרי שהפונקציות כבר קיימות. שימו לב שמעבירים את הפונקציות *בלי* סוגריים: אנחנו נותנים למנוע את הפונקציות כדי שיוכל לקרוא להן בעצמו.

## המסך והציור

המסך הוא **ברוחב 320 פיקסלים ובגובה 240**. הנקודה `(0, 0)` היא הפינה **השמאלית העליונה**. הערך `x` גדל ימינה, והערך `y` גדל **כלפי מטה**. את הגדלים אפשר לקבל כ-`game.WIDTH` וכ-`game.HEIGHT`.

| קריאה | מה היא עושה |
| --- | --- |
| `game.clear(color)` | ממלאת את כל המסך בצבע אחד. עשו זאת ראשון ב-`draw`. |
| `game.rect(x, y, w, h, color)` | מלבן מלא. `(x, y)` היא הפינה השמאלית העליונה שלו. |
| `game.text(x, y, message, color, size)` | כותבת טקסט. השתמשו ב-`str(...)` כדי להפוך מספר לטקסט. |

הצבעים הזמינים: `game.BLACK WHITE GRAY DARK RED ORANGE YELLOW GREEN CYAN BLUE PURPLE PINK`.

## מצב והמילה `global`

דברים שמשתנים עם הזמן (מיקום הקופסה) נשמרים ב**משתנים (variables) מחוץ לפונקציות**. זה ה*מצב* (state) של המשחק. כדי לשנות אחד מהם מתוך `update`, מודיעים ל-Python באמצעות `global`:

```python
x = 20

def update(dt):
    global x
    x = x + 10
```

## למה מכפילים ב-dt

אם מוסיפים `5` פיקסלים קבועים בכל פריים, מחשב מהיר (יותר פריימים) מזיז את הקופסה מהר יותר ממחשב איטי. במקום זה, חשבו "הקופסה נעה 200 **פיקסלים בשנייה**". בפריים אחד, שנמשך `dt` שניות, היא עוברת `200 * dt` פיקסלים. מוסיפים את זה, והמהירות זהה בכל מקום:

```python
x = x + speed * dt     # speed is in pixels per second
```

> **שימו לב:** אם שוכחים את `global x` בתוך `update`, מקבלים `UnboundLocalError: cannot access local variable 'x'`. Python חושבת שאתם יוצרים משתנה מקומי חדש.
>
> **שימו לב:** אם הקופסה לא זזה, בדקו ש-`game.run(update, draw)` נמצאת בתחתית ושכתבתם `speed * dt` ולא רק `speed`.
>
> **שימו לב:** `"x = " + x` נכשל עם `TypeError` כי אי אפשר לחבר מספר לטקסט. השתמשו ב-`str(x)`.

ההקפצה בקירות כבר כתובה: כשהקופסה עוברת את הקיר הימני `speed` הופך לשלילי, ולכן `x` קטן והקופסה חוזרת. בשיעורים הבאים תכתבו בעצמכם קוד כזה.

## להתקדם הלאה

שנו את `speed`, את `size`, את `y` ואת הצבע. הוסיפו `game.rect` שני בתוך `draw`. לחצו על Run וצפו בשידור חי!

> **תורכם:** בתוך `update`, הוסיפו שורה אחת שגורמת ל-`x` לגדול ב-`speed * dt` בכל פריים.
