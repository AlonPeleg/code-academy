**C#** (נהגה "סי שארפ") היא שפה מודרנית עם טיפוסים (typed) של מיקרוסופט. משתמשים בה ל-back-end של אתרים, ליישומי שולחן עבודה ולפיתוח משחקים (Unity). בשיעור הראשון הזה תכתבו את תוכנית ה-C# הקטנה ביותר שעדיין שימושית, ותלמדו מה משמעותה של כל שורה בה.

C# היא שפה **מקומפלת** (compiled). כשלוחצים על **Run**, הקוד נשלח לשרת שמתרגם אותו ("מקמפל") לתוכנית, מריץ אותה ושולח אליכם בחזרה את הטקסט שהודפס. אם עשיתם שגיאת הקלדה, תקבלו שגיאת מהדר במקום פלט, וזה לגמרי נורמלי בזמן הלמידה.

## המבנה של תוכנית C#

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello!");
    }
}
```

בואו נעבור על זה חלק אחר חלק.

- `using System;` הוא **ייבוא** (import). מרחב השמות (namespace) `System` מכיל דברים מובנים שימושיים כמו `Console`. בלי השורה הזו הייתם צריכים לכתוב `System.Console.WriteLine(...)` בכל פעם.
- `class Program { ... }` היא **מחלקה** (class), מכל לקוד. ב-C# כל הקוד נמצא בתוך מחלקות. השם `Program` הוא רק מוסכמה.
- `static void Main()` היא **מתודה** (method), בלוק קוד בעל שם. ל-`Main` יש תפקיד מיוחד: בה התוכנית שלכם **מתחילה**. `static` אומר שאפשר להריץ אותה בלי ליצור קודם אובייקט, ו-`void` אומר שהיא לא מחזירה ערך. בינתיים התייחסו לשורה הזו כאל טקס קבוע.
- הסוגריים המסולסלים `{ }` מסמנים איפה בלוק מתחיל ואיפה הוא נגמר. לכל `{` חייב להיות `}` תואם.
- `Console.WriteLine("Hello!");` מדפיסה טקסט ואז עוברת לשורה הבאה. הטקסט נכתב ב**מרכאות כפולות**. כל פקודה מסתיימת ב**נקודה-פסיק** `;`.

## Write לעומת WriteLine

`Console.WriteLine` מדפיסה ואז מוסיפה מעבר שורה. `Console.Write` מדפיסה בלי מעבר שורה, כך שהפלט הבא ממשיך באותה שורה:

```csharp
Console.Write("Hello, ");
Console.Write("world");
Console.WriteLine("!");
// prints: Hello, world!
```

## הערות

כל מה שאחרי `//` בשורה הוא **הערה** (comment). המהדר מתעלם ממנה. השתמשו בהערות כדי להשאיר הערות לבני אדם:

```csharp
// This line is ignored by the computer
Console.WriteLine("Hi"); // so is this part
```

## גודל האותיות חשוב

C# היא **תלוית רישיות** (case-sensitive): `Console` ו-`console` הם שמות שונים. לפי המוסכמה, מתודות ומחלקות ב-C# מתחילות באות גדולה (`WriteLine`, `Main`).

> **שימו לב:**
> - שכחת נקודה-פסיק גורמת ל-`error CS1002: ; expected`. הסתכלו בשורה שקודמת לשורה שהשגיאה מצביעה עליה.
> - כתיבה של `console.writeline(...)` באותיות קטנות גורמת ל-`error CS0103: The name 'console' does not exist in the current context`.
> - שימוש בגרשיים בודדים `'Hello'` עבור טקסט. ב-C# גרשיים בודדים מיועדים לתו אחד בלבד (`'a'`); טקסט צריך מרכאות כפולות `"Hello"`.
> - שכחת `using System;` גורמת ל-`error CS0103: The name 'Console' does not exist in the current context`.

## להמשיך הלאה

נסו להוסיף שורת `Console.WriteLine` שנייה עם השם שלכם. שורות רצות מלמעלה למטה, לפי הסדר שבו כתבתם אותן.

> **תורכם:** בתוך `Main`, הדפיסו בדיוק `Hello, C#!` בעזרת `Console.WriteLine`.
