תוכניות הופכות לשימושיות כשהן יכולות לזכור דברים ולהגיב למה שאדם מקליד. בשיעור הזה תלמדו על משתנים, ששומרים ערכים, ועל `input()`, ששואלת את המשתמש שאלה.

## משתנים

**משתנה** (variable) הוא שם שמצביע על ערך, קצת כמו קופסה עם תווית. יוצרים אותו בהשמה עם סימן `=` אחד:

```python
city = "Haifa"
score = 10
print(city)     # prints: Haifa
print(score)    # prints: 10
```

הסימן `=` כאן לא אומר "שווה" כמו במתמטיקה. הוא אומר "שמרי את הערך שמימין תחת השם שמשמאל". ולכן זה לגמרי תקין:

```python
score = score + 5
```

Python מחשבת קודם את `score + 5` לפי הערך הישן, ואז שומרת את התוצאה בחזרה ב-`score`.

כללי מתן שמות: השתמשו באותיות, ספרות וקווים תחתונים, לעולם אל תתחילו בספרה, והעדיפו שמות תיאוריים באותיות קטנות, כמו `total_price`. רווחים אסורים.

## קריאת קלט

`input()` עוצרת את התוכנית, ממתינה שהאדם יקליד שורה, ומחזירה לכם את מה שהוקלד:

```python
name = input()
print(name)
```

חשוב: `input()` **תמיד מחזירה טקסט**, גם כשהאדם מקליד ספרות. הטקסט `"20"` אינו המספר `20`, ולכן עדיין אי אפשר לעשות איתו חשבון. ממירים אותו עם `int()` למספרים שלמים או עם `float()` למספרים עשרוניים:

```python
age = int(input())
print(age + 1)
```

בלשונית **Input** מתחת לעורך אפשר להקליד מה שהתוכנית צריכה לקרוא, שורה אחת לכל קריאה ל-`input()`. בשיעור הזה כבר מולאו שם `Ava` ו-`20`. בתרגילים האלה קוראים ל-`input()` בלי כלום בתוך הסוגריים.

## מחרוזות f

**מחרוזת f** (f-string) היא מחרוזת שמתחילה באות `f` לפני המרכאה הפותחת. כל מה שנמצא בתוך `{curly braces}` מוחלף בערך שלו, ואפשר אפילו לעשות שם חשבון:

```python
city = "Haifa"
score = 10
print(f"{city} has score {score}")          # prints: Haifa has score 10
print(f"Double the score is {score * 2}")   # prints: Double the score is 20
```

> **שימו לב:**
> - חשבון על טקסט נכשל: `"20" + 1` מניב `TypeError: can only concatenate str (not "int") to str`. המירו קודם עם `int()`.
> - אם מעבירים ל-`int()` משהו שאינו מספר, מקבלים `ValueError: invalid literal for int() with base 10`.
> - אם שוכחים את ה-`f` לפני המרכאה, הסוגריים המסולסלים מודפסים כפי שהם: `"Hi {name}"` מציג `Hi {name}`.
> - שימוש בשם לפני שיצרתם אותו מניב `NameError: name 'x' is not defined`.

> **תורכם:** קראו שם וגיל, ואז הדפיסו `Hello, Ava! Next year you will be 21.` בעזרת מחרוזת f.
