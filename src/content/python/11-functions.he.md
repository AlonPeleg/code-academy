ככל שתוכניות גדלות, תמצאו את עצמכם כותבים שוב ושוב את אותן כמה שורות. **פונקציה** (function) היא בלוק קוד עם שם שאפשר להשתמש בו שוב: כותבים פעם אחת, ומשתמשים כמה שרוצים. כבר קראתם לפונקציות כמו `print()` ו-`len()`. עכשיו תכתבו פונקציות משלכם.

## הגדרת פונקציה

```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)   # prints: 5
```

חלק אחר חלק:

- `def` אומרת לפייתון שאתם מגדירים פונקציה.
- `add` הוא השם שבחרתם. השתמשו במילים באותיות קטנות המחוברות בקו תחתון, כמו `is_adult`.
- `(a, b)` מפרטת את ה**פרמטרים** (parameters): הקלטים שהפונקציה מצפה להם. הם מתנהגים כמו משתנים שקיימים רק בתוך הפונקציה.
- הנקודתיים `:` והשורות **המוזחות** יוצרים את **גוף** הפונקציה.
- `return` מעבירה ערך בחזרה למי שקרא לפונקציה.

הגדרת פונקציה אינה מריצה אותה. הגוף רץ רק כשאתם **קוראים** לה עם ערכים, שנקראים **ארגומנטים** (arguments): `add(2, 3)`. הם מותאמים לפרמטרים לפי הסדר, ולכן `a` הוא 2 ו-`b` הוא 3.

## return מול print

זו הבלבול הנפוץ ביותר אצל מתחילים:

```python
def add_print(a, b):
    print(a + b)         # shows the result, then the function gives back None

def add_return(a, b):
    return a + b         # gives the result back so you can use it

total = add_return(2, 3) * 10
print(total)             # prints: 50
```

`print` נועדה לבני אדם שקוראים את המסך. `return` נועדה לשאר התוכנית שלכם. פונקציה שמחשבת משהו צריכה כמעט תמיד להחזיר אותו עם `return`. ברגע שפייתון מגיעה ל-`return`, הפונקציה מסתיימת, וכל שורה אחריה מדולגת. פונקציה בלי `return` מחזירה `None`.

## פונקציות יכולות להחזיר כל דבר

השוואה כמו `age >= 18` היא בעצמה ערך (`True` או `False`), ולכן אפשר להחזיר אותה ישירות בלי `if`:

```python
def is_adult(age):
    return age >= 18
```

פונקציות יכולות גם לקרוא לפונקציות אחרות, לא לקבל פרמטרים בכלל, ולהחזיר טקסט, רשימות או מילונים.

## הסדר חשוב

פייתון קוראת מלמעלה למטה, ולכן פונקציה חייבת להיות מוגדרת **לפני** השורה שקוראת לה:

```python
print(double(4))      # NameError: name 'double' is not defined
def double(n):
    return n * 2
```

> **שימו לב:**
> - שוכחים את הנקודתיים אחרי הסוגריים: מתקבלת `SyntaxError: expected ':'`.
> - שוכחים להזיח את הגוף: מתקבלת `IndentationError: expected an indented block after function definition`.
> - מספר ארגומנטים שגוי: קריאה ל-`add(1)` נותנת `TypeError: add() missing 1 required positional argument: 'b'`.
> - כותבים את שם הפונקציה בלי סוגריים, כמו `print(area)`, וזה לא קורא לה. מודפס משהו כמו `<function area at 0x...>`.
> - משתמשים ב-`print` במקום ב-`return`: הערך מוצג אבל מי שקרא מקבל `None`, ולכן `area(3, 4) + 1` נכשלת.

> **תורכם:** כתבו את `area` ו-`is_adult` מעל שורות ה-print כך ששלוש קריאות ה-`print` יציגו `12`, `True` ו-`False`.
