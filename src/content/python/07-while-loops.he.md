לולאת `for` מושלמת כשיודעים כמה פעמים לחזור. לולאת `while` מיועדת למצב שבו לא יודעים מראש: "המשיכו עד שמשהו קורה". דמיינו שאתם מערבבים סיר עד שהרוטב מסמיך.

## לולאת while

```python
n = 1
while n <= 3:
    print(n)
    n += 1
print("Done")
```

```text
1
2
3
Done
```

צעד אחר צעד:

1. Python בודקת את התנאי `n <= 3`.
2. אם הוא `True`, היא מריצה את הגוף המוזח, ואז חוזרת לצעד 1.
3. אם הוא `False`, הלולאה הסתיימה ו-Python ממשיכה מתחתיה.

השורה `n += 1` היא קיצור של `n = n + 1`. יש גרסאות מתאימות לשאר האופרטורים: `-=`, `*=`, `/=`.

הגוף חייב לשנות משהו שמשפיע על התנאי. אחרת התנאי נשאר נכון לנצח ומקבלים **לולאה אינסופית** (infinite loop).

## break: יוצאים מהלולאה עכשיו

`break` קופצת מיד אל מחוץ ללולאה הקרובה ביותר, גם אם התנאי עדיין נכון:

```python
n = 1
while True:          # on purpose: this would never stop on its own
    if n * n > 50:
        break
    n += 1
print(n)             # prints: 8
```

`while True:` עם `break` בפנים הוא דפוס נפוץ של "חזרו עד שהמשתמש יעשה X".

## continue: מדלגים לסיבוב הבא

`continue` זונחת את שאר הסיבוב הנוכחי וחוזרת ישר לתנאי:

```python
n = 0
while n < 5:
    n += 1
    if n == 3:
        continue     # skip printing 3
    print(n)
# prints: 1 2 4 5
```

שימו לב ש-`n += 1` מופיעה **לפני** ה-`continue`. אילו הייתה אחריו, בסיבוב 3 הלולאה הייתה קופצת חזרה בלי להגדיל את `n`, והייתה נתקעת על 3 לנצח.

## מתי להשתמש בכל לולאה

| מצב | לולאה |
| --- | --- |
| לעבור על רשימה, או לספור מ-1 עד 10 | `for` |
| לחזור עד שמשהו משתנה | `while` |
| לעצור מוקדם או לדלג על פריט | להוסיף `break` / `continue` |

אותם `break` ו-`continue` עובדים גם בתוך לולאות `for`.

> **שימו לב:**
> - אם שוכחים לעדכן את המשתנה בגוף הלולאה, נוצרת לולאה אינסופית. ייתכן שהדף יתקע. אם כך, טענו אותו מחדש.
> - שימוש ב-`continue` לפני שהמונה מתעדכן (ראו למעלה) גם הוא יוצר לולאה אינסופית.
> - טעויות של אחד: `while n < 10` נעצרת ב-9, ואילו `while n <= 10` כוללת את 10.
> - אם שוכחים נקודתיים מקבלים `SyntaxError: expected ':'`.

> **תורכם:** בחלק 1 ספרו עם לולאת `while`, דלגו על כפולות של 3 עם `continue` ועצרו ב-8 עם `break`. בחלק 2 הכפילו את `savings` בכל שנה עד שהוא מגיע ל-1000, וספרו את `years`.
