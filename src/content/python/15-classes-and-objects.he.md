עד עכשיו הנתונים שלכם (מספרים, טקסט, רשימות) והקוד שלכם (פונקציות) חיו בנפרד. **מחלקה** (class) מאפשרת לאגד אותם: דבר אחד שיודע גם מה הוא מחזיק וגם מה הוא יכול לעשות. הרעיון הזה, שנקרא תכנות מונחה עצמים, נמצא כמעט בכל פרויקט פייתון גדול.

## תבנית והדברים שנבנים ממנה

חשבו על מחלקה כעל **תבנית** (blueprint) של בית, ועל **אובייקט** (שנקרא גם **מופע**, instance) כעל בית אמיתי שנבנה ממנה. אפשר לבנות הרבה בתים מתבנית אחת, ולכל אחד יש צבע ומספר חדרים משלו.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{self.name} says woof")

rex = Dog("Rex")
fido = Dog("Fido")
rex.bark()       # prints: Rex says woof
fido.bark()      # prints: Fido says woof
```

## החלקים

- `class Dog:` מתחילה את התבנית. שמות מחלקות כתובים ב-CapitalizedWords.
- `def __init__(self, name):` היא ה**בנאי** (constructor), שיטה מיוחדת שרצה אוטומטית בכל פעם שיוצרים אובייקט (`Dog("Rex")`). הקווים התחתונים הכפולים בכל צד מסמנים אותה כמיוחדת.
- `self` הוא האובייקט עצמו. פייתון מעבירה אותו אוטומטית כפרמטר הראשון של כל שיטה; לעולם לא כותבים אותו בקריאה. ב-`rex.bark()`, `self` הוא `rex`.
- `self.name = name` יוצרת **תכונה** (attribute): משתנה ששמור על האובייקט. לכל אובייקט יש עותק משלו.
- `bark` היא **שיטה** (method): פונקציה שחיה במחלקה ופועלת על `self`.
- `Dog("Rex")` יוצרת אובייקט חדש. קריאת תכונה נעשית עם נקודה: `rex.name`.

## אובייקטים זוכרים את מצבם

שיטות יכולות לשנות את התכונות, והשינוי נשאר באותו אובייקט:

```python
class Counter:
    def __init__(self):
        self.value = 0

    def add(self):
        self.value += 1

c = Counter()
c.add()
c.add()
print(c.value)    # prints: 2
```

אם תיצרו מונה שני, `d = Counter()`, הוא עדיין יהיה על 0. כל אובייקט שומר על המצב שלו.

## בשביל מה כל זה?

השוו חשבון בנק ששמור כמשתנים נפרדים לבין אובייקט אחד שיודע להפקיד, למשוך ולהגן על עצמו מפני משיכת יתר. כל הכללים נמצאים במקום אחד, ושאר התוכנית פשוט אומרת `acct.withdraw(30)`.

השתמשתם באובייקטים כל הזמן: מחרוזת היא אובייקט מסוג `str` עם שיטות כמו `.upper()`, ורשימה היא אובייקט עם `.append()`.

> **שימו לב:**
> - שוכחים `self` בהגדרת שיטה: `def bark():` נותנת `TypeError: bark() takes 0 positional arguments but 1 was given`.
> - שוכחים `self.` בזמן שמירה: כתיבת `name = name` בתוך `__init__` לא שומרת דבר על האובייקט. השתמשו ב-`self.name = name`.
> - איות שגוי של `__init__` (למשל `_init_`) אומר שהיא אף פעם לא רצה, ותראו `TypeError: Dog() takes no arguments`.
> - שימוש בתכונה שאף פעם לא נקבעה נותן `AttributeError: 'Dog' object has no attribute 'age'`.

> **תורכם:** השלימו את המחלקה `Account` עם בנאי (`owner`, `balance=0`), שיטת `deposit` ושיטת `withdraw` שמסרבת למשוך יתר. השורות שמתחת למחלקה משתמשות בה.
