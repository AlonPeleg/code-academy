Python היא אחת משפות התכנות הפופולריות בעולם. היא מפורסמת בקוד שנקרא כמעט כמו אנגלית, ומשתמשים בה לאתרים, למדעי הנתונים, לאוטומציה ולבינה מלאכותית. בשיעור הראשון הזה תכתבו את התוכנית הראשונה שלכם ותגרמו למחשב לדבר בחזרה.

## שורת הקוד הראשונה שלכם

הכלי להצגת משהו על המסך הוא `print`:

```python
print("Hello!")
```

בואו נפרק את זה לחלקים:

- `print` הוא שם של **פונקציה** (function), פעולה מוכנה. הפונקציה הזו אומרת "הציגי את זה על המסך".
- הסוגריים העגולים `( )` מכילים את מה שמעבירים לפונקציה. מה שנמצא בתוכם נקרא **ארגומנט** (argument).
- `"Hello!"` הוא **טקסט** (מתכנתים אומרים **מחרוזת**, string). מחרוזות חייבות להיות עטופות במרכאות, כפולות `"double"` או בודדות `'single'`.

הריצו ותראו את `Hello!` מופיע בחלונית הפלט. ההרצה הראשונה יכולה לקחת כמה שניות, כי Python עצמה נטענת לתוך הדפדפן שלכם.

## התוכנית רצה מלמעלה למטה

Python קוראת את הקובץ שלכם שורה אחר שורה, מההתחלה. כל `print` כותב שורה משלו:

```python
print("First")
print("Second")
```

```text
First
Second
```

## עושים חשבון

מספרים לא צריכים מרכאות, ו-Python יודעת לחשב אותם בשבילכם:

```python
print(2 + 3)      # prints: 5
print(10 - 4)     # prints: 6
print(6 * 7)      # prints: 42
print(9 / 2)      # prints: 4.5
```

הטקסט שאחרי `#` הוא **הערה** (comment). Python מתעלמת ממנו לגמרי, ולכן אפשר להשתמש בהערות כדי להשאיר הערות לעצמכם ולאנשים אחרים.

השוו בין שתי השורות האלה בקפידה:

```python
print(2 + 3)      # prints: 5
print("2 + 3")    # prints: 2 + 3
```

עם מרכאות זה רק טקסט, ולכן Python מציגה אותו בדיוק כפי שנכתב. בלי מרכאות זה חישוב, ולכן Python מחשבת קודם את התשובה.

> **שימו לב:**
> - אם שוכחים את המרכאה הסוגרת, כמו ב-`print("Hello)`, מקבלים `SyntaxError: unterminated string literal`.
> - Python מבחינה בין אותיות גדולות לקטנות. `Print("Hi")` נכשלת עם `NameError: name 'Print' is not defined`. צריך לכתוב `print` באותיות קטנות.
> - אם שוכחים סוגר, כמו ב-`print("Hi"`, מקבלים `SyntaxError: '(' was never closed`.
> - מרכאות מעוקלות ("חכמות") שהועתקו ממסמך הן לא מרכאות אמיתיות. הקלידו מרכאות ישרות `"`.

## ממשיכים הלאה

נסו להדפיס את השם שלכם, או חישוב כמו `print(365 * 24)` כדי לראות כמה שעות יש בשנה. אפשר גם להדפיס כמה דברים בבת אחת על ידי הפרדה ביניהם בפסיקים: `print("Total:", 2 + 3)` מדפיס `Total: 5`.

> **תורכם:** הדפיסו את הטקסט `Hello, Python!` בשורה הראשונה, ואז הדפיסו את התוצאה של `2 + 3` בשורה השנייה.
