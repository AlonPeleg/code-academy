Python היא מחשבון מצוין, וכמעט כל תוכנית עושה קצת חשבון: סכומים, ממוצעים, שעונים, ניקוד. בשיעור הזה תלמדו את כל אופרטורי החשבון ואת שני האופרטורים המפתיעים, `//` ו-`%`.

## האופרטורים

| אופרטור | משמעות | דוגמה | תוצאה |
| --- | --- | --- | --- |
| `+` | חיבור | `7 + 2` | `9` |
| `-` | חיסור | `7 - 2` | `5` |
| `*` | כפל | `7 * 2` | `14` |
| `/` | חילוק (תמיד נותן עשרוני) | `7 / 2` | `3.5` |
| `//` | חילוק שלם | `7 // 2` | `3` |
| `%` | שארית | `7 % 2` | `1` |
| `**` | חזקה | `7 ** 2` | `49` |

מופיעים שני סוגי מספרים: **int** (מספרים שלמים כמו `5`) ו-**float** (מספרים עם נקודה עשרונית כמו `5.0` או `3.14`). שימו לב ש-`/` תמיד מפיק float, גם כשהתשובה שלמה: `10 / 2` הוא `5.0`.

## חילוק, חילוק שלם ושארית

דמיינו שמחלקים 17 סוכריות בין 5 ילדים. כל ילד מקבל 3 סוכריות, ו-2 סוכריות נשארות. Python יכולה להגיד לכם את שני החלקים:

```python
print(17 // 5)   # prints: 3   (how many whole times 5 fits into 17)
print(17 % 5)    # prints: 2   (what is left over)
print(17 / 5)    # prints: 3.4 (the exact answer)
```

שני האופרטורים האלה הם זוג מושלם לפירוק סכום כולל ליחידות, כמו שניות לדקות ולשניות, או אגורות לשקלים ולאגורות:

```python
total = 135
print(total // 60)   # prints: 2   minutes
print(total % 60)    # prints: 15  seconds
```

השארית גם עונה על השאלה "האם המספר זוגי?": `n % 2 == 0` נכון עבור מספרים זוגיים.

## סדר פעולות החשבון

Python פועלת לפי אותם כללים כמו בחשבון מבית הספר: קודם חזקה, אחר כך `*` `/` `//` `%`, ואז `+` `-`. השתמשו בסוגריים עגולים כדי להבהיר:

```python
print(2 + 3 * 4)     # prints: 14
print((2 + 3) * 4)   # prints: 20
```

## פונקציות שימושיות

```python
print(round(3.14159, 2))   # prints: 3.14
print(abs(-7))             # prints: 7
print(max(3, 9, 4))        # prints: 9
print(min(3, 9, 4))        # prints: 3
```

`round(number, digits)` מעגלת למספר הספרות העשרוניות שביקשתם. זהירות: `round(2.5)` נותנת `2` כי Python מעגלת חצאים מדויקים למספר הזוגי הקרוב ביותר.

> **שימו לב:**
> - חילוק באפס קורס עם `ZeroDivisionError: division by zero`.
> - `^` אינו "חזקה" ב-Python. זו פעולה אחרת, ולכן השתמשו ב-`**`.
> - מספרים עשרוניים נשמרים בקירוב: `0.1 + 0.2` מדפיס `0.30000000000000004`. השתמשו ב-`round()` כשמציגים תוצאות.
> - ערבוב של טקסט ומספרים, כמו ב-`"5" + 2`, מניב `TypeError`. המירו קודם עם `int("5")`.

> **תורכם:** פרקו `3725` שניות לשעות, דקות ושניות בעזרת `//` ו-`%`, הדפיסו אותן בצורה `1h 2m 5s`, ואז הדפיסו את `2 ** 10` ואת `10 / 3` מעוגל לשתי ספרות אחרי הנקודה.
