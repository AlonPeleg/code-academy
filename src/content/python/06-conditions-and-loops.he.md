עד עכשיו כל שורה בתוכנית שלכם רצה, אחת אחרי השנייה. תוכניות אמיתיות צריכות לקבל החלטות ולחזור על פעולות. בשיעור הזה תשתמשו ב-`if` כדי לבחור וב-`for` כדי לחזור על פעולות, ואז תפתרו חידה מפורסמת למתחילים שנקראת FizzBuzz.

## if, elif, else

**תנאי** (condition) הוא שאלה שהתשובה עליה היא `True` או `False`. הקוד המוזח מתחת ל-`if` רץ רק כשהתנאי נכון:

```python
age = 15
if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teen")
else:
    print("Child")
# prints: Teen
```

- `if` נבדק ראשון.
- `elif` (קיצור של "else if", כלומר "אחרת אם") נבדק רק כשכל מה שמעליו היה שקרי. אפשר להשתמש בכמה שרוצים.
- `else` תופס את כל השאר. אין לו תנאי.
- **רק ענף אחד רץ**, הראשון שנכון.

## הזחה ונקודתיים

כל שורה של `if`, `elif`, `else` ולולאה מסתיימת בנקודתיים `:`. השורות ששייכות אליה **מוזחות** ב-4 רווחים. ההזחה הזו אינה קישוט, בזכותה Python יודעת איפה הבלוק מתחיל ואיפה הוא נגמר:

```python
if age >= 18:
    print("Adult")      # inside the if
print("Done")           # always runs (not indented)
```

## לולאות for ו-range

**לולאה** (loop) חוזרת על קוד. `for` עוברת על סדרת ערכים, אחד בכל פעם:

```python
for i in range(1, 4):
    print(i)
# prints: 1  2  3  (one per line)
```

`range(1, 4)` מפיקה 1, 2, 3. היא מתחילה במספר הראשון ונעצרת **לפני** השני. `range(5)` הוא קיצור של `0, 1, 2, 3, 4`. אפשר גם לעבור בלולאה על טקסט או על רשימות: `for letter in "abc":`.

## טריק השארית

`i % 3 == 0` פירושו "חילוק ב-3 לא משאיר שארית", כלומר "i מתחלק ב-3". תשתמשו בבדיקה הזו הרבה.

## FizzBuzz

FizzBuzz הוא תרגיל קלאסי. סופרים מ-1 עד 15, אבל מדפיסים `Fizz` עבור כפולות של 3, `Buzz` עבור כפולות של 5, ו-`FizzBuzz` עבור מספרים שהם כפולות של שניהם (15 מתחלק גם ב-3 וגם ב-5). המלכודת: אם בודקים קודם "מתחלק ב-3", המספר 15 אף פעם לא מגיע למקרה המשולב. **שימו את המקרה הכי ספציפי ראשון.**

> **שימו לב:**
> - נקודתיים חסרות מניבות `SyntaxError: expected ':'`.
> - אם שוכחים להזיח את הגוף מקבלים `IndentationError: expected an indented block`.
> - ערבוב של טאבים ורווחים גורם ל-`TabError`. היצמדו ל-4 רווחים.
> - שימוש ב-`=` בתנאי (`if i % 3 = 0:`) הוא `SyntaxError`. השוו עם `==`.
> - טעות של אחד: `range(1, 15)` נעצרת ב-14. כדי לכלול את 15 צריך `range(1, 16)`.

> **תורכם:** החליפו את `pass` בלולאת `for` על המספרים 1 עד 15 שמדפיסה `FizzBuzz`, `Fizz`, `Buzz` או את המספר עצמו, כשהמקרה המשולב נבדק ראשון.
