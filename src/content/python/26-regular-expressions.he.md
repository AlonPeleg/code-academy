**ביטוי רגולרי** (regular expression, או בקיצור regex) הוא שפה קטנה לתיאור הצורה של טקסט: "ארבע ספרות, מקף, שתי ספרות" או "אותיות, שטרודל, עוד אותיות". במקום לעבור על התווים בלולאה עם משפטי `if`, מתארים את התבנית פעם אחת ומשאירים למודול `re` לבצע את החיפוש. אימות קלט, סריקת יומנים (logs) וניקוי נתונים הופכים לקצרים.

## בניית תבנית

תמיד כתבו תבניות כ**מחרוזות גולמיות** (raw strings, `r"..."`): האות `r` בהתחלה אומרת ל-Python להשאיר את הלוכסנים האחוריים כמות שהם, כי ב-regex משתמשים בהם הרבה.

| תבנית | משמעות |
| --- | --- |
| `\d` | ספרה אחת (`\D` היא כל דבר חוץ מספרה) |
| `\w` | אות, ספרה או קו תחתון |
| `\s` | רווח, טאב או שורה חדשה (`\S` היא כל דבר אחר) |
| `.` | כל תו בודד חוץ משורה חדשה |
| `[abc]`, `[A-Z]` | תו אחד מתוך קבוצה או טווח |
| `+`, `*`, `?` | אחד או יותר, אפס או יותר, אפס או אחד |
| `{4}`, `{2,3}` | בדיוק 4, בין 2 ל-3 |
| `^`, `$` | תחילת הטקסט וסופו |
| `( )` | קבוצה: חלק מההתאמה שאפשר לשלוף החוצה |

## ארבע הפונקציות העיקריות

```python
import re

text = "Order 66 shipped on 2024-03-01"

print(re.search(r"\d+", text).group())      # prints: 66  (first match anywhere)
print(re.match(r"\d+", text))               # prints: None (must match at the START)
print(re.findall(r"\d+", text))             # prints: ['66', '2024', '03', '01']
print(re.sub(r"\d", "#", text))             # prints: Order ## shipped on ####-##-##
```

- `re.search` מוצאת את ההתאמה הראשונה בכל מקום ומחזירה **אובייקט התאמה** (match object), או `None`.
- `re.match` דומה ל-`search` אבל מצליחה רק בתחילת הטקסט.
- `re.findall` מחזירה רשימה עם כל ההתאמות.
- `re.sub(pattern, replacement, text)` מחזירה טקסט חדש שבו כל ההתאמות הוחלפו. ההחלפה יכולה להיות גם פונקציה שמקבלת כל התאמה.

אם משתמשים באותה תבנית שוב ושוב, כדאי לקמפל אותה פעם אחת: `pattern = re.compile(r"\d+")`, ואז לקרוא ל-`pattern.search(text)`.

## קבוצות

סוגריים עגולים לוכדים חלקים מההתאמה. תנו להם שמות עם `(?P<name>...)` כדי שהקוד יסביר את עצמו:

```python
m = re.match(r"(?P<year>\d{4})-(?P<month>\d{2})", "2024-03-01")
print(m.group("year"), m.group("month"))   # prints: 2024 03
print(m.groupdict())                       # prints: {'year': '2024', 'month': '03'}
```

תמיד בדקו אם התוצאה היא `None` לפני שקוראים ל-`.group()`: התאמה שנכשלה מחזירה `None`, והקריאה `None.group()` מפילה את התוכנית.

## חמדן מול עצלן

כברירת מחדל `+` ו-`*` הם **חמדנים** (greedy): הם לוקחים כמה שיותר. הוספת `?` הופכת אותם לעצלנים (lazy).

```python
html = "<b>one</b> and <b>two</b>"
print(re.findall(r"<b>.*</b>", html))    # one big match (greedy)
print(re.findall(r"<b>.*?</b>", html))   # ['<b>one</b>', '<b>two</b>'] (lazy)
```

> **שימו לב:**
> - שכחתם מחרוזת גולמית: `"\d"` גורמת ל-`SyntaxWarning` על רצף בריחה לא תקין, ו-`"\b"` אומרת בשקט תו מחיקה (backspace).
> - קריאה ל-`re.match(...).group()` על התאמה שנכשלה נותנת `AttributeError: 'NoneType' object has no attribute 'group'`.
> - `.` לא מתאימה לנקודה אמיתית. כדי להתאים נקודה אמיתית כתבו `\.`.
> - תבנית שבורה כמו `r"(abc"` זורקת `re.error: missing ), unterminated subpattern`.
> - Regex אינו כלי לכל דבר: אל תנסו לנתח באמצעותו HTML שלם או לאמת כל כתובת אימייל אפשרית. שמרו על תבניות פשוטות.

## להמשך

נסו את הדגל `re.IGNORECASE`, למשל `re.findall(r"error", log, re.IGNORECASE)`, ואת `re.split(r"[,;]\s*", "a, b;c")` כדי לפצל לפי כמה מפרידים בבת אחת.

> **תורכם:** מלאו את ארבעת החלקים: אספו תאריכים עם `re.findall`, נתחו את השורות עם קבוצות בעלות שם וספרו את הרמות, מצאו את כתובות האימייל, והשתמשו ב-`re.sub` כדי להסתיר את האימיילים ולהפוך את `95%` ל-`N%`.
