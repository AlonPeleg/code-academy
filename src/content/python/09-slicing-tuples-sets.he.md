כבר אתם יודעים איך לתפוס פריט אחד עם אינדקס. חיתוך (slicing) מאפשר לתפוס טווח שלם בבת אחת. בשיעור הזה תכירו גם שני סוגי אוספים נוספים: טאפלים וקבוצות.

## חיתוך

לחיתוך יש הצורה `[start:stop:step]`. הוא מתחיל ב-`start`, מגיע עד `stop` אבל **לא כולל אותו**, וזז בצעדים של `step`. כל חלק הוא אופציונלי.

```python
nums = [10, 20, 30, 40, 50]
print(nums[1:3])     # prints: [20, 30]
print(nums[:2])      # prints: [10, 20]      (from the beginning)
print(nums[3:])      # prints: [40, 50]      (to the end)
print(nums[-2:])     # prints: [40, 50]      (the last two)
print(nums[::2])     # prints: [10, 30, 50]  (every second item)
print(nums[::-1])    # prints: [50, 40, 30, 20, 10]  (backwards)
```

אותו דבר עובד על טקסט, כי מחרוזת היא רצף של תווים:

```python
word = "python"
print(word[:2])      # prints: py
print(word[2:])      # prints: thon
print(word[::-1])    # prints: nohtyp
```

חיתוך תמיד נותן רשימה או מחרוזת **חדשה**, ואף פעם לא גורם לשגיאה בגלל שהוא ארוך מדי. `nums[3:100]` פשוט נעצר בסוף.

## טאפלים

**טאפל** (tuple) הוא כמו רשימה שאי אפשר לשנות. כותבים אותו עם סוגריים עגולים:

```python
point = (3, 4)
print(point[0])      # prints: 3
# point[0] = 9       # TypeError: 'tuple' object does not support item assignment
```

טאפלים אידיאליים לקבוצות קטנות וקבועות, כמו קואורדינטות או זוג (שם, גיל). אפשר **לפרק** אותם למשתנים נפרדים בשורה אחת:

```python
x, y = point
print(x)             # prints: 3
print(y)             # prints: 4
```

אותו טריק מחליף בין שני משתנים: `a, b = b, a`.

## קבוצות

**קבוצה** (set) היא אוסף בלי כפילויות ובלי סדר מסוים. היא נכתבת עם סוגריים מסולסלים או עם `set(...)`:

```python
scores = [3, 1, 3, 2, 1]
unique = set(scores)
print(sorted(unique))      # prints: [1, 2, 3]
print(2 in unique)         # prints: True   (very fast lookup)
unique.add(7)
```

`sorted()` הופכת כל אוסף לרשימה ממוינת. קבוצות תומכות גם בפעולות הדומות לפעולות במתמטיקה: `a & b` (בשתיהן), `a | b` (באחת מהן), `a - b` (ב-a אבל לא ב-b).

| סוג | סוגריים | מסודר | ניתן לשינוי | כפילויות |
| --- | --- | --- | --- | --- |
| רשימה | `[ ]` | כן | כן | כן |
| טאפל | `( )` | כן | לא | כן |
| קבוצה | `{ }` | לא | כן | לא |
| מילון | `{k: v}` | כן | כן | המפתחות ייחודיים |

> **שימו לב:**
> - `{}` לבדו יוצרים **מילון** ריק, לא קבוצה. השתמשו ב-`set()` לקבוצה ריקה.
> - טאפל עם פריט אחד צריך פסיק בסוף: `(5,)`. בלעדיו, `(5)` הוא סתם המספר 5.
> - בפירוק צריך מספרים תואמים: `a, b = (1, 2, 3)` מניב `ValueError: too many values to unpack`.
> - לקבוצות אין אינדקס, ולכן `my_set[0]` מניב `TypeError: 'set' object is not subscriptable`.

> **תורכם:** השתמשו בחיתוכים, בפירוק טאפל ובקבוצה כדי להדפיס את ששת התוצאות שמופיעות בהערות.
