כל החלטה שתוכנית מקבלת מסתכמת בשאלה עם תשובה של כן או לא. ל-Python יש סוג מיוחד לתשובות כאלה, שנקרא **בוליאני** (boolean), ויש לו בדיוק שני ערכים: `True` ו-`False`. שניהם מתחילים באות גדולה.

## אופרטורי השוואה

השוואה שואלת שאלה ומחזירה ערך בוליאני:

| אופרטור | שאלה | דוגמה | תוצאה |
| --- | --- | --- | --- |
| `==` | שווה? | `3 == 3` | `True` |
| `!=` | לא שווה? | `3 != 3` | `False` |
| `<` | קטן יותר? | `2 < 5` | `True` |
| `>` | גדול יותר? | `2 > 5` | `False` |
| `<=` | קטן או שווה? | `5 <= 5` | `True` |
| `>=` | גדול או שווה? | `4 >= 5` | `False` |

```python
age = 17
print(age >= 18)   # prints: False
print(age == 17)   # prints: True
```

שננו את זה: סימן `=` יחיד **שומר** ערך, וסימן `==` כפול **שואל** אם שני ערכים שווים.

## משלבים שאלות: and, or, not

- `a and b` הוא `True` רק כש**שניהם** נכונים.
- `a or b` הוא `True` כש**לפחות אחד** נכון.
- `not a` הופך את התשובה.

```python
has_ticket = True
age = 17
print(has_ticket and age >= 18)   # prints: False (the second part fails)
print(has_ticket or age >= 18)    # prints: True  (the first part is enough)
print(not has_ticket)             # prints: False
```

אפשר להשתמש בסוגריים עגולים כדי לקבץ, בדיוק כמו במתמטיקה: `(a or b) and c`.

## השוואות משורשרות והאופרטור in

Python מאפשרת לכתוב בדיקת טווח כמו שכותבים בשיעור מתמטיקה:

```python
age = 17
print(13 <= age <= 19)   # prints: True
```

המילה `in` בודקת אם משהו נמצא בתוך משהו אחר:

```python
print("py" in "python")        # prints: True
print("z" in "python")         # prints: False
print(3 in [1, 2, 3])          # prints: True
```

## משווים טקסט

טקסט מושווה אות אחר אות, ואותיות גדולות שונות מאותיות קטנות: `"Python" == "python"` הוא `False`. טריק נפוץ הוא להפוך קודם את שני הצדדים לאותיות קטנות: `a.lower() == b.lower()`.

> **שימו לב:**
> - כתיבת `if age = 18:` היא `SyntaxError`. השתמשו ב-`==` כשרוצים להשוות.
> - `true` ו-`false` באותיות קטנות מניבים `NameError: name 'true' is not defined`. כתבו `True` ו-`False`.
> - `13 <= age <= 19` עובד, אבל `age == 13 or 14` לא אומר מה שנראה שהוא אומר. כתבו `age == 13 or age == 14`, או `age in (13, 14)`.
> - השוואה בין מספר לטקסט, כמו `5 < "7"`, מניבה `TypeError`.

> **תורכם:** הדפיסו את התשובות לשש השאלות שבהערות, אחת בכל שורה, בעזרת `and`, `not`, `or`, השוואה משורשרת, `==` ו-`in`.
