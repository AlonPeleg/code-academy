בשיעור הקודם פונקציית צבירה סיכמה את הטבלה כולה לשורה אחת. לעיתים קרובות יותר רוצים סיכום אחד **לכל קטגוריה**: סטודנטים לכל עיר, ציון ממוצע לכל קורס, סך נקודות הזכות לכל שפה. זו העבודה של `GROUP BY`.

## איך GROUP BY עובד

`GROUP BY` מחלק קודם את השורות לערימות (קבוצות) שחולקות אותו ערך, ואז פונקציית הצבירה רצה פעם אחת לכל ערימה.

```sql
SELECT city, COUNT(*) AS students
FROM students
GROUP BY city;
```

תארו לעצמכם שמסד הנתונים שם את כל הסטודנטים מחיפה בערימה אחת, את כל הסטודנטים מתל אביב בערימה אחרת, וכן הלאה. לכל ערימה הוא מוציא שורה אחת: העיר, ומספר השורות בערימה.

דוגמה נוספת, עם הציון הממוצע לכל קורס:

```sql
SELECT course_id, AVG(grade) AS average
FROM enrollments
GROUP BY course_id;
```

## כלל הזהב

כל עמודה ברשימת ה-`SELECT` חייבת להיות אחת משתיים:

1. רשומה ב-`GROUP BY`, או
2. עטופה בפונקציית צבירה (`COUNT`, `AVG`, `SUM`, ...).

`city` היא עמודת הקיבוץ ו-`COUNT(*)` היא פונקציית צבירה, ולכן `SELECT city, COUNT(*)` תקין.

## אפשר להשתמש גם ב-WHERE

`WHERE` מסנן שורות **לפני** שהן מקובצות:

```sql
SELECT course_id, COUNT(*) AS enrolled
FROM enrollments
WHERE grade >= 80
GROUP BY course_id;
```

זה סופר רק את הציונים הגבוהים לכל קורס.

## מיון קבוצות

אחרי הקיבוץ אפשר למיין לפי הכינוי או לפי העמודה. כמה מפתחות מיון מופרדים בפסיקים:

```sql
ORDER BY students DESC, city
```

זה מציב את הקבוצות הגדולות ראשונות, ואת הערים עם אותה ספירה לפי סדר האלף-בית של האנגלית. הסעיף `ORDER BY` בא אחרון, אחרי `GROUP BY`.

## ל-NULL יש קבוצה משלו

ל-Yael אין עיר. שורות עם `NULL` יוצרות קבוצה בפני עצמה, וב-SQLite הערך `NULL` ממוין לפני טקסט, ולכן הוא מופיע מעל Eilat בשבירת השוויון האלפביתית בתרגיל שלנו.

## סדר הסעיפים עד כה

`SELECT`, `FROM`, `WHERE`, `GROUP BY`, `ORDER BY`, `LIMIT`.

> **שימו לב:**
> - בחירת עמודה רגילה שאינה ב-`GROUP BY`, כמו `SELECT name, city, COUNT(*) ... GROUP BY city`, מתקבלת ב-SQLite אבל מציגה רק שם אקראי אחד לכל קבוצה. מסדי נתונים אחרים דוחים זאת עם שגיאה.
> - `GROUP BY` בא אחרי `WHERE` ולפני `ORDER BY`; שינוי הסדר גורם ל-`near "GROUP": syntax error`.
> - אי אפשר לסנן לפי פונקציית צבירה עם `WHERE`. השתמשו ב-`HAVING`, שהוא השיעור הבא.
> - אם משנים שם של עמודה עם `AS students`, זכרו שזה גם שם של טבלה. SQL מסתדרת עם זה כאן, אבל זה יכול לבלבל.

> **תורכם:** ספרו את הסטודנטים בכל עיר, הקבוצות הגדולות ראשונות, ובשוויון לפי סדר האלף-בית.
