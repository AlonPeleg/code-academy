לפעמים שאלה אחת תלויה בתשובה לשאלה אחרת: "מי מבוגר יותר מהסטודנט הממוצע?" כדי לענות עליה צריך קודם את הממוצע, ואז משווים אליו כל סטודנט. אפשר להריץ שתי שאילתות ולהעתיק את המספר ביד, אבל אז השאילתה שלכם תישבר ברגע שהנתונים ישתנו. ל-SQL יש דרך טובה יותר: לשים את השאילתה הראשונה **בתוך** השנייה. זו **תת-שאילתה**.

## תת-שאילתה שמחזירה ערך אחד

```sql
SELECT AVG(age) FROM students;
```

מחזירה מספר אחד (בערך 21.14). אפשר להשתמש בשאילתה הזו בכל מקום שבו מצופה ערך בודד, אם עוטפים אותה בסוגריים עגולים:

```sql
SELECT name, age
FROM students
WHERE age > (SELECT AVG(age) FROM students);
```

מסד הנתונים מריץ קודם את השאילתה הפנימית, מקבל מספר אחד, ואז משתמש בו כאילו הקלדתם אותו שם. אם הנתונים ישתנו מחר, הממוצע יתעדכן מעצמו.

אפשר גם להשתמש בתת-שאילתה כזו ברשימת ה-`SELECT`:

```sql
SELECT name, age,
       age - (SELECT AVG(age) FROM students) AS difference
FROM students;
```

## תת-שאילתה שמחזירה רשימה

עם `IN`, השאילתה הפנימית יכולה להחזיר עמודה שלמה של ערכים:

```sql
SELECT name
FROM students
WHERE id IN (SELECT student_id
             FROM enrollments
             WHERE course_id = 3);
```

השאילתה הפנימית מחזירה את ה-ids של כל הרשומים לקורס 3 (Python), והשאילתה החיצונית הופכת את ה-ids האלה לשמות. `NOT IN` מוצא את ההפך: סטודנטים שהם **לא** ברשימה.

אפשר לכתוב את זה גם כ-`JOIN`. שתי הדרכים תקינות; תתי-שאילתות הן לרוב קלות יותר לקריאה בשאלות מסוג "האם שייך לקבוצה", ו-joins עדיפים כשצריך עמודות משתי הטבלאות.

## תת-שאילתה כטבלה

תת-שאילתה ב-`FROM` מתנהגת כמו טבלה זמנית. חובה לתת לה כינוי:

```sql
SELECT AVG(per_course.n) AS average_enrolments
FROM (SELECT course_id, COUNT(*) AS n
      FROM enrollments
      GROUP BY course_id) AS per_course;
```

קודם השאילתה הפנימית סופרת הרשמות לכל קורס, ואז החיצונית מחשבת ממוצע של הספירות האלה.

## כללי אצבע

- תמיד עטפו תת-שאילתה בסוגריים עגולים.
- תת-שאילתה שמשמשת עם `=`, `>`, `<` חייבת להחזיר **בדיוק ערך אחד** (שורה אחת, עמודה אחת).
- תת-שאילתה שמשמשת עם `IN` חייבת להחזיר **עמודה אחת**.
- הזיזו תתי-שאילתות פנימה (indent) כדי שהמבנה יהיה גלוי.

> **שימו לב:**
> - שכחת הסוגריים גורמת ל-`near "SELECT": syntax error`.
> - השוואה עם תת-שאילתה שמחזירה כמה עמודות גורמת ל-`sub-select returns 2 columns - expected 1`.
> - תת-שאילתה ב-`FROM` בלי כינוי היא שגיאה במסדי נתונים רבים. תמיד הוסיפו `AS name`.
> - `NOT IN` עם רשימה שמכילה `NULL` לא מחזיר שורות בכלל. סננו את ערכי ה-`NULL` בתוך תת-השאילתה עם `WHERE col IS NOT NULL`.

> **תורכם:** הציגו את `name` ו-`age` של הסטודנטים שמבוגרים מהגיל הממוצע, הצעיר ביותר ראשון, באמצעות תת-שאילתה שמחשבת את הממוצע.
