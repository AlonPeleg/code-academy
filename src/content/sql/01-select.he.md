**מסד נתונים** (database) שומר נתונים ב**טבלאות** (tables), די דומה לגיליונות אלקטרוניים. כמעט כל אפליקציה שאתם משתמשים בה, מחנויות מקוונות ועד רשתות חברתיות, שומרת את המידע שלה במסד נתונים. **SQL** (בדרך כלל נהגה "סיקוול") היא השפה שבעזרתה שואלים מסד נתונים שאלות. בשיעור הזה תכתבו את השאילתה (query) הראשונה שלכם.

## טבלאות, עמודות ושורות

בטבלה יש **עמודות** (columns, סוגי העובדות, כמו `name` או `age`) ו**שורות** (rows, הרשומות הבודדות, כמו סטודנט אחד). פתחו את הלשונית **Sample data** שליד לשונית Result כדי לראות את שלוש הטבלאות שנתרגל עליהן:

- `students` עם `id`, `name`, `age` ו-`city`
- `courses` עם `id`, `title`, `language` ו-`credits`
- `enrollments` שמקשרת בין סטודנטים לקורסים ושומרת `grade`

## השאילתה הראשונה שלכם

הפקודה החשובה ביותר היא `SELECT`:

```sql
SELECT name, age
FROM students;
```

חלק אחרי חלק:

- אחרי `SELECT` באות העמודות שאתם רוצים, מופרדות בפסיקים.
- `FROM` נותנת את שם הטבלה לקריאה.
- נקודה-פסיק `;` מסיימת את ההוראה.

התוצאה היא טבלה קטנה חדשה עם שתי העמודות האלה בלבד, ושורה אחת לכל סטודנט. השורות חוזרות לפי הסדר שבו נשמרו, אלא אם מבקשים משהו אחר (שיעור מאוחר יותר מראה איך).

## כל העמודות עם *

הכוכבית היא קיצור ל"כל העמודה":

```sql
SELECT *
FROM courses;
```

היא מצוינת לחקירת טבלה, אבל בפרויקטים אמיתיים עדיף לרשום את העמודות שאתם באמת צריכים.

## טוב לדעת

- מילות מפתח ב-SQL כמו `SELECT` ו-`FROM` אינן רגישות לאותיות גדולות וקטנות. כתיבה באותיות גדולות היא רק הרגל שהופך שאילתות לקריאות יותר.
- העימוד חופשי: אפשר לכתוב את כל השאילתה בשורה אחת או לפצל אותה על פני כמה שורות. הסגנון הנפוץ הוא לפצל בכל מילת מפתח.
- שורה שמתחילה ב-`--` היא **הערה** (comment) ש-SQL מתעלמת ממנה.
- ערך חסר מופיע כ-`NULL`. ל-Yael אין עיר, ולכן תראו `NULL` בשורה שלה.
- העורך משלים אוטומטית שמות של טבלאות ועמודות. לחצו Tab או Enter כדי לקבל הצעה.

> **שימו לב:**
> - עמודה שנכתבה עם שגיאת כתיב גורמת להודעה `no such column: nam`.
> - טבלה שנכתבה עם שגיאת כתיב גורמת להודעה `no such table: student`.
> - פסיק אחרי העמודה האחרונה, כמו ב-`SELECT name, FROM students`, גורם להודעה `near "FROM": syntax error`.
> - אם שוכחים את הפסיק בין עמודות (`SELECT name city`) אין שגיאה, אבל מתקבלת עמודה אחת בשם `name` ו-`city` נחשב לתווית החדשה שלה.

> **תורכם:** הציגו את `name` ו-`city` של כל סטודנט.
