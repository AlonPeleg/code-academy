כל תוכנית שימושית מתחילה בהחלטה איך הנתונים שלה נראים. בפרויקט הזה תבנו **מעקב הוצאות**: תוכנית שמתעדת על מה אתם מוציאים כסף, מסכמת, מתריעה על התקציב ומדפיסה דוח מסודר. השלב הראשון הוא החשוב ביותר, כי כל השאר נבנה על הצורה של הנתונים.

## איפה אנחנו עומדים

עדיין אין כלום, רק רשימה ריקה. בסוף השלב הזה התוכנית תחזיק שלוש הוצאות ותדפיס אותן עם סכום כולל.

## מה נוסיף

**מודל נתונים**: ההחלטה איך מייצגים הוצאה אחת ואוסף של הוצאות. אפליקציית כספים אמיתית צריכה לזכור ארבע עובדות על כל קנייה: **מתי** היא קרתה (date), **כמה** היא עלתה (amount), **איזה סוג** של הוצאה זו הייתה (category), והערה (note) חופשית.

## הרעיון: מילון לדבר אחד, רשימה להרבה דברים

מילון (dictionary) שומר עובדות תחת שמות (מפתחות):

```python
expense = {"date": "2025-02-03", "amount": 12.50, "category": "food", "note": "lunch"}
print(expense["amount"])    # prints: 12.5
```

כל ארבע העובדות נשארות ביחד, וקוראים כל אחת לפי השם שלה, וזה הרבה יותר ברור מאשר לזכור ש"מקום 2 הוא הקטגוריה".

הרבה הוצאות נכנסות לרשימה (list):

```python
expenses = []
expenses.append(expense)    # add one dict to the end
print(len(expenses))        # prints: 1
```

רשימה של מילונים היא צורת הנתונים הנפוצה ביותר בתוכניות Python אמיתיות. זה בדיוק מה שמקבלים מתשובת JSON מהרשת או מקובץ CSV, ולכן המיומנות הזו שימושית בכל מקום.

## מדריך צעד אחר צעד

1. **מוסיפים את שתי ההוצאות האחרות.** קוד ההתחלה כבר מכיל את הראשונה. העתיקו את הצורה שלה עבור אלה:
   * `2025-02-05`, `45.00`, `transport`, `train pass`
   * `2025-02-14`, `60.00`, `fun`, `concert ticket`

   אפשר לבנות את המילון ישירות בתוך הקריאה: `expenses.append({"date": ..., ...})`.
2. **סופרים אותן.** `print("Expenses recorded:", len(expenses))` מדפיסה את התווית ואת המספר עם רווח ביניהם.
3. **עוברים על כל הוצאה בלולאה.** לולאת `for` נותנת לכם מילון אחד בכל פעם:

```python
for expense in expenses:
    print(expense["date"], expense["note"])
```

4. **מעצבים כל שורה.** f-string מאפשרת לשים ערכים ישירות בתוך טקסט. מפני שמפתחות המילון כתובים במרכאות כפולות, השתמשו במרכאות בודדות בתוך הסוגריים המסולסלים (או להפך):

```python
print(f"{expense['date']} | {expense['category']} | {expense['amount']:.2f} | {expense['note']}")
```

   החלק אחרי הנקודתיים, `.2f`, פירושו "מספר עשרוני עם בדיוק שתי ספרות אחרי הנקודה", ולכן `12.5` מודפס כ-`12.50`. זה מה שרוצים עבור כסף.
5. **שומרים סכום מצטבר.** לפני הלולאה כתבו `total = 0`. בתוך הלולאה, `total += expense["amount"]` מוסיפה אליו את הסכום הנוכחי. אחרי הלולאה, הדפיסו `Total: ` באותו פורמט של שתי ספרות אחרי הנקודה.

## הערה על כסף

מספרי `float` של Python לא יכולים לשמור כל מספר עשרוני במדויק (לדוגמה `0.1 + 0.2` הוא `0.30000000000000004`). בכלי קטן, עיגול לשתי ספרות עשרוניות בזמן ההדפסה מספיק. תוכנות בנקאיות שומרות אגורות שלמות כמספרים שלמים או משתמשות במודול `decimal`. זכרו את זה כשהפרויקט שלכם יגדל.

> **שימו לב:**
> - `KeyError: 'Amount'` אומרת שטעיתם בהקלדת מפתח. מפתחות רגישים לאותיות גדולות וקטנות וחייבים להתאים בדיוק.
> - `TypeError: unsupported operand type(s) for +=: 'int' and 'str'` אומרת ששמרתם סכום כטקסט (`"12.50"`) ולא כמספר (`12.50`). אל תשימו מרכאות סביב סכומים.
> - שימוש באותן מרכאות בתוך ביטוי של f-string, כמו `f"{expense["date"]}"`, עלול להיות שגיאת תחביר ב-Python ישנה יותר. השתמשו במרכאות בודדות בפנים.
> - אם שוכחים `total = 0` לפני הלולאה, מקבלים `NameError: name 'total' is not defined`.
> - אם שמים את `print(f"Total...")` בתוך הלולאה, מודפס סכום כולל בכל שורה במקום פעם אחת.

> **תורכם:** הוסיפו את שתי ההוצאות הנותרות עם append, הדפיסו `Expenses recorded: 3`, עברו בלולאה על הרשימה והדפיסו שורה אחת לכל הוצאה בצורה `2025-02-03 | food | 12.50 | lunch`, חברו את הסכומים לסכום כולל עם `+=`, וסיימו עם `Total: 117.50`.
