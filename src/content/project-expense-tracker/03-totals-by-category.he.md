"כמה הוצאתי על אוכל?" היא השאלה הראשונה שכולם שואלים מול מעקב הוצאות. כדי לענות עליה צריך **לקבץ** את ההוצאות לפי קטגוריה ולחבר כל קבוצה. זה אחד הדפוסים השימושיים ביותר בתכנות.

## איפה אנחנו עומדים

אתם יכולים להוסיף הוצאות, להציג אותן עם מספרים ולחשב את הסכום הכולל. התוכנית יודעת את הסכום הכולל, אבל לא יודעת כלום על לאן הכסף הלך.

## מה נוסיף

פונקציה `totals_by_category(expenses)` שמחזירה מילון (dictionary) כמו `{"food": 63.05, "transport": 60.0, ...}`, וקטע קצר בתוכנית שמדפיס אותו. אפליקציות אמיתיות מציגות את זה כתרשים עוגה או כטבלה; הלוגיקה שמתחת היא בדיוק הפונקציה הזו.

## דפוס המצבר עם מילון

אתם כבר מכירים את דפוס "הסכום המצטבר": מתחילים ב-0 ומוסיפים בלולאה. כאן אנחנו צריכים סכום מצטבר אחד **לכל קטגוריה**. מילון מושלם לזה: המפתחות הם הקטגוריות והערכים הם הסכומים המצטברים.

```python
totals = {}
for expense in expenses:
    category = expense["category"]
    totals[category] = totals.get(category, 0) + expense["amount"]
```

קראו את השורה האחרונה לאט:

1. `totals.get(category, 0)` מחפשת את הסכום הנוכחי של הקטגוריה. אם הקטגוריה **עדיין לא נראתה**, `get` מחזירה את הארגומנט השני, `0`, במקום לזרוק שגיאה.
2. `+ expense["amount"]` מוסיף את ההוצאה הזו.
3. `totals[category] = ...` שומרת את הסכום החדש בחזרה תחת אותו מפתח (ויוצרת את המפתח אם צריך).

עברו ביד על שתי ההוצאות הראשונות של אוכל: בפעם הראשונה `get` נותנת 0, ולכן food הופך ל-`0 + 12.5 = 12.5`. ההוצאה הבאה על אוכל נותנת `12.5 + 8.2 = 20.7`. כל קטגוריה גדלה בנפרד.

## מדריך צעד אחר צעד

1. החליפו את `totals_by_category` הריקה כך שתבנה ותחזיר את המילון כמו למעלה. החזירו את המילון, אל תדפיסו בתוך הפונקציה.
2. בתוכנית, אחרי השורה "Total spent", הדפיסו את הכותרת `By category:`.
3. עברו בלולאה על הזוגות של המילון עם `.items()` ופרקו כל זוג לשני שמות:

```python
for category, amount in totals_by_category(expenses).items():
    print(f"  {category}: {amount:.2f}")
```

   `.items()` מייצרת זוגות `(key, value)`. שני הרווחים בתחילת ה-f-string מזיזים את השורות פנימה מתחת לכותרת.
4. הריצו. מילונים זוכרים את הסדר שבו המפתחות נוספו לראשונה, ולכן הקטגוריות מופיעות לפי הסדר שבו הן מופיעות לראשונה בדוגמה: food, transport, fun, bills.

## דרך אחרת לכתוב את אותו הדבר

יש אנשים שמעדיפים בדיקה מפורשת:

```python
if category in totals:
    totals[category] += expense["amount"]
else:
    totals[category] = expense["amount"]
```

שתי הדרכים עובדות. `get` קצרה יותר כשמתרגלים אליה. ב-Python יש גם `collections.defaultdict(float)`, שעושה בשבילכם את ה"התחלה מאפס"; אפשר לנסות אותה בהמשך.

## בדיקה צולבת של העבודה

הרגל טוב: סכום כל הסיכומים לפי קטגוריה חייב להיות שווה לסכום הכולל. כאן `63.05 + 60.00 + 90.00 + 175.40 = 388.45`, בהתאמה ל-"Total spent". אם הם שונים, קטגוריה הולכת לאיבוד.

> **שימו לב:**
> - `KeyError: 'food'` מופיעה אם כותבים `totals[category] += amount` עבור קטגוריה שעדיין לא נמצאת במילון. השתמשו ב-`.get(category, 0)` או בדקו קודם.
> - כתיבת `totals = {}` **בתוך** הלולאה מאפסת את המילון בכל הוצאה, ולכן נשארת רק האחרונה.
> - `ValueError: too many values to unpack` קורית אם עוברים בלולאה על המילון עצמו (`for category, amount in totals`), מה שנותן רק את המפתחות. הוסיפו `.items()`.
> - שגיאות כתיב בקטגוריה (`"Food"` לעומת `"food"`) יוצרות שתי קבוצות נפרדות. בשלב 4 ננרמל את הטקסט.
> - החזרה בתוך הלולאה (הזחה רחבה מדי) מסיימת את הפונקציה אחרי הוצאה אחת.

> **תורכם:** כתבו את `totals_by_category(expenses)` והוסיפו את הקטע `By category:` אחרי שורת הסכום הכולל, עם שורה אחת לכל קטגוריה בצורה `  food: 63.05`.
