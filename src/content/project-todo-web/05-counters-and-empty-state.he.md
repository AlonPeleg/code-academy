ממשקים טובים עונים על שאלות עוד לפני ששואלים אותן: "כמה נשאר?" ו"למה המסך ריק?". בשלב הזה תוסיפו שתי תכונות קטנות שגורמות לאפליקציה להרגיש גמורה: מונה חי והודעת מצב ריק.

## איפה אנחנו

אפשר להוסיף משימות, לסמן אותן ולמחוק אותן. הדף לא מספר כמה משימות פתוחות, ואם מוחקים הכול נשאר שטח לבן ריק.

## מה נוסיף, ולמה זה חשוב

- מונה שאומר `2 tasks left`, ו-`1 task left` ביחיד. דקדוק שגוי כמו "1 tasks left" נראה מרושל, והמשתמשים שמים לב.
- **מצב ריק** (empty state): הודעה ידידותית כמו "Nothing to do. Enjoy your day!" כשאין משימות ברשימה. מעצבים מציינים את זה כאחד החלקים הנשכחים ביותר באפליקציה. אזור ריק נראה כמו באג.

הרעיון החשוב כאן הוא לשמור את המצב ב**פונקציה אחת**. הרבה מקומות משנים את הרשימה (הוספה, סימון, מחיקה). אם כל אחד מהם יעדכן את המספרים בדרך משלו, במוקדם או במאוחר הם יסתרו זה את זה. פונקציה אחת, `updateStatus()`, שקוראת את הרשימה ומרעננת הכול, לא יכולה לסתור את עצמה.

## הדרכה צעד אחר צעד

**1. הוסיפו את שתי הפסקאות ב-HTML.** ההודעה הריקה והמונה קיימים מההתחלה, ו-JavaScript רק משנה אותם:

```html
<p id="empty-message" class="empty">Nothing to do. Enjoy your day!</p>
<p id="counter" class="counter"></p>
```

**2. ספרו עם סלקטורים של CSS.** `querySelectorAll` מחזירה את כל ההתאמות, ולכן ה-`length` שלה הוא ספירה. הסלקטור `li:not(.done)` פירושו "אלמנטי li שאין להם את המחלקה done":

```js
const total = list.querySelectorAll('li').length;
const left = list.querySelectorAll('li:not(.done)').length;
```

**3. כתבו את הטקסט, ביחיד וברבים.** אופרטור התנאי (ternary) `condition ? valueIfTrue : valueIfFalse` הוא `if` קומפקטי:

```js
counter.textContent = left + (left === 1 ? ' task left' : ' tasks left');
// 0 -> "0 tasks left", 1 -> "1 task left", 5 -> "5 tasks left"
```

**4. הציגו או הסתירו את ההודעה הריקה.** לכל אלמנט יש תכונה בשם `hidden`. קביעה שלה ל-`true` מסתירה את האלמנט, ו-`false` מציגה אותו. מכיוון ש-`total > 0` הוא בעצמו אמת או שקר, שורה אחת עושה את העבודה:

```js
emptyMessage.hidden = total > 0;
```

**5. קראו לפונקציה בכל מקום שבו הרשימה משתנה.** בסוף `addTask`, בסוף מאזין הלחיצות (אחרי הסימון או המחיקה) ופעם אחת בהתחלה, כך שהדף נכון עוד לפני שקורה משהו:

```js
updateStatus();
```

**6. אל תתנו ל-CSS להילחם בתכונה.** התכונה `hidden` היא רק רמז חלש. אם כותבים `.empty { display: block; }` (או flex, או grid) הכלל הזה מנצח וההודעה מוצגת בכל זאת. התיקון הוא כלל אחד שגורם ל-`hidden` לנצח תמיד: `[hidden] { display: none !important; }`.

## מה ההדגמה עושה עכשיו

ההדגמה מוסיפה שלוש משימות, מסמנת את הראשונה ומוחקת את האחרונה. נשארות ברשימה שתי משימות, אחת מהן הושלמה, ולכן המונה מציג **1 task left** וההודעה הריקה מוסתרת. נסו למחוק ידנית את כל המשימות: ההודעה תופיע והמונה יציג `0 tasks left`.

> **שימו לב:**
> - מעדכנים את המונה רק בתוך `addTask`. אחרי סימון או מחיקה הוא מציג מספר ישן. קראו ל-`updateStatus()` גם במאזין הלחיצות.
> - אופרטור התנאי צריך סוגריים: `left + left === 1 ? ...` נקרא כ-`(left + left) === 1`, והפלט חסר היגיון. כתבו `left + (left === 1 ? ... : ...)`.
> - קריאה ל-`updateStatus()` לפני שהקבועים קיימים גורמת ל-`ReferenceError: Cannot access 'counter' before initialization`. הגדירו קודם את הקבועים.
> - `emptyMessage.hidden = 'false'` מסתירה את ההודעה, כי המחרוזת `'false'` נחשבת אמת (truthy). השתמשו בערכים בוליאניים אמיתיים.

> **תורכם:** הוסיפו את שתי הפסקאות ל-`index.html`, כתבו את `updateStatus()` (טקסט המונה ביחיד וברבים, וההודעה הריקה מוסתרת כשיש משימות), קראו לה בשלושת המקומות, והוסיפו את ה-CSS מרשימת ה-TODO כולל הכלל `[hidden]`. אחרי ההדגמה הדף חייב להציג "1 task left" וההודעה הריקה חייבת להיות מוסתרת.
