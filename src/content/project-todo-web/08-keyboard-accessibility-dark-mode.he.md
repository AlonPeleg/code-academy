האפליקציה שלכם עובדת. עכשיו נגרום לה לעבוד עבור **כולם**: אנשים שמשתמשים רק במקלדת, אנשים שמשתמשים בקורא מסך, ואנשים שמעדיפים מסך כהה. שלב הליטוש הזה מפריד בין הדגמה לבין משהו שתהיו גאים לפרסם. הוא גם מלמד שנגישות היא בעיקר שימוש באלמנטי ה-HTML הנכונים.

## איפה אנחנו

האפליקציה מוסיפה, מסמנת, מוחקת, מסננת ושומרת משימות, ויש לה מראה משלה. אבל משתמש מקלדת לא יכול לסמן משימה (`li` לא יכול לקבל פוקוס), קורא מסך לא יכריז שהמונה השתנה, והדף לבן וזוהר בחצות.

## מה נוסיף, ולמה זה חשוב

בערך אחד מכל ארבעה מבוגרים סובל ממוגבלות כלשהי, ועוד רבים פשוט מעדיפים את המקלדת או את המצב הכהה. נגישות גם נבדקת בראיונות עבודה ולעיתים קרובות נדרשת בחוק באתרים ציבוריים. החדשות הטובות: את רובה מקבלים מבחירת אלמנטים נכונים, לא מכתיבת קוד נוסף.

## הדרכה צעד אחר צעד

**1. השתמשו בבקרים אמיתיים.** החליפו את הטקסט הלחיץ בתיבת סימון ובתווית:

```js
const checkbox = document.createElement('input');
checkbox.type = 'checkbox';
checkbox.id = 'task-' + task.id;
checkbox.checked = task.done;

const label = document.createElement('label');
label.htmlFor = checkbox.id;      // the JavaScript name of the "for" attribute
label.textContent = task.text;
```

אפשר להתמקד בתיבת סימון עם Tab, להחליף אותה עם מקש הרווח, והיא מוכרזת כ"checkbox, checked". היא מפעילה אירוע `change`, ולכן האזינו ל-`change` ברשימה במקום ל-`click`. התווית מקושרת לתיבת הסימון, ולכן לחיצה על הטקסט עדיין מחליפה אותה. תנו לכפתור Delete שם מדויק: `remove.setAttribute('aria-label', 'Delete task: ' + task.text)`, כי משתמש בקורא מסך ששומע "Delete, Delete, Delete" לא יכול להבדיל בין הכפתורים.

**2. שמרו על הפוקוס.** `render()` זורקת את האלמנטים הישנים, ותיבת הסימון שהמשתמש בדיוק לחץ עליה נעלמת איתם. פוקוס המקלדת היה חוזר לראש הדף. אחרי סימון, מצאו את תיבת הסימון החדשה וקראו לה `.focus()`. אחרי מחיקה, העבירו את הפוקוס לשדה הקלט.

**3. הכריזו על שינויים.** `aria-live="polite"` על המונה ועל ההודעה הריקה גורם לקוראי מסך להקריא את הטקסט החדש כשהוא משתנה. `aria-pressed="true"` על כפתור מתג (כפתורי המסננים וכפתור ערכת הנושא) אומר איזה מהם נבחר, ולא רק בעזרת צבע.

**4. קיצורי מקלדת.** אובייקט האירוע אומר לכם איזה מקש נלחץ:

```js
input.addEventListener('keydown', function (event) {
  if (event.key === 'Escape') input.value = '';
});
```

מאזין על `document` יכול לתפוס את `/` כדי לקפוץ לשדה הקלט. מנעו את פעולת ברירת המחדל (הקלדת קו נטוי) רק כשאתם לא כבר עומדים בתוך שדה הקלט.

**5. מצב כהה עם משתנים.** בשלב 2 כל צבע הפך למשתנה. ערכת נושא כהה צריכה רק ערכים חדשים, שמוגבלים לתכונת data על אלמנט ה-`html`:

```css
:root[data-theme="dark"] {
  --bg: #111827;
  --card: #1f2937;
  --text: #f9fafb;
  --muted: #9ca3af;
  --border: #374151;
}
```

```js
document.documentElement.dataset.theme = 'dark';   // sets data-theme="dark" on <html>
```

`document.documentElement` הוא אלמנט ה-`html`. כתיבה ל-`dataset.theme` קובעת את התכונה וה-CSS משתלט. כפתור המתג מעדכן גם את הערך `aria-pressed` שלו ואת הטקסט שלו. אנחנו שומרים את הבחירה באותו `storage` של המשימות, כך שאתר אמיתי היה זוכר אותה.

**6. ההדגמה.** הסקריפט מסמן את תיבת הסימון הראשונה ולוחץ על כפתור ערכת הנושא, כך שהתצוגה המקדימה נפתחת במצב כהה. מחקו את השורה האחרונה כדי להתחיל במצב בהיר.

> **שימו לב:**
> - `label.for = ...` לא עושה דבר: ב-JavaScript התכונה נקראת `htmlFor`.
> - אזורי `aria-live` חייבים להיות קיימים בדף **לפני** שהטקסט שלהם משתנה. אל תיצרו אותם באותו זמן עם ההודעה.
> - אל תסירו את מסגרת הפוקוס (`outline: none`) בלי תחליף. משתמשי מקלדת לא יוכלו לראות איפה הם נמצאים. הכלל `:focus-visible` שלנו מציג אותה רק בשימוש במקלדת.
> - צבעים שנכתבו ישירות (`#fff`) בכללים אחרים לא יעקבו אחרי ערכת הנושא. תמיד השתמשו ב-`var(--...)`.

> **תורכם:** עקבו אחרי רשימת ה-TODO בשלושת הקבצים. המשימות חייבות להשתמש בתיבת סימון, בתווית ובכפתור Delete עם `aria-label`. הוסיפו את מאזין `change`, את הקיצורים Escape ו-`/`, את כפתור ערכת הנושא עם `setTheme`, את `aria-live` על המונה ואת `aria-pressed` על המתג ועל המסננים, ואת ה-CSS של ערכת הנושא הכהה. כשההדגמה מסתיימת הדף במצב כהה, המתג אומר "Light mode" ורקע ה-body הוא `#111827`.

## מה לבנות אחר כך

יש לכם עכשיו אפליקציה שלמה. רעיונות לתרגול: שדה תאריך יעד לכל משימה ומיון לפי תאריך; עריכת משימה בלחיצה כפולה; כפתור "Clear completed"; סידור מחדש בגרירה ושחרור; שימוש ב-`prefers-color-scheme` כדי לבחור את ערכת הנושא ההתחלתית; או פיצול `script.js` למספר קבצים וטעינתם כמודולים. כשתהיו מוכנים לנתונים בצד השרת, הפרויקט הבא, ספריית האנשים (People Directory), מחבר אפליקציית React ל-API של אינטרנט.
