ברוכים הבאים לפרויקט האמיתי הראשון שלכם. במהלך שמונה שלבים תבנו אפליקציית משימות שאפשר להעלות לאתר אמיתי: הוספת משימות, סימון שבוצעו, מחיקה, סינון, שמירה ואפילו מעבר למצב כהה. בכל שלב תקבלו את הקוד המוגמר של השלב הקודם, וכמה הערות `TODO` שאומרות מה להוסיף. שום דבר לא מוסתר: עד שלב 8 תכתבו, או לפחות תקראו ותבינו, כל שורה.

## איפה אנחנו עומדים

אנחנו בתחילת הדרך. יש לכם דף כמעט ריק. בסוף השלב הזה הדפדפן יציג כותרת, טופס קטן ורשימה עם פריט מקום שמור אחד. הוא עדיין לא יעשה דבר, כי זו המשימה של JavaScript, שמגיע בשלב 3. אפליקציות טובות מתחילות במבנה טוב, וזה HTML.

## מה נוסיף, ולמה זה חשוב

אפליקציית משימות היא למעשה שלושה דברים: מקום **להקליד** (הטופס), מקום **לראות** את התוצאה (הרשימה), וכותרת. כדאי לבנות קודם את ה-HTML נכון, וזה ישתלם בהמשך. JavaScript יצטרך למצוא את הטופס, את ה-input ואת הרשימה, ולכן נותנים לכל אחד מהם `id`, שם ייחודי שהקוד יכול להשתמש בו כדי למצוא אלמנט. אפליקציות אמיתיות בנויות בדיוק כך: קודם מבנה, אחר כך מראה, ואחר כך התנהגות.

## הדרכה שלב אחר שלב

**1. עוטפים את הדף ב-`main`.** האלמנט `main` מסמן את התוכן הראשי של הדף. תנו לו מחלקה כדי שנוכל לעצב אותו בשלב 2:

```html
<main class="app">
  ...
</main>
```

**2. מוסיפים את הכותרת.** לכל דף צריך `h1` אחד שאומר על מה הדף:

```html
<h1>My Tasks</h1>
```

**3. בונים את הטופס.** טופס מקבץ את הפקדים שהמשתמש ממלא. לשלנו שלושה חלקים:

```html
<form id="task-form">
  <label for="task-input">New task</label>
  <input id="task-input" type="text" placeholder="What needs doing?">
  <button type="submit">Add</button>
</form>
```

חלק אחר חלק:

- `<label for="task-input">` הוא הכיתוב הגלוי. ה-`for` שלו חייב להיות בדיוק ה-`id` של ה-input שהוא מתאר. לחיצה על ה-label ממקדת את ה-input, וקוראי מסך מקריאים אותו. `placeholder` אינו תחליף ל-label, כי הוא נעלם כשמקלידים.
- `<input type="text">` הוא תיבת טקסט בשורה אחת. `autocomplete="off"` מונע מהדפדפן להציע ערכים ישנים (אפשר להוסיף אותו, השיעור מקבל את שני המצבים).
- `<button type="submit">` שולח את הטופס. כשהמשתמש לוחץ עליו, או לוחץ Enter בתוך ה-input, הדפדפן מפעיל אירוע `submit`. בשלב 3 נאזין לו.

**4. מוסיפים את הרשימה.** רשימת משימות היא רשימה, ולכן אנחנו משתמשים ב-`ul` (רשימה לא ממוספרת) עם אלמנטי `li` (פריט ברשימה) כבנים:

```html
<ul id="task-list">
  <li>Placeholder task</li>
</ul>
```

מקום השמור נמצא שם רק כדי שתוכלו לראות את הרשימה. בשלב 3 JavaScript ייצור את הפריטים האמיתיים ואנחנו נמחק את זה.

## נסו בתצוגה המקדימה

הריצו את הקוד. אתם אמורים לראות את הכותרת, את ה-label, תיבת טקסט, כפתור Add ותבליט אחד. לחצו על **Add**: הדף נטען מחדש, כי טפסים שולחים נתונים לשרת כברירת מחדל. זה תקין לעת עתה, ובשלב 3 נעצור את זה.

> **שימו לב:**
> - ל-label ש-`for` שלו לא תואם לאף `id` אין שום השפעה. שגיאות הקלדה כמו `for="task-imput"` נכשלות בשקט.
> - ערכי id חייבים להיות ייחודיים בדף. שני אלמנטים עם `id="task-list"` יבלבלו את JavaScript בהמשך.
> - אם שוכחים לסגור תגית (`</form>`, `</ul>`) הדפדפן מנחש, והפריסה נראית מוזרה. הזיזו את הקוד פנימה כדי לראות את ההקננה.
> - שימו `li` רק בתוך `ul` או `ol`, לעולם לא ישירות בתוך ה-body.

> **תורכם:** בצעו את ארבע הערות ה-`TODO` בקובץ `index.html`. הדף חייב להכיל `main.app` עם `h1` שאומר "My Tasks", `form#task-form` עם label שמחובר ל-`input#task-input` וכפתור שליחה שאומר "Add", ו-`ul#task-list` עם `li` אחד.
