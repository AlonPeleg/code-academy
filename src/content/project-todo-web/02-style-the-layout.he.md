יש לכם מבנה דף שעובד. עכשיו נגרום לו להיראות כמו משהו שאנשים ירצו להשתמש בו. CSS היא שפת המראה, ובשלב הזה תלמדו את שלושת הכלים שנושאים את רוב הפריסות האמיתיות: משתנים, מודל הקופסה (box model) ו-flexbox.

## איפה אנחנו עומדים

בדף יש כותרת, טופס ורשימה, אבל הכול מכווץ אל הקצה השמאלי בסגנון ברירת המחדל של הדפדפן. עדיין אין שום התנהגות.

## מה נוסיף, ולמה זה חשוב

גיליון סגנונות מקצועי אינו ערימה של צבעים אקראיים. הוא מתחיל בכך שהוא נותן שמות להחלטות שלו: זה צבע המותג שלנו, זה המרווח שלנו. אם מעצב או מעצבת יגידו אחר כך "תכהו קצת את הסגול", תשנו שורה אחת במקום לחפש בחמישים. אנחנו רוצים גם **כרטיס**: קופסה ממורכזת עם רוחב מרבי, כך שהאפליקציה תיראה טוב בטלפון ובמסך ענק.

## הדרכה שלב אחר שלב

**1. מגדירים משתנים על `:root`.** `:root` הוא האלמנט העליון של הדף (כמו `html`). מאפיין מותאם אישית מתחיל בשני מקפים, ו-`var()` קורא אותו בחזרה:

```css
:root {
  --primary: #6d5efc;
  --radius: 12px;
}

button { background: var(--primary); }
```

משתנים עוברים בירושה לכל אלמנט שמתחת ל-`:root`, ולכן הם עובדים בכל מקום. שימו שם את כל שמונת המשתנים מרשימת ה-`TODO`: רקע, כרטיס, טקסט, טקסט עמום, צבע ראשי, מסגרת, רדיוס ומרווח.

**2. הופכים קופסאות לצפויות.** כל אלמנט הוא קופסה עם תוכן, padding ומסגרת. כברירת מחדל, `width: 200px` ועוד `padding: 20px` נותנים קופסה של 240px, וזה מבלבל. כלל אוניברסלי אחד מתקן את זה:

```css
* { box-sizing: border-box; }
```

**3. מעצבים את ה-body ואת הכרטיס.** ה-body מקבל את רקע הדף וגופן קריא. הכרטיס ממרכז את עצמו בעזרת `margin: 0 auto` (אפס למעלה ולמטה, אוטומטי משמאל ומימין) ומסרב לגדול מעבר ל-`max-width: 480px`:

```css
.app {
  max-width: 480px;
  margin: 0 auto;
  padding: 24px;
  background: var(--card);
  border-radius: var(--radius);
}
```

בטלפון צר הכרטיס פשוט מתכווץ כדי להתאים. זו פיסה זעירה של **עיצוב רספונסיבי (responsive design)**.

**4. מסדרים את הטופס בעזרת flexbox.** מכל flex מציב את הבנים שלו בשורה. `gap` מוסיף רווח ביניהם, ו-`flex-wrap: wrap` מאפשר ל-label, שאנחנו כופים עליו `flex-basis: 100%`, לשבת בשורה משלו מעל ה-input והכפתור. `flex: 1` על ה-input אומר "קח את כל הרוחב שנשאר":

```css
#task-form { display: flex; flex-wrap: wrap; gap: 8px; }
#task-form label { flex-basis: 100%; }
#task-form input { flex: 1; }
```

**5. מלטשים את הכפתור ואת הרשימה.** תנו לכפתור את `var(--primary)` כרקע וטקסט לבן, הסירו את מסגרת ברירת המחדל והוסיפו `cursor: pointer`. ברשימה, `list-style: none` מסיר את התבליטים ו-`padding: 0` מסיר את ההזחה. מסגרת תחתונה על כל `li` יוצרת קווי הפרדה דקים.

> **שימו לב:**
> - נקודה-פסיק חסרה שוברת בשקט את השורה הזו ואת זו שאחריה. אם סגנון לא חל, הסתכלו על השורה שמעליו.
> - `var(--primary)` צריך את השם המדויק. `var(--primay)` לא יוצר שגיאה, פשוט מתעלמים מהמאפיין.
> - מאפיינים מותאמים אישית חייבים להיות מוגדרים במקום שבו הבנים יכולים לרשת אותם. אם תשימו אותם על `.app` הכלל של `body` לא יוכל להשתמש בהם.
> - צבעים בצורת hex צריכים את ה-`#`. `6d5efc` לבדו אינו תקין.

> **תורכם:** כתבו את ה-CSS בקובץ `style.css` לפי שבעת פריטי ה-`TODO`. הבדיקה מסתכלת על ערכים מחושבים אמיתיים: משתנה `:root` בשם `--primary`, רקע הדף, כרטיס ברוחב 480px עם padding של 24px וקצוות מעוגלים של 12px, טופס flex עם רווח של 8px, כפתור סגול עם טקסט לבן, ורשימה בלי תבליטים. השתמשו ב-`var(--primary)` וב-`var(--bg)` במקום לחזור על הצבעים.
