**JavaScript** היא שפת התכנות של הרשת, אבל היא רצה גם על שרתים, על טלפונים ואפילו על רובוטים. בשיעור הזה תריצו את התוכנית הראשונה שלכם ותלמדו איך רואים מה היא עושה.

## מהי תוכנית?

תוכנית היא רשימת הוראות שהמחשב מבצע אחת אחרי השנייה, מלמעלה למטה. כל הוראה נקראת **פקודה** (statement). הפקודה הראשונה שלנו תדפיס הודעה, כדי שנראה שהתוכנית חיה.

## console.log

הכלי להדפסה הוא `console.log`:

```js
console.log("Hello!");
```

בואו נפרק אותו לחלקים:

- `console` הוא אובייקט (object) מובנה ב-JavaScript שמייצג את אזור הפלט (ה"קונסולה").
- `.log` היא פקודה ששייכת לקונסולה. פקודה שמחוברת לאובייקט בצורה כזו נקראת **מתודה** (method).
- הסוגריים `( )` מכילים את ה**ארגומנט** (argument): הדבר שרוצים להדפיס.
- `"Hello!"` הוא הארגומנט. טקסט בתוך מרכאות נקרא **מחרוזת** (string).
- נקודה-פסיק `;` מסמנת את סוף הפקודה. בהרבה מקרים היא אופציונלית, אבל זה הרגל טוב.

כשלוחצים על **Run** (או על `Ctrl/Cmd + Enter`), ההודעה מופיעה בחלונית **Output**.

## יותר משורה אחת

כל `console.log` מדפיס בשורה משלו:

```js
console.log("First");
console.log("Second");
// prints:
// First
// Second
```

המחשב מריץ את השורות לפי הסדר. אם תחליפו ביניהן, גם הפלט יתחלף.

## הדפסת דברים אחרים

אפשר להדפיס מספרים בלי מרכאות, ואפילו לחשב בתוך הפקודה:

```js
console.log(42);      // prints: 42
console.log(10 + 5);  // prints: 15
console.log("10 + 5"); // prints: 10 + 5   (it is text, so no maths happens)
```

אפשר להדפיס כמה דברים בקריאה אחת אם מפרידים ביניהם בפסיקים. הם יודפסו עם רווח ביניהם:

```js
console.log("I am", 20, "years old"); // prints: I am 20 years old
```

## הערות

שורה שמתחילה ב-`//` היא **הערה** (comment). המחשב מתעלם ממנה, ולכן אפשר להשאיר בה פתקים לעצמכם ולאנשים אחרים. קוד ההתחלה בכל שיעור משתמש בהערות כדי להסביר לכם מה לעשות.

```js
// This line does nothing, it is just a note.
console.log("This line prints."); // you can also comment at the end of a line
```

> **שימו לב:**
> - שכחתם את המרכאות: `console.log(Hello)` גורם ל-`ReferenceError: Hello is not defined`, כי JavaScript חושבת ש-`Hello` הוא שם של משתנה (variable).
> - מרכאות או סוגריים שלא תואמים: `console.log("Hi);` גורם ל-`SyntaxError: Invalid or unexpected token`. לכל מרכאה או סוגר פותח צריך להיות זוג.
> - אותיות גדולות במקום הלא נכון: `Console.log("Hi")` או `console.Log("Hi")` נכשלים עם `ReferenceError` או `TypeError`. JavaScript מבחינה בין אותיות גדולות וקטנות (case-sensitive).
> - מילים עם שגיאות כתיב: `consol.log("Hi")` גורם ל-`ReferenceError: consol is not defined`.
> - קריאת השגיאה: הטקסט האדום בחלונית הפלט מסביר מה השתבש, ולעיתים קרובות גם באיזו שורה. אל תיבהלו, זה רק רמז.

## להמשיך הלאה

הדפיסו את השם שלכם, את האוכל האהוב עליכם ומספר, כל אחד בשורה משלו. נסו לכתוב הערה מעל כל שורה. אחר כך נסו משהו שנכשל בכוונה (מחקו מרכאה) כדי לראות איך נראית הודעת שגיאה.

> **תורכם:** הדפיסו `Hello, world!` ואחריו `I am learning JavaScript`, כל אחד בשורה משלו. אחר כך לחצו על **Check answer**.
