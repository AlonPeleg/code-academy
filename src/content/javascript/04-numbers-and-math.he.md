מספרים הם הלב של כל תוכנית: ניקוד, מחירים, מיקומים, טיימרים. ל-JavaScript יש טיפוס מספרי אחד בלבד, והוא משמש גם למספרים שלמים (`7`) וגם למספרים עשרוניים (`3.14`). בשיעור הזה תכירו את אופרטורי החשבון ואת כלי `Math` המובנים.

## האופרטורים

| Operator | משמעות | Example | Result |
| --- | --- | --- | --- |
| `+` | חיבור | `5 + 2` | `7` |
| `-` | חיסור | `5 - 2` | `3` |
| `*` | כפל | `5 * 2` | `10` |
| `/` | חילוק | `5 / 2` | `2.5` |
| `%` | שארית | `5 % 2` | `1` |
| `**` | חזקה | `2 ** 3` | `8` |

אופרטור ה**שארית** `%` עונה על השאלה "מה נשאר אחרי החילוק?" הוא שימושי מאוד. `n % 2 === 0` נכון עבור מספרים זוגיים, ו-`n % 10` נותן את הספרה האחרונה של מספר.

JavaScript פועלת לפי סדר פעולות החשבון הרגיל: כפל וחילוק לפני חיבור וחיסור. השתמשו בסוגריים כדי להיות ברורים: `(1 + 2) * 3` הוא `9`.

## קיצורים

```js
let score = 10;
score += 5;  // same as score = score + 5  -> 15
score -= 3;  // 12
score *= 2;  // 24
score++;     // add one -> 25
```

## מספרים עשרוניים ו-toFixed

מחשבים שומרים מספרים עשרוניים בדרך שלפעמים מסתירה סטייה קטנה:

```js
console.log(0.1 + 0.2); // prints: 0.30000000000000004
```

זה נורמלי כמעט בכל שפת תכנות. לצורכי כסף והצגה, מעגלים את התוצאה עם `toFixed`, שמחזיר **טקסט** עם מספר קבוע של ספרות אחרי הנקודה:

```js
const total = 19.99 * 3;
console.log(total.toFixed(2)); // prints: 59.97
```

## האובייקט Math

ל-`Math` יש כלים שימושיים:

```js
Math.round(2.6);     // 3   nearest whole number
Math.floor(2.9);     // 2   always down
Math.ceil(2.1);      // 3   always up
Math.max(3, 9, 4);   // 9
Math.min(3, 9, 4);   // 3
Math.abs(-5);        // 5   remove the minus sign
Math.sqrt(81);       // 9   square root
Math.random();       // a random number from 0 up to (not including) 1
```

מספר שלם אקראי בין 1 ל-6, כמו קובייה: `Math.floor(Math.random() * 6) + 1`.

## מספרים וטקסט

טקסט שנראה כמו מספר הוא עדיין טקסט. השתמשו ב-`Number(...)` כדי להמיר:

```js
console.log("5" + 3);          // prints: 53   (joined as text)
console.log(Number("5") + 3);  // prints: 8
console.log(Number("hello"));  // prints: NaN  (not a number)
```

`NaN` פירושו "Not a Number" (לא מספר). זו התוצאה של חישוב חסר משמעות.

> **שימו לב:**
> - `"5" + 3` הוא `"53"`, לא `8`. אם אחד הצדדים של `+` הוא טקסט, JavaScript מצמידה במקום לחבר.
> - חילוק באפס לא גורם לקריסה: `5 / 0` הוא `Infinity`.
> - השוואת מספרים עשרוניים: `0.1 + 0.2 === 0.3` הוא `false`. עגלו לפני שמשווים.
> - `x ** y` היא חזקה. הכתיבה `x ^ y` היא משהו אחר (אופרטור ביטים) ונותנת מספרים מוזרים.
> - `toFixed` מחזיר מחרוזת (string), ולכן `total.toFixed(2) + 1` מצמיד טקסט ונותן `"59.971"`.
> - כתיבת `Math.floor 7.9` בלי סוגריים היא `SyntaxError`.

## להמשיך הלאה

הדפיסו את השטח של עיגול ברדיוס 5: `Math.PI * 5 ** 2`, מעוגל ל-2 ספרות אחרי הנקודה. צרו משתנה שמחזיק הטלת קובייה אקראית.

> **תורכם:** עקבו אחרי ההערות הממוספרות והדפיסו את חמש התוצאות, אחת בכל שורה.
