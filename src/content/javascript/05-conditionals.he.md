תוכניות נהיות מעניינות כשהן יכולות **להחליט**. עם משפט `if`, הקוד שלכם יכול ללכת בדרכים שונות לפי המצב: להציג אזהרה רק אם הסוללה חלשה, או להדפיס ברכה אחרת בלילה.

## משפט if

```js
const age = 20;

if (age >= 18) {
  console.log("Adult");
}
```

- `if` פותח את ההחלטה.
- ה**תנאי** (condition) נכתב בסוגריים. הוא חייב להיות משהו ששווה `true` או `false`.
- הקוד שבתוך `{ }` רץ **רק אם** התנאי מתקיים.

## else

`else` נותן דרך שנייה למקרה שהתנאי לא מתקיים:

```js
if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}
// prints: Adult
```

## else if

כדי לבדוק כמה דברים לפי הסדר, משרשרים עם `else if`. JavaScript בודקת מלמעלה ומריצה את הענף **הראשון** שהתנאי שלו מתקיים, ואז מדלגת על השאר:

```js
if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("Try again");
}
```

מכיוון שהסדר חשוב, בדקו קודם את המקרה הספציפי ביותר.

## אופרטורי השוואה

| Operator | משמעות |
| --- | --- |
| `<` , `>` | קטן מ-, גדול מ- |
| `<=` , `>=` | קטן או שווה, גדול או שווה |
| `===` | שווה (אותו ערך ואותו טיפוס) |
| `!==` | לא שווה |

השתמשו תמיד ב-`===` (שלושה סימני שוויון) ולא ב-`==`. הגרסה הקצרה ממירה טיפוסים בדרכים מבלבלות, למשל `0 == ""` נכון.

## שילוב תנאים

- `&&` פירושו **וגם** (and): שני הצדדים חייבים להיות נכונים. `age >= 13 && age <= 19` נכון עבור בני נוער.
- `||` פירושו **או** (or): לפחות צד אחד חייב להיות נכון. `day === "Sat" || day === "Sun"` נכון בסופי שבוע.
- `!` פירושו **לא** (not): הוא הופך בין true ל-false. `!isRaining` נכון כשלא יורד גשם.

## ערכים truthy ו-falsy

בתוך תנאי, כמה ערכים נחשבים "שקריים": `0`, `""` (טקסט ריק), `null`, `undefined` ו-`NaN`. כל השאר נחשב "אמת". לכן `if (name)` בודק שהשם אינו ריק.

## מבט ראשון על פונקציות

קוד ההתחלה של השיעור הזה משתמש ב**פונקציה** (function), שתכירו כמו שצריך בשיעור שאחרי הבא. לעת עתה: פונקציה היא בלוק קוד עם שם שמריצים אותו על ידי קריאה לשמו, כמו `describeTemp(5)`. המילה `return` שולחת ערך בחזרה למי שקרא לפונקציה. ברגע שפונקציה מגיעה ל-`return`, היא נעצרת.

> **שימו לב:**
> - סימן שוויון אחד בתנאי: `if (age = 18)` מציב ערך במקום להשוות. השתמשו ב-`===`.
> - השוואה בין מחרוזות למספרים: `5 === "5"` הוא `false`.
> - בדיקת המקרה הגדול קודם: עם `if (temp < 25) ... else if (temp < 10)` הענף השני לעולם לא ירוץ, כי כל מספר מתחת ל-10 כבר קטן מ-25.
> - שכחתם את הסוגריים המסולסלים `{ }` או את הסוגריים העגולים: `if age > 5 {` גורם ל-`SyntaxError: Unexpected identifier`.
> - פונקציה שלא מחזירה כלום: אם אף ענף לא רץ, `describeTemp` מחזירה `undefined`, והקונסולה מדפיסה `undefined`.
> - כתיבת נקודה-פסיק מיד אחרי התנאי, `if (x > 1);`, שמסיימת את המשפט בלי שום דבר בתוכו.

## להמשיך הלאה

הוסיפו ענף עבור `temp < 0` שמחזיר `"freezing"`. נסו `&&` כדי להחזיר `"nice"` עבור טמפרטורות מ-20 עד 25.

> **תורכם:** השלימו את `describeTemp` כך שתחזיר `"cold"` מתחת ל-10, `"warm"` מתחת ל-25, ו-`"hot"` בכל מקרה אחר.
