תוכניות אמיתיות כמעט אף פעם לא עוסקות בערך בודד. הן עוסקות באוספים: רשימת שמות, ציונים, מוצרים. ב-JavaScript **מערך** (array) הוא רשימה מסודרת של ערכים. בשילוב עם לולאה אפשר לעבד כל כמות של נתונים בכמה שורות.

## יצירה וקריאה של מערך

```js
const fruits = ["apple", "banana", "cherry"];

console.log(fruits[0]);     // prints: apple
console.log(fruits[2]);     // prints: cherry
console.log(fruits.length); // prints: 3
```

- הפריטים מופרדים בפסיקים בתוך סוגריים מרובעים `[ ]`.
- לכל פריט יש **אינדקס** (index), כלומר מיקום, וה**ספירה מתחילה מ-0**. הפריט האחרון נמצא ב-`length - 1`.
- `array.length` אומר לכם כמה פריטים יש.
- מערך יכול להחזיק כל סוג של ערך, וגם סוגים מעורבים.

## שינוי מערך

```js
fruits.push("date");        // add to the end
fruits.pop();               // remove the last item
fruits[0] = "avocado";      // replace the first item
console.log(fruits);        // prints: ["avocado", "banana", "cherry"]
```

למרות ש-`fruits` הוא `const`, מותר לשנות את מה ש*בתוכו*. מה ש-`const` מונע הוא להפנות את השם למערך אחר.

## מעבר על מערך בלולאה

`for...of` מבקרת בכל פריט בתורו:

```js
for (const fruit of fruits) {
  console.log(fruit);
}
```

בכל סיבוב, `fruit` מחזיק את הפריט הבא. אם צריך גם את המיקום, משתמשים בלולאת `for` רגילה עם `i`:

```js
for (let i = 0; i < fruits.length; i++) {
  console.log(i + ": " + fruits[i]);
}
```

## צבירה

כדי לסכום מספרים, מתחילים עם משתנה ב-`0` ומוסיפים אליו כל פריט:

```js
let sum = 0;
for (const n of [5, 10, 15]) {
  sum += n;
}
console.log(sum); // prints: 30
```

## סינון

למערכים יש מתודות מובנות למשימות נפוצות. `filter` יוצרת **מערך חדש** שמכיל רק את הפריטים שעוברים בדיקה. הבדיקה היא פונקציה קטנה שמחזירה `true` (לשמור) או `false` (לזרוק):

```js
const big = [3, 8, 12, 5].filter((n) => n > 4);
console.log(big); // prints: [8, 12, 5]
```

המערך המקורי נשאר כמו שהיה. בשיעורים הבאים תכירו עוד מתודות כאלה.

## תוספות שימושיות

| Code | Result |
| --- | --- |
| `fruits.includes("banana")` | `true` אם הפריט נמצא במערך |
| `fruits.indexOf("cherry")` | המיקום שלו, או `-1` אם הוא חסר |
| `fruits.join(", ")` | `"apple, banana, cherry"` כמחרוזת אחת |
| `fruits.slice(0, 2)` | עותק של שני הפריטים הראשונים |

> **שימו לב:**
> - טעויות של אחד פחות או אחד יותר (off-by-one): `fruits[3]` במערך בן 3 פריטים נותן `undefined`, כי האינדקס האחרון הוא 2.
> - קריאת תכונה של `undefined`: `fruits[10].length` נכשל עם `TypeError: Cannot read properties of undefined (reading 'length')`.
> - שימוש ב-`for...in` במקום ב-`for...of`: `for (const x in arr)` נותן את האינדקסים כטקסט, לא את הערכים.
> - כתיבת `sum` בתוך הלולאה, כך שהוא מתחיל מ-0 בכל סיבוב.
> - ציפייה ש-`filter` תשנה את המערך המקורי. היא מחזירה מערך חדש, אז שמרו אותו במשתנה.
> - שכחתם `return` בפונקציית `filter` שמשתמשת בסוגריים מסולסלים: `filter((n) => { n > 2 })` לא שומרת כלום, כי הפונקציה מחזירה `undefined`.

## להמשיך הלאה

הדפיסו את המספר הגדול ביותר במערך באמצעות לולאה ומשתנה שזוכר את הגדול ביותר עד כה. השתמשו ב-`filter` כדי לשמור רק מספרים הגדולים מ-3.

> **תורכם:** חשבו את `sum` עם לולאה ובנו את `evens` עם `filter`.
