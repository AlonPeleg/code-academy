תוכניות צריכות לזכור דברים: ניקוד, שם, סכום. **משתנה** (variable) הוא קופסה עם שם שמחזיקה ערך. בשיעור הזה תלמדו ליצור משתנים, לשנות אותם ולהשתמש בהם.

## יצירת משתנה

```js
const city = "Haifa";
let score = 0;
```

- `const` ו-`let` הן מילות מפתח (keywords) שאומרות "אני יוצר משתנה".
- `city` ו-`score` הם ה**שמות** שאתם בוחרים.
- `=` הוא אופרטור ה**השמה** (assignment). הוא לא אומר "שווה" כמו במתמטיקה; הוא אומר "שים את הערך שמימין בקופסה שמשמאל".
- `"Haifa"` ו-`0` הם ה**ערכים**.

## const או let?

- `const` יוצר משתנה שאי אפשר **להציב לו ערך חדש**. השתמשו בו כברירת מחדל: הוא מגן עליכם משינויים בטעות.
- `let` יוצר משתנה שאפשר לשנות אחר כך. השתמשו בו כשהערך הולך להשתנות, כמו מונה או ניקוד.

```js
let score = 0;
score = score + 10;   // now 10
score = score + 5;    // now 15
console.log(score);   // prints: 15
```

את השורה `score = score + 10` קוראים מימין לשמאל: לוקחים את הערך הנוכחי של `score`, מוסיפים 10 ושומרים את התוצאה בחזרה ב-`score`. יש גם קיצור: `score += 10;` עושה אותו דבר.

## סוגי ערכים

לכל ערך יש **טיפוס** (type):

| Type | Example | What it is |
| --- | --- | --- |
| מחרוזת (string) | `"Ava"` | טקסט, בתוך מרכאות |
| מספר (number) | `42`, `3.14` | כל מספר |
| בוליאני (boolean) | `true`, `false` | כן או לא |

אפשר לשאול מה הטיפוס באמצעות `typeof`:

```js
console.log(typeof "hi");  // prints: string
console.log(typeof 7);     // prints: number
console.log(typeof true);  // prints: boolean
```

## חיבור טקסט עם +

האופרטור `+` מחבר מספרים, אבל עם מחרוזות הוא **מצמיד** אותן. זה נקרא *שרשור* (concatenation):

```js
const name = "Ava";
console.log("Hello, " + name + "!"); // prints: Hello, Ava!
```

אם מערבבים מחרוזת ומספר, המספר הופך לטקסט, ולכן `"Age: " + 21` נותן `"Age: 21"`.

## כללי מתן שמות

- שמות יכולים להכיל אותיות, ספרות, `_` ו-`$`, אבל לא יכולים להתחיל בספרה.
- בלי רווחים ובלי מקפים. כתבו ב-**camelCase**: `playerScore`, `firstName`.
- שמות מבחינים בין אותיות גדולות לקטנות: `score` ו-`Score` הם שני משתנים שונים.
- בחרו שמות ברורים. `age` עדיף על `a`.

> **שימו לב:**
> - שינוי של `const`: `const age = 20; age = 21;` גורם ל-`TypeError: Assignment to constant variable.` השתמשו ב-`let` אם הערך יתחלף.
> - שימוש במשתנה לפני שיצרתם אותו: `console.log(x); let x = 1;` גורם ל-`ReferenceError: Cannot access 'x' before initialization`.
> - יצירת אותו שם פעמיים עם `let` או `const`: `SyntaxError: Identifier 'age' has already been declared`. כדי לשנות ערך, מציבים בלי מילת המפתח: `age = 21;`.
> - כתיבת מרכאות סביב שם של משתנה. `"name"` הוא הטקסט name, ואילו `name` הוא המשתנה.
> - שכחתם רווחים בתוך מחרוזות מחוברות: `"Hello" + name` מדפיס `HelloAva`. שימו את הרווח בתוך המרכאות.

## להמשיך הלאה

צרו `const` בשם `price` ו-`let` בשם `quantity`. הגדילו את `quantity` והדפיסו משפט שמשתמש בשניהם. נסו `typeof` על כל אחד מהמשתנים.

> **תורכם:** עקבו אחרי ההערות בעורך. התוכנית צריכה להדפיס `Ava is 21`.
