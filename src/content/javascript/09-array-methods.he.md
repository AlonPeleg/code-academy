בשיעור הקודם השתמשתם בלולאה וב-`filter`. ל-JavaScript המודרנית יש ארגז כלים שלם של **מתודות מערך** שעושות את המשימות הנפוצות בשורה אחת קריאה. שלוש החשובות ביותר הן `map`, `filter` ו-`reduce`.

## הרעיון: מעבירים פונקציה

כל אחת מהמתודות האלה מקבלת **פונקציה** (function) כארגומנט וקוראת לה עבור כל פריט. בדרך כלל כותבים את הפונקציה כפונקציית חץ קצרה:

```js
const numbers = [1, 2, 3, 4];
numbers.map((n) => n * 10);
```

כאן `(n) => n * 10` מקבלת פריט אחד בכל פעם בשם `n`.

## map: המרת כל פריט

`map` יוצרת מערך חדש **באותו אורך**, שבו כל פריט הוא התוצאה של הפונקציה שלכם.

```js
const doubled = [1, 2, 3].map((n) => n * 2);
console.log(doubled.join(", ")); // prints: 2, 4, 6

const names = ["ann", "bob"].map((s) => s.toUpperCase());
// ["ANN", "BOB"]
```

## filter: שמירת חלק מהפריטים

`filter` יוצרת מערך חדש רק עם הפריטים שעבורם הפונקציה שלכם מחזירה `true`.

```js
const big = [3, 8, 12, 5].filter((n) => n > 4);
console.log(big.join(", ")); // prints: 8, 12, 5
```

## reduce: צמצום לערך אחד

`reduce` עוברת על המערך ונושאת איתה **צובר** (accumulator) רץ. הפונקציה שלכם מקבלת את הצובר עד כה ואת הפריט הנוכחי, ומחזירה את הצובר החדש. הארגומנט השני של `reduce` הוא ערך ההתחלה.

```js
const total = [5, 10, 15].reduce((sum, n) => sum + n, 0);
console.log(total); // prints: 30
```

צעד אחר צעד: מתחילים עם `sum = 0`; אחר כך `0 + 5 = 5`; אחר כך `5 + 10 = 15`; ואחר כך `15 + 15 = 30`.

## find, some, every

```js
const nums = [4, 9, 16];
nums.find((n) => n > 5);      // 9      the first match (or undefined)
nums.findIndex((n) => n > 5); // 1      its position (or -1)
nums.some((n) => n > 10);     // true   is at least one a match?
nums.every((n) => n > 10);    // false  do all match?
```

## sort

`sort` מסדרת את הפריטים, ו**משנה את המערך המקורי**. עבור מספרים, תנו לה פונקציית השוואה:

```js
const sorted = [...prices].sort((a, b) => a - b); // small to large
```

אם הפונקציה מחזירה מספר שלילי, `a` בא ראשון. בלעדיה הפריטים מושווים כטקסט, ולכן `[10, 9, 1].sort()` נותן `[1, 10, 9]`. שלוש הנקודות ב-`[...prices]` מעתיקות את המערך קודם (עוד על זה בהמשך) כך שהמקורי נשאר ללא שינוי.

## שרשור

מכיוון ש-`map` ו-`filter` מחזירות מערכים, אפשר לשרשר אותן:

```js
const result = [1, 2, 3, 4, 5, 6]
  .filter((n) => n % 2 === 0)  // [2, 4, 6]
  .map((n) => n * n);          // [4, 16, 36]
console.log(result.join(", ")); // prints: 4, 16, 36
```

> **שימו לב:**
> - לשכוח ש-`map` ו-`filter` מחזירות מערך **חדש**. כתיבת `prices.map(...)` לבדה בשורה לא משנה כלום. שמרו או הדפיסו את התוצאה.
> - לשכוח את ערך ההתחלה ב-`reduce`: בלי `0` הפריט הראשון הופך לצובר, מה שנותן תשובות שגויות עבור מערכים ריקים (`TypeError: Reduce of empty array with no initial value`).
> - שימוש בסוגריים מסולסלים בפונקציית חץ בלי `return`: `map((p) => { p * 2 })` מחזירה `undefined` עבור כל פריט. או שמסירים את הסוגריים או שמוסיפים `return`.
> - מיון מספרים בלי פונקציית השוואה.
> - קריאה ל-`.sort()` ישירות על הנתונים שלכם כשרציתם לשמור על הסדר המקורי. `sort` משנה את המערך במקום.
> - קריאה ל-`find` כשאין התאמה נותנת `undefined`, ולכן בדקו לפני שמשתמשים בתוצאה.

## להמשיך הלאה

השתמשו ב-`reduce` כדי למצוא את המספר הגדול ביותר, או כדי לספור כמה מחירים הם מעל 12. שרשרו `filter`, `map` ו-`join` כדי להדפיס `"$25, $40, $15"`.

> **תורכם:** עקבו אחרי ההערות הממוספרות והשתמשו ב-`map`, `filter`, `reduce`, `find` ו-`sort` כדי להדפיס את חמש השורות.
