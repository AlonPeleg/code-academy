מחשב מצוין בלעשות אותו דבר אלף פעמים בלי להשתעמם. **לולאה** (loop) חוזרת על בלוק קוד. תשתמשו בלולאות כדי לספור, לסכום דברים ולעבור על רשימות.

## לולאת for

כשיודעים כמה פעמים לחזור, משתמשים ב-`for`:

```js
for (let i = 1; i <= 3; i++) {
  console.log("Round " + i);
}
// prints:
// Round 1
// Round 2
// Round 3
```

שלושת החלקים שבתוך הסוגריים, מופרדים בנקודה-פסיק:

1. `let i = 1` רץ **פעם אחת בהתחלה** ויוצר את המונה.
2. `i <= 3` הוא ה**תנאי**, שנבדק לפני כל סיבוב. כשהוא הופך ל-false, הלולאה מסתיימת.
3. `i++` רץ **אחרי כל סיבוב**. `i++` פירושו "הוסף אחד ל-i" (`i--` מחסיר אחד).

כך `i` עובר 1, 2, 3. ב-4 התנאי הוא false ו-JavaScript ממשיכה אחרי הלולאה.

## סיכום דברים

תבנית נפוצה מאוד היא **מצבר** (accumulator): משתנה מחוץ ללולאה שאוסף תוצאה.

```js
let sum = 0;
for (let i = 1; i <= 4; i++) {
  sum += i;       // same as sum = sum + i
}
console.log(sum); // prints: 10   (1+2+3+4)
```

## ספירה לאחור

מתחילים גבוה, בודקים עם `>=`, ומשתמשים ב-`i--`:

```js
for (let i = 3; i >= 1; i--) {
  console.log(i);
}
// prints: 3, 2, 1 (each on its own line)
```

## לולאת while

ללולאת `while` יש רק תנאי. היא חוזרת כל עוד התנאי נכון:

```js
let n = 1;
while (n < 50) {
  n = n * 2;
}
console.log(n); // prints: 64   (1, 2, 4, 8, 16, 32, 64)
```

גוף הלולאה חייב לעשות משהו שבסופו של דבר יהפוך את התנאי ל-false. כאן `n` ממשיך לגדול עד שהוא מגיע ל-50 או יותר. בחרו ב-`while` כשאתם לא יודעים מראש כמה סיבובים תצטרכו.

## break ו-continue

- `break` יוצא מהלולאה מיד.
- `continue` מדלג על שאר הסיבוב הנוכחי ועובר לבא.

```js
for (let i = 1; i <= 10; i++) {
  if (i === 3) continue;  // skip 3
  if (i === 6) break;     // stop at 6
  console.log(i);
}
// prints: 1, 2, 4, 5
```

## לולאות עם החלטות

לולאות ומשפטי `if` משתלבים יפה. כדי להדפיס רק את המספרים הזוגיים עד 6:

```js
for (let i = 1; i <= 6; i++) {
  if (i % 2 === 0) {
    console.log(i);
  }
}
```

> **שימו לב:**
> - **לולאה אינסופית**: `while` שהתנאי שלה לעולם לא הופך ל-false, או `for` עם `i--` כשהתנאי מצפה ש-`i` יגדל. העורך עוצר את התוכנית אחרי 5 שניות עם הודעה. בדקו שמשהו בגוף הלולאה משנה את התנאי.
> - טעויות של אחד פחות או אחד יותר (off-by-one): `i < 3` רץ 3 פעמים כשמתחילים מ-0, ואילו `i <= 3` רץ 4 פעמים. חשבו על הערך הראשון ועל האחרון.
> - הגדרת המונה עם `const`: `for (const i = 0; i < 3; i++)` נכשל עם `TypeError: Assignment to constant variable.` המונה חייב להיות `let`.
> - הצבת המצבר `let sum = 0;` בתוך הלולאה. הוא מאופס בכל סיבוב.
> - שכחתם את נקודה-פסיק בכותרת של ה-`for`: משתמשים ב-`;` בין שלושת החלקים, לא בפסיקים.

## להמשיך הלאה

הדפיסו את לוח הכפל של 7 (`7 x 1 = 7` וכן הלאה) עם לולאת `for`. אחר כך השתמשו בלולאת `while` כדי למצוא את החזקה הראשונה של 3 שגדולה מ-1000.

> **תורכם:** עקבו אחרי שלוש ההערות: סכמו את 1 עד 10 עם לולאת `for`, הכפילו את `n` עם לולאת `while`, וספרו לאחור מ-3 עם לולאת `for` שנייה.
