**מערך** (array) הוא שורה של קופסאות מאותו טיפוס, השמורות זו אחרי זו בזיכרון. הוא מאפשר לשמור 5, 50 או 5000 ערכים תחת שם אחד, במקום להמציא `score1`, `score2`, `score3`... בשיעור הזה תיצרו מערכים, תקראו את האיברים שלהם ותעברו עליהם בלולאה.

## יוצרים מערך

כותבים את טיפוס האיבר, שם, ואת מספר האיברים בסוגריים מרובעים:

```c
int numbers[3] = {10, 20, 30};   // three ints
double temps[2] = {21.5, 19.0};  // two doubles
int zeros[4] = {0};              // all four elements are 0
int auto_size[] = {1, 2, 3, 4};  // the compiler counts: 4 elements
```

אם יוצרים מערך **בלי** לתת לו ערכים (`int a[4];`), התוכן שלו הוא כל זבל שהיה בזיכרון. תמיד אתחלו אותו לפני שאתם קוראים ממנו.

## אינדקסים מתחילים ב-0

לכל איבר יש **אינדקס** (index), המיקום שלו. לאיבר הראשון יש אינדקס **0**:

```c
int numbers[3] = {10, 20, 30};
printf("%d\n", numbers[0]);   // prints: 10
printf("%d\n", numbers[2]);   // prints: 30
numbers[1] = 99;              // change the middle element
```

במערך בגודל 3 האינדקסים התקינים הם 0, 1 ו-2. האינדקס התקין האחרון הוא תמיד `size - 1`.

## עוברים על מערך בלולאה

מערכים ולולאות `for` הולכים יחד באופן טבעי:

```c
int total = 0;
for (int i = 0; i < 3; i++) {
    total += numbers[i];
}
```

## כמה גדול המערך?

מערכי C לא זוכרים את האורך שלהם. אבל האופרטור `sizeof` אומר לכם כמה **בייטים** משהו תופס, ולכן חלוקת המערך כולו באיבר אחד נותנת את מספר האיברים:

```c
int count = sizeof(numbers) / sizeof(numbers[0]);   // 3
```

זה עובד רק בפונקציה שבה המערך הוצהר (בשיעור על מצביעים תראו למה).

## הערה על ממוצעים

אם `sum` ו-`count` הם שניהם `int`, אז `sum / count` הוא חילוק שלמים וזורק את הספרות העשרוניות. **המרה** (cast) כמו `(double) sum` ממירה קודם את הערך ל-`double`, ולכן החילוק שומר על הספרות העשרוניות:

```c
printf("%.1f\n", (double) 402 / 5);   // prints: 80.4
```

> **שימו לב:**
> - **גישה מחוץ לגבולות.** `numbers[3]` במערך בגודל 3 מתקמפל בסדר אבל קורא זיכרון שאינו שלכם. הוא עלול להדפיס זבל או לקרוס עם `Segmentation fault`. באג קלאסי הוא `i <= 3` במקום `i < 3` בלולאה.
> - אי אפשר להשים או להשוות מערכים עם `=` או `==`. `int b[3] = a;` נותן `error: invalid initializer`. העתיקו איבר אחרי איבר בלולאה.
> - יותר מדי ערכים התחלתיים, כמו ב-`int a[2] = {1, 2, 3};`, נותנים `warning: excess elements in array initializer`.
> - שימוש ב-`int a[n]` עם גודל משתנה אפשרי ב-C מודרנית אבל מסוכן. העדיפו גודל קבוע או את השיעור על זיכרון דינמי.

## להמשיך הלאה

מצאו גם את הציון הנמוך ביותר. אחר כך נסו להדפיס את הציונים לאחור בעזרת לולאה שסופרת למטה מ-`count - 1` עד `0`.

> **תורכם:** חשבו את `count` בעזרת `sizeof`, עברו בלולאה על `scores` כדי למצוא את הסכום ואת המקסימום, ואז הדפיסו את ארבע השורות המופיעות בהערות, כולל `Average: 80.4`.
