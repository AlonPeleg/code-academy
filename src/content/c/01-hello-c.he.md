בשיעור הזה תכתבו, תקמפלו ותריצו את תוכנית ה-C הראשונה שלכם. C היא אחת השפות הוותיקות והמשפיעות ביותר: מערכות הפעלה, מנועי משחקים והשבבים הקטנים שבתוך מכונות כביסה כתובים בה. לימוד C מראה לכם מה המחשב באמת עושה מתחת לשפות הידידותיות יותר.

## מקומפלת, לא מתורגמת בזמן ריצה

JavaScript ופייתון מורצות שורה אחרי שורה על ידי מפרש (interpreter). C היא שפה **מקומפלת**: תוכנית שנקראת *קומפיילר* (compiler) מתרגמת קודם את כל הקובץ שלכם לקוד מכונה, ורק אז התוצאה רצה. כשאתם לוחצים על **הרצה**, הקוד שלכם נשלח לשרת הרצה שמקמפל אותו עם `gcc` ושולח בחזרה את מה שהתוכנית הדפיסה. אם הקומפיילר מוצא טעות, תראו את הודעת השגיאה שלו במקום כל פלט.

## התוכנית השימושית הקטנה ביותר

```c
#include <stdio.h>

int main(void) {
    printf("Hello!\n");
    return 0;
}
```

בואו נפרק אותה חלק אחרי חלק:

- `#include <stdio.h>` מעתיק פנימה את התיאור של ספריית הקלט והפלט הסטנדרטית. בלעדיו הקומפיילר לא היה יודע מהו `printf`. השם פירושו "standard input output, header".
- `int main(void)` מגדיר את הפונקציה (function) בשם `main`. כל תוכנית C מתחילה לרוץ ב-`main`. `int` אומר שהיא מחזירה מספר שלם כשהיא מסתיימת, ו-`void` אומר שהיא לא מקבלת קלט.
- הסוגריים המסולסלים `{ ... }` מכילים את גוף הפונקציה.
- `printf("Hello!\n");` קורא לפונקציה `printf` (print formatted) ונותן לה טקסט בתוך מרכאות כפולות.
- `\n` הוא **רצף בריחה** (escape sequence) שמשמעותו "שורה חדשה". בלעדיו, הדבר הבא שיודפס ימשיך באותה שורה.
- `;` מסיים הוראה, כמו שנקודה מסיימת משפט.
- `return 0;` מסיים את `main`. לפי המסורת `0` אומר "הכול עבר בסדר".
- שורה שמתחילה ב-`//` היא **הערה** (comment). הקומפיילר מתעלם ממנה, ולכן משתמשים בהערות כדי להסביר את הקוד לבני אדם.

## יותר משורה אחת

כל `printf` מדפיס בדיוק את מה שנתתם לו, לא יותר. שתי ההוראות האלה מדפיסות בשתי שורות:

```c
printf("First\n");
printf("Second\n");
// prints:
// First
// Second
```

> **שימו לב:**
> - אם שוכחים את הנקודה-פסיק מקבלים `error: expected ';' before 'return'`. מספר השורה בהודעה הוא לעיתים קרובות השורה *שאחרי* הטעות האמיתית.
> - אם שוכחים את ה-`#include` מקבלים `warning: implicit declaration of function 'printf'` או שגיאה מוחלטת.
> - שימוש במרכאות בודדות `'Hello'` במקום מרכאות כפולות `"Hello"` גורם לשגיאות. ב-C מרכאות כפולות הן לטקסט, ומרכאות בודדות הן לתו אחד.
> - C רגישה לאותיות גדולות וקטנות: `Printf` ו-`printf` הם שמות שונים.

## להמשיך הלאה

הוסיפו `printf` שני שמדפיס את השם שלכם, ונסו להסיר את ה-`\n` כדי לראות מה קורה לפלט.

> **תורכם:** בתוך `main`, השתמשו ב-`printf` כדי להדפיס `Hello, C!` בשורה משלו.
