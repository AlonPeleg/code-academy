תוכניות נעשות שימושיות כשהן יכולות לבחור בין פעולות. בשיעור הזה תלמדו את `if`, `else if`, `else` ו-`switch`, וגם את אופרטורי ההשוואה והלוגיקה שמזינים אותם.

## תנאים

תנאי (condition) הוא משהו שהוא או אמת או שקר. ב-C הקלאסית אין טיפוס בוליאני נפרד: **אפס פירושו שקר וכל מספר אחר פירושו אמת**. השוואות נותנות `1` (אמת) או `0` (שקר):

| אופרטור | משמעות |
| --- | --- |
| `==` | שווה ל |
| `!=` | לא שווה ל |
| `<` `<=` | קטן מ, קטן או שווה ל |
| `>` `>=` | גדול מ, גדול או שווה ל |
| `&&` | וגם (שניהם חייבים להיות אמת) |
| `\|\|` | או (לפחות אחד אמת) |
| `!` | לא (הופך אמת ושקר) |

## if, else if ו-else

```c
int temp = 25;

if (temp > 30) {
    printf("Hot\n");
} else if (temp > 20) {
    printf("Warm\n");
} else {
    printf("Cool\n");
}
// prints: Warm
```

C בודקת את התנאים מלמעלה למטה ומריצה רק את הבלוק **הראשון** שהתנאי שלו אמת, ואז מדלגת על השאר. בגלל זה הסדר חשוב: אילו בדקתם קודם את `temp > 20`, טמפרטורה של 35 הייתה מדפיסה "Warm". ה-`else` האחרון הוא אופציונלי ותופס את כל מה שנשאר.

אפשר לשלב בדיקות: `if (age >= 13 && age <= 19) { ... }` פירושו "בין 13 ל-19".

## switch

כשמשווים משתנה אחד למספר ערכים מדויקים, `switch` מסודר יותר משרשרת ארוכה של `else if`:

```c
int n = 2;

switch (n) {
    case 1:
        printf("one\n");
        break;
    case 2:
        printf("two\n");
        break;
    default:
        printf("something else\n");
        break;
}
// prints: two
```

C קופצת ל-`case` המתאים. ה-`break;` יוצא מה-switch. `default` רץ אם שום דבר לא התאים. switch עובד עם מספרים שלמים ותווים בודדים (כמו `case 'a':`), אבל לא עם מספרים עשרוניים או טקסט.

> **שימו לב:**
> - כתיבת `if (x = 5)` משימה 5 ל-`x` ותמיד אמת. הקומפיילר מזהיר: `suggest parentheses around assignment used as truth value`. השתמשו ב-`==` כדי להשוות.
> - בלי `break`, ה-switch **נופל הלאה**: `case 1` יריץ גם את הקוד של `case 2`. לפעמים זה שימושי, אבל בדרך כלל זה באג.
> - נקודה-פסיק מיד אחרי התנאי, `if (x > 3);`, גורמת ל-`if` לא לעשות כלום, והבלוק שמתחתיו תמיד רץ.
> - הצהרה על משתנה ישירות מתחת לתווית `case:` יכולה לתת `error: a label can only be part of a statement`. עטפו את גוף ה-case ב-`{ }` אם אתם צריכים משתנים מקומיים.

## להמשיך הלאה

שנו את `score` ל-`95`, ל-`60` ול-`10`, ואת `day` ל-`7`, ובדקו שכל ענף עובד.

> **תורכם:** השתמשו בשרשרת `if` / `else if` / `else` כדי להדפיס את הציון של `score`, ואז השתמשו ב-`switch` על `day` כדי להדפיס את שם היום. עם המספרים הנתונים התוכנית מדפיסה `Grade: C` ו-`Wednesday`.
