לולאת `for` מושלמת כשיודעים כמה פעמים לחזור. לעיתים קרובות לא יודעים: רוצים להמשיך **עד שמשהו קורה**, למשל מספר שמגיע ל-1, משתמש שמקליד "quit", או קובץ שנגמר. בשביל זה יש ב-C את `while` ו-`do-while`.

## לולאת while

```c
int count = 3;
while (count > 0) {
    printf("%d\n", count);
    count--;
}
printf("Liftoff!\n");
// prints: 3, 2, 1, Liftoff! (each on its own line)
```

איך זה עובד:

1. C בודקת את התנאי `count > 0`.
2. אם הוא אמת, הגוף רץ, ו-C חוזרת לצעד 1.
3. אם הוא שקר, הלולאה מסתיימת והתוכנית ממשיכה אחריה.

אם התנאי שקר כבר מההתחלה, הגוף אף פעם לא רץ. לולאת `while` היא בעצם לולאת `for` עם החלק האמצעי בלבד. ההתחלה והצעד נכתבים על ידכם, לפני הלולאה ובתוכה. `count--` פירושו `count = count - 1`.

## לולאת do-while

`do-while` בודקת את התנאי שלה **אחרי** הגוף, ולכן הגוף תמיד רץ לפחות פעם אחת:

```c
int n = 10;
do {
    printf("n is %d\n", n);
    n++;
} while (n < 5);
// prints: n is 10   (once, even though 10 < 5 is false)
```

שימו לב לנקודה-פסיק אחרי `while (...)`. היא נדרשת כאן ורק כאן.

## אופרטורים שימושיים

- `%` הוא **שארית** (modulo): `17 % 5` הוא `2`. מספר הוא זוגי כש-`n % 2 == 0`.
- `x = x / 10` מסיר את הספרה האחרונה של מספר שלם (חילוק שלמים זורק את השאר): `12345 / 10` הוא `1234`.
- קיצורים: `x += 3` פירושו `x = x + 3`, ו-`x /= 10` פירושו `x = x / 10`. כך גם `-=`, `*=`, ו-`++`/`--`.

## break ו-continue

`break;` יוצא מיד מהלולאה הקרובה ביותר. `continue;` מדלג על שאר הסיבוב הזה וממשיך לבא:

```c
int i = 0;
while (1) {              // 1 is always true: loop "forever"
    if (i == 3) break;   // ...until we decide to stop
    i++;
}
```

> **שימו לב:**
> - **לולאות אינסופיות.** אם שום דבר בגוף לא משנה את התנאי (שכחתם `count--`), התוכנית לא נגמרת לעולם. שרת ההרצה יעצור אותה אחרי כמה שניות עם שגיאת חריגה ממגבלת זמן.
> - נקודה-פסיק אחרי `while (x > 0);` (בלולאת while רגילה) יוצרת לולאה ריקה שמסתובבת לנצח.
> - שימוש ב-`=` במקום ב-`==` בתנאי, למשל `while (n = 1)`, משימה במקום להשוות. הקומפיילר מזהיר: `suggest parentheses around assignment used as truth value`.
> - ב-`do-while`, שכחת הנקודה-פסיק הסופית נותנת `error: expected ';' before 'return'`.

## להמשיך הלאה

סדרת קולאץ היא חידה מפורסמת: אף אחד לא הוכיח שכל מספר התחלתי מגיע ל-1. נסו ערכי התחלה אחרים כמו 7 או 27 וראו כמה ארוכה הסדרה.

> **תורכם:** השתמשו בלולאת `while` כדי להדפיס את סדרת קולאץ של 6 (`6 3 10 5 16 8 4 2 1` בשורה אחת), ואז השתמשו בלולאת `do-while` כדי לספור את הספרות של `x` ולהדפיס `Digits: 5`.
