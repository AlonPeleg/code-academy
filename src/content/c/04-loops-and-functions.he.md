שניים מהרעיונות החשובים ביותר בתכנות כולו: **לולאות** (loops) חוזרות על עבודה, ו**פונקציות** (functions) נותנות לקטע קוד שם כדי שאפשר יהיה להשתמש בו שוב. בשיעור הזה תשתמשו בשניהם יחד.

## לולאת for

ללולאת `for` יש שלושה חלקים בתוך הסוגריים, המופרדים בנקודה-פסיק:

```c
for (int i = 0; i < 3; i++) {
    printf("%d\n", i);
}
// prints: 0 then 1 then 2
```

1. **התחלה**: `int i = 0` יוצר מונה ונותן לו ערך התחלתי. זה רץ פעם אחת.
2. **תנאי**: `i < 3` נבדק לפני כל סיבוב. כשהוא נהיה שקר, הלולאה מסתיימת.
3. **צעד**: `i++` רץ אחרי כל סיבוב. זו קיצור של `i = i + 1`.

אחר כך הגוף שב-`{ }` רץ פעם אחת בכל סיבוב. כדי לספור מ-1 עד 5 מתחילים ב-1 ומשתמשים ב-`i <= 5`.

## פונקציות

**פונקציה** נותנת שם לבלוק קוד. כותבים את הטיפוס שהיא מחזירה, את שמה, ואת הפרמטרים (parameters) שלה (עם טיפוסים) בסוגריים:

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int result = add(2, 3);
    printf("%d\n", result);    // prints: 5
    return 0;
}
```

- `int` לפני `add` פירושו "הפונקציה הזו מחזירה int".
- `a` ו-`b` הם **פרמטרים**: קלטים שהפונקציה מקבלת. הערכים שאתם מעבירים בקריאה (`2` ו-`3`) נקראים **ארגומנטים** (arguments).
- `return` שולח את התשובה בחזרה למי שקרא ומסיים את הפונקציה.
- פונקציה שלא מחזירה כלום משתמשת בטיפוס `void`, למשל `void greet(void) { printf("Hi\n"); }`.

## הסדר חשוב

C קוראת את הקובץ מלמעלה למטה. אם `main` קורא לפונקציה שהקומפיילר עוד לא ראה, מקבלים אזהרה או שגיאה. או שכותבים את הפונקציה **מעל** `main`, או שמניחים **אב-טיפוס** (prototype) (רק השורה הראשונה ועוד נקודה-פסיק) בראש הקובץ:

```c
int add(int a, int b);     // prototype

int main(void) { ... }

int add(int a, int b) { return a + b; }
```

> **שימו לב:**
> - טעויות של אחד פחות או אחד יותר: `i < 5` רץ עבור 0 עד 4, בעוד `i <= 5` רץ עבור 0 עד 5. חשבו איזה מהם אתם רוצים.
> - קריאה לפונקציה עם מספר שגוי של ארגומנטים נותנת `error: too few arguments to function 'add'`.
> - שכחת `return` בפונקציית `int` הופכת את התוצאה לבלתי מוגדרת (`warning: control reaches end of non-void function`).
> - לעולם אל תשימו נקודה-פסיק מיד אחרי `for (...)`: זה יוצר לולאה ריקה והבלוק שלכם רץ רק פעם אחת.

## להמשיך הלאה

כתבו פונקציה `int cube(int n)` והדפיסו את הקוביות מ-1 עד 5, או גרמו ללולאה לספור לאחור עם `i--`.

> **תורכם:** כתבו את `int square(int n)` מעל `main`, ואז השתמשו בלולאת `for` שקוראת לה עבור המספרים 1 עד 5 ומדפיסה כל תוצאה בשורה משלה.
