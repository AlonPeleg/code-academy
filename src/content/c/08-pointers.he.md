למצביעים יש מוניטין מפחיד, אבל הרעיון פשוט. כל משתנה גר איפשהו בזיכרון של המחשב, ולכל מקום בזיכרון יש **כתובת** (מספר). **מצביע** (pointer) הוא משתנה ששומר כתובת כזאת. הוא מאפשר לפונקציות לשנות את המשתנים של הקורא, לעבוד עם מערכים ביעילות ולבנות נתונים דינמיים. הבנה שלהם היא הצעד המרכזי בלימוד C.

## כתובות ומצביעים

```c
int x = 10;
int *p = &x;      // p holds the address of x

printf("%d\n", x);    // prints: 10
printf("%d\n", *p);   // prints: 10   (follow the pointer)

*p = 25;              // change the value p points to
printf("%d\n", x);    // prints: 25
```

הסימנים, אחד אחד:

- `int *p` מצהירה על `p` כ**מצביע ל-int**. הסימן `*` בהצהרה פירושו "מצביע".
- `&x` הוא האופרטור **כתובת של** (address-of): "איפה x גר?".
- `*p` בתוך ביטוי הוא האופרטור **הפניה** (dereference): "לכו לכתובת שב-p ותנו לי מה שיש שם". אפשר לקרוא אותו או לשים בו ערך.

תחשבו על `x` כעל בית, על `&x` ככתובת הרחוב שלו כתובה על כרטיס, ועל `p` כעל האדם שמחזיק את הכרטיס. `*p` זה ללכת עד הבית.

## למה פונקציות צריכות מצביעים

C מעבירה ארגומנטים **לפי ערך** (by value), כלומר הפונקציה מקבלת עותק. הפונקציה הזאת לא יכולה לעבוד:

```c
void broken(int n) {
    n = 99;          // changes only the local copy
}
```

אם מעבירים את הכתובת במקום זאת, הפונקציה יכולה להגיע למקור:

```c
void set99(int *n) {
    *n = 99;
}

int v = 1;
set99(&v);
printf("%d\n", v);   // prints: 99
```

כך גם `scanf` ממלאת את המשתנים שלכם (בשיעור מאוחר יותר).

## מצביעים ומערכים

שם של מערך הופך למצביע לאיבר הראשון שלו כשמעבירים אותו לפונקציה. לכן הפונקציה מקבלת רק את הכתובת וצריך להעביר את האורך בנפרד (וגם לכן `sizeof` לא עובד עליו שם):

```c
void print_all(int *arr, int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);   // arr[i] is the same as *(arr + i)
    }
}
```

הוספת 1 למצביע מזיזה אותו ל**איבר הבא** מהטיפוס שלו, ולכן `*(arr + 1)` הוא `arr[1]`. שינויים שנעשים דרך `arr[i]` בתוך הפונקציה משנים את המערך של הקורא, כי לא נוצר עותק של המערך.

> **שימו לב:**
> - מצביע שלא אותחל (`int *p;`) מצביע למקום אקראי. הפניה אליו בדרך כלל קורסת עם `Segmentation fault`. התחילו מצביעים כ-`NULL` או כוונו אותם למשהו אמיתי, ולעולם אל תשתמשו ב-`*p` כש-`p` הוא `NULL`.
> - ערבוב בין המשמעויות של `*`: `int *p = &x;` מצהירה ומאתחלת את המצביע, אבל `*p = 5;` בהמשך כותבת למה שהוא מצביע עליו. לעומת זאת `p = 5;` מנסה להזיז את המצביע עצמו ונותנת `warning: assignment to 'int *' from 'int' makes pointer from integer without a cast`.
> - שכחתם `&` בקריאה ל-`swap(a, b)` נותן `warning: passing argument 1 of 'swap' makes pointer from integer without a cast`.
> - לעולם אל תדפיסו ואל תסתמכו על הערך המספרי של כתובת בתוכנית שהפלט שלה צריך להיות צפוי. הוא משתנה מהרצה להרצה.

## להמשיך הלאה

כתבו `void minmax(int *arr, int n, int *min, int *max)` שממלאת שתי תוצאות דרך מצביעים. זו הדרך ב-C לפונקציה להחזיר יותר מערך אחד.

> **תורכם:** ב-`main`, כוונו את `p` אל `x` ושנו את `x` ל-25 דרך `p`. אחר כך השלימו את `swap` (החלפת הערכים ש-`a` ו-`b` מצביעים עליהם) ואת `double_all` (הכפלת כל איבר). התוכנית צריכה להדפיס `x is 25`, `After swap: a=7 b=3` ו-`Doubled: 2 4 6`.
