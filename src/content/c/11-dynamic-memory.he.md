לכל המשתנים עד עכשיו היה גודל קבוע בזמן שכתבתם את התוכנית. מה אם אתם לא יודעים כמה פריטים תצטרכו עד שהתוכנית רצה, למשל מספר השורות בקובץ? C מאפשרת לבקש ממערכת ההפעלה זיכרון **בזמן ריצה** עם `malloc`, ולהחזיר אותו עם `free`. אזור הזיכרון הזה נקרא ה-**heap** (ערימה).

## malloc ו-free

```c
#include <stdlib.h>

int *numbers = malloc(3 * sizeof(int));   // room for 3 ints
numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
printf("%d\n", numbers[1]);   // prints: 20
free(numbers);               // give it back
```

- `malloc(bytes)` שומרת את מספר הבייטים הזה ומחזירה **מצביע** לראשון שבהם. היא נמצאת ב-`<stdlib.h>`.
- `sizeof(int)` הוא הגודל של int אחד, ולכן `3 * sizeof(int)` מספיק לשלושה. תמיד הכפילו ב-`sizeof` של הטיפוס במקום לנחש גדלים.
- משתמשים במצביע בדיוק כמו במערך: `numbers[i]`.
- `free(pointer)` משחררת את הזיכרון כדי שאפשר יהיה להשתמש בו שוב. לכל `malloc` צריך להיות בדיוק `free` אחד.

## בדיקת כישלון

אם המערכת לא יכולה לתת לכם את הזיכרון, `malloc` מחזירה `NULL`. בתוכניות רציניות תמיד בדקו:

```c
if (numbers == NULL) {
    printf("Out of memory\n");
    return 1;
}
```

## הגדלה עם realloc

`realloc(pointer, newBytes)` משנה את הגודל של בלוק ושומרת על התוכן הישן. היא עשויה להעביר את הנתונים למקום חדש, ולכן תמיד שמרו את הערך שהיא מחזירה:

```c
int *bigger = realloc(numbers, 6 * sizeof(int));
if (bigger != NULL) {
    numbers = bigger;
}
```

האיברים הישנים נשמרים; החדשים **לא** מאותחלים, ולכן קבעו אותם בעצמכם. (`calloc(count, size)` דומה ל-`malloc` אבל ממלאת את הזיכרון באפסים.)

## מחרוזות ב-heap

מחרוזת צריכה בייט אחד נוסף בשביל ה-`\0`:

```c
char *copy = malloc(strlen(text) + 1);
strcpy(copy, text);
...
free(copy);
```

> **שימו לב:**
> - **דליפת זיכרון (memory leak)**: אם שוכחים `free`, הזיכרון אבוד עד שהתוכנית נגמרת. בתוכנית שרצה זמן רב זה אוכל את כל הזיכרון.
> - **שימוש אחרי שחרור (use after free)**: קריאה או כתיבה דרך מצביע אחרי `free(p)` היא התנהגות לא מוגדרת ועלולה להקריס או להדפיס זבל. הרבה מתכנתים מציבים `p = NULL;` מיד אחרי השחרור.
> - **שחרור כפול (double free)**: קריאה ל-`free` פעמיים על אותו מצביע קורסת עם `free(): double free detected`.
> - **כתיבה מחוץ לגבולות**: הקצאת `n` מספרים שלמים וכתיבה ל-`arr[n]` משחיתה את ה-heap. זכרו שהאינדקסים החוקיים הם 0 עד n-1.
> - לעולם אל תקראו זיכרון מה-heap שלא כתבתם אליו: `malloc` לא מנקה אותו, ולכן התוכן שלו לא צפוי.

## להמשיך הלאה

הקצו מערך של 1000 מספרים שלמים, מלאו אותו, סכמו אותו ושחררו אותו. בדקו מה קורה אם מסירים את ה-`+ 1` בהעתקת המחרוזת (זה באג: התו המסיים נכתב מחוץ לבלוק).

> **תורכם:** הקצו מקום ל-5 מספרים שלמים עם `malloc`, מלאו אותם בריבועים והדפיסו אותם, הגדילו את הבלוק ל-8 עם `realloc`, הדפיסו שוב ושחררו אותו עם `free`. אחר כך צרו ב-heap עותק של `"hello"` והדפיסו אותו.
