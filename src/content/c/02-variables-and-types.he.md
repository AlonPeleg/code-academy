בשיעור הזה תלמדו איך C שומרת מספרים ואותיות ב**משתנים** (variables), ואיך להדפיס אותם עם `printf`. בניגוד לפייתון או ל-JavaScript, C דורשת שתגידו מהו ה**טיפוס** (type) של כל משתנה, כי הטיפוס קובע כמה זיכרון הוא תופס ומה אפשר לעשות איתו.

## הצהרה על משתנים

משתנה הוא קופסה בעלת שם בזיכרון. יוצרים אותו על ידי כתיבת הטיפוס, השם ו(בדרך כלל) ערך התחלתי:

```c
int age = 20;
double price = 9.99;
char grade = 'A';
```

| טיפוס | מה הוא שומר | דוגמה | סימון מקום ב-printf |
| --- | --- | --- | --- |
| `int` | מספרים שלמים | `42`, `-7` | `%d` |
| `double` | מספרים עשרוניים | `3.14`, `0.5` | `%f` |
| `char` | תו אחד | `'A'`, `'z'` | `%c` |

שימו לב ש-`char` משתמש במרכאות **בודדות** ואילו טקסט משתמש במרכאות כפולות.

## מדפיסים ערכים עם printf

בתוך הטקסט שאתם נותנים ל-`printf`, כל סימון מקום עם `%` מוחלף בערך הבא שאתם מעבירים אחרי הטקסט, לפי הסדר:

```c
printf("Age: %d\n", age);          // prints: Age: 20
printf("Price: %.2f\n", price);    // prints: Price: 9.99
printf("Grade: %c\n", grade);      // prints: Grade: A
printf("%d is %c\n", age, grade);  // prints: 20 is A
```

`%.2f` פירושו "מספר עשרוני עם בדיוק 2 ספרות אחרי הנקודה". `%.1f` נותן ספרה אחת ומעגל בשבילכם.

## עושים חשבון

אפשר לחשב עם `+ - * /` ולהשתמש בסוגריים, ואז לשמור את התוצאה במשתנה חדש:

```c
int a = 7;
int b = 2;
int sum = a + b;           // 9
int half = a / b;          // 3  (not 3.5!)
double exact = 7 / 2.0;    // 3.5
printf("%d %d %.1f\n", sum, half, exact);
```

כששני צדי ה-`/` הם `int`, C מבצעת **חילוק שלמים** וזורקת את השארית. הפכו צד אחד ל-`double` (כמו `2.0`) כדי לקבל תשובה עשרונית. כשמערבבים `int` ו-`double`, C הופכת קודם את ה-`int` ל-`double`, ובגלל זה `price + tax` שלמטה עובד.

> **שימו לב:**
> - הדפסת `double` עם `%d` מדפיסה זבל. הקומפיילר מזהיר: `format '%d' expects argument of type 'int', but argument 2 has type 'double'`. התאימו את סימון המקום לטיפוס.
> - העברת פחות ערכים מסימוני מקום (למשל `printf("%d %d\n", a);`) מדפיסה מספר אקראי עבור הערך החסר.
> - חובה להצהיר על משתנה לפני השימוש בו: `error: 'total' undeclared (first use in this function)`.
> - השימוש ב-`=` הוא השמה (שמירת ערך), לא השוואה. השוואה תבוא בשיעור הבא.

## להמשיך הלאה

נסו לשנות את `tax` ל-`0.25` ולהדפיס אותו עם `%.2f`. מה קורה אם מדפיסים `apples / 2`?

> **תורכם:** צרו `int` בשם `total` ששווה ל-`apples * price`, הדפיסו `Total: 12`, ואז הדפיסו `With tax: 4.5` בעזרת `price + tax` ו-`%.1f`.
