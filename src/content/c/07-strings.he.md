ל-C אין טיפוס טקסט מובנה. **מחרוזת** (string) היא פשוט מערך של `char` שמסתיים בתו מיוחד בלתי נראה, **תו הסיום null** שנכתב `'\0'` (התו שמספרו 0). בשיעור הזה תיצרו מחרוזות, תמדדו אותן, תעתיקו אותן ותשוו ביניהן.

## יוצרים מחרוזות

```c
char greeting[] = "Hello";   // the compiler makes room for 6 chars
char name[20] = "Ava";       // room for 19 letters + the terminator
```

`"Hello"` תופס **6** בייטים בזיכרון: `H e l l o \0`. תו הסיום הוא הדרך שבה פונקציות כמו `printf` יודעות איפה הטקסט נעצר. מדפיסים מחרוזת עם סימון המקום `%s`:

```c
printf("%s\n", greeting);   // prints: Hello
printf("%c\n", greeting[1]); // prints: e   (one character)
```

אפשר לשנות תווים בודדים, למשל `greeting[0] = 'J';` הופך אותה ל-`Jello`.

## פונקציות העזר של string.h

הוסיפו `#include <string.h>` כדי להשתמש בפונקציות האלה:

| פונקציה | מה היא עושה |
| --- | --- |
| `strlen(s)` | מספר התווים לפני ה-`\0` |
| `strcpy(dest, src)` | מעתיקה את `src` אל `dest` |
| `strcat(dest, src)` | מוסיפה את `src` לסוף של `dest` |
| `strcmp(a, b)` | מחזירה `0` אם שוות, ומספר שלילי או חיובי אחרת |

```c
char a[20] = "Hi";
strcat(a, " there");
printf("%s has %zu letters\n", a, strlen(a));
// prints: Hi there has 8 letters
```

`strlen` מחזירה טיפוס חסר סימן בשם `size_t`; הדפיסו אותו עם `%zu` (או המירו אותו ל-`int` והשתמשו ב-`%d`).

## למה strcmp ולא ==

אם כותבים `a == b` עבור שתי מחרוזות, משווים **איפה הן נמצאות בזיכרון**, לא מה הן אומרות. השתמשו ב-`strcmp(a, b) == 0` כדי לשאול "האם האותיות זהות?".

## עוברים על מחרוזת

מכיוון שהמחרוזת מסתיימת ב-`'\0'`, אפשר לעבור בלולאה עד שמוצאים אותו:

```c
for (int i = 0; greeting[i] != '\0'; i++) {
    printf("%c ", greeting[i]);
}
// prints: H e l l o
```

> **שימו לב:**
> - **מאגר קטן מדי.** `char small[3] = "Hello";` או העתקה של מחרוזת ארוכה למערך קצר כותבים אל מעבר לסוף המערך, מה שעלול לגרום לקריסה או להשחית משתנים אחרים (`warning: initializer-string for array of chars is too long`). תמיד הגדירו את היעד גדול מספיק לטקסט **ועוד אחד** עבור תו הסיום.
> - מרכאות בודדות מול כפולות: `'a'` הוא תו אחד (בעצם מספר), `"a"` היא מחרוזת של שני בייטים (`a` ו-`\0`). `char c = "a";` נותן `warning: initialization of 'char' from 'char *' makes integer from pointer`.
> - אי אפשר להשים מחרוזת עם `=` אחרי ההצהרה: `name = "Bob";` נותן `error: assignment to expression with array type`. השתמשו ב-`strcpy(name, "Bob");`.
> - `char s[5]; printf("%s", s);` מדפיס זבל, כי שום דבר לא שם `\0` במערך. אתחלו את המחרוזות שלכם.

## להמשיך הלאה

כתבו לולאה שסופרת כמה פעמים האות `'o'` מופיעה במחרוזת בלי להשתמש ב-`strlen`.

> **תורכם:** עקבו אחרי ההערות הממוספרות: הדפיסו את האורך של `word`, בנו את `code-academy` עם `strcpy` ו-`strcat`, הדפיסו את האותיות מופרדות במקפים בעזרת לולאה עד `'\0'`, והשתמשו ב-`strcmp` כדי להדפיס `Same word`.
