עד עכשיו כל קומפוננטה הייתה עלה: היא הציגה את התגיות של עצמה ותו לא. ממשקים אמיתיים נבנים בעזרת **הרכבה** (composition), כלומר הכנסת קומפוננטות לתוך קומפוננטות אחרות, כמו ש-HTML מכניס אלמנטים לתוך אלמנטים.

## קומפוננטות בתוך קומפוננטות

קומפוננטה יכולה להשתמש בקומפוננטות אחרות בתגיות שלה:

```jsx
function Avatar() {
  return <span>:-)</span>;
}

function Header() {
  return (
    <header>
      <Avatar />
      <h1>My site</h1>
    </header>
  );
}
```

חשבו על עץ הקומפוננטות כעל משפחה: `App` מכילה את `Header`, שמכילה את `Avatar`. הנתונים זורמים מטה בעץ דרך props.

## ה-prop בשם children

לפעמים קומפוננטה היא **עוטפת**: מסגרת, כרטיס או לוח שהתוכן שלו נקבע על ידי מי שמשתמש בו. בשביל זה React נותנת לכל קומפוננטה prop מיוחד בשם **`children`**. הוא מחזיק את כל מה שכותבים בין התגית הפותחת לתגית הסוגרת:

```jsx
function Card({ title, children }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      {children}
    </div>
  );
}

function App() {
  return (
    <Card title="Tips">
      <p>Drink water</p>
      <p>Sleep well</p>
    </Card>
  );
}
```

עקבו אחרי הנתונים:

1. `App` כותבת שתי פסקאות בין `<Card>` ל-`</Card>`.
2. React מעבירה אותן ל-`Card` בתור `children`.
3. `Card` מחליטה **איפה** הן יופיעו על ידי הדפסת `{children}`. כאן זה מתחת לכותרת.

ה-children יכולים להיות טקסט, אלמנטים, קומפוננטות אחרות או שילוב. אם `Card` שוכחת להדפיס את `{children}`, התוכן פשוט אף פעם לא מופיע ואין שגיאה, ולכן זו תעלומה קלאסית שגורמת לגרד בראש.

## למה זה חשוב

הרכבה שומרת על הפרדה בין המסגרת לתוכן. כותבים פעם אחת את הגבול, המרווחים ועיצוב הכותרת של הכרטיס, ואז משתמשים בו שוב בכל מקום עם תוכן אחר בפנים. תראו את אותו טריק בפריסות (layouts), בחלונות קופצים (modals), בכפתורים עם אייקונים ובכמעט כל ספריית ממשק.

> **שימו לב:**
> - תוכן חסר בקומפוננטה עוטפת: הקומפוננטה מקבלת `children` אבל אף פעם לא מדפיסה `{children}`.
> - כתיבת `<Card title="A" />` עם לוכסן סוגר עצמי ואז הצבת תוכן אחריה. התוכן חייב להיות **בין** התגיות, ולכן השתמשו ב-`<Card title="A"> ... </Card>`.
> - אם שוכחים את הסוגריים המסולסלים וכותבים `children` בתוך התגיות, React תציג את המילה עצמה.
> - רינדור של כמה children בתוך עוטפת בלי הורה משותף הוא בסדר, כי `children` יכול להחזיק הרבה אלמנטים בבת אחת.

> **תורכם:** גרמו ל-`Card` להציג את `{children}` שלה, ואז הוסיפו כרטיס שלישי עם הכותרת `Hobbies` שמכיל את הפסקה `Chess`.
