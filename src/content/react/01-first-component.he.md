**React** היא ספרייה (library) לבניית ממשקי משתמש מחלקים קטנים וניתנים לשימוש חוזר שנקראים **קומפוננטות** (components). ברגע שמבינים קומפוננטה אחת, כל אפליקציית React היא פשוט הרבה קומפוננטות שמורכבות יחד.

## קומפוננטה היא פונקציה

```jsx
function App() {
  return <h1>Hello!</h1>;
}

export default App;
```

בואו נפרק את זה:

1. `function App() { ... }` היא פונקציה רגילה של JavaScript.
2. מה שהפונקציה **מחזירה** הוא מה ש-React מציבה על המסך.
3. `<h1>Hello!</h1>` נראה כמו HTML, אבל זה **JSX**, תחביר שמאפשר לכתוב תגיות בתוך JavaScript. סביבת העבודה הופכת אותו לקריאות JavaScript רגילות לפני ההרצה.
4. `export default App;` אומרת לתצוגה המקדימה "זו הקומפוננטה שצריך להציג". כל שיעור במסלול הזה צריך את השורה הזו בסוף.

השם `App` מתחיל באות גדולה בכוונה. React מתייחסת ל-`<App />` כאל קומפוננטה ול-`<div>` כאל תגית HTML רגילה, והיא מחליטה מי מהם מי לפי האות הראשונה.

## הכללים של JSX

JSX קפדנית יותר מ-HTML:

- קומפוננטה חייבת להחזיר אלמנט הורה **אחד**. כדי להחזיר כמה, עוטפים אותם ב-`<div>`, או בעטיפה ריקה `<>...</>` (שנקראת fragment).
- כל תגית חייבת להיסגר. תגיות שנסגרות בעצמן צריכות את הלוכסן: `<br />`, `<img src="a.png" />`.
- חלק מהמאפיינים (attributes) קיבלו שם אחר כי הם מתנגשים עם מילים של JavaScript: `className` במקום `class`.
- כש-JSX נפרס על כמה שורות, עוטפים אותו בסוגריים אחרי `return` כדי ש-JavaScript לא תעצור מוקדם מדי.

```jsx
function App() {
  return (
    <div>
      <h1>My page</h1>
      <p>Welcome to React.</p>
    </div>
  );
}
```

## קומפוננטות בתוך קומפוננטות

אחרי שקומפוננטה קיימת, משתמשים בה כמו בתגית HTML משלכם:

```jsx
function Title() {
  return <h1>My page</h1>;
}

function App() {
  return (
    <div>
      <Title />
      <Title />
    </div>
  );
}
```

זה מציג את הכותרת פעמיים. לכתוב פעם אחת ולהשתמש הרבה פעמים, זה הרעיון הגדול שמאחורי React.

> **שימו לב:**
> - `Adjacent JSX elements must be wrapped in an enclosing tag`: החזרתם שני אלמנטים זה לצד זה. עטפו אותם ב-`<div>` או ב-`<>...</>`.
> - קומפוננטה שלא מציגה כלום: שכחתם את ה-`return`, או שבפונקציה כתוב `return null`.
> - `<title />` באותיות קטנות היא תגית ה-HTML, לא הקומפוננטה שלכם. קומפוננטות חייבות להתחיל באות גדולה.
> - `Unterminated JSX contents`: לתגית חסרה התגית הסוגרת `</h1>` או לוכסן סוגר עצמי.

> **תורכם:** גרמו ל-`App` להחזיר `<h1>` שכתוב בו `Hello, React!`.
