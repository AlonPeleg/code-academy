ה-state פרטי לרכיב שהוא הבעלים שלו. אז מה עושים כששני רכיבים שונים צריכים להציג או לשנות את אותו ערך? **מרימים את ה-state למעלה** (lifting state up): מעבירים אותו לאב המשותף הקרוב ביותר שלהם ומעבירים אותו משם למטה.

## הבעיה

דמיינו מונה בן שלושה חלקים: רכיב אחד מציג את הסכום, רכיב שני מציג את הכפול שלו, ולשלישי יש את הכפתורים. אם לכל אחד היה `useState` משלו, לחיצה על כפתור הייתה מעדכנת רק את הרכיב שהכפתור שייך לו. האחרים לא היו יודעים כלום. שני עותקים של אותם נתונים תמיד יתרחקו זה מזה.

## הפתרון: בעלים אחד

תנו את הנתונים ל**רכיב אחד**, האב של כל האחרים, ותנו לו לחלק לכל ילד את מה שהוא צריך:

```jsx
function App() {
  const [count, setCount] = useState(5);

  return (
    <div>
      <Display count={count} />
      <Double count={count} />
      <Controls onAdd={() => setCount(count + 1)} />
    </div>
  );
}
```

יש כאן שני סוגי props:

- **נתונים שיורדים למטה.** `count={count}` נותן לילדים את הערך הנוכחי. `Display` ו-`Double` רק מציגים אותו. הם לא הבעלים שלו ולא יכולים לשנות אותו.
- **פונקציות שיורדות למטה.** `onAdd={() => setCount(count + 1)}` נותנת ל-`Controls` דרך לבקש שינוי. הפונקציה חיה ב-`App`, שבו `setCount` זמינה, ו-`Controls` פשוט קוראת לה.

בתוך `Controls` משתמשים ב-prop כמו בכל פונקציה אחרת:

```jsx
function Controls({ onAdd }) {
  return <button onClick={onAdd}>Add</button>;
}
```

## מה קורה בלחיצה

1. המשתמש לוחץ על `Add`.
2. `Controls` קוראת ל-`onAdd()`, שהיא פונקציית החץ שנוצרה ב-`App`.
3. היא קוראת ל-`setCount(count + 1)`, ולכן ה-state ב-`App` משתנה.
4. React מרנדרת מחדש את `App`, שמעבירה את `count` החדש אל `Display` ואל `Double`. כולם מציגים מספרים עקביים.

זו **זרימת נתונים חד-כיוונית**: ערכים נעים למטה דרך props, ובקשות לשינוי נעות למעלה דרך קריאות לפונקציות. זה שומר על אפליקציות גדולות צפויות, כי לכל פיסת state יש בדיוק מקום אחד לחפש בו.

## כלל אצבע טוב

התחילו עם state ברכיב שמשתמש בו. כשרכיב שני צריך אותו, העבירו אותו למעלה לאב הקרוב ביותר שמכיל את שניהם. אל תרימו אותו גבוה יותר מהנדרש.

> **שימו לב:**
> - העברת `onAdd={setCount(count + 1)}` במקום פונקציית חץ: זה קורא ל-setter בזמן הרינדור ומוביל ל-`Too many re-renders`.
> - שכחתם להעביר prop: אז `Display` מציג `Total: ` בלי כלום אחרי זה, כי `count` הוא `undefined`.
> - ניסיון לשנות prop בתוך הילד (`count = count + 1`). props הם לקריאה בלבד. קראו לפונקציה מההורה.
> - מתן `useState(count)` משלו לילד, כלומר עותק. העותק הזה מתעלם משינויים מאוחרים יותר מההורה. השתמשו ב-prop ישירות.

> **תורכם:** צרו את ה-state ב-`App` (התחילו מ-`5`), העבירו את `count` אל `Display` ואל `Double`, ותנו ל-`Controls` את הפונקציות `onAdd` ו-`onReset`.
