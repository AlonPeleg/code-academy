כמעט כל אפליקציה מציגה רשימות: הודעות, מוצרים, תוצאות חיפוש. ב-React לא כותבים את הפריטים ביד. שומרים את הנתונים ב**מערך** (array) ומשאירים ל-JavaScript להפוך כל פריט לאלמנט.

## map: מנתונים לאלמנטים

שיטת המערך `map` מריצה פונקציה על כל פריט ואוספת את התוצאות למערך חדש. React יודעת להציג מערך של אלמנטים:

```jsx
const names = ["Ava", "Noam"];

<ul>
  {names.map((name) => (
    <li key={name}>{name}</li>
  ))}
</ul>
```

קוראים את זה צעד אחר צעד:

1. `names.map(...)` עוברת על המערך. עבור `"Ava"` פונקציית החץ מקבלת `name = "Ava"`.
2. פונקציית החץ מחזירה `<li key={name}>{name}</li>`, אלמנט אחד לכל פריט.
3. הכול יושב בתוך סוגריים מסולסלים, כי זה JavaScript בתוך JSX.
4. אם במערך יש 100 פריטים מקבלים 100 פריטי רשימה, ואם הנתונים משתנים הרשימה מתעדכנת.

## רשימות של אובייקטים

נתונים אמיתיים הם בדרך כלל אובייקטים, ולכן קוראים את התכונות שלהם בתוך הפונקציה:

```jsx
const courses = [
  { id: 1, title: "Intro to Python", hours: 10 },
  { id: 2, title: "Web Basics", hours: 6 },
];

<ol>
  {courses.map((course) => (
    <li key={course.id}>
      {course.title} ({course.hours}h)
    </li>
  ))}
</ol>
```

זה מציג `Intro to Python (10h)` ו-`Web Basics (6h)`.

## בשביל מה צריך key?

כל פריט ברשימה צריך prop בשם **`key`**: ערך שייחודי בין האחים שלו ואינו משתנה. כשהרשימה משתנה (פריט נוסף, נמחק או זז) React משווה בין המפתחות הישנים לחדשים כדי להבין מה קרה, וכך היא מעדכנת רק את מה שצריך ושומרת דברים כמו טקסט שהוקלד מחובר לשורה הנכונה.

- הכי טוב: `id` שמגיע עם הנתונים שלכם.
- מקובל ברשימות קבועות של טקסט ייחודי: הטקסט עצמו.
- להימנע: האינדקס במערך (`key={index}`) כשאפשר לשנות את סדר הפריטים או למחוק אותם, ולעולם לא להשתמש ב-`Math.random()`, כי הוא יוצר key חדש בכל רינדור.

ה-key הולך על האלמנט החיצוני ביותר בתוך `map`, והוא לא מועבר לרכיב (component) שלכם בתור prop.

> **שימו לב:**
> - `Warning: Each child in a list should have a unique "key" prop`: הוסיפו `key={...}` לאלמנט ש-`map` מחזירה.
> - שימוש בסוגריים מסולסלים `{ }` בגוף פונקציית החץ בלי `return`: הקוד `(x) => { <li>{x}</li> }` לא מחזיר כלום. השתמשו בסוגריים עגולים `(x) => ( <li>...</li> )` או הוסיפו `return`.
> - הצבת ה-key על המיכל `ul` במקום על כל `li`.
> - `Objects are not valid as a React child`: הדפסתם אובייקט שלם כמו `{course}`. הדפיסו את התכונות שלו.

> **תורכם:** הציגו את שלוש השפות ב-`<ul>` ואת שני הקורסים ב-`<ol>` (בצורה `Title (Nh)`), כשלכל אחד `key` נכון.
