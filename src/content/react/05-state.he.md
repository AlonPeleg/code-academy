Props מגיעים מבחוץ. **State** (מצב) הוא הזיכרון של הקומפוננטה עצמה: ערכים שיכולים להשתנות כשהדף פתוח, כמו מונה, הטקסט בתיבה, או אם תפריט פתוח. כשה-state משתנה, React מעדכנת את המסך אוטומטית.

## useState

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}
```

חלק אחר חלק:

1. `import { useState } from 'react';` מביאה את הכלי. פונקציות שמתחילות ב-`use` נקראות **hooks**.
2. `useState(0)` יוצרת פיסת state ש**ערך ההתחלה** שלה הוא `0`.
3. היא מחזירה מערך עם שני פריטים. הסוגריים המרובעים משמאל (`[count, setCount]`) מפרקים אותם לשני שמות: **הערך הנוכחי** ו**פונקציה מעדכנת** (setter). אפשר לבחור כל שם, והדפוס הרגיל הוא `thing` ו-`setThing`.
4. `onClick={() => ...}` מריצה את פונקציית החץ כשלוחצים על הכפתור. שימו לב שמעבירים פונקציה ולא קוראים לה.
5. `setCount(count + 1)` שומרת ערך חדש. אז React **מרנדרת מחדש** (קוראת שוב לפונקציית הקומפוננטה שלכם) ו-`count` גבוה עכשיו באחד.

## למה לא פשוט להשתמש במשתנה רגיל?

אם הייתם כותבים `let count = 0;` ובמטפל בלחיצה עושים `count = count + 1;`, המשתנה היה משתנה אבל שום דבר לא היה אומר ל-React לצייר מחדש. ה-state הוא האות: קריאה לפונקציה המעדכנת אומרת "זה השתנה, בבקשה עדכני את המסך". בנוסף, בכל פעם ש-React מרנדרת מחדש, משתנה רגיל היה מתאפס שוב ל-`0`, ואילו state נזכר בין רינדורים.

## מעדכנים לפי הערך הקודם

כשהערך החדש תלוי בישן, אפשר להעביר לפונקציה המעדכנת פונקציה. React קוראת לה עם הערך העדכני ביותר:

```jsx
setCount((c) => c + 1);
```

זו הצורה הבטוחה ביותר אם מעדכנים כמה פעמים ברצף. ללחיצות פשוטות `setCount(count + 1)` מספיקה.

## לכל קומפוננטה יש state משלה

אם שמים את `<Counter />` שלוש פעמים, לכל עותק יש `count` עצמאי משלו. ה-state שייך למופע אחד של קומפוננטה.

> **שימו לב:**
> - `onClick={setCount(count + 1)}` קוראת לפונקציה המעדכנת מיד בזמן הרינדור וגורמת ל-`Too many re-renders`. עטפו אותה: `onClick={() => setCount(count + 1)}`.
> - שינוי של state ישירות (`count = 5` או `list.push(x)`) לא עושה שום דבר גלוי. תמיד השתמשו בפונקציה המעדכנת, ותנו לה ערך חדש.
> - `useState is not defined`: שכחתם את השורה `import { useState } from 'react';`.
> - קריאה ל-hooks בתוך משפטי `if` או לולאות. hooks חייבים להיקרא בראש הקומפוננטה, בכל פעם.

> **תורכם:** בנו מונה. הוא צריך להציג `Count: 0`, לכלול כפתור `Add one` שמוסיף אחד, וכפתור `Reset` שמחזיר את המונה לאפס.
