פונג הוא המשחק האמיתי הראשון הקלאסי: כדור, שני מחבטים וניקוד. בשיעור הזה תתנו למחבט הימני **מוח**: קטע קוד זעיר שרודף אחרי הכדור, ותלמדו לשנות struct מתוך פונקציה על ידי העברת **מצביע** (pointer).

## השחקנים: כדור ומחבטים

כל מה שיש בפונג מתואר בשני structs קטנים:

```c
typedef struct { int x, y, w, h; } Paddle;
typedef struct { int x, y, vx, vy, size; } Ball;
```

לכדור יש מיקום (`x`, `y`) ו**מהירות** (`vx`, `vy`): כמה פיקסלים הוא זז בכל פריים. פריים אחד הוא 1/30 שנייה, ולכן `vx = 4` פירושו 120 פיקסלים בשנייה. בכל פריים המשחק עושה בדיוק את זה:

```c
ball.x += ball.vx;
ball.y += ball.vy;
```

כדי לגרום לכדור לקפוץ, הופכים את הסימן של אחת המהירויות. פגיעה בקיר העליון או התחתון הופכת את `vy`; פגיעה במחבט הופכת את `vx`:

```c
if (ball.y < 0 || ball.y + ball.size > SCREEN_H) ball.vy = -ball.vy;
```

## מצביעים: לתת לפונקציה לשנות את ה-struct שלכם

אם מעבירים struct לפונקציה בדרך הרגילה, C מוסרת **עותק**, והשינויים הולכים לאיבוד. כדי להזיז את מחבט המחשב מתוך פונקציה, אנחנו מעבירים במקום זה את **הכתובת** שלו:

```c
static void ai_move(Paddle *p, const Ball *b) {
    p->y += 2;            // p->y means (*p).y : the y of the paddle p points to
}

ai_move(&cpu, &ball);     // &cpu = "the address of cpu"
```

- `Paddle *p` נקרא "p הוא מצביע ל-Paddle".
- `&cpu` מפיק את הכתובת של המשתנה `cpu`.
- `p->y` עוקב אחרי המצביע ומגיע לשדה. משתמשים ב-`->` עבור מצביעים וב-`.` עבור structs רגילים.
- `const Ball *b` מבטיח שהפונקציה רק תסתכל על הכדור ולעולם לא תשנה אותו. המהדר אוכף את ההבטחה הזאת.

## שחקן מחשב שאפשר לנצח

שחקן מחשב שתמיד יושב בדיוק בגובה הכדור לעולם לא יפספס, והמשחק לא יהיה כיף. הטריק הוא לגרום לו **לעקוב אחרי הכדור, אבל לאט**. בכל פריים הוא משווה את אמצע המחבט שלו לאמצע הכדור וזז לעברו לכל היותר `AI_SPEED` פיקסלים:

```c
int target = b->y + b->size / 2;      // the ball's middle
int middle = p->y + p->h / 2;         // the paddle's middle
if (middle < target - 4)      p->y += AI_SPEED;   // ball is lower: go down
else if (middle > target + 4) p->y -= AI_SPEED;   // ball is higher: go up
```

ה-`4` יוצר **אזור מת** (dead zone): אם המחבט כבר קרוב מספיק, הוא נשאר במקומו ולא רועד. מכיוון ש-`AI_SPEED` (2) קטן מהמהירות האנכית של הכדור (3), אפשר לברוח מהמחשב כשהכדור קופץ בזווית חדה. זה בדיוק מה שהופך את המשחק לבן-ניצחון.

שימו לב שזו כל ה"בינה המלאכותית": השוואה אחת. בינה מלאכותית במשחקים היא בדרך כלל פשוטה כמו זו. היא רק צריכה להרגיש אמינה.

## ניקוד והגשה

כשהכדור יוצא מהמסך, מישהו קלע. ה-x של הכדור קטן מאפס כשהוא עבר את המחבט השמאלי, וגדול מ-`SCREEN_W` כשהוא עבר את הימני. אחרי נקודה אנחנו קוראים ל-`serve`, שמחזירה את הכדור לאמצע ושולחת אותו לעבר השחקן שהפסיד את הנקודה (`dir` הוא -1 לשמאל, +1 לימין).

## איך ההשמעה החוזרת הזאת עובדת

המחבט השמאלי נשלט על ידי **שחקן מתוסרט**: הטקסט ב-`stdin` מפרט את הרגעים שבהם מקשי החץ למעלה ולמטה נלחצים ומשתחררים. התוכנית רצה על שרת, והדפדפן משמיע את ההקלטה. פתחו את הלשונית **קלט השחקן** (Player input) ושנו כמה מספרי פריימים: תשחקו משחק אחר ותקבלו תוצאה אחרת. הבדיקה עוברת רק עבור התסריט המדויק שמגיע עם השיעור, ולכן החזירו אותו לפני שתלחצו על בדיקת תשובה.

> **שימו לב:**
> - `p.y` על מצביע לא יתקמפל: `error: 'p' is a pointer; did you mean to use '->'?`. השתמשו ב-`p->y`.
> - אם שוכחים את ה-`&` בקריאה: `ai_move(cpu, &ball)` נותן `incompatible type for argument 1`.
> - שימוש ב-`/` על שני int-ים זורק את השבר: `size / 2` כש-`size = 5` הוא 2, לא 2.5. כאן זה בסדר, אבל זה מפתיע מתחילים.
> - אם מהירות המחשב שווה למהירות הכדור, הוא אף פעם לא מפספס, והניקוד נשאר 0 : N.

## להמשיך הלאה

נסו `AI_SPEED 3` וראו את המחשב לוקח כל נקודה. אחר כך הגדילו מעט את מהירות הכדור אחרי כל נקודה, או תנו לזווית להיות תלויה במקום שבו הוא פוגע במחבט, כפי שתעשו בשיעור על Breakout.

> **תורכם:** מלאו את `ai_move` בעזרת target, middle והאזור המת של 4 פיקסלים עם `AI_SPEED`, והוסיפו את הניקוד: כשהכדור יוצא בצד שמאל, המחשב מקבל נקודה וקוראים ל-`serve(&ball, -1)`; כשהוא יוצא בצד ימין, השחקן מקבל נקודה וקוראים ל-`serve(&ball, 1)`. עם המקשים שניתנו התוכנית אמורה להדפיס `player 4, computer 3`.
