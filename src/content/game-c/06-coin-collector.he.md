אתם כבר יודעים להזיז שחקן, להשאיר אותו על המסך, לשמור אובייקטים ב-structs ולשמור הרבה מהם במערך. הגיע הזמן לחבר הכול: בשיעור הזה תוסיפו **זיהוי התנגשות** (collision detection) ו**ניקוד** כדי לבנות משחק קטן ושלם לאיסוף מטבעות.

## מתי שני מלבנים נוגעים?

כמעט כל דבר במשחק פשוט הוא מלבן, שנקרא **תיבה תוחמת** (bounding box). שתי תיבות `a` ו-`b` חופפות כשהן חופפות בשני הצירים *בו זמנית*. בציר x זה אומר שני דברים:

1. הקצה השמאלי של `a` נמצא **משמאל לקצה הימני של b**: `a.x < b.x + b.w`
2. הקצה הימני של `a` נמצא **מימין לקצה השמאלי של b**: `a.x + a.w > b.x`

אם שניהם נכונים, יש להם מרחב אופקי משותף. אותן שתי בדיקות עם `y` ו-`h` מטפלות בציר האנכי. חברו את כל הארבע עם `&&` ("וגם"):

```c
typedef struct { int x, y, w, h; } Rect;

int overlaps(Rect a, Rect b) {
    return a.x < b.x + b.w && a.x + a.w > b.x &&
           a.y < b.y + b.h && a.y + a.h > b.y;
}
```

השוואה כמו `a.x < b.x + b.w` מפיקה `1` (אמת) או `0` (שקר), ולכן הביטוי כולו הוא כבר התשובה שאנחנו רוצים להחזיר עם `return`. הפונקציה הזאת מקבלת את המלבנים שלה **לפי ערך** (עותקים), וזה בסדר כי היא רק קוראת אותם.

> טיפ: ציירו שני ריבועים על נייר, החליקו אחד מעל השני, וצפו איזה מארבעת התנאים הופך לשקרי ראשון. זו הדרך הטובה ביותר להבין את זה.

## מטבעות שאפשר לאסוף פעם אחת

כל מטבע הוא struct עם תיבה ודגל:

```c
typedef struct { Rect box; int collected; } Coin;
```

struct יכול להחזיק struct אחר, ולכן `coins[i].box.x` אומר "ה-x של התיבה של המטבע ה-i". בדיקת ההתנגשות בלולאת המשחק:

```c
for (int i = 0; i < NUM_COINS; i++) {
    if (!coins[i].collected && overlaps(player, coins[i].box)) {
        coins[i].collected = 1;
        score++;
    }
}
```

- `!coins[i].collected` אומר "עדיין לא נאסף" (`!` הופך אמת ושקר).
- מכיוון שהלולאה רצה 30 פעמים בשנייה, והשחקן חופף למטבע כמה מסגרות ברצף, הדגל חיוני. ברגע שהוא נקבע, המטבע הזה מתעלמים ממנו והוא כבר לא מצויר.
- `score++` מוסיף 1.

## המשחק המוגמר, צעד אחר צעד

ראו איך החלקים מכל השיעורים הקודמים מתחברים יחד במסגרת אחת:

1. **קלט**: מקשי החצים משנים את `player.x` ואת `player.y` (שיעורים 2 ו-3).
2. **עדכון**: בודקים כל מטבע להתנגשות ומעדכנים את הניקוד (לולאה בסגנון שיעור 5).
3. **ציור**: מנקים, מציירים את המטבעות שלא נאספו, את השחקן ואת טקסט הניקוד.
4. **הצגה** (Present).

אחרי שהלולאה מסתיימת, התוכנית מדפיסה `score: ...`, וזה מה ש**בדיקת תשובה** (Check answer) קוראת.

> **שימו לב:**
> - כתיבת `||` (או) במקום `&&` ב-`overlaps` גורמת לכמעט הכול להיחשב כנוגע.
> - שוכחים את הדגל `collected` ומקבלים מטבע אחד ששווה 10 או 20 נקודות.
> - מבלבלים בין `=` ל-`==`: `if (coins[i].collected = 0)` מבצע השמה, ו-gcc מזהיר `suggest parentheses around assignment used as truth value`.
> - שוכחים ש-`x` ו-`y` הם הפינה השמאלית העליונה. עבור עיגול שמצויר עם `engine_circle`, המיקום הוא ה*מרכז*, ולכן מוסיפים חצי מהגודל כשמציירים את המטבע.

## להמשך

המטבע החמישי יושב בפינה הימנית התחתונה, מחוץ להישג ידו של התסריט הנתון. ערכו את הקלט של השחקן כך שהשחקן יאסוף את כל החמישה והתוכנית תדפיס `score: 5`. אחר כך נסו להוסיף טקסט "YOU WIN" כש-`score == NUM_COINS`.

> **תורכם:** סיימו את הפונקציה `overlaps` עם ארבע ההשוואות, ובלולאת המטבעות סמנו מטבע שלא נאסף ונוגע כנאסף והוסיפו אחד ל-`score`. עם תסריט המקשים הנתון התוכנית צריכה להדפיס `score: 4`.
