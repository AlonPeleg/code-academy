משחקים הם כיפיים רק כשאפשר לשחק בהם. בשיעור הזה תקראו את המקלדת ותזיזו ריבוע על המסך, ותלמדו את ההבדל בין *החזקת* מקש לבין *הקשה* עליו.

## שאלות על מקשים

המנוע נותן לכם שתי שאלות שאפשר לשאול, כל אחת עם שם מקש כמו `KEY_LEFT`:

```c
if (key_down(KEY_RIGHT)) {
    x += 4;            /* true on EVERY frame the key is held */
}

if (key_pressed(KEY_SPACE)) {
    jumps++;           /* true on ONE frame: the moment the key goes down */
}
```

- `key_down(key)` היא **אמת כל עוד המקש לחוץ**. השתמשו בה להליכה.
- `key_pressed(key)` היא **אמת רק בפריים הראשון** של לחיצה. השתמשו בה לפעולות שצריכות לקרות פעם אחת בכל לחיצה, כמו ירי או ספירת הקשה. החזקת המקש במשך שנייה לא חוזרת עליה.

שתיהן מחזירות מספר: 1 עבור אמת ו-0 עבור שקר, וכך `if` עובד ב-C.

## מהירות לפריים

אם השחקן מחזיק ימינה במשך 30 פריימים וכל פריים מוסיף 4 ל-`x`, הריבוע עובר `4 x 30 = 120` פיקסלים. את ה-4 אנחנו קוראים **מהירות בפיקסלים לפריים**. הרבה מנועי משחק נותנים לכם `dt` (הזמן שעבר מאז הפריים הקודם) כדי שיוכלו להכפיל בו את המהירות. המנוע הזה תמיד רץ באותם 30 פריימים קבועים בשנייה, ולכן אפשר לוותר על `dt` ופשוט להזיז כמות קבועה בכל פריים. זה פשוט, וזה ניתן לשחזור לגמרי, וזה חשוב כי התוכנית שלכם מנוגנת מחדש מתסריט.

במקום לכתוב `4` במקומות רבים, תנו למהירות שם:

```c
#define SPEED 4   /* pixels per frame */
```

`#define` גורם למהדר (compiler) להחליף את המילה `SPEED` ב-`4` בכל מקום. אם בהמשך תרצו שחקן מהיר יותר, תשנו שורה אחת. **אין נקודה-פסיק** אחרי `#define`.

## קואורדינטות מסך וכיוון

מכיוון ש-`y` גדל כלפי מטה, ארבעת הכיוונים נראים כך:

| מקש | שינוי |
|---|---|
| שמאלה | `x -= SPEED` |
| ימינה | `x += SPEED` |
| למעלה | `y -= SPEED` |
| למטה | `y += SPEED` |

שימו לב שהוראות `if` הן בלתי תלויות. אם שמאלה וימינה לחוצים יחד, שתי ההשפעות מבטלות זו את זו. החזקת ימינה ולמטה יחד מזיזה באלכסון, מעט מהר יותר מכיוון בודד, וזו תכונה מפורסמת של משחקים פשוטים.

## הצגת מספר על המסך

`engine_text` מקבלת מחרוזת (string) רגילה, ולכן כדי להציג מספר קודם בונים את המחרוזת בעזרת `snprintf`. היא עובדת כמו `printf` אבל כותבת לתוך מערך (array) של char:

```c
char label[40];
snprintf(label, sizeof label, "taps: %d", taps);
engine_text(8, 8, 14, RGB_WHITE, label);
```

> **שימו לב:**
> - שימוש ב-`key_down` לספירת הקשות סופר כל פריים: החזקת רווח במשך 30 פריימים נותנת 30 "הקשות". השתמשו ב-`key_pressed`.
> - `if (key_down(KEY_UP)) y += SPEED;` היא טעות קלאסית: למעלה חייב להקטין את `y`.
> - כתיבת `#define SPEED = 4` או `#define SPEED 4;` יוצרת שגיאות מוזרות כמו `expected expression before '=' token`. ל-`#define` אין `=` ואין `;`.
> - הקלדת שם מקש באותיות קטנות (‏`key_left`) נותנת `'key_left' undeclared`. השמות באותיות גדולות: `KEY_LEFT`.

## להמשך

לשונית קלט השחקן (player input) מפרטת את לחיצות המקשים של ההקלטה הזאת, אחת בכל שורה: `<frame> <key> <down|up>`. שנו את המספרים, הוסיפו שורה `left down`, לחצו על Run, וראו את הריבוע עוקב אחרי התסריט החדש שלכם. אחר כך ראו איך השורה המודפסת משתנה.

> **תורכם:** הוסיפו את המקשים UP ו-DOWN (הם משנים את `y` ב-`SPEED`), והוסיפו `1` ל-`taps` בכל פעם שמקש הרווח (SPACE) נלחץ, בעזרת `key_pressed`. עם הקלט הנתון, התוכנית צריכה להדפיס `final: 270, 50, taps: 3`.
