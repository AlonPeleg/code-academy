כרגע הריבוע שלכם יכול לשוטט אל מחוץ למסך ולא לחזור. בשיעור הזה תבנו פונקציית עזר קטנה, **clamp**, ותשתמשו בה כדי לכלוא את השחקן בתוך החלון. תכירו גם מאקרו (macro) לגודל המסך.

## קבועי גודל המסך

המנוע נותן לכם שני שמות, `SCREEN_W` (‏320) ו-`SCREEN_H` (‏240). השתמשו תמיד בהם במקום להקליד 320 ו-240: כך הקוד שלכם אומר מה המספרים אומרים, ועדיין יעבוד אם גודל המסך ישתנה פעם.

זכרו ש-`x` ו-`y` של מלבן הם **הפינה השמאלית העליונה** שלו. עבור שחקן ברוחב 20 פיקסלים, הקצה הימני נמצא ב-`x + 20`. כדי שכל השחקן יישאר גלוי:

```
0  <=  x  <=  SCREEN_W - 20      (that is 300)
0  <=  y  <=  SCREEN_H - 20      (that is 220)
```

כדי לא לחזור על החישוב, מגדירים מאקרו:

```c
#define PLAYER_SIZE 20
#define MAX_X (SCREEN_W - PLAYER_SIZE)
```

**מאקרו** הוא החלפת טקסט שנעשית לפני ההידור: בכל מקום שכתבתם `MAX_X`, המהדר רואה `(320 - 20)`. הסוגריים מגנים עליכם כשהמאקרו משמש בתוך ביטוי גדול יותר.

## מהו clamping?

**לעשות clamp** למספר פירושו לדחוס אותו לתוך טווח. אם הוא קטן מדי, משתמשים בערך הקטן ביותר המותר. אם הוא גדול מדי, משתמשים בערך הגדול ביותר המותר. אחרת משאירים אותו כמו שהוא.

```c
int clamp(int value, int low, int high) {
    if (value < low) return low;
    if (value > high) return high;
    return value;
}
```

חלק אחר חלק:

- `int clamp(...)` מצהירה על פונקציה (function) ש**מחזירה int**.
- `int value, int low, int high` הם שלושת ה**פרמטרים** (parameters): הקלטים של הפונקציה.
- `return low;` יוצאת מיד מהפונקציה ומחזירה את `low` לקורא. השורות הבאות אף פעם לא רצות.
- ה-`return value;` האחרון קורה רק אם שתי בדיקות ה-`if` היו שקריות, כלומר הערך כבר היה תקין.

שימוש בה:

```c
printf("%d\n", clamp(-5, 0, 100));   /* prints 0   */
printf("%d\n", clamp(250, 0, 100));  /* prints 100 */
printf("%d\n", clamp(42, 0, 100));   /* prints 42  */
```

בלולאת המשחק, קודם זזים, אחר כך עושים clamp, ואז מציירים:

```c
x += SPEED;                  /* may go past the edge for a moment */
x = clamp(x, 0, MAX_X);      /* ...but is fixed before we draw */
```

קריאה ל-`clamp(x, 0, MAX_X);` לבדה לא עושה שום דבר מועיל: הפונקציה מחזירה מספר חדש ולא משנה את `x`. צריך להציב את התוצאה בחזרה עם `x = ...`.

> **שימו לב:**
> - כתיבת `clamp(x, 0, MAX_X);` בלי `x =` משאירה את הבאג: שום דבר לא משתנה. לא מוצגת שגיאה, וזה מה שהופך את הטעות הזאת לקשה לאיתור.
> - הכנסת הארגומנטים בסדר שגוי, כמו `clamp(x, MAX_X, 0)`, הופכת את הטווח לריק ונותנת תוצאות מוזרות.
> - שימוש ב-`SCREEN_W` כגבול במקום `SCREEN_W - PLAYER_SIZE` נותן לשחקן להחליק חצי החוצה בצד ימין.
> - `return` חסר בסוף נותן את האזהרה `control reaches end of non-void function`.

## להמשך

במקום לעצור בקיר אפשר לגרום לשחקן להופיע בצד הנגדי (wrap around). נסו להחליף את ה-clamp ב-`if (x > MAX_X) x = 0;`.

> **תורכם:** השלימו את הפונקציה `clamp` (שתי בדיקות ה-`if` וה-`return` הסופי), ואז השתמשו בה בלולאה כדי לשמור על `x` בין `0` ל-`MAX_X` ועל `y` בין `0` ל-`MAX_Y`. הקלט הנתון רץ אל הפינה, חוזר שמאלה וקופץ למעלה, ולכן התוכנית צריכה להדפיס `final: 0, 200`.
