תוכניות נעשות מעניינות כשהן יכולות **להחליט** ו**לחזור על פעולות**. השיעור הזה עוסק ב-`if`/`else`, באופרטורי השוואה ובלולאות של Java.

## קבלת החלטות עם if

`if` מריץ בלוק רק כשהתנאי שלו הוא `true`. התנאי נכתב בסוגריים והבלוק בסוגריים מסולסלים:

```java
int temperature = 28;
if (temperature > 25) {
    System.out.println("It is hot");
} else if (temperature > 15) {
    System.out.println("It is nice");
} else {
    System.out.println("It is cold");
}
// prints: It is hot
```

Java בודקת את התנאים מלמעלה למטה ומריצה רק את הבלוק **הראשון** שמתאים. ה-`else` שבסוף הוא ברירת המחדל.

## השוואה וחיבור

אופרטורי השוואה מחזירים `boolean`:

| אופרטור | משמעות |
|---|---|
| `==` | שווה ל |
| `!=` | לא שווה ל |
| `<` `<=` | קטן מ, קטן או שווה ל |
| `>` `>=` | גדול מ, גדול או שווה ל |

מחברים תנאים עם `&&` (וגם), `||` (או) ו-`!` (לא):

```java
if (age >= 13 && age <= 19) {
    System.out.println("teenager");
}
```

זכרו ש-`=` מאחסן ערך ואילו `==` משווה. ב-Strings משווים עם `.equals(...)`, לא עם `==`.

## switch

כשמשווים ערך אחד מול הרבה אפשרויות קבועות, `switch` מסודר יותר:

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("Mon");
        break;
    case 2:
        System.out.println("Tue");
        break;
    default:
        System.out.println("Some other day");
}
```

ה-`break` מונע מ-Java לרוץ אל ה-case הבא. שכחה שלו היא באג מפורסם שנקרא "fall-through" (נפילה).

## לולאת for

משתמשים ב-`for` כשיודעים כמה פעמים לחזור:

```java
for (int i = 1; i <= 3; i++) {
    System.out.println("Round " + i);
}
```

בסוגריים יש שלושה חלקים שמופרדים בנקודה-פסיק: **אתחול** (`int i = 1`, רץ פעם אחת), **תנאי** (`i <= 3`, נבדק לפני כל סיבוב), ו**עדכון** (`i++`, רץ אחרי כל סיבוב). `i++` פירושו "הוסף אחד ל-i".

## לולאת while

משתמשים ב-`while` כשחוזרים עד שמשהו משתנה:

```java
int n = 1;
while (n < 100) {
    n = n * 2;
}
System.out.println(n);   // prints: 128
```

לולאת `do { ... } while (condition);` זהה, אלא שהיא מריצה את הגוף קודם ובודקת אחר כך, ולכן הגוף תמיד רץ לפחות פעם אחת.

אפשר לצאת מלולאה מוקדם עם `break`, או לדלג לסיבוב הבא עם `continue`.

## טריק השארית

`i % 3 == 0` נכון בדיוק כש-`i` מתחלק ב-3 ללא שארית. זו הדרך הסטנדרטית לבדוק "כל פריט שלישי" או "האם המספר זוגי" (`i % 2 == 0`). מתכנתים משתמשים בזה כל הזמן.

> **שימו לב:**
> - כתיבת `if (x = 5)` גורמת לשגיאה `error: incompatible types: int cannot be converted to boolean`. התכוונתם ל-`==`.
> - נקודה-פסיק מיד אחרי הסוגריים, `if (x > 3);` או `for (...);`, מסיימת את הפקודה מיד, ולכן הבלוק שאחריה לא נשלט על ידה. המהדר שותק, אז חפשו את זה כשלולאה עושה משהו מוזר.
> - אם תנאי הלולאה אף פעם לא נהיה שקר, התוכנית רצה לנצח (**לולאה אינסופית**). ודאו שמשהו בפנים משתנה, כמו `n++`.
> - טעויות של אחד (off-by-one): `i < 15` נעצר ב-14, `i <= 15` נעצר ב-15. בדקו את הערך הראשון והאחרון.
> - הצבת המקרה הכללי ראשון בשרשרת if/else, למשל בדיקת `i % 3` לפני `i % 15`, גורמת לכך שלעולם לא מגיעים למקרה הספציפי.
