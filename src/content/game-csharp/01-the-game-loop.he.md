כל משחק וידאו, מ-Pong ועד הכותרים הגדולים ביותר של Unity, בנוי סביב רעיון אחד: **לולאת משחק** (game loop). בשיעור הזה תכתבו את הלולאה הראשונה שלכם, תגרמו לריבוע להחליק על המסך ותכירו את כל ארגז הכלים (ה"מנוע") שהמסלול הזה נותן לכם.

## מהי לולאת משחק?

משחק נראה כאילו הוא נע, אבל באמת הוא מציג תמונה נייחת חדשה, שנקראת **פריים** (frame), פעמים רבות בשנייה. כאן אנחנו מציירים **30 פריימים בשנייה**, ולכן פריים אחד נמשך 1/30 שנייה. בכל פריים המשחק מבצע את אותן שלוש משימות:

1. **עדכון**: משנים את המספרים שמתארים את העולם (מיקומים, ניקוד, ...).
2. **ציור**: מציירים את המצב הנוכחי של העולם.
3. **הצגה**: אומרים למנוע "הפריים הזה הסתיים, הציגו אותו".

ב-C# זו לולאת `while`:

```csharp
while (Engine.Running())
{
    // update
    // draw
    Engine.Present();
}
```

`Engine.Running()` עונה `true` כל עוד נשארו פריימים להקלטה, ו-`false` בסוף, מה שיוצא מהלולאה. בכל פעם היא גם מקדמת את השעון בפריים אחד.

## זו הקלטה, לא משחק חי

תוכנית ה-C# שלכם רצה על שרת, ולכן היא לא יכולה לקרוא את המקלדת שלכם בזמן אמת. במקום זאת הלשונית **Player input** מכילה תסריט קטן של לחיצות מקשים (‏`10 right down` פירושו "בפריים 10 השחקן לוחץ על חץ ימינה"). התוכנית מריצה את כל המשחק, המנוע מקליט כל צורה שאתם מציירים, והדפדפן מנגן את ההקלטה כמו וידאו. מכיוון שזו הקלטה, **הכול חייב להיות צפוי**: בלי מספרים אקראיים ובלי שעון. ערכו את תסריט הקלט כדי "לשחק" אחרת.

כל מה שמדפיסים עם `Console.WriteLine` מופיע כפלט רגיל. כך **Check answer** יודע מה קרה במשחק שלכם, ולכן כל שיעור מסתיים בהדפסת תוצאה.

## המסך

המסך הוא **ברוחב 320 פיקסלים ובגובה 240**. הנקודה `(0, 0)` היא הפינה **השמאלית העליונה**, `x` גדל ימינה ו-`y` גדל **כלפי מטה** (ההפך מגרף במתמטיקה).

## מדריך למנוע

כל מה שלהלן זמין אוטומטית. אין צורך לכתוב אותו בעצמכם.

**`Engine`** (חברים סטטיים, ולכן כותבים `Engine.Something`)

| חבר | מה הוא עושה |
|---|---|
| `Engine.Width`, `Engine.Height` | גודל המסך: 320 ו-240. |
| `Engine.Frames(n)` | כמה פריימים להקליט (ברירת מחדל 180, שהם 6 שניות; מקסימום 600). קראו לה פעם אחת לפני הלולאה. |
| `Engine.Frame` | מספר הפריים הנוכחי, מתחיל מ-0. |
| `Engine.Running()` | תנאי הלולאה: `true` כל עוד נשארו פריימים. |
| `Engine.KeyDown(Key.Left)` | `true` בכל פריים שהמקש לחוץ. |
| `Engine.KeyPressed(Key.Space)` | `true` רק בפריים היחיד שבו המקש יורד. |
| `Engine.Clear(color)` | ממלאת את כל המסך בצבע אחד. |
| `Engine.Rect(x, y, w, h, color)` | מלבן מלא, ‏`(x, y)` היא הפינה השמאלית העליונה שלו. |
| `Engine.Circle(x, y, radius, color)` | עיגול מלא, ‏`(x, y)` הוא המרכז שלו. |
| `Engine.Line(x1, y1, x2, y2, color)` | קו בין שתי נקודות. |
| `Engine.Text(x, y, size, color, "text")` | טקסט, ‏`(x, y)` היא הפינה השמאלית העליונה שלו. |
| `Engine.Present()` | סוף הפריים. |

כל מתודת ציור מקבלת גם שלושה מספרים רגילים במקום צבע, למשל `Engine.Clear(0, 0, 0)`.

**`Color`**: ‏`Color.Black`, `White`, `Gray`, `Dark`, `Red`, `Orange`, `Yellow`, `Green`, `Cyan`, `Blue`, `Purple`, `Pink`. צרו צבע משלכם עם `new Color(r, g, b)` כשכל ערך הוא 0 עד 255.

**`Key`**: ‏`Key.Left`, `Right`, `Up`, `Down`, `Space`, `A`, `D`, `W`, `S`, `Z`, `X`, `Enter`.

## הסדר חשוב בציור

צורות נצבעות בסדר שבו קוראים להן, ולכן צורות מאוחרות מכסות מוקדמות. תמיד קראו קודם ל-`Clear`, אחרת התמונה של הפריים הקודם נשארת על המסך.

```csharp
Engine.Clear(Color.Dark);               // background first
Engine.Circle(160, 120, 30, Color.Red); // then things on top
Engine.Text(8, 8, 14, Color.White, "Hi");
```

> **שימו לב:**
> - שכחת `Engine.Present()` פירושה שהפריים אף פעם לא מסתיים ושום דבר לא מוצג.
> - הצבת `Engine.Clear` בסוף הלולאה מוחקת את מה שציירתם הרגע.
> - כתיבת `engine.running()` באותיות קטנות נותנת `error CS0103: The name 'engine' does not exist in the current context`. C# רגישה לאותיות גדולות וקטנות.
> - שימוש ב-`Engine.Frames(...)` בתוך הלולאה מאוחר מדי; קראו לה לפני שהלולאה מתחילה.
> - אל תגדירו טיפוסים משלכם בשם `Engine`, `Key` או `Color`: הם כבר קיימים.

## להמשך

שנו את המהירות מ-`2` ל-`3` (ואת התוצאה הצפויה), או צרו `Engine.Circle` במקום מלבן. נסו `Engine.Frames(300)` כדי להקליט עשר שניות.

> **תורכם:** בתוך הלולאה גרמו ל-`x` לגדול ב-2 בכל פריים, קראו ל-`Engine.Present()` כשורה האחרונה של הלולאה, ואחרי הלולאה הדפיסו `final x: ` ואחריו את `x` (התוצאה צריכה להיות 180).
