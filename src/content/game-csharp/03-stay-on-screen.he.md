אם תחזיקו את מקש החץ זמן רב מדי, הריבוע שלכם יצא מהחלון ויאבד לנצח. בשיעור הזה תבצעו **הגבלה** (clamp) של המיקום: תכריחו מספר להישאר בין מינימום למקסימום. הגבלה כזו נמצאת בכל מקום במשחקים: חיים שלא יכולים לרדת מתחת ל-0, מצלמה שנעצרת בקצה המפה, משוט שנשאר בתוך המגרש.

## המחלקה Math

ב-C# יש מחלקה (class) בשם `Math` (היא נמצאת ב-`using System;`) מלאה בפונקציות עזר. שתיים מהן הן כל מה שצריך:

```csharp
Math.Min(7, 3)   // 3  : the smaller of the two
Math.Max(7, 3)   // 7  : the larger of the two
```

נדמה שהן עושות את ההפך ממה שרוצים, ולכן כדאי לחשוב עליהן כך:

- `Math.Min(x, 300)` היא **תקרה**: התוצאה לעולם לא תהיה גדולה מ-300.
- `Math.Max(0, x)` היא **רצפה**: התוצאה לעולם לא תהיה קטנה מ-0.

שלבו ביניהן ויש לכם הגבלה:

```csharp
x = Math.Max(0, Math.Min(x, 300));
// x = 450  ->  Min gives 300  ->  Max gives 300
// x = -30  ->  Min gives -30  ->  Max gives 0
// x = 120  ->  Min gives 120  ->  Max gives 120
```

קראו את זה מבפנים החוצה: קודם מפעילים את התקרה, ואחר כך את הרצפה.

## איפה הקצה הימני?

מלבן מצויר מ**הפינה השמאלית העליונה** שלו. אם הריבוע ברוחב 20 פיקסלים והקצה השמאלי שלו `x` הוא 310, הקצה הימני שלו נמצא ב-330, וזה כבר מחוץ למסך ברוחב 320 פיקסלים. לכן ה-`x` הגדול ביותר המותר אינו רוחב המסך, אלא:

```csharp
Engine.Width - Size    // 320 - 20 = 300
```

בציר האנכי משתמשים ב-`Engine.Height - Size` (240 - 20 = 220). הערכים `Engine.Width` ו-`Engine.Height` הם קבועים מובנים, ולכן אין צורך להקליד בעצמכם 320 או 240.

## סדר שלבי העדכון

בתוך הלולאה (loop) הסדר הוא: **קודם לזוז, אחר כך להגביל**, ואז לצייר. אם מגבילים לפני התנועה, אפשר עדיין לצייר את השחקן מחוץ למסך למשך פריים אחד.

```csharp
x += Speed;                                        // 1. move
x = Math.Max(0, Math.Min(x, Engine.Width - Size)); // 2. clamp
Engine.Rect(x, y, Size, Size, Color.Cyan);         // 3. draw
```

## מעקב אחרי שיא

`Math.Max` היא גם הדרך לזכור את הערך הגדול ביותר שנראה אי פעם. אם `best` מחזיק את השיא עד כה, אז `best = Math.Max(best, x);` מעלה אותו בכל פעם ש-`x` עוקף אותו, ומשאיר אותו כמו שהוא בכל מקרה אחר.

> **שימו לב:**
> - החלפה בין השתיים: `Math.Max(x, 300)` **לא** מגבילה את x ל-300, אלא מכריחה את x להיות לפחות 300.
> - שכחה לחסר את הגודל: ההגבלה `Math.Min(x, Engine.Width)` מאפשרת לריבוע להחליק החוצה מהחלון עד חציו.
> - הכתיבה `Math.min(...)` באותיות קטנות גורמת ל-`error CS0117: 'Math' does not contain a definition for 'min'`.
> - שכחה של `using System;` גורמת ל-`error CS0103: The name 'Math' does not exist in the current context`.
> - קריאה ל-`Math.Min(x)` עם ארגומנט אחד בלבד גורמת ל-`error CS1501: No overload for method 'Min' takes 1 arguments`.

## להתקדם הלאה

נסו לגרום לריבוע "להיעטף" במקום זאת: אם `x` עובר את הקצה הימני, החזירו אותו ל-0. מה מרגיש טוב יותר בחללית? ומה במשחק פלטפורמה?

> **תורכם:** אחרי משפטי ה-`if` של התנועה, הגבילו את `x` בין 0 ל-`Engine.Width - Size` ואת `y` בין 0 ל-`Engine.Height - Size`, והחזיקו ב-`furthestRight` את ה-`x` הגדול ביותר שהושג. בסוף אמורים להתקבל `x = 0`, `y = 120`, ו-furthest right של 300.
