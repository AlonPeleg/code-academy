איקס עיגול הוא משחק פתור: במשחק מושלם אף אחד לא מנצח אלא אם הצד השני עושה טעות. בשיעור הזה המחשב משחק בצורה מושלמת, והדרך שבה הוא עושה זאת, אלגוריתם שנקרא **minimax**, היא האב הקדמון של כל מנוע שחמט ומשחקי לוח. זה גם תרגיל מצוין ב**רקורסיה** (recursion): מתודה שקוראת לעצמה.

## הלוח

הלוח הוא תשעה תאים, ממוספרים 0 עד 8, ששמורים במערך (array) של `char`: ‏`' '` לתא ריק, `'X'` לאדם ו-`'O'` למחשב.

```
0 | 1 | 2
3 | 4 | 5
6 | 7 | 8
```

יש בדיוק שמונה דרכים לנצח: שלוש שורות, שלוש עמודות ושני אלכסונים. המחלקה `Board` שומרת אותם בטבלה של מספרי תאים (`new[] { 0, 4, 8 }` הוא האלכסון הראשי), ו-`Winner()` בודקת כל קו: שלושה תאים שווים ולא ריקים אומרים שהשחקן הזה ניצח. טבלה של נתונים במקום שמונה משפטי `if` היא תבנית שתשתמשו בה כל הזמן במשחקים.

## הרעיון מאחורי minimax

איך תוכנית מחליטה על מהלך? היא מדמיינת את העתיד. לכל תא ריק היא שואלת: "אם אשחק כאן, ואז היריב יענה הכי טוב שאפשר, ואני אענה הכי טוב שאפשר, וכן הלאה עד שהמשחק נגמר, איך הוא ייגמר?" כל משחק שנגמר מקבל ציון מנקודת המבט של המחשב:

| סוף המשחק | ציון |
|---|---|
| המחשב (O) מנצח | +1 |
| האדם (X) מנצח | -1 |
| תיקו | 0 |

המחשב, כשהתור שלו, בוחר את המהלך עם הציון **הגבוה** ביותר. מניחים שהאדם, כשהתור שלו, בוחר את המהלך עם הציון **הנמוך** ביותר, כי זה הכי טוב בשבילו. ה"מקסימום, מינימום, מקסימום, מינימום" המתחלף הזה הוא מקור השם.

## רקורסיה

```csharp
static int Minimax(Board board, bool computersTurn)
{
    char w = board.Winner();
    if (w == 'O') return 1;
    if (w == 'X') return -1;
    if (board.IsFull()) return 0;

    int best = computersTurn ? -2 : 2;
    for (int i = 0; i < 9; i++)
    {
        if (board.Cells[i] != ' ') continue;
        board.Cells[i] = computersTurn ? 'O' : 'X';      // try the move
        int score = Minimax(board, !computersTurn);      // ask: how does that end?
        board.Cells[i] = ' ';                            // undo the move
        best = computersTurn ? Math.Max(best, score) : Math.Min(best, score);
    }
    return best;
}
```

שלושה דברים לשים לב אליהם. ראשית, **מקרה הבסיס** בראש: המתודה מפסיקה לקרוא לעצמה כשהמשחק נגמר. בלי מקרה בסיס הרקורסיה אף פעם לא נגמרת והתוכנית מתה עם stack overflow. שנית, `-2` ו-`2` הם פשוט ערכי התחלה ש"גרועים מכל ציון אמיתי", כך שהציון האמיתי הראשון תמיד מחליף אותם. שלישית, **לנסות ואז לבטל**: אותו אובייקט לוח משמש לכל עתיד מדומיין, ולכן אחרי כל ניסיון מחזירים את התא ל-`' '`. אם שוכחים לבטל, הלוח האמיתי נהרס.

`BestMove` היא אותה לולאה ברמה העליונה: היא מנסה כל תא עבור O, שואלת את `Minimax(board, false)` (אחר כך בא האדם), וזוכרת את התא עם הציון הגבוה ביותר. בתיקו נשמר התא הראשון שנמצא, וזה הופך את המחשב לדטרמיניסטי. כל עץ המשחק של איקס עיגול מכיל פחות מ-550,000 מצבים, ולכן החיפוש מסתיים ברגע ולא צריך שום טריקים. בשחמט יש יותר מצבים מאטומים ביקום, ולכן מנועי שחמט צריכים גיזום חכם בהרבה.

## מקשים בוחרים את התא

האדם מזיז **סמן** (cursor) עם מקשי החיצים ולוחץ על Space. הסמן הוא מספר אחד, 0 עד 8, והתנועה היא חשבון: שמאלה וימינה משנים אותו ב-1, למעלה ולמטה ב-3. השמירות `cursor % 3 > 0` ו-`cursor >= 3` מונעות ממנו לעטוף שורה או לצאת מהלוח. אחרי שהאדם זז, המחשב מחכה עשרה פריימים (כדי שתוכלו לראות אותו "חושב"), ואז משחק `board.Cells[Ai.BestMove(board)] = 'O'`.

> **שימו לב:**
> - מקרה בסיס חסר: `System.StackOverflowException` או timeout.
> - אם לא מבטלים את המהלך הניסיוני: הלוח מתמלא בכלים דמיוניים והמשחק האמיתי משתבש.
> - מתן ציון מהצד הלא נכון. אם מחזירים +1 כש-X מנצח, המחשב משחק כדי להפסיד. תמיד תנו ציון מנקודת המבט של המחשב והשתמשו ב-max בתור שלו וב-min בתור של האדם.
> - בחירת ה*ציון* במקום ה*תא*: `BestMove` חייבת לזכור את `i`, לא את `score`.

## מה ההקלטה עושה

השחקן מתחיל בתא 0, משחק שם X, אחר כך משחק בתא האמצעי העליון ולבסוף בתא האמצעי השמאלי. המחשב עונה במרכז, חוסם את השורה העליונה, ואז רואה שתא 6 גם חוסם את האדם וגם משלים את האלכסון שלו. עם ה-stub של `return 0` מקוד ההתחלה המחשב סתם משחק בתא הריק הראשון והמשחק אף פעם לא נגמר.

## להמשיך הלאה

תנו לאדם להתחיל בפינות שונות בתסריט הקלט וראו את התוצאה משתנה לתיקו. הוסיפו ארגומנט `depth` ועדיפו ניצחונות מהירים (`return 10 - depth`).

> **תורכם:** כתבו את `Minimax`: החזירו 1, -1 או 0 כשהמשחק נגמר, ואחרת נסו כל תא ריק, קראו רקורסיבית עם התור הפוך, בטלו את המהלך, ושמרו את הציון הגבוה ביותר בתור של המחשב או את הנמוך ביותר בתור של האדם. התוכנית צריכה להדפיס `winner: O`.
