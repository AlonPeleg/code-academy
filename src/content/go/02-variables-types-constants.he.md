משתנים הם קופסאות בעלות שם עבור ערכים. Go היא שפה **בעלת טיפוסים סטטיים**: לכל משתנה יש טיפוס קבוע, וזה עוזר למהדר לתפוס טעויות מוקדם. אבל Go גם משתדלת מאוד לחסוך לכם הקלדה, כפי שתראו בשיעור הזה.

## הצהרה עם var

```go
var name string = "Ada"
var age int = 36
var height float64 = 1.68
```

המבנה הוא `var name type = value`. בניגוד ל-Java או ל-C, ה**טיפוס בא אחרי השם**. אפשר להשמיט את הטיפוס אם יש ערך (Go מסיקה אותו): `var age = 36`. אפשר גם להשמיט את הערך, והמשתנה מקבל את **ערך האפס** (zero value) שלו:

```go
var count int      // 0
var price float64  // 0
var ok bool        // false
var label string   // "" (empty string)
```

ב-Go אין "זבל לא מאותחל" כמו ב-C: משתנה תמיד מחזיק משהו הגיוני. זו תכונת בטיחות נחמדה.

## ההצהרה הקצרה :=

בתוך פונקציות אפשר לכתוב את הצורה הקצרה ביותר:

```go
age := 36
name := "Ada"
ratio := 0.75
```

הסימן `:=` גם יוצר את המשתנה וגם בוחר את הטיפוס שלו לפי הערך (כאן `int`, ‏`string`, ‏`float64`). זו הצורה שבה תשתמשו הכי הרבה. בהמשך מציבים ערך חדש עם `=` רגיל: `age = 37`. אי אפשר להשתמש ב-`:=` מחוץ לפונקציה, ואי אפשר להצהיר מחדש על אותו שם באותו תחום (scope).

אפשר להצהיר על כמה משתנים בבת אחת: `x, y := 1, 2`, ולהחליף שני ערכים בצורה אלגנטית: `x, y = y, x`.

## טיפוסים בסיסיים

| טיפוס | משמעות | דוגמה |
|---|---|---|
| `int` | מספר שלם (בגודל המילה של המחשב שלכם, בדרך כלל 64 ביט) | `42` |
| `float64` | מספר עשרוני | `3.14` |
| `string` | טקסט, בלתי ניתן לשינוי | `"hello"` |
| `bool` | `true` או `false` | `true` |
| `byte`, `rune` | בית; תו Unicode | `'A'` |

יש גם מספרים שלמים בגדלים מוגדרים כמו `int8`, ‏`int32`, ‏`int64`, ‏`uint` (ללא סימן) ו-`float32`. השתמשו ב-`int` וב-`float64` רגילים אלא אם יש לכם סיבה.

## קבועים

ערך שלעולם לא משתנה הוא **קבוע** (constant):

```go
const taxRate = 0.2
const (
    Small  = 1
    Medium = 2
)
```

ניסיון להציב ערך בקבוע הוא שגיאת קומפילציה. קבועים נבדקים בזמן הקומפילציה ויכולים להיות "ללא טיפוס": `const big = 1000000` מתאים לכל טיפוס מספרי שתשתמשו בו איתו.

## המרות הן מפורשות

Go אף פעם לא ממירה בין טיפוסים מספריים מאחורי הגב שלכם. צריך לכתוב את ההמרה בצורה `Type(value)`:

```go
a := 7
b := 2
fmt.Println(a / b)                    // 3   (integer division drops the .5)
fmt.Println(float64(a) / float64(b))  // 3.5
```

ערבוב טיפוסים בלי המרה, כמו `a + 1.5` כש-`a` הוא משתנה `int`, הוא שגיאה. בהתחלה זה מרגיש קפדני, אבל זה מסלק קטגוריה שלמה של באגים מפתיעים.

## הדפסת טיפוסים וערכים

`%v` מדפיס ערך, ו-`%T` מדפיס את הטיפוס שלו, וזו דרך מצוינת לבדוק מה `:=` החליטה:

```go
x := 42
fmt.Printf("%v is a %T\n", x, x)   // prints: 42 is a int
```

> **שימו לב:**
> - Go מתלוננת על **משתנים שאינם בשימוש**: `declared and not used: count`. מחקו אותו או השתמשו בו (אפילו `_ = count` עובד בזמן שמתנסים).
> - שימוש ב-`:=` על שם שכבר קיים באותו תחום מניב `no new variables on left side of :=`. השתמשו ב-`=` במקום.
> - שימוש ב-`:=` ברמה העליונה של הקובץ מניב `syntax error: non-declaration statement outside function body`.
> - טיפוסים מעורבים מניבים `invalid operation: a + b (mismatched types int and float64)`. המירו אחד הצדדים.
> - השמה של טיפוס לא נכון מניבה `cannot use "five" (untyped string constant) as int value in assignment`.
> - חילוק שלמים משמיט את השבר בשקט, ולכן `1 / 2` הוא `0`. המירו ל-`float64` קודם כשצריך ספרות עשרוניות.

## להתקדם הלאה

הדפיסו `%T` עבור כמה ערכים: `3`, ‏`3.0`, ‏`"x"`, ‏`'x'`, ‏`true`. נסו `int(3.99)` עם משתנה וראו שהוא חותך. השתמשו ב-`math.MaxInt64` וחשבו מה קורה בגלישה.

> **תורכם:** עקבו אחר השלבים הממוספרים: `var name string = "Ada"` ו-`age := 36`; קבוע `const taxRate = 0.2` והסכום `Total with tax: 60.00`; שלושה משתנים בלי ערך שמודפסים עם `%d %t %q` בתור `Zero values: 0 false ""`; ולבסוף חילוק שלמים `7 / 2 = 3` לעומת חילוק `float64` ‏`7 / 2.0 = 3.5`.
