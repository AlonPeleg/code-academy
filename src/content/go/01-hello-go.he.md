בשיעור הזה תכתבו את תוכנית ה-Go הראשונה שלכם ותכירו את אבני הבניין שיש בכל קובץ Go: **חבילה** (package), כמה **ייבואים** (imports) ו**פונקציה main**. השפה Go (שנקראת לפעמים Golang) נוצרה בגוגל כדי להיות פשוטה, מהירה לקומפילציה וטובה בביצוע דברים רבים בו-זמנית. היא מפעילה כלים כמו Docker ו-Kubernetes.

## תוכנית ה-Go הקטנה ביותר

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, world!")
}
```

הרצתה מדפיסה:

```
Hello, world!
```

שורה אחר שורה:

* `package main` אומרת לאיזו **חבילה** הקובץ הזה שייך. קוד Go מאורגן בחבילות, תיקיות של קוד קשור. חבילה בשם `main` היא מיוחדת: היא מייצרת תוכנית שאפשר להריץ, ולא ספרייה.
* `import "fmt"` מביאה חבילה אחרת. `fmt` ("format", עיצוב) היא חלק מהספרייה הסטנדרטית של Go ומטפלת בהדפסה ובעיצוב של טקסט.
* `func main() { ... }` מצהירה על **פונקציה** (function) בשם `main`. כשמריצים את התוכנית, Go מתחילה כאן. המילה `func` פותחת כל פונקציה, הסוגריים העגולים מכילים את הפרמטרים (אין כאן אף אחד), והסוגריים המסולסלים מכילים את הגוף.
* `fmt.Println("...")` קוראת לפונקציה `Println` מהחבילה `fmt`. היא מדפיסה את הארגומנטים שלה ומסיימת בשורה חדשה.

שימו לב למה ש**חסר** בהשוואה לשפות רבות: אין נקודה-פסיק בסוף השורות (Go מוסיפה אותן בשבילכם), ואין מחלקה (class) סביב הקוד.

## ייבוא של כמה חבילות

מקבצים כמה ייבואים בתוך סוגריים עגולים:

```go
import (
    "fmt"
    "math"
    "strings"
)
```

משתמשים בתכנים של חבילה על ידי כתיבת `packagename.Thing`:

```go
fmt.Println(strings.ToUpper("hello")) // prints: HELLO
fmt.Println(math.Sqrt(16))            // prints: 4
fmt.Println(math.Pi)                  // prints: 3.141592653589793
```

למה השמות מתחילים באות גדולה? ב-Go שם שמתחיל ב**אות גדולה** הוא **מיוצא** (exported), כלומר חבילות אחרות רשאיות להשתמש בו. שם באות קטנה הוא פרטי לחבילה שלו. לכן כותבים `Println` ו-`ToUpper`, ולעולם לא `println` מתוך `fmt`. הכלל הפשוט הזה מחליף מילות מפתח כמו `public` ו-`private`.

## Println ו-Printf

`Println` מדפיסה כל ארגומנט, מופרדים ברווחים, ובסוף שורה חדשה:

```go
fmt.Println("Total:", 42, true)   // prints: Total: 42 true
```

`Printf` מאפשרת לעצב את הפלט באמצעות **מחרוזת תבנית** (format string) שמכילה **מציינים** (verbs) שמתחילים ב-`%`:

| מציין | מדפיס |
|---|---|
| `%d` | מספר שלם |
| `%s` | מחרוזת (string) |
| `%f` | מספר עשרוני (השתמשו ב-`%.2f` לשתי ספרות אחרי הנקודה) |
| `%v` | כל ערך בתבנית ברירת המחדל |
| `%t` | true או false |
| `%q` | מחרוזת בתוך מרכאות |

```go
fmt.Printf("%s is %d years old\n", "Ada", 36)  // prints: Ada is 36 years old
fmt.Printf("%.1f\n", 2.25)                      // prints: 2.2  (rounded to one decimal)
```

`Printf` **לא** מוסיפה שורה חדשה מעצמה, ולכן כותבים בעצמכם `\n` בסוף מחרוזת התבנית.

## העיצוב מובנה

עם Go מגיע כלי, `gofmt`, שמסדר כל תוכנית בסגנון סטנדרטי אחד (טאבים להזחה, רווחים סביב אופרטורים). מתכנתי Go לא מתווכחים על סגנון: הם מריצים את הכלי. הסוגר המסולסל הפותח `{` חייב להישאר באותה שורה עם `func`, אחרת זו שגיאת תחביר.

> **שימו לב:**
> - ייבוא של חבילה שאינכם משתמשים בה הוא **שגיאה** ב-Go, לא אזהרה: `"strings" imported and not used`. הסירו את הייבוא או השתמשו בו.
> - גם ההפך נכשל: שימוש ב-`strings.ToUpper` בלי לייבא את `strings` מניב `undefined: strings`.
> - `fmt.println("hi")` עם p קטנה מניב `undefined` או `cannot refer to unexported name fmt.println`. שמות מיוצאים צריכים אות גדולה.
> - מחרוזות צריכות **מרכאות כפולות**. מרכאות בודדות מיועדות לתווים בודדים (שנקראים runes), ולכן `fmt.Println('hi')` מניבה `more than one character in rune literal`.
> - הצבת הסוגר הפותח בשורה משלו מניבה `syntax error: unexpected semicolon or newline before {`.
> - שכחה של `\n` ב-`Printf` גורמת לפלט הבא להידבק לאותה שורה.

## להתקדם הלאה

נסו `fmt.Printf("%5d|%-5d|\n", 42, 42)` כדי לראות ריפוד. הדפיסו ערך עם `%v` ועם `%T` (הטיפוס שלו). נסו `math.Max(3, 9)` ו-`strings.Repeat("ab", 3)`.

> **תורכם:** ב-`main`, הדפיסו `Hello, Go!`, אחר כך הדפיסו `go is simple` באותיות גדולות באמצעות `strings.ToUpper`, ולבסוף השתמשו ב-`fmt.Printf` עם `%.2f` ועם `math.Pi` כדי להדפיס `Pi is about 3.14`.
