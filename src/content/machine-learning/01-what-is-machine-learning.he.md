למידת מכונה (machine learning, או ML) נשמעת מסתורית, אבל הרעיון המרכזי פשוט: במקום לכתוב את הכללים בעצמכם, מראים למחשב הרבה **דוגמאות** ונותנים לו להבין את הכללים. בשיעור הזה תבנו את תוכנית ה"למידה" הקטנה ביותר האפשרית ותלמדו את המילים שבהן ישתמש שאר המסלול.

## כללים לעומת דוגמאות

נניח שאתם רוצים לנחש מחיר של בית. אפשר לכתוב כללים ידנית: "התחילו מ-5, הוסיפו 3 על כל מטר רבוע". אבל מאיפה מגיעים 5 ו-3? תצטרכו לנחש, ובכל עיר המספרים שונים.

הדרך של למידת מכונה היא לאסוף בתים שכבר נמכרו, עם הגדלים והמחירים שלהם, ולתת למחשב **למצוא** את המספרים. אז הוא יכול לחזות את המחיר של בית שמעולם לא ראה.

## אוצר המילים

| Word | משמעות | בדוגמה שלנו |
|---|---|---|
| **מאפיין** (Feature) | קלט שהמודל מסתכל עליו | הגודל של הבית |
| **תווית** (Label, או target) | התשובה שאנחנו רוצים לחזות | המחיר |
| **דוגמה** (Example, או row, sample) | זוג אחד של מאפיין ותווית | בית אחד שנמכר |
| **אימון** (Training) | מציאת המספרים הטובים ביותר מתוך הדוגמאות | התאמת קו |
| **מודל** (Model) | מה שנלמד ויכול לחזות | הקו עצמו |
| **חיזוי** (Prediction) | התשובה של המודל עבור נתונים חדשים | המחיר של בית בן 100 מ"ר |

כשהדוגמאות מגיעות עם תוויות, זה נקרא **למידה מונחית** (supervised learning). המסלול הזה עוסק בעיקר בלמידה מונחית (חיזוי מספרים וחיזוי קטגוריות), ועוד קצת בלמידה בלי תוויות, כמו קיבוץ של פריטים דומים.

## מודל ראשון עם NumPy

NumPy היא הספרייה של Python למספרים. בפעם הראשונה שתוכנית מייבאת ספרייה כמו NumPy, pandas, matplotlib או scikit-learn, הדפדפן שלכם מוריד אותה. זה יכול לקחת כמה שניות וצריך חיבור לאינטרנט; אחר כך היא נשמרת במטמון (cache) ונטענת מהר. כל הנתונים בשיעורים האלה מובנים, ולכן תקבלו אותן תוצאות בכל פעם.

```python
import numpy as np

size = np.array([50, 60, 70, 80, 90])
price = np.array([155, 178, 212, 238, 272])

slope, intercept = np.polyfit(size, price, 1)
print(round(slope, 2), round(intercept, 2))   # prints: 2.94 5.2
```

חלק אחר חלק:

- `np.array([...])` הופכת רשימה של Python למערך (array) של NumPy, שהוא רשימה מהירה של מספרים (עוד עליו בשיעור הבא).
- `np.polyfit(x, y, 1)` מוצאת את הקו הישר המתאים ביותר לנקודות. ה-`1` פירושו "פולינום ממעלה 1", שהוא פשוט קו ישר.
- היא מחזירה את ה**שיפוע** (slope), כלומר בכמה המחיר עולה על כל מטר רבוע נוסף, ואת **נקודת החיתוך** (intercept), כלומר המחיר שבו הקו חוצה את האפס.

עכשיו המודל הוא הקו `price = slope * size + intercept`, ועריכת חיזוי היא פשוט חשבון:

```python
prediction = slope * 100 + intercept
print(round(prediction, 1))                   # prints: 299.2
```

## קריאת התוצאה

שיפוע של 2.94 אומר: "כל מטר רבוע נוסף מוסיף בערך 2.94 אלף למחיר". החיזוי של 299.2 עבור 100 מ"ר גבוה מכל בית שאימנו עליו (90 מ"ר היה הגדול ביותר). חיזוי מחוץ לטווח של נתוני האימון נקרא **אקסטרפולציה** (extrapolating), והוא מסוכן יותר מחיזוי בין נקודות ידועות.

## המתמטיקה, בקצרה

ל"קו הטוב ביותר" יש משמעות מדויקת. בכל דוגמה, הקו טועה בשגיאה מסוימת (המחיר האמיתי פחות המחיר החזוי). הפונקציה `polyfit` בוחרת את השיפוע ואת נקודת החיתוך שגורמים ל**סכום ריבועי השגיאות** להיות קטן ככל האפשר. זה נקרא **שיטת הריבועים הפחותים** (least squares). העלאה בריבוע הופכת כל שגיאה לחיובית ומענישה טעויות גדולות יותר מקטנות.

> **שימו לב:**
> - שכחתם את הורדת הספרייה: ההרצה הראשונה של שיעור עם `import numpy` יכולה לקחת כמה שניות. חכו, זו עלות חד-פעמית.
> - בלבול בסדר: `np.polyfit(price, size, 1)` היא קריאה חוקית, אבל היא מתאימה את הגודל לפי המחיר, והפוך ממה שרוצים. המאפיין בא קודם, התווית שנייה.
> - אמון בחיזוי רחוק מאוד מהנתונים שלכם. מודל יודע רק מה שהדוגמאות שלו הראו לו.
> - ציפייה לחיזויים מושלמים. המחירים האמיתיים לא בדיוק על הקו; המודל נותן את הפשרה הטובה ביותר.

> **תורכם:** אמנו קו עם `np.polyfit(size, price, 1)`, חזו את המחיר של בית בן 100 מ"ר, והדפיסו את השיפוע, את נקודת החיתוך ואת החיזוי עם 2 ספרות אחרי הנקודה כל אחד, כמו בפלט הצפוי.
