נתונים אמיתיים כמעט אף פעם לא מגיעים כרשימה מסודרת של מספרים. הם מגיעים כ**טבלה**: שורות של רשומות ועמודות של עובדות, כמו גיליון אלקטרוני. הספרייה **pandas** נותנת ל-Python טיפוס של טבלה שנקרא **DataFrame**, והוא הכלי שבו תשתמשו כדי להסתכל על נתונים ולהכין אותם לפני שמודל כלשהו רואה אותם.

## יצירת DataFrame מטקסט CSV

CSV (ערכים מופרדים בפסיקים, comma separated values) הוא פורמט הטבלה הנפוץ ביותר בטקסט פשוט: השורה הראשונה מכילה את שמות העמודות, וכל שורה אחריה היא רשומה אחת. בשיעורים האלה הנתונים נמצאים בתוך הקוד כטקסט, ולכן אין מה להוריד:

```python
import io
import pandas as pd

csv_text = """name,age,city
Ada,36,Leeds
Bo,29,York
Cy,41,Leeds
"""
df = pd.read_csv(io.StringIO(csv_text))
print(df)
```

`io.StringIO(text)` גורם למחרוזת להתנהג כמו קובץ פתוח, וזה מה ש-`pd.read_csv` מצפה לקבל. לפי המוסכמה קוראים ל-DataFrame בשם `df`. ההדפסה נראית כך:

```
  name  age   city
0  Ada   36  Leeds
1   Bo   29   York
2   Cy   41  Leeds
```

המספרים משמאל (0, 1, 2) הם ה**אינדקס** (index), התווית של כל שורה.

## מסתכלים על הטבלה

```python
print(df.shape)       # prints: (3, 3)   3 rows, 3 columns
print(df.columns)     # the column names
print(df.head(2))     # the first 2 rows (tail shows the last ones)
```

`shape` הוא `(rows, columns)`, בדיוק כמו במערך NumPy. DataFrame בנוי על NumPy, ולכן הרבה רעיונות עוברים מכאן לשם.

## בחירת עמודות

עמודה אחת בסוגריים מרובעים נותנת **Series**, רשימה של ערכים עם תוויות. רשימה של שמות נותנת DataFrame קטן יותר:

```python
ages = df["age"]              # a Series
print(ages.mean())            # prints: 35.333333333333336
print(df[["name", "age"]])    # a DataFrame with two columns
```

שימו לב לסוגריים הכפולים כשבוחרים כמה עמודות: הסוגריים הפנימיים הם רשימה רגילה של Python.

## סינון שורות

השוואה על עמודה נותנת ערך True/False לכל שורה. כשמציבים אותה בסוגריים אחרי `df`, נשארות רק השורות שמתאימות:

```python
adults_over_30 = df[df["age"] > 30]
print(len(adults_over_30))    # prints: 2
print(df[df["city"] == "Leeds"])
```

קראו את `df[df["age"] > 30]` כך: "השורות של df שבהן הגיל גדול מ-30". כדי לשלב תנאים משתמשים ב-`&` וב-`|`, כל תנאי בסוגריים משלו: `df[(df["age"] > 30) & (df["city"] == "Leeds")]`.

## יצירת עמודות חדשות

השמה לשם של עמודה שעדיין לא קיימת יוצרת אותה. החישוב פועל על העמודה כולה בבת אחת, בדיוק כמו ב-NumPy:

```python
df["age_in_months"] = df["age"] * 12
```

יצירת עמודות חדשות מעמודות ישנות נקראת **הנדסת מאפיינים** (feature engineering), והיא אחד הדברים החזקים ביותר שאפשר לעשות בשביל מודל. למשל, "מחיר למטר רבוע" יכול להגיד יותר ממחיר וגודל בנפרד.

## למה זה חשוב ללמידת מכונה

כל מודל של scikit-learn רוצה טבלה של **מאפיינים** (features, העמודות שממנן הוא לומד) ועמודה אחת של **תווית** (label). pandas היא הדרך שבה בונים את הטבלה הזו, בוחרים את העמודות הנכונות ושומרים רק את השורות שצריך.

> **שימו לב:**
> - שימוש ב-`and` / `or` בסינון: `df[df["age"] > 30 and df["city"] == "Leeds"]` גורם ל-`ValueError: The truth value of a Series is ambiguous`. השתמשו ב-`&` / `|` עם סוגריים.
> - כתיבת `df["price"]` עם שם שגוי גורמת ל-`KeyError: 'price'`. הדפיסו את `df.columns` כדי לראות את השמות האמיתיים (שימו לב לרווחים מיותרים ולאותיות גדולות).
> - שכחתם שסינון לא משנה את `df`. `df[df["age"] > 30]` מחזיר טבלה חדשה; שמרו אותה עם `adults = df[...]`.
> - סוגריים בודדים בשביל כמה עמודות: `df["name", "age"]` הוא `KeyError`. השתמשו ב-`df[["name", "age"]]`.

> **תורכם:** קראו את נתוני הבתים ל-`df`, הדפיסו את הצורה שלו ואת המחיר הממוצע, שמרו ב-`big` את הבתים עם 3 חדרים או יותר והדפיסו כמה יש, ואז הוסיפו עמודה `price_per_m2` והדפיסו את המקסימום שלה. עגלו את הספרות העשרוניות כמו בפלט הצפוי.
