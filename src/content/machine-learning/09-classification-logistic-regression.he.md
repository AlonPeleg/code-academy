עד עכשיו התווית הייתה מספר (מחיר). לעיתים קרובות התווית היא **קטגוריה**: ספאם או לא ספאם, לאיזה מין שייך פרח, האם מטופל חולה. חיזוי של קטגוריה נקרא **סיווג** (classification), וכל קטגוריה אפשרית היא **מחלקה** (class).

## רגרסיה לעומת סיווג

- **רגרסיה**: חוזים מספר (מחיר, טמפרטורה).
- **סיווג**: חוזים אחת מקבוצה קבועה של מחלקות (setosa, versicolor, virginica).

תהליך העבודה של scikit-learn לא משתנה בכלל: מפצלים, יוצרים, `fit`, `predict`. רק המודל והדרך למדוד אותו שונים.

## מערך הנתונים איריס

scikit-learn מגיעה עם כמה מערכי נתונים קטנים לתרגול, כך שאין צורך להוריד כלום. מערך הנתונים **איריס** (iris) המפורסם מכיל 150 פרחים משלושה מינים, וארבעה מאפיינים שנמדדו בסנטימטרים: אורך עלה גביע, רוחב עלה גביע, אורך עלה כותרת ורוחב עלה כותרת. התווית היא המין כמספר: 0, 1 או 2.

```python
from sklearn.datasets import load_iris

data = load_iris()
print(data.data.shape)        # prints: (150, 4)
print(data.target_names)      # prints: ['setosa' 'versicolor' 'virginica']
```

`data.data` הם המאפיינים (X), `data.target` הם התוויות (y), ו-`data.target_names` מתרגם מספר מחלקה בחזרה לשם.

## רגרסיה לוגיסטית

השם מבלבל: רגרסיה לוגיסטית היא **מסווג** (classifier). הרעיון במילים פשוטות: כמו רגרסיה ליניארית היא מחשבת סכום משוקלל של המאפיינים, אבל אחר כך היא דוחסת את הסכום הזה למספר בין 0 ל-1 וקוראת אותו כ**הסתברות**. עבור כמה מחלקות היא מחשבת הסתברות אחת לכל מחלקה, והמודל חוזה את המחלקה עם ההסתברות הגבוהה ביותר.

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)
model.predict(new_flowers)        # class numbers
model.predict_proba(new_flowers)  # a row of probabilities per flower
```

`max_iter=200` מאפשר לאלגוריתם האימון לבצע עד 200 צעדים; ברירת המחדל של 100 עלולה להיות קצרה מעט ומדפיסה אזהרה.

## פיצול מרובד (stratified)

עם 150 פרחים בשלוש קבוצות, פיצול אקראי עלול בטעות לשים מעט מדי פרחים של מין אחד בקבוצת הבדיקה. `stratify=y` גורם לפיצול לשמור על אותם יחסים של כל מחלקה בשני החלקים. זה הרגל טוב לכל בעיית סיווג.

## דיוק (accuracy)

הציון הפשוט ביותר הוא **דיוק**: החלק מהדוגמאות שסווגו נכון. עבור מסווגים `model.score(X_test, y_test)` מחזירה בדיוק את זה. בתרגיל דיוק הבדיקה הוא 1.00 (כל 38 פרחי הבדיקה נכונים) ודיוק האימון הוא 0.96. אל תופתעו שציון הבדיקה גבוה מציון האימון: עם 38 פרחי בדיקה בלבד למזל יש חלק גדול. קבוצת בדיקה קטנה כל כך נותנת הערכה גסה, לא הבטחה.

עבור הפרח השני, `predict_proba` נותנת בערך `[0.02, 0.86, 0.12]`: המודל בטוח ב-86 אחוז שזה versicolor. ההסתברויות של פרח אחד תמיד מסתכמות ל-1.

## המתמטיקה, בקצרה

פונקציית הדחיסה היא ה**סיגמואיד** (sigmoid), `1 / (1 + e^(-z))`, כאשר `z` הוא הסכום המשוקלל של המאפיינים. `z` חיובי גדול נותן הסתברות קרובה ל-1, `z` שלילי גדול קרוב ל-0, ו-`z = 0` נותן בדיוק 0.5. בהמשך המסלול תבנו רגרסיה לוגיסטית מאפס.

> **שימו לב:**
> - דיוק יכול להטעות כשהמחלקות לא מאוזנות. אם 95 אחוז מהמיילים הם לא ספאם, מודל שתמיד אומר "לא ספאם" מדויק ב-95 אחוז וחסר תועלת. השיעור על מטריצות בלבול (confusion matrix) מתקן את זה.
> - `ConvergenceWarning: lbfgs failed to converge` אומרת שהאימון היה צריך עוד צעדים: הגדילו את `max_iter` או סקלו את המאפיינים (בשיעור הבא).
> - לבלבל בין מספרי מחלקות לשמות: `model.predict` מחזירה מספרים. השתמשו ב-`names[number]` כדי לקבל את המין.
> - להעביר פרח בודד כרשימה שטוחה. זו חייבת להיות טבלה: `[[5.1, 3.5, 1.4, 0.2]]` היא עם שורה אחת.

> **תורכם:** פצלו את נתוני האיריס (מרובד), אמנו רגרסיה לוגיסטית, הדפיסו את דיוק הבדיקה ואת דיוק האימון, סווגו את הפרח החדש והדפיסו את ההסתברות שהפרח השני הוא versicolor.
