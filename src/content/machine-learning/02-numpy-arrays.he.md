למידת מכונה היא בעיקר חישובים על המון מספרים. רשימות של Python איטיות ומסורבלות בשביל זה, ולכן כמעט כל ספריית ML בנויה על **NumPy** ועל ה**מערך** (array) שלה. בשיעור הזה תלמדו ליצור מערכים, לחשב איתם בלי לכתוב לולאות ולבחור את הערכים שאתם רוצים.

## מערכים וחישוב וקטורי

מערך NumPy מחזיק מספרים מאותו סוג בבלוק אחד של זיכרון:

```python
import numpy as np

heights = np.array([150, 160, 170, 180])
print(heights * 2)        # prints: [300 320 340 360]
print(heights + 10)       # prints: [160 170 180 190]
print(heights.mean())     # prints: 165.0
```

ברשימה רגילה, `[150, 160] * 2` היה חוזר על הרשימה. עם מערך, החישוב מופעל על **כל איבר בבת אחת**. זה נקרא חישוב **וקטורי** (vectorised): בלי לולאת `for`, קוד קצר יותר, ומהיר הרבה יותר כי העבודה מתבצעת בקוד מקומפל.

אפשר גם לשלב שני מערכים באותו אורך, איבר מול איבר:

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
print(a + b)              # prints: [11 22 33]
print(a * b)              # prints: [10 40 90]
```

## צורה: שורות ועמודות

למערך יכולים להיות כמה ממדים. רשימה של רשימות הופכת למערך דו-ממדי, שהוא כמו טבלה של מספרים:

```python
grid = np.array([[1, 2, 3],
                 [4, 5, 6]])
print(grid.shape)         # prints: (2, 3)   (2 rows, 3 columns)
```

`shape` היא התכונה השימושית ביותר ב-ML. כמעט כל הודעת שגיאה שתיתקלו בה קשורה לצורות שלא מתאימות. ב-scikit-learn המאפיינים הם תמיד מערך דו-ממדי בצורה `(number of rows, number of features)`.

## סיכומים ו-axis

מערכים יודעים לסכם את עצמם: `.sum()`, `.mean()`, `.min()`, `.max()`, `.std()`. במערך דו-ממדי, `axis` בוחר את הכיוון:

```python
print(grid.sum())         # prints: 21   (everything)
print(grid.sum(axis=0))   # prints: [5 7 9]   (down the columns)
print(grid.sum(axis=1))   # prints: [ 6 15]   (across the rows)
```

דרך קלה לזכור: `axis=0` מכווץ את השורות, ולכן מקבלים תוצאה אחת לכל עמודה.

## בחירת ערכים עם מסכה בוליאנית

השוואה על מערך נותנת מערך של `True` ו-`False`. כשמשתמשים בו בתוך סוגריים מרובעים, נשארים רק הערכים שמתאימים:

```python
nums = np.array([4, 12, 7, 20, 15])
big = nums > 10
print(big)                # prints: [False  True False  True  True]
print(nums[big])          # prints: [12 20 15]
print((nums > 10).sum())  # prints: 3   (True counts as 1)
```

אותו רעיון הוא הדרך שבה תסננו בהמשך שורות של טבלה. משלבים תנאים עם `&` (וגם) ו-`|` (או), ושמים כל תנאי בסוגריים משלו: `nums[(nums > 5) & (nums < 15)]`.

## קריאת מערכים מודפסים

NumPy מדפיסה מערכים בלי פסיקים: `[300 320 340 360]`. מספרים עשרוניים מיושרים בעמודות, ולכן `[54.5 64.4 77. ]` עשוי להציג `77.` עם נקודה בסוף ורווחים נוספים. זה רק עיצוב. כדי להימנע מספרות עשרוניות ארוכות ומכוערות, השתמשו ב-`arr.round(2)` או ב-`np.round(arr, 2)`.

## המתמטיקה, בקצרה

מערך של מספרים הוא **וקטור**; טבלה של מספרים היא **מטריצה**. הממוצע הוא הסכום חלקי הכמות, ובעמודה של מטריצה הוא מחושב לאורך אותה עמודה. כל מה שכאן הוא בדיוק זה, מופעל על הרבה מספרים בבת אחת.

> **שימו לב:**
> - שימוש ב-`and` / `or` על מערכים: `nums[(nums > 5) and (nums < 15)]` גורם ל-`ValueError: The truth value of an array with more than one element is ambiguous`. השתמשו ב-`&` וב-`|` עם סוגריים.
> - חיבור מערכים באורכים שונים: `[1, 2, 3] + [1, 2]` כמערכים נותן `ValueError: operands could not be broadcast together with shapes (3,) (2,)`.
> - שכחתם שרשימה היא לא מערך: `[1, 2, 3] * 2` חוזרת על הרשימה. עטפו אותה קודם ב-`np.array(...)`.
> - בלבול בין `axis=0` ל-`axis=1`. כשיש ספק, הדפיסו את התוצאה והסתכלו על הצורה שלה.
