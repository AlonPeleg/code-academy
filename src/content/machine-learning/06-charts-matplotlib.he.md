טבלה של מספרים מסתירה דפוסים שתמונה מראה בשנייה. תרשימים הם הדרך לבדוק את הנתונים לפני בניית מודל ולשפוט את המודל אחר כך. ספריית התרשימים הסטנדרטית של Python היא **matplotlib**, ומשתמשים בה דרך המודול `pyplot`, שלפי המוסכמה מיובא בשם `plt`.

## הקצב של שלושה שלבים

כמעט כל תרשים הוא אותם שלושה שלבים: **לצייר**, **לקשט**, **להציג**.

```python
import matplotlib.pyplot as plt

days = [1, 2, 3, 4, 5]
sales = [3, 5, 4, 8, 9]

plt.plot(days, sales)            # 1. draw a line chart
plt.xlabel("Day")                # 2. decorate
plt.ylabel("Sales")
plt.title("Sales per day")
plt.show()                       # 3. show it
```

`plt.show()` מציגה את התרשים בחלונית הפלט שמתחת לקוד שלכם. אחרי `show()` הדמות (figure) גמורה, והציור הבא מתחיל תרשים ריק חדש. בפעם הראשונה שמייבאים את matplotlib הדפדפן מוריד אותה, אז התאזרו בסבלנות בהרצה הראשונה.

## ארבעה סוגי תרשימים שתשתמשו בהם כל הזמן

| Chart | Call | Use it for |
|---|---|---|
| קו (Line) | `plt.plot(x, y)` | ערך שמשתנה לפי סדר, כמו זמן או התקדמות הלמידה של מודל |
| פיזור (Scatter) | `plt.scatter(x, y)` | הקשר בין שתי עמודות מספריות, נקודה אחת לכל שורה |
| היסטוגרמה (Histogram) | `plt.hist(values, bins=5)` | ההתפלגות של עמודה אחת: כמה ערכים נופלים בכל טווח |
| עמודות (Bar) | `plt.bar(names, heights)` | השוואת מספר בין קטגוריות |

**תרשים פיזור** הוא החשוב ביותר בלמידת מכונה. אם הנקודות יוצרות פס עולה, שתי העמודות קשורות באופן חיובי ומודל של קו ישר יעבוד. אם הן נראות כמו ערפל אקראי, אין מה ללמוד. לעמודה אחת, **היסטוגרמה** מקבצת את הערכים לטווחים שנקראים **bins** ומציירת כמה נופלים בכל אחד, כך שאפשר לראות אם הנתונים בצורת פעמון, מוטים לצד אחד או שיש בהם חריגים מוזרים.

## כמה דברים בתרשים אחד

קראו לפונקציות הציור כמה פעמים לפני `plt.show()` וכל מה שציירתם ינחת על אותם צירים. הוסיפו `label=` ו-`plt.legend()` כדי להבדיל בין קווים:

```python
plt.scatter(days, sales, label="real data")
plt.plot(days, [2, 4, 6, 8, 10], color="red", label="a guess")
plt.legend()
plt.show()
```

בדיוק בתבנית הזו תשתמשו בהמשך כדי לצייר את הקו של מודל מעל הנתונים.

## ציור מ-NumPy ומ-pandas

matplotlib מקבלת רשימות, מערכי NumPy ועמודות של pandas באותה מידה: `plt.scatter(df["hours"], df["score"])`. ל-DataFrames יש גם קיצור, `df.plot()`, אבל הכרת `plt` ישירות נותנת לכם שליטה בכל פרט.

## מה התרשים אומר לכם

בתרגיל, הנקודות של שעות מול ציונים מטפסות בהתמדה מלמטה שמאלה אל למעלה ימינה, וזה מתאים לקורלציה של 0.96 שאתם מדפיסים. תרשים ומספר הם שני מבטים על אותה עובדה, וכדאי לבדוק את שניהם. קורלציה יכולה להטעות, אבל תמונה כמעט אף פעם לא.

> **שימו לב:**
> - שכחתם `plt.show()`: הקוד רץ בלי שגיאה, אבל לא רואים תרשים.
> - הצבת הקישוטים אחרי `plt.show()`: הכותרת והתוויות שייכות אז לתרשים הבא, הריק. מציירים, מקשטים, ואז מציגים.
> - מתן אורכים שונים ל-x ול-y גורם ל-`ValueError: x and y must be the same size`.
> - תרשימים בלי כותרת, בלי תוויות או עם צבעים שאי אפשר לקרוא. תרשים שאי אפשר לקרוא הוא תרשים שלא עשה את העבודה שלו.
> - ערימה של אלפי נקודות אחת על השנייה. השתמשו ב-`plt.scatter(x, y, alpha=0.3)` כדי להפוך את הנקודות לשקופות.

> **תורכם:** ציירו תרשים פיזור מתויג של שעות מול ציונים והציגו אותו, ואז ציירו תרשים עמודות עם כותרת של ממוצעי הכיתות והציגו אותו. לבסוף הדפיסו את שלוש השורות מהפלט הצפוי.
