נתונים אמיתיים הם מבולגנים: שגיאות כתיב, רווחים תועים, מספרים שנשמרו כטקסט, אותה שורה פעמיים, חורים במקום שאף אחד לא מילא ערך. מודל שמקבל נתונים מבולגנים לומד את הבלגן. ניקוי הוא לא עבודה זוהרת, אבל מדעני נתונים מבלים בו חלק גדול מהזמן, והוא קובע עד כמה המודל שלכם יכול להיות טוב.

## בודקים לפני שמתקנים

קודם מסתכלים. הקריאות האלה אומרות לכם מה לא בסדר:

```python
print(df.dtypes)          # the type of each column
print(df.isna().sum())    # missing values per column
print(df.duplicated().sum())   # how many rows repeat an earlier row
```

**dtype** הוא הטיפוס של עמודה: `int64`, `float64` (מספרים עשרוניים), או טקסט. אם בעמודה של מספרים יש אפילו ערך פסול אחד, כמו `"unknown"`, pandas שומרת את כל העמודה כטקסט, ואי אפשר לחשב איתה.

## תיקון טקסט

לעמודות טקסט יש ארגז כלים `.str` שפועל על כל הערכים בבת אחת:

```python
df["city"] = df["city"].str.strip().str.title()
```

`.strip()` מסיר רווחים משני הקצוות, `.title()` הופך גם את `leeds` וגם את `LEEDS` ל-`Leeds`, ו-`.lower()` / `.upper()` עושים מה ששמם אומר. אפשר לשרשר אותם. שימו לב שאנחנו מציבים את התוצאה בחזרה: מתודות של `.str` מחזירות עמודה חדשה ולא משנות את הישנה.

## תיקון טיפוסים

`pd.to_numeric` ממירה טקסט למספרים. ההגדרה `errors="coerce"` אומרת "אם אי אפשר להמיר ערך, הפוך אותו לחסר במקום לקרוס":

```python
df["age"] = pd.to_numeric(df["age"], errors="coerce")   # "unknown" becomes NaN
```

`NaN` פירושו "not a number" והוא הדרך של pandas לסמן ערך חסר. אחרי זה לעמודה יש הטיפוס `float64`, גם אם כל הערכים שנשארו נראים כמו מספרים שלמים (NaN הוא מספר עשרוני).

## כפילויות

```python
df = df.drop_duplicates()
```

שומרת את העותק הראשון של כל שורה זהה. שתי שורות נחשבות זהות רק כשכל הערכים שלהן תואמים, ולכן צריך לנקות קודם את הטקסט: `" alice "` ו-`"alice "` נראים שונים למחשב עד שמסירים את הרווחים.

## ערכים חסרים: להסיר או למלא?

יש לכם שתי אפשרויות פשוטות:

- **להסיר** שורות עם חורים: `df.dropna()`. קל, אבל מאבדים נתונים, ובטבלה קטנה אפשר לאבד הרבה.
- **למלא** את החורים בערך הגיוני: `df["age"].fillna(34)`. ערכי המילוי הרגילים הם ה**חציון** (median, הערך האמצעי, שערכים קיצוניים לא מפריעים לו) או ה**ממוצע** (mean). בעמודות טקסט, הערך הנפוץ ביותר עובד.

```python
median_age = df["age"].median()
df["age"] = df["age"].fillna(median_age)
```

חשבו תמיד את ערך המילוי מהנתונים שיש לכם, וכתבו את התוצאה בחזרה לעמודה. (`fillna` מחזירה עמודה חדשה; היא לא משנה את המקורית אלא אם מציבים אותה.)

## איך קוראים את הפלט של התרגיל

אחרי ניקוי הטקסט נשארים חמישה אנשים שונים, ולכן `rows: 5`. לשניים מהם אין גיל (אחד ריק, אחד "unknown") ולאחד אין משכורת. אחרי מילוי בחציונים, בסכומים אין חורים: אפשר שוב לחשב עם העמודות.

## למה זה חשוב ללמידת מכונה

רוב המודלים של scikit-learn פשוט מסרבים לערכי NaN: תקבלו `ValueError: Input X contains NaN`. ניקוי גם מונע נזק שקט: כפילויות גורמות למודל לספור את אותה דוגמה פעמיים, ואותיות גדולות וקטנות מעורבות גורמות לאותה עיר להיראות כמו שלוש ערים שונות. בהמשך תלמדו לשים את שלב המילוי בתוך pipeline כך שיילמד רק מנתוני האימון.

> **שימו לב:**
> - שכחתם להציב בחזרה: `df["city"].str.title()` לבדו לא משנה כלום. כתבו `df["city"] = ...`.
> - שימוש ב-`.str` על עמודה מספרית גורם ל-`AttributeError: Can only use .str accessor with string values`.
> - מילוי בממוצע של כל הטבלה לפני הפיצול לקבוצות אימון ובדיקה מדליף מידע מנתוני הבדיקה. תראו בשיעורים הבאים איך נמנעים מזה.
> - הסרה שקטה של כל השורות עם חורים: בדקו את `len(df)` לפני ואחרי כדי לדעת מה איבדתם.

> **תורכם:** נקו את הטבלה כמתואר בהערות, ואז הדפיסו את שש השורות שמופיעות בפלט הצפוי.
