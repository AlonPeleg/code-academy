בשיעור הקודם דחפתם נתונים קדימה דרך רשת עם משקלות שנבחרו ביד. רשתות אמיתיות צריכות למצוא את המשקלות בעצמן. השיטה היא **backpropagation**: מחשבים כמה כל משקל אשם בשגיאה, ומזיזים אותו. זו ירידת גרדיאנט (שיעור 20) עבור רשת, ולכן אתם כבר מכירים את הלולאה. החלק החדש הוא חישוב הגרדיאנטים שכבה אחרי שכבה.

## התוכנית

1. **מעבר קדימה:** מחשבים את השכבה החבויה ואת הפלט `p`.
2. **הפסד:** משווים לאמת בעזרת ה-log loss (שיעור 21).
3. **מעבר אחורה:** מחשבים את הגרדיאנט של ההפסד ביחס לכל משקל ולכל הטיה (bias).
4. **עדכון:** `param -= lr * gradient`.
5. חוזרים על זה הרבה פעמים.

## כלל השרשרת במילים פשוטות

אם ההפסד תלוי ב-`p`, ו-`p` תלוי בציון `z2`, ו-`z2` תלוי במשקל `W2`, אז "איך ההפסד מגיב ל-`W2`" הוא המכפלה של שלוש התגובות הקטנות לאורך השרשרת. כלל המכפלה הזה הוא **כלל השרשרת** (chain rule). Backpropagation עושה אותו מהפלט אחורה ומשתמש מחדש בתוצאות קודמות, וזה זול.

דוגמה קטנה עם נוירון אחד: קלט `x = 1`, משקל `w = 0.5`, הטיה 0, תווית אמיתית `y = 1`. הציון הוא `0.5`, ולכן `p = sigmoid(0.5) = 0.62`. עבור סיגמואיד עם log loss החוליה הראשונה בשרשרת קורסת ל-`p - y = -0.38`. הקלט הוא 1, ולכן `dw = (p - y) * x = -0.38`. גרדיאנט שלילי אומר "הגדילו את `w`", וזה אכן מקרב את `p` ל-1.

## ארבע השורות שחשובות

עבור רשת 2-4-1 שלנו עם `n` דגימות:

```python
dz2 = (p - y) / n                          # error at the output
dW2 = hidden.T @ dz2                       # weights output <- hidden
db2 = dz2.sum(axis=0)
dhidden = dz2 @ W2.T                       # push the error back through W2
dz1 = dhidden * hidden * (1 - hidden)      # through the sigmoid
dW1 = X.T @ dz1                            # weights hidden <- input
db1 = dz1.sum(axis=0)
```

קראו אותן כתבנית. בכל שכבה: גרדיאנט המשקלות הוא **הקלט של אותה שכבה, מוחלף (transposed), כפול השגיאה בציון של אותה שכבה** (`hidden.T @ dz2`, `X.T @ dz1`). השגיאה נעה אחורה על ידי כפל במשקלות המוחלפים (`dz2 @ W2.T`) ועוברת דרך הנגזרת של פונקציית ההפעלה. הנגזרת של הסיגמואיד היא `s * (1 - s)` כאשר `s` הוא הפלט של הסיגמואיד: ב-`s = 0.5` היא `0.25`, הנקודה התלולה ביותר, וקרוב ל-0 או ל-1 היא כמעט אפס (הנוירון "רווי" ולומד לאט). חלוקה ב-`n` הופכת את זה לגרדיאנט של ההפסד ה**ממוצע**.

## תמיד בדקו את הגרדיאנטים

באג ב-backprop בדרך כלל לא קורס. הרשת פשוט לומדת גרוע. רשת הביטחון הסטנדרטית היא **בדיקת גרדיאנט** (gradient check): מזיזים משקל אחד למעלה ולמטה ב-`eps` זעיר, רואים איך ההפסד משתנה, ומשווים:

```text
numeric = (loss(w + eps) - loss(w - eps)) / (2 * eps)
```

אם הגרדיאנט האנליטי שלכם מסכים (`np.isclose`), כמעט בטוח שהנוסחאות שלכם נכונות. גרדיאנטים מספריים איטיים מדי לאימון, אבל מושלמים לבדיקות.

## למה משקלות התחלתיים אקראיים?

אנחנו מתחילים עם `rng.normal(...)`: מספרים אקראיים קטנים. אילו כל משקל היה מתחיל שווה, כל הנוירונים החבויים היו מחשבים אותו דבר ומקבלים גרדיאנטים זהים, ולכן היו נשארים שכפולים לנצח. אקראיות שוברת את הסימטריה כדי שהנוירונים יוכלו להתמחות. הטיות יכולות להתחיל ב-0. אנחנו משתמשים ב-seed קבוע כדי שההרצה תחזור בדיוק.

## איך קוראים את הפלט

* `loss before 0.9`: רשת אקראית טועה, וה-log loss גבוה בערך כמו הערך 0.69 של "תמיד אמרו 0.5", או יותר.
* `gradient check: True`: המעבר אחורה שלכם תואם את החשבון הדיפרנציאלי.
* `loss after < 0.01: True` וההסתברויות `[0. 1. 1. 0.]`: הרשת למדה XOR מאפס. המודל בעל הנוירון האחד משיעור 21 לעולם לא יכול לעשות זאת.
* עקומת ההפסד בדרך כלל יורדת לאט בהתחלה (הרשת מחפשת ייצוג חבוי שימושי), אחר כך צונחת מהר, ואז משתטחת.

> **שימו לב:**
> - שכחה של `hidden * (1 - hidden)` ב-`dz1` היא הבאג הקלאסי. ההפסד עדיין יורד קצת, אבל הרשת לומדת גרוע מאוד.
> - `ValueError: operands could not be broadcast together`: הדפיסו את הצורות של `dW1`, `W1` וכן הלאה. לגרדיאנט חייבת להיות בדיוק הצורה של הפרמטר שלו.
> - עדכון המשקלות *במקום* (in place) בזמן שעדיין מחשבים גרדיאנטים אחרים. חשבו קודם את כל הגרדיאנטים, ורק אז עדכנו.
> - קצב למידה גדול מדי גורם להפסד לקפוץ או להפוך ל-`nan`. אם ההפסד עולה, הורידו אותו.
> - אימון XOR עלול לפעמים להיתקע בגלל התחלה אקראית גרועה. seed קבוע ב-`rng` הופך את ההרצה שלכם לניתנת לחזרה, וניסיון של seed אחר הוא תיקון ראשון רגיל.

> **תורכם:** מלאו את המעבר אחורה ב-`gradients`, הריצו את בדיקת הגרדיאנט המספרית על `dW2[0, 0]`, אמנו 5000 epochs תוך רישום ההפסד, הדפיסו את התוצאות וציירו את עקומת ההפסד.
