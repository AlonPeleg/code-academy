דיוק (accuracy), החלק מהחיזויים הנכונים, נשמע כמו הציון המושלם. אבל הוא מסתיר איזה סוג טעויות המודל עושה, ויש טעויות שעולות הרבה יותר מאחרות. בדיקת סרטן שמפספסת גידול גרועה בהרבה מבדיקה שמעלה אזעקת שווא. השיעור הזה נותן לכם את הכלים להסתכל על טעויות כמו שצריך.

## שני סוגי נכון, שני סוגי שגוי

בחרו מחלקה אחת להיות המחלקה ה**חיובית** (positive), בדרך כלל הנדירה או החשובה (כאן: גידול ממאיר). כל חיזוי נופל אז לאחת מארבע תיבות:

| | חזוי חיובי | חזוי שלילי |
|---|---|---|
| **בפועל חיובי** | **חיובי אמיתי (TP)**: נתפס נכון | **שלילי שגוי (FN)**: החמצה |
| **בפועל שלילי** | **חיובי שגוי (FP)**: אזעקת שווא | **שלילי אמיתי (TN)**: נקבע נכון שהוא שלילי |

**מטריצת הבלבול** (confusion matrix) היא טבלת הספירות הזאת:

```python
from sklearn.metrics import confusion_matrix

print(confusion_matrix(y_test, pred))
# [[103   4]      row 0 = actually negative: 103 TN, 4 FP
#  [  4  60]]     row 1 = actually positive:   4 FN, 60 TP
```

ב-scikit-learn השורות הן המחלקות ה**אמיתיות** והעמודות המחלקות ה**חזויות**, מסודרות 0 ואז 1. לכן הפינה השמאלית העליונה היא שליליים אמיתיים והפינה הימנית התחתונה היא חיוביים אמיתיים. למודל טוב יש מספרים גדולים על האלכסון וקטנים מחוצה לו. כאן: 4 גידולים ממאירים הוחמצו (FN) ו-4 מקרים בריאים סומנו (FP).

## Precision ו-recall

שני מספרים מסכמים את המחלקה החיובית:

- **Precision** (דיוק חיובי) = TP / (TP + FP). "מכל מה שהמודל סימן כחיובי, כמה באמת היה?" precision גבוה פירושו מעט אזעקות שווא.
- **Recall** (נקרא גם רגישות, sensitivity) = TP / (TP + FN). "מכל החיוביים האמיתיים, כמה המודל מצא?" recall גבוה פירושו מעט החמצות.

```python
from sklearn.metrics import precision_score, recall_score

precision_score(y_test, pred)    # 60 / (60 + 4) = 0.9375 -> 0.94
recall_score(y_test, pred)       # 60 / (60 + 4) = 0.9375 -> 0.94
```

שתי הפונקציות מקבלות קודם את התוויות האמיתיות. ה**ציון F1** הקשור (`f1_score`) הוא מספר יחיד שמשלב precision ו-recall; הוא גבוה רק כששניהם גבוהים.

## האיזון והסף

מסווג כמו רגרסיה לוגיסטית מוציא בעצם הסתברות, ו-`predict` הופכת אותה למחלקה בעזרת **סף** (threshold) של 0.5: "חיובי אם ההסתברות היא לפחות 0.5". אפשר לבחור סף אחר בעצמכם:

```python
careful = (proba >= 0.2).astype(int)
```

הורדת הסף ל-0.2 פירושה "לסמן גידול גם כשהמודל בטוח רק ב-20 אחוז". תתפסו יותר מקרים אמיתיים (ה-recall עולה ל-0.95, רק 3 החמצות) אבל גם תעלו יותר אזעקות שווא (ה-precision יורד ל-0.82). העלאת הסף עושה את ההפך. precision ו-recall מושכים בכיוונים הפוכים, והיכן לקבוע את האיזון תלוי במחיר של כל טעות: בסינון למחלה חמורה העדיפו recall; למשהו כמו מחיקה אוטומטית של מיילים העדיפו precision.

## למה דיוק משקר

דמיינו שעסקה אחת מכל 100 היא הונאה. מודל שאומר "אף פעם לא הונאה" מדויק ב-99 אחוז ולא תופס כלום: ה-recall שלו להונאה הוא 0. מטריצת הבלבול וה-recall חושפים את זה מיד. תמיד הסתכלו עליהם כשמחלקה אחת נדירה או כשלטעויות יש מחירים שונים.

## המתמטיקה, בקצרה

עם ארבע הספירות: accuracy = (TP + TN) / total, precision = TP / (TP + FP), recall = TP / (TP + FN), ו-F1 = 2 * precision * recall / (precision + recall), הממוצע ההרמוני, שנמשך למטה על ידי הנמוך מבין השניים.

> **שימו לב:**
> - לקרוא את המטריצה הפוך: שורות הן המחלקות ה**אמיתיות**, עמודות הן ה**חיזויים**. בדקו איזו מחלקה היא 1 לפני שאתם מפרשים.
> - להפוך את התוויות. כאן `1` פירושו ממאיר כי בנינו את `y` כך. במערך הנתונים הגולמי של scikit-learn, ממאיר הוא 0, ו-`precision_score` הייתה אז מודדת את המחלקה השפירה אלא אם מעבירים `pos_label=0`.
> - להעביר קודם את החיזויים: `recall_score(pred, y_test)` רצה אבל מחליפה את המשמעות של precision ו-recall.
> - לכוונן את הסף על קבוצת הבדיקה ואז לדווח על ציון הבדיקה. בחרו ספים על נתוני אימות נפרדים כדי להימנע מדליפת נתונים.
> - לשכוח סקיילינג ברגרסיה לוגיסטית: היא עדיין עובדת, אבל צריכה הרבה יותר צעדים ועלולה להדפיס `ConvergenceWarning`.

> **תורכם:** הדפיסו את מטריצת הבלבול, את ה-precision ואת ה-recall של המודל, ואז הורידו את הסף ל-0.2 והדפיסו את ה-recall וה-precision החדשים.
