עכשיו תכירו את הכלי שרוב למידת המכונה (machine learning) בעולם האמיתי בפייתון משתמשת בו: **scikit-learn** (מיובא בשם `sklearn`). היתרון הגדול שלו הוא שכל מודל עובד באותו אופן, ולכן אחרי שמכירים אחד, כמעט מכירים את כולם. מתחילים עם הפשוט ביותר, **רגרסיה ליניארית**.

## רגרסיה והקו הישר

**רגרסיה** (regression) פירושה חיזוי של מספר (מחיר, טמפרטורה, כמות מכירות). **ליניארית** פירושו שהמודל הוא קו ישר. עם מאפיין (feature) אחד זה

```
prediction = coefficient * feature + intercept
```

ה**מקדם** (coefficient) אומר בכמה החיזוי משתנה כשהמאפיין גדל ב-1. ה**חיתוך** (intercept) הוא החיזוי כשהמאפיין שווה 0. עם כמה מאפיינים יש מקדם אחד לכל מאפיין, והחיזוי הוא הסכום של כל החלקים `coefficient * feature` ועוד החיתוך. זה אותו קו ששרטטתם עם `np.polyfit` בשיעור 1, אבל עכשיו בצורה שעובדת עם הרבה מאפיינים.

## התבנית של scikit-learn: ליצור, לאמן, לחזות

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()      # 1. create an untrained model
model.fit(X, y)                 # 2. train: learn from the examples
model.predict(new_X)            # 3. predict for new data
```

כל מה שמסתיים בקו תחתון, כמו `coef_` ו-`intercept_`, הוא משהו שהמודל **למד**. הוא קיים רק אחרי `fit`.

## כללי הצורה

- `X`, המאפיינים, חייב להיות **דו-ממדי**: שורות על עמודות. גם עם מאפיין אחד זו טבלה עם עמודה אחת. עם pandas משתמשים בסוגריים כפולים: `df[["ad_spend"]]`.
- `y`, התווית (label), הוא **חד-ממדי**: עמודה אחת או רשימה: `df["sales"]`.
- גם `predict` רוצה טבלה דו-ממדית עם אותם שמות עמודות, ולכן שורה חדשה אחת היא `pd.DataFrame({"ad_spend": [10]})` (שורה אחת שמכילה מאפיין אחד). עם נתוני NumPy פשוטים `[[10]]` עובד גם כן.

`X` גדולה ו-`y` קטנה היא קונבנציה אוניברסלית: טבלה היא מטריצה (אות גדולה), עמודה היא וקטור (אות קטנה).

## קריאת הפלט

```python
print(model.coef_)        # an array, one number per feature
print(model.intercept_)   # one number
print(model.score(X, y))  # R squared
```

בתרגיל המקדם יוצא בערך 3.00: כל אלף נוסף שמוציאים על פרסום מלווה בכ-300 יחידות נוספות שנמכרות. החיתוך 9.01 הוא מה שהקו חוזה עבור הוצאה אפס.

**R בריבוע** (`score`) אומר כמה מהעליות והירידות של התווית הקו מסביר. 1.0 הוא התאמה מושלמת, 0.0 הוא לא טוב יותר מניחוש תמידי של הממוצע. כאן הוא 0.999, קו כמעט מושלם, כי הנתונים כמעט על קו. שימו לב: הציון הזה חושב על אותם נתונים שהמודל למד מהם, וזה מחמיא לו. השיעורים הבאים מראים איך למדוד ביושר.

## המתמטיקה, בקצרה

האימון מוצא את המקדם והחיתוך שממזערים את סכום ריבועי השגיאות, אותו רעיון של ריבועים פחותים (least squares) משיעור 1. עבור קו ישר יש אפילו נוסחה ישירה, ולכן `fit` מיידי. בהמשך המסלול תמצאו את אותם מספרים צעד אחר צעד בעזרת gradient descent.

> **שימו לב:**
> - העברת רשימה חד-ממדית בתור `X` נותנת `ValueError: Expected 2D array, got 1D array instead`. השתמשו ב-`df[["col"]]` או ב-`.reshape(-1, 1)`.
> - כתיבה של `model.predict(10)` נותנת שגיאה מאותו סוג. עטפו אותו בטבלה עם שורה אחת.
> - אימון על DataFrame וחיזוי עם רשימה חשופה כמו `[[10]]` עובד אבל מדפיס `UserWarning: X does not have valid feature names`. חזו עם DataFrame שיש לו אותם שמות עמודות.
> - קריאת `coef_` לפני `fit` זורקת `AttributeError: 'LinearRegression' object has no attribute 'coef_'`.
> - להאמין לחיזוי רחוק מאוד מהנתונים, כמו לבקש הוצאה על פרסום של 1000. הקו הישר ממשיך גם כשהעולם האמיתי לא.
> - להתייחס לציון R בריבוע של האימון כהוכחה שהמודל טוב. את זה תתקנו בשיעור הבא.

> **תורכם:** אמנו `LinearRegression` על `ad_spend` ו-`sales`, הדפיסו את המקדם, את החיתוך ואת R בריבוע, ואז חזו את המכירות עבור הוצאה על פרסום של 10.
