**גרף** (graph) הוא פשוט דברים והקשרים ביניהם. ערים וכבישים, אנשים וחברויות, דפי אינטרנט וקישורים, משימות והמשימות שהן תלויות בהן. ברגע שאפשר לייצג בעיה כגרף, קבוצה קטנה של אלגוריתמים עונה על שאלות כמו "מה המסלול המהיר ביותר?", "אפשר להגיע מכאן לשם?" ו"מי נמצא במרחק שני קשרים ממני?".

## מילים שצריך להכיר

- **צומת** (node, או vertex) הוא דבר.
- **קשת** (edge) היא קשר בין שני צמתים.
- **שכנים** (neighbours) הם צמתים שמחוברים בקשת.
- **מסלול** (path) הוא רצף של צמתים שבו כל זוג מחובר בקשת.
- בגרף **לא מכוון** (undirected) קשת עובדת בשני הכיוונים (חברות). בגרף **מכוון** (directed) יש לה כיוון (קישור מדף אחד לדף אחר).

```text
    D
    |
    B --- E
    |     |
    A     |
    |     |
    C --- F          G   (not connected to anything)
```

## מילון השכנויות

הדרך הפשוטה ביותר לשמור גרף ב-Python: מילון (dictionary) שממפה כל צומת לרשימת השכנים שלו.

```python
graph = {
    "A": ["B", "C"],
    "B": ["A", "D", "E"],
    "C": ["A", "F"],
    "D": ["B"],
    "E": ["B", "F"],
    "F": ["C", "E"],
}
print(graph["B"])   # prints: ['A', 'D', 'E']
```

מכיוון שהגרף לא מכוון, כל קשת רשומה פעמיים (ל-A יש את B, ול-B יש את A). חיפוש השכנים של צומת הוא חיפוש מהיר אחד במילון.

## חיפוש לרוחב (BFS)

BFS חוקר כמו אדווה במים: קודם צומת ההתחלה, אחר כך כל מה שבמרחק צעד אחד, אחר כך כל מה שבמרחק שני צעדים, וכן הלאה. את הסדר הזה יוצר **תור**: צמתים חדשים הולכים לסוף, ותמיד מטפלים בראש.

```text
start A, goal F
queue: [A]
take A  -> add B, C            queue: [B, C]
take B  -> add D, E            queue: [C, D, E]
take C  -> add F               queue: [D, E, F]
take D  -> nothing new         queue: [E, F]
take E  -> nothing new         queue: [F]
take F  -> it is the goal!   path found: A, C, F  (2 steps)
```

מכיוון ש-BFS מגיע לצמתים לפי סדר המרחק, **הפעם הראשונה** שהוא מגיע ליעד היא לאורך מסלול עם **הכי מעט צעדים**. כך מוצאים "דרגות הפרדה" ומסלולים קצרים בגרפים בלי משקלים.

במקום לזכור איך הגענו לכל צומת, אפשר לשים בתור את המסלול כולו:

```python
queue = deque([[start]])        # a queue of paths
path = queue.popleft()
node = path[-1]                 # the last node of this path
queue.append(path + [neighbour])
```

קבוצת ה-**visited** חיונית. בגרפים יכולים להיות **מעגלים** (A אל B אל E אל F אל C אל A). בלעדיה הייתם מסתובבים לנצח. סמנו צומת כמבוקר ברגע שאתם מוסיפים אותו לתור, כדי שלא ייכנס לתור פעמיים. BFS עולה **O(V + E)**: כל צומת וכל קשת מטופלים בערך פעם אחת.

## חיפוש לעומק (DFS)

DFS מתנהג כמו חקירה של מבוך: בוחרים מסדרון ועוקבים אחריו עד הסוף, ורק כשפוגעים בדרך ללא מוצא חוזרים אחורה ומנסים את הבא. רקורסיה עושה בשבילכם את החזרה אחורה:

```python
def dfs_order(graph, node, visited=None):
    if visited is None:
        visited = []
    visited.append(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs_order(graph, neighbour, visited)
    return visited

print(dfs_order(graph, "A"))   # prints: ['A', 'B', 'D', 'E', 'F', 'C']
```

מ-A הוא הולך ל-B, אחר כך לעומק ל-D (דרך ללא מוצא), חוזר ל-B, ממשיך ל-E, אחר כך ל-F, ואז ל-C. DFS **לא** מוצא מסלולים קצרים, אבל הוא מצוין ל"האם יש מסלול כלשהו?", למציאת קבוצות מחוברות, לזיהוי מעגלים, לפתרון מבוכים ולחקירת כל האפשרויות (backtracking).

| | BFS | DFS |
| --- | --- | --- |
| משתמש ב | תור | מחסנית (או רקורסיה) |
| סדר | הקרוב ראשון | העמוק ראשון |
| מסלול קצר ביותר (בלי משקלים) | כן | לא |

> **שימו לב:**
> - אם שוכחים את קבוצת ה-visited מקבלים לולאה אינסופית בכל גרף שיש בו מעגל.
> - שימוש ב-`visited = []` כארגומנט ברירת מחדל (`def dfs(graph, node, visited=[])`) חולק רשימה אחת בין כל הקריאות. לכן הקוד ההתחלתי משתמש ב-`visited=None`.
> - `graph[node]` גורם ל-`KeyError: 'Z'` עבור צומת שלא נמצא במילון. בדקו שצומת ההתחלה והיעד קיימים.
> - סימון צמתים כמבוקרים כשלוקחים אותם מהתור (במקום כשמוסיפים אותם) עדיין עובד, אבל מכניס כפילויות לתור.
> - צומת בלי שכנים עדיין צריך רשומה, כמו `"G": []`, אחרת חיפושי שכנים גורמים ל-`KeyError`.

## להמשיך הלאה

ספרו את הקבוצות המחוברות של גרף על ידי הרצת חיפוש מכל צומת שעוד לא ביקרתם בו. או הפכו את רעיון המבוך לקוד: רשת של תאים היא גרף שבו לכל תא יש עד ארבעה שכנים.

> **תורכם:** ממשו את `shortest_path` עם BFS (`deque` של מסלולים וקבוצת `visited`) ואת `dfs_order` עם רקורסיה. `shortest_path` מחזירה את המסלול כרשימה, או `None` כשאין מסלול.
