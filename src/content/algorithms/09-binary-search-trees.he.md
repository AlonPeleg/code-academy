רשימות ושרשרות הן **ליניאריות**: פריט אחרי פריט. הרבה דברים בעולם האמיתי הם דווקא **היררכיות**: תיקיות בתוך תיקיות, עץ משפחה, המבנה של דף אינטרנט, האפשרויות במשחק. מבנה הנתונים לזה הוא **העץ** (tree). בשיעור הזה תבנו את הסוג המפורסם ביותר, **עץ חיפוש בינארי** (binary search tree, או BST), ותשתמשו עליו ברקורסיה.

## אוצר מילים של עצים

עץ בנוי מ**צמתים** (nodes) שמחוברים בקישורים. הצומת העליון הוא ה**שורש** (root). הקישורים של צומת מצביעים על ה**ילדים** שלו. צומת בלי ילדים הוא **עלה** (leaf). ה**גובה** (height) הוא מספר הרמות מהשורש ועד העלה העמוק ביותר. בעץ **בינארי** לכל צומת יש לכל היותר שני ילדים, שנקראים `left` ו-`right`.

```text
          50          <- root
        /    \
      30      70
     /  \    /  \
    20  40  60  80    <- leaves
```

## הכלל של עץ חיפוש

עץ חיפוש בינארי מוסיף כלל אחד שהופך אותו לחזק: **לכל צומת, כל מה שבתת-העץ השמאלי שלו קטן יותר, וכל מה שבתת-העץ הימני שלו גדול יותר.** בעץ שלמעלה, 30 משמאל ל-50, וכל מה שמתחת ל-70 גדול מ-50.

זה חיפוש בינארי שהפך למבנה נתונים. כדי למצוא את 60: מתחילים ב-50, 60 גדול יותר ולכן הולכים ימינה. ב-70, 60 קטן יותר ולכן הולכים שמאלה. מצאנו. ביקרנו בשלושה צמתים במקום שבעה. בעץ **מאוזן** סביר, חיפוש, הכנסה ומחיקה הם כולם **O(log n)**.

## רקורסיה מתאימה לעצים בצורה מושלמת

כל ילד הוא בעצמו שורש של עץ קטן יותר. לכן פונקציה על עץ יכולה לטפל ב"צומת הזה" ואז לקרוא לעצמה על הילד השמאלי והימני. מקרה הבסיס הוא תמיד העץ הריק: `None`.

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

**הכנסה** יורדת כמו חיפוש ומחברת עלה חדש במקום שבו החיפוש נגמר:

```python
def insert(node, value):
    if node is None:                         # found the empty spot
        return Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    elif value > node.value:
        node.right = insert(node.right, value)
    return node                              # unchanged tree (or equal value ignored)
```

שימו לב לתבנית `node.left = insert(node.left, value)`: הקריאה הרקורסיבית מחזירה את השורש (שאולי חדש) של תת-העץ הזה, ואנחנו שומרים אותו בחזרה. כשהמקום ריק, `insert` מחזירה צומת חדש לגמרי, וככה בדיוק העץ גדל.

**חיפוש** הוא אותה הליכה בלי שינויים:

```python
def search(node, value):
    if node is None:
        return False
    if value == node.value:
        return True
    if value < node.value:
        return search(node.left, value)
    return search(node.right, value)
```

## סריקה: ביקור בכל צומת

כדי לבקר בכל הצמתים יש כמה סדרים. המועיל ביותר ל-BST הוא **בסדר תוכני** (in-order): תת-העץ השמאלי, אחר כך הצומת, ואז תת-העץ הימני.

```python
def in_order(node):
    if node is None:
        return []
    return in_order(node.left) + [node.value] + in_order(node.right)
```

עבור העץ שלמעלה זה נותן `[20, 30, 40, 50, 60, 70, 80]`: **ממוין**. BST ממיין את הנתונים שלו כתוצר לוואי של המבנה. (סריקה בסדר מקדים, pre-order, שמבקרת קודם בצומת, היא הדרך להעתיק עץ. סריקה בסדר מאוחר, post-order, שמבקרת בצומת אחרון, היא הדרך למחוק עץ.)

## החולשה: איזון

הכניסו את הערכים `1, 2, 3, 4, 5` בסדר הזה לעץ ריק. כל ערך גדול מכל מי שלפניו, ולכן כל אחד הולך ימינה:

```text
1
 \
  2
   \
    3
     \
      4
       \
        5
```

העץ הוא פשוט רשימה מקושרת, הגובה שלו הוא `n`, וכל פעולה הופכת ל-**O(n)**. לכן מבנים תעשייתיים כמו עצי AVL, עצים אדומים-שחורים ועצי B **מאזנים** את עצמם מחדש. המילון של Python בכלל לא משתמש בעץ (הוא משתמש בטבלת גיבוב), אבל מסדי נתונים משתמשים בעצי B בכל מקום כדי למצוא שורות מהר.

> **שימו לב:**
> - אם שוכחים **להחזיר** (return) מהקריאות הרקורסיביות (`search(node.left, value)` בלי `return`), הפונקציה מחזירה `None`.
> - כתיבה של `insert(node.left, value)` בלי להציב אותה בחזרה מאבדת את הצומת החדש. צריך `node.left = insert(...)`.
> - אם שוכחים את מקרה הבסיס `node is None`, מקבלים `AttributeError: 'NoneType' object has no attribute 'value'`.
> - עץ עמוק מאוד שנבנה מנתונים ממוינים עושה רקורסיה אחת לכל רמה ויכול להגיע ל-`RecursionError: maximum recursion depth exceeded`.
> - BST צריך ערכים שאפשר להשוות. ערבוב של מספרים ומחרוזות גורם ל-`TypeError: '<' not supported between instances of 'str' and 'int'`.

## להמשיך הלאה

הוסיפו `minimum(node)` (ממשיכים שמאלה) ו-`maximum(node)`. אחר כך נסו את `count_leaves`. מחיקת צומת מ-BST היא התרגיל הקשה המפורסם, כי צומת עם שני ילדים צריך תחליף: היורש שלו בסדר תוכני.

> **תורכם:** ממשו ברקורסיה את `insert`, `search`, `in_order` ו-`height`. הבדיקה בונה עץ, בודקת שהסריקה ממוינת, ומראה איך קלט ממוין הופך את העץ למוטה (גובה 5).
