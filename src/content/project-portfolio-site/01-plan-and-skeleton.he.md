ברוכים הבאים לפרויקט הגדול האחרון באקדמיה: אתר אישי אמיתי שאפשר להעלות לאינטרנט בחינם ולשלוח למעסיקים. במהלך עשרה שלבים תבנו ארבעה עמודים (בית, פרויקטים, אודות ויצירת קשר), תעצבו אותם עם Bootstrap 5.3 ועם גיליון סגנונות משלכם, תוסיפו מעט JavaScript, תהפכו את האתר לנגיש ותסיימו ברשימת בדיקה לפני פרסום. בכל שלב מקבלים את הקוד המוגמר של השלב הקודם, ועוד כמה הערות `TODO`. שום דבר לא מוסתר.

## איפה אנחנו עומדים

אנחנו בתחילת הדרך ממש. דף הבית כמעט ריק. בסוף השלב הזה הוא יטען את Bootstrap מהאינטרנט, יטען את גיליון הסגנונות והסקריפט שלכם, ויציג כותרת. זה נשמע קטן, אבל כל שלב מאוחר יותר נשען על זה.

## מה נוסיף, ולמה זה חשוב

לתיק עבודות (portfolio) יש משימה אחת: להראות מי אתם, מה בניתם ואיך אפשר ליצור איתכם קשר. ארבעה עמודים מספיקים, וכל אחד מקבל קובץ משלו:

| קובץ | למה הוא משמש |
|---|---|
| `index.html` | בית: אזור פתיחה, כישורים, פרויקטים נבחרים, קריאה לפעולה |
| `projects.html` | כל הפרויקטים, עם כפתורי סינון |
| `about.html` | הסיפור שלכם, ציר זמן והכישורים שלכם |
| `contact.html` | טופס יצירת קשר ודרכים נוספות להגיע אליכם |
| `404.html` | העמוד לכתובת שגויה (מסיימים בשלב 10) |
| `css/style.css` | הסגנונות שלכם, נטענים אחרי Bootstrap |
| `js/main.js` | סקריפטים קטנים המשותפים לכל עמוד |

התיקיות `css/` ו-`js/` שומרות על האתר מסודר. העמודים שאחרי דף הבית כבר קיימים כמקומות שמורים זעירים, כך שקישורים אף פעם לא מובילים לשום מקום. תחליפו אותם אחד אחד.

**למה Bootstrap ו-CSS משלכם?** Bootstrap נותן לכם רשת (grid), סרגל ניווט, כרטיסים ועיצוב לטפסים שנבדקו וכבר עובדים בטלפונים. הקובץ שלכם נותן לאתר אישיות. בעבודות אמיתיות תראו לא פעם בדיוק את השילוב הזה, ולכן כדאי להציג אותו.

## מדריך צעד אחר צעד

**1. טוענים את ה-CSS של Bootstrap.** CDN (רשת להפצת תוכן) הוא שרת ציבורי מהיר שמארח ספריות פופולריות. שורה אחת ב-head מספיקה:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
```

**2. טוענים את ה-CSS שלכם שני.** כששני כללים ספציפיים באותה מידה, זה שבא מאוחר יותר מנצח. לכן הקובץ שלכם בא אחרי Bootstrap:

```html
<link rel="stylesheet" href="css/style.css">
```

הנתיב הוא *יחסי*: הוא מתחיל מהתיקייה של הדף. זה מה שגורם לאתר להמשיך לעבוד כשמעבירים אותו לאחסון אינטרנט.

**3. מוסיפים את הסקריפטים בסוף ה-body.** החבילה של Bootstrap מפעילה דברים כמו תפריט המובייל (היא מכילה גם את Popper, שממקם חלונות קופצים). ה-`main.js` שלכם בא אחריה:

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

**4. שמים תוכן אמיתי בתוך `main`.** `container` ממרכז את התוכן ונותן לו רוחב מרבי סביר. `py-5` פירושו ריווח פנימי למעלה ולמטה, שלב 5 בסולם הריווחים של Bootstrap (3rem, כלומר 48px):

```html
<div class="container py-5">
  <h1>Alex Rivers</h1>
  <p class="lead">Junior web developer.</p>
</div>
```

**5. מגדירים את אסימוני העיצוב (design tokens) שלכם.** פתחו את `css/style.css`. כלל על `:root` (הדף כולו) יכול להחזיק *תכונות מותאמות* (custom properties): שמות שמתחילים ב-`--` ומחזיקים ערך שמשתמשים בו שוב ושוב. בשלבים מאוחרים יותר כותבים `var(--brand)` במקום לחזור על קוד הקסדצימלי.

```css
:root {
  --brand: #4f46e5;
  --radius: 1rem;
}
```

> **שימו לב:**
> - אם גיליון הסגנונות שלכם בא **לפני** Bootstrap, Bootstrap עוקף את הכללים שלכם ונדמה שכלום לא עובד.
> - התצוגה המקדימה מזהה את התגים של Bootstrap רק בצורה המדויקת שמוצגת למעלה. שגיאת כתיב בכתובת משאירה את הדף בלי עיצוב, ובקונסולת הדפדפן מופיע `Failed to load resource`.
> - נתיב כמו `/css/style.css` (עם לוכסן בתחילתו) מצביע על שורש השרת כולו ונשבר באתרי פרויקט ב-GitHub Pages. השתמשו ב-`css/style.css`.
> - שמות של תכונות מותאמות רגישים לאותיות גדולות וקטנות: `--Brand` ו-`--brand` הם שני שמות שונים.

> **תורכם:** עקבו אחרי ארבע הערות ה-`TODO` ב-`index.html`, ואחר כך אחרי ה-`TODO` ב-`css/style.css`. דף הבית צריך את גיליון הסגנונות של Bootstrap, אחריו `css/style.css`, אלמנט `main` עם `div.container` שמכיל `h1` שאומר "Alex Rivers" ו-`p.lead`, ואת שני הסקריפטים בסוף ה-body. ב-CSS, הגדירו את `--brand`, `--brand-dark`, `--brand-text`, `--brand-soft`, `--accent`, `--accent-soft` ו-`--radius` על `:root`.
