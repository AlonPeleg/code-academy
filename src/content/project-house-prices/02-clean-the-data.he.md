נתונים אמיתיים מבולגנים: ערכים חסרים, מישהו הקליד אפס מיותר, שורה הודבקה פעמיים. אם מזינים את זה ישר למודל, המודל לומד בנאמנות את הבלגן. השלב הזה הופך את הטבלה הגולמית לטבלה נקייה.

## איפה אנחנו עומדים

שלב 1 טוען את הטבלה עם `df = make_data()`. הסיכום שלה הראה שני סימני אזהרה: ב-`age_years` יש פחות ערכים ממספר השורות, וה-`area_m2` הגדול ביותר הוא 1450. שימו לב שמעכשיו אנחנו מוותרים על ההדפסות של השלב הקודם: קוד ההתחלה שומר רק את הקוד ששינה את הנתונים, כדי שהפלט יישאר קצר.

## מה נוסיף

בלוק ניקוי שמוצא שלושה סוגי בעיות ומתקן כל אחת:

* **ערכים חסרים** (`NaN`, "לא מספר"): התא פשוט ריק. רוב המודלים קורסים בגללם.
* **חריג** (outlier): ערך כל כך קיצוני שהוא כמעט בוודאות טעות. מודל שמשקיע מאמץ להתאים אליו מתעוות.
* **כפילויות** (duplicates): אותה שורה פעמיים. הן סופרות את הבית פעמיים, ובהמשך עלולות "לדלוף" בין נתוני האימון לנתוני הבדיקה.

כל החלטת ניקוי היא שיקול דעת, ולכן תמיד **מדפיסים לפני ואחרי** כדי לראות מה עשינו.

## מדריך צעד אחר צעד

**1. ספרו את הערכים החסרים.** `isna()` יוצרת טבלה של True/False ("האם התא הזה חסר?"). `sum()` מחברת את ה-True, לכל עמודה:

```python
print(df.isna().sum())               # one count per column
print(int(df.isna().sum().sum()))    # the grand total: second sum() adds the column totals
```

**2. כפילויות וחריגים.** `df.duplicated()` מסמנת כל שורה שחוזרת על שורה קודמת. עבור החריג, השתמשו בהשוואה כדי ליצור True/False וספרו את ה-True:

```python
print(df.duplicated().sum())
print((df["area_m2"] > 400).sum())
```

למה 400? טבלת describe הראתה שטחים טיפוסיים של 35 עד 200, ולכן 400 נדיב ו-1450 הוא בבירור שגיאת הקלדה (כנראה 145). אנחנו לא יכולים לדעת מה הערך האמיתי, ולכן מסירים את השורה ולא מנחשים.

**3. תקנו אותם.** הסדר חשוב קצת: קודם עותקים, אחר כך החריג, ואחר כך החורים (את החציון צריך לחשב מהשורות שנשארות).

```python
df = df.drop_duplicates()
df = df[df["area_m2"] <= 400]      # a filter: keep only the rows where the test is True
```

אפשר להסיר ערכים חסרים (`dropna()`) או **למלא** אותם (imputation). הסרה הייתה מבזבזת שורות שלמות בגלל גיל חסר אחד, ולכן ממלאים ב**חציון**, הערך האמצעי. לולאה חוסכת חזרות:

```python
for col in ["age_years", "distance_to_center_km"]:
    df[col] = df[col].fillna(df[col].median())
```

לבסוף `df = df.reset_index(drop=True)` ממספרת מחדש את השורות 0, 1, 2, ... כי השורות שהוסרו השאירו חורים בתוויות השורות.

**4. בדקו.** הדפיסו את ה-shape החדש (אמור להיות 4 שורות פחות מקודם), את סך החסרים (0) ואת השטח הגדול ביותר החדש.

> **שימו לב:**
> - `df["age_years"].fillna(...)` לבדה לא משנה כלום: pandas מחזירה עמודה חדשה. תמיד שמרו אותה בחזרה עם `df[col] = ...`.
> - אל תכתבו `df[col].fillna(x, inplace=True)`. ב-pandas העדכנית הצורה השרשורית הזו לא משנה את `df` ומציגה אזהרה (`ChainedAssignmentError`).
> - `df.isna().sum()` מסתיימת בשורת סיום `dtype: int64` כשמדפיסים אותה; זה תקין.
> - מילוי בחציון של כל הטבלה "מציץ" מעט בשורות שיהיו בהמשך בקבוצת הבדיקה. זה קיצור דרך קטן ונפוץ בפרויקט ראשון. בייצור היו שמים `SimpleImputer` בתוך הצינור (pipeline); שלב 5 מראה את הרעיון של צינורות.

> **תורכם:** הדפיסו `missing cells:` (הסכום כמספר שלם), את מספר החסרים בכל עמודה, `duplicate rows:` ו-`areas above 400:`. אחר כך הסירו את הכפילויות, הסירו את השורות עם שטח מעל 400, מלאו את שני החורים בחציונים ואפסו את האינדקס. לבסוף הדפיסו `shape after:`, `missing after:`, `area max after:` ו-`age median:`.
